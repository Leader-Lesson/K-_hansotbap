# 시연용 작업계획서 (합성 데이터)

`app/samples/make_samples.py` 가 만드는 복사본입니다. 손으로 고치지 말고 스크립트를 다시 돌리세요.
여기 파일은 화면에서 **올리고 제출해야만** 일정에 들어갑니다. 시연 전후에는 `npm run seed` 로 시작 상태(충돌 0건)로 되돌립니다.

## 순서

1. `npm run seed` → 화면 충돌 0건 확인 (기준 일정은 업체가 오전·오후로 이어받게 짜여 있다. 예: 12-10 노저)
2. 오른쪽 위 **보는 사람**을 파일의 업체로 바꾼다
3. `1_적용_안겹침/` 파일 1건을 올려 제출 → 새 충돌 0건 (바뀐 게 없으면 조용하다)
4. `2_충돌_겹침/S1_…` 을 올려 제출 → 순서 위반 금지 → 원청 화면에서 조정안 적용 → 재판정 → 해소
5. 끝나면 `npm run seed`
