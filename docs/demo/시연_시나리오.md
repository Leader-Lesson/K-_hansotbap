# 시연 시나리오 — 협력사별로 올릴 파일 (합성 데이터)

시작 상태는 항상 `npm run seed` 입니다. 축로I·기계J 두 계획서가 승인된 상태로 들어갑니다.
파일은 모두 `app/samples/` 에 있습니다. 올리기 전에 오른쪽 위 **보는 사람**을 그 파일의 업체로 바꿉니다.

## 먼저 알아 둘 것: 기준 일정만으로도 충돌이 108건입니다

- 판정 대상은 원청 기준 일정 37개(`app/backend/data/gy2bf_wbs.csv`, 협력사 15곳 작업 전부) 위에 각 협력사의 최근 제출분을 덮은 일정입니다
- 아무것도 올리지 않아도 기준 일정 자체에서 **108건(금지 51 · 조건부 57)** 이 나옵니다. 계획서를 올릴 때 화면에 충돌이 많이 보이는 이유가 이것입니다
- S2(기계J × 축로I)·S3(양중C × 주상K)·S7(철구B × 비계)은 이 108건 안에 **이미 들어 있습니다**. 그래서 파일을 올려서 "새로 생기게" 보여 줄 수 없습니다
- 기준 일정과 같은 계획서(주상K·철구B·출선D·해체G·내화H·양중C·축로I)는 올려도 **새 충돌이 0건**입니다. 올리는 것은 문제없고 해당 업체 제출 이력만 하나 늘어납니다
