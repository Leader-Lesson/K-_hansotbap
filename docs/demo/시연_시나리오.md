# 시연 시나리오 — 협력사별로 올릴 파일 (합성 데이터)

시작은 항상 `npm run seed` 입니다(축로I·기계J 계획서가 승인된 상태). 올리기 전에 오른쪽 위 **보는 사람**을 그 파일의 업체로 바꿉니다.

## 기준 일정은 충돌 0건입니다

- 원청 기준 일정은 **주간 작업만**, 작업마다 하루 작업시간(오전 07~12 · 오후 13~18 · 하루 07~18)을 정해 **서로 이어받게** 짜 두었습니다
- 예) 노저 12-08~12-23: 내화H 천공 07~12 → 내화H 발파 12~13(전원 대피) → 해체G 파쇄물 반출 13~17
- 그래서 시드 직후 충돌은 0건이고, **협력사가 계획을 바꿔 낸 순간에만** 빨간색이 생깁니다

## 안 겹치는 파일 — `app/samples/` 15건

기준 일정과 같은 날짜·시간입니다. 몇 개를 어떤 순서로 올려도 새 충돌이 없습니다. (배관O 만 절차에 '작업 전 가스 측정'이 없어 표준서 **결함** 2건 — F8 장면)
