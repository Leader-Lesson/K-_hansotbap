# 한솥밥 프로토타입 (현장 상황판 시안)

개수공사 동시작업 간섭 감지 · 팀 세이프루프(SafeLoop)
POSCO K-뉴딜 아카데미 해커톤 (2026-11-09 ~ 11-10)

화면 시안과 시연 흐름을 확인하기 위한 **정적 웹 프로토타입**입니다. 빌드 과정 없이 `index.html`을 브라우저로 열면 동작합니다. 모든 데이터는 합성 데이터이고 협력사명은 가상입니다.

> 실제 서비스는 기획서의 React + Vite + TypeScript 프런트와 FastAPI 백엔드로 만듭니다. 이 폴더는 그 화면과 흐름의 기준이 되는 시안입니다.

## 실행

레포 루트에서:

```bash
npm run dev
```

브라우저가 `http://localhost:5173/prototype/index.html`(이 시안)로 자동으로 열립니다. 팀 React 앱은 그대로 `http://localhost:5173/`에 있습니다.

- **3D · 충돌 탭**은 같은 출처의 `/scene3d/index.html`(`app/frontend/public/scene3d`)을 iframe으로 넣고 `postMessage`로 데이터를 넘깁니다. 그래서 `npm run dev`(또는 `npm run build` 뒤 `vite preview`)로 열어야 동작합니다. `index.html` 파일을 직접 열면 3D 탭에 안내만 뜹니다.
- 인터넷 연결이 필요합니다. 웹폰트(Google Fonts)를 CDN에서 불러옵니다. 3D(scene3d)는 `vendor/`에 three.js를 포함하고 있어 인터넷이 없어도 됩니다.

## 화면

| 탭 | 내용 |
| --- | --- |
| 현재 상황판 | 시안4 시간표형 (07:00–19:00, 30분 칸). 위험 시간대 띠(F9), 구역별 업체 막대, 지금 선, 겹침 띠, 조치 카드, 착수 승인 대기, 안전 작업 가이드 |
| 3D · 충돌 | **scene3d**(팀 3D 화면) 하나만 사용: 시안의 날짜·작업·충돌·역할(직영관리자/파트장/작업자)을 넘기고, 시연 7번·충돌 상세의 "3D로 보기"는 해당 작업을 선택합니다. 2D 도면·시간·작업자·위험/안전 영역은 scene3d 안에서 봅니다 |
| TBM 확인 | M1 큰 체크리스트. 공유된 충돌·조정, 위험 시간대, 작업표준서 항목을 팀장 발언과 대조 |
| 이력 | 제64조 이행 기록 (반려·조정·전체 알림·착수 승인·TBM 등), 계획서 버전, 공유 현황, CSV 복사 |

모든 화면 공통 요소:

- **계획서 올리기** (상단 파란 버튼): 구글 드라이브형 팝업, 올린 파일 목록, 제출 이력(v1 → v2 반려 → v3), 추출 표(F1), 작업표준서 매칭(F8)
- **AI 챗봇** (우측 하단): 음성(누르고 말하기) + 글자 입력, 권한 범위 안에서 답변(F6)
- **알림 센터** (상단 종): 전체 알림, 착수 보류, 승인, 반려
- **긴급·변수 등록** (시간표 위): 긴급 작업 / 작업 지연 / 현장 변수(강풍·가스 농도)

## 시연 순서 (상단 "시연" 띠)

1. 계획서 5건 올리기
2. 오늘 겹침 보기 (D65 · 2027.01.15 10:30)
3. C사 변경본 도착 (질소 라인 연결 2/24 → 1/15, 새 충돌 4건)
4. 포스코 본청 반려
5. C사 수정본 재제출 (충돌 4건 해소)
6. C사 화면 (권한 적용)
7. 3D에서 겹침 보기
8. 챗봇 음성 질문
9. TBM 전달 확인 (녹음 B: 일부 누락)
10. 작업 지연 → 전체 알림
11. 긴급 작업 → 착수 승인

## scene3d 연동 (assets/js/app.js `s3Payload`·`s3Sync`)

| 방향 | 메시지 | 내용 |
| --- | --- | --- |
| 시안 → scene3d | `data` | 그날 작업(`src/types.ts`의 `Task` 모양, `crew` 추가)과 충돌(`Conflict` 모양). 협력사로 보면 권한 범위 안의 작업만 |
| 시안 → scene3d | `role` | `{kind:"prime"}` 또는 `{kind:"contractor", contractor:"가상-C사", level:"lead"\|"worker"}` |
| 시안 → scene3d | `time` · `selectTask` | 2D 도면 시각 · 시연/충돌 상세에서 고른 작업 |
| scene3d → 시안 | `ready` · `select` · `decision` | 준비 완료 시 데이터 전송, 선택한 작업의 충돌 포커스, 승인·반려는 이력에 기록 |

구역 매핑: 노정→`TOP`, 노 내부 상부·중부→`STACK`, 노 내부 하부→`BELLY_BOSH`, 풍구 층→`TUYERE`, 노 내부 바닥→`HEARTH`, 외부 작업대→`SHELL`, 주상→`CASTHOUSE`, 열풍로→`STOVE`

## 시연판에서 흉내만 낸 부분

- 음성 인식(Whisper), 챗봇 질문 이해, TBM 전달 판단은 예시 문장과 패턴으로 동작합니다. 화면에 "AI 문장", "AI 판단"으로 표시했습니다.
- 계획서 파싱은 하지 않습니다. 업로드한 파일은 목록에만 보관하고, 구조화 결과는 합성 데이터입니다.
- 시각은 시연 시각(10:30)으로 고정입니다. 지연은 자동 감지하지 않고 사람이 보고합니다.
- 상태는 브라우저 메모리에만 있어 새로고침하면 처음으로 돌아갑니다.
