# SOP-04 가스 배관 연결·기밀시험 작업표준 — 합성

- 출처: KOSHA GUIDE P-35-2012(화기작업 시 가스농도 측정), 산업안전보건기준에 관한 규칙 제619조·제241조 를 바탕으로 해커톤 시연용으로 합성한 문서. 실제 사업장 표준서가 아니다.
- 적용 작업 유형: `gas`
- 적용 작업 예(기준 일정): P05 가스 계통 차단·퍼지, P10 하강관 가스 배관 보수, P34 질소·가스·송풍 라인 복구 연결, P35 기밀시험·퍼지
- 문서번호 SOP-04 · 개정 1 · 제정(가정) 2026-11-09 · 관리 부서: 원청 안전환경팀(가상) · 적용 현장: 광양 2고로 2차 개수(합성)

## 1. 목적과 적용 범위

- 목적: 고로가스(BFG, CO 포함)·질소·송풍·열풍 계통의 배관을 끊고, 막고, 다시 잇고, 가스를 살리는 작업에서 잔류 가스 폭발·CO 중독과, 계통 안에 사람이 남은 채 질소·가스가 들어가는 질식 사고를 막는다.
- 적용 범위: 가스 계통 차단·퍼지(P05), 가스 배관 절단·보수(P10), 라인 복구 연결(P34), 승온·기밀시험·퍼지(P35)와, 그 밖에 가스 배관 플랜지를 열거나 맹판을 넣고 빼는 모든 작업. 작업별 표준서(SOP-P04·P05·P06·P09·P10·P25·P34·P35·P36·P37)가 이 표준서를 공통 단계로 끌어다 쓴다.
- 적용 제외: 연결부 용접의 화기 관리는 SOP-01, 계통 안에서 하는 내부 작업은 SOP-02 를 따른다. 원청 조업 절차(종풍·화입)는 원청 절차서가 우선하고 이 표준서는 협력사와 겹치는 구간에만 쓴다.

## 2. 작업 개요 (적용 작업 유형·적용 작업 예)

- 적용 작업 유형: 가스계통(`gas`) — 계획서 위험 유형에 가스계통이 있거나 작업명에 연결·기밀·퍼지·복구·투입·승온 낱말이 있을 때
- 적용 작업 예(기준 일정): P05, P10, P34, P35
- 구역: DOWNCOMER(상승관·하강관), GCP(제진기), TUYERE(환상관·송풍지관), STOVE(열풍로), TOP(노정 블리더). 연결 대상 계통이 노 내부로 이어지면 HEARTH·TUYERE·BELLY_BOSH·STACK 전체가 "같은 계통"이다
- 위험 분류 코드(시행령 제53조의2): 1호 화재·폭발, 8호 질식·중독
- 필요 허가: 화기·가스(연결부 용접이 있으면 화기 허가를 함께)
- 겹치면 안 되는 작업: 같은 계통·11m 안 화기(R04), 계통 안 밀폐공간 작업(R07·R08), 풍하측 일반 작업(R10 조건부), 개구부 주변 작업 중 질소 퍼지(R09)

## 3. 위험 요인과 예상 사고

- 폭발·화재: 플랜지를 열 때 남은 고로가스가 새어 나와 11m 안 용접 불티·그라인더에 닿는다. LEL 10% 이상이면 작업 자체를 멈춘다(KOSHA P-35).
- CO 중독: 고로가스의 CO가 풍하측 작업자에게 닿는다. 냄새가 없어 경보기 없이는 모른다. CO 30ppm 미만이 기준이다.
- 질식: 연결 대상 계통(노 내부·열풍로·제진기) 안에 축조·보수 인원이 남아 있는데 라인을 살리면 질소가 들어가 전원이 쓰러진다(현대제철 2013 공개 사례). 맹판 없이 밸브만 닫힌 상태는 차단이 아니다.
- 압력: 기밀시험 중 과압으로 가스켓·맹판이 튀어나온다. 압력을 빼기 전 볼트를 푸는 사고.
- 끼임·낙하: 대구경 플랜지 정렬 중 손 끼임, 높은 배관에서 볼트·공구가 아래층으로 떨어진다.

## 4. 투입 인원과 역할 (기준 최소 5명 역할, 계획서 인원과 맞춘다)

- 작업책임자 1명: 화기·가스 허가 발급, LOTO 번호·맹판 위치 관리, 연결 대상 계통의 내부 작업 완료 서명 수령(5단계), 원청 설비 담당과 연결 시점 협의
- 가스측정 담당 1명(작업책임자 겸임 가능): 작업 전·2시간마다·용접 재개 때 LEL·O2·CO 측정, 기록
- 화재감시자 1명(연결부 용접 시): 용접 중 상주, 종료 후 30분 감시
- 배관공 2명 이상: 플랜지 면 청소, 가스켓·볼트 체결, 맹판 설치·제거, 기밀시험 가압
- 용접사(연결부 용접 시): 자격 보유

## 5. 투입 장비·자재·보호구

- 장비: 복합 가스측정기(LEL·O2·CO) 2대, 용접기, 질소 가압 장비(레귤레이터·압력계), 토크렌치, 체인블록(플랜지 정렬), 고소작업대 또는 비계(높은 배관), 환기팬(개방 구간)
- 자재: 맹판(블라인드 플랜지)·꼬리표, 가스켓(규격별), 볼트·너트, LOTO 잠금장치·꼬리표, 비눗물·누설 검지기, 불티비산방지포, 파이프 랙
- 보호구: 안전모·안전화·보안경, 휴대용 CO 경보기(전원), 송기마스크 또는 공기호흡기(대피용), 용접 보안면·방열 장갑, 안전대(고소)

## 6. 작업 순서 (상세)

1. 작업허가서(화기·가스) 발급 — 작업책임자가 원청 안전환경팀에서 가스 허가(연결부 용접이 있으면 화기 허가도)를 받는다. 허가서에 배관 계통·플랜지 번호, 시간, 감시자 이름, 연결 대상 계통과 그 안의 다른 작업(P20·P21·P22·P26·P27 등)을 적고 허가 번호를 서로 기재한다(R29). 확인: 허가서 번호 기록.
2. 상류 차단밸브 잠금·LOTO — 가스·질소·송풍 상류 밸브를 닫고 잠금장치·꼬리표를 건다. 잠금 번호를 허가서와 작업일지에 적는다. P06 에너지 격리 목록과 대조한다. 확인: 잠금 사진 1장, LOTO 번호 기록.
3. 맹판(블라인드) 설치 확인 — 밸브만 닫힌 상태를 차단으로 보지 않는다. 상류 쪽 플랜지에 맹판이 들어 있는지 눈으로 확인하고 꼬리표를 건다. 맹판은 8단계 전까지 빼지 않는다. 확인: 맹판 위치·수량 기록.
4. 작업 전 가스 측정(LEL 10% 미만·O2 18~23.5%) — 개방·연결할 플랜지 양쪽 배관 안과 작업 위치 호흡 높이에서 LEL·O2·CO를 잰다. LEL 10% 이상이거나 O2가 범위 밖이거나 CO 30ppm 이상이면 멈추고 퍼지·환기 뒤 다시 잰다. 2시간마다, 용접 재개 때마다 다시 잰다. 확인: 측정값·시각·측정자를 허가서에 기록.
5. 연결 대상 계통 내부 작업 완료·인원 철수 확인 — 연결하면 가스·질소가 닿는 모든 공간(노 내부 HEARTH·TUYERE·BELLY_BOSH·STACK, 열풍로, 제진기)의 작업 협력사 작업책임자에게 "작업 완료·인원 철수 확인" 서명을 받는다(SOP-02 8단계). 출입자 명부가 0명인지 확인한다. 서명이 없으면 연결을 시작하지 않는다(R07·R08). 확인: 인계 서명지 보관.
6. 연결 작업(볼트 체결·용접) — 플랜지 면 청소, 가스켓 교체, 대각선 순서 토크 체결. 용접은 자격자가 하고 SOP-01 에 따라 화재감시자·불티비산방지포를 둔다. 확인: 토크 값·용접사 이름 기록.
7. 기밀시험(질소 가압·누설 확인) — 원청 설비 담당이 정한 시험 압력으로 질소를 넣고 비눗물·검지기로 플랜지·용접부 누설을 확인한다. 누설이 있으면 압력을 완전히 뺀 뒤 6단계로 돌아간다. 가압 중 플랜지 정면에 서지 않는다. 확인: 시험 압력·유지 시간·결과 기록.
8. 맹판 제거·LOTO 해제 기록 — 기밀시험 합격 뒤 맹판을 빼고 잠금을 푼다. 해제는 그 계통에 걸린 모든 관련 허가가 반납된 뒤에만 한다(R23). 푼 시각·사람을 기록한다. 확인: 해제 기록.
9. 허가서 반납 — 용접이 있었으면 30분 화재감시를 마친 뒤 허가서를 반납한다. 연결 완료·가스 투입 예정 시각을 원청 안전환경팀과 그 계통 주변 협력사에 알린다. 확인: 반납·통보 기록.

## 필수 단계

1. 작업허가서(화기·가스) 발급
2. 상류 차단밸브 잠금·LOTO
3. 맹판(블라인드) 설치 확인
4. 작업 전 가스 측정(LEL 10% 미만·O2 18~23.5%)
5. 연결 대상 계통 내부 작업 완료·인원 철수 확인
6. 연결 작업(볼트 체결·용접)
7. 기밀시험(질소 가압·누설 확인)
8. 맹판 제거·LOTO 해제 기록
9. 허가서 반납

## 판정에 쓰는 기준

- 계획서 절차에 4·5 단계가 없으면 F8 "필수 단계 누락" → F2 결함. 시연 샘플 `가상-배관O_가스라인_복구_작업계획서.hwpx` 의 절차가 이 경우다(가스 측정·맹판 확인·내부 작업 완료 확인 없음)
- 핵심 단계를 4·5로 고른 이유: 둘 다 빠지면 바로 사망사고로 이어지는 단계다. 4(가스 측정)는 잔류 고로가스 폭발·CO 중독을 막는 유일한 수치 확인이고, 5(내부 작업 완료·인원 철수 확인)는 연결 순간 질소가 들어갈 공간에 사람이 없음을 보장하는 마지막 확인이다(규칙 619조②4호, 현대제철 2013). 1·2·3·6·7·8·9는 빠져도 허가 발급·LOTO 절차·기밀시험 결과에서 다시 걸리거나 사고가 즉시 나지 않는다.
- 연결 대상 계통의 밀폐공간 작업이 끝나기 전에 시작하면 R08(순서 위반, 금지)·R07(금지)
- 같은 구역에 화기작업이 겹치면 R04(금지)

## 작업 금지·출입 제한

- 연결 대상 계통 내부(노 내부·열풍로·제진기) 작업 완료·퇴출 확인 서명 전 연결·가스 투입 착수 금지(R07·R08)
- 플랜지 개방·연결 중 같은 계통과 반경 11m 안 타 업체 화기 금지(R04)
- 가스 배관 개방 중 풍하측 일반 작업은 휴대용 CO 경보기·측정 기록 없이 금지(R10)
- 질소 퍼지 중 개구부·맨홀 반경 [팀 설정값 5m] 안 작업 금지(R09)
- 맹판 제거·LOTO 해제는 관련 허가 전부 반납 전 금지(R23)

## 3D 연결 (출입 제한 데이터)

- 구역: 적용 작업의 구역ID(DOWNCOMER·GCP·TUYERE·STOVE·TOP 중 계획서 구역). 연결 대상 계통이 노 내부로 이어지면 HEARTH·TUYERE·BELLY_BOSH·STACK 전체가 계통 제한 대상
- 제한 1: 구역 = 작업 구역, 방위 SAME, 종류 HOT_WORK_BAN, 대상 OTHERS, 적용 시점 DURING, 범위 반경 11m(규칙 241조의2) + 같은 계통 전체, 규칙 R04, 3D 표시 TAPE + SIGN「가스 배관 개방·연결 중 · 화기 금지」
- 제한 2: 구역 = 연결 대상 계통 전체(노 내부면 HEARTH·TUYERE·BELLY_BOSH·STACK, 열풍로면 STOVE, 제진기면 GCP·DOWNCOMER), 방위 ALL, 종류 GAS_IN_BAN(착수 조건), 대상 OTHERS(계통 내부 작업 P20·P21·P22·P26·P27 등), 적용 시점 UNTIL_HANDOVER(내부 작업 완료·퇴출 확인 서명 전까지), 범위 계통 전체, 규칙 R08·R07, 3D 표시 BAR_RED(이 연결 작업 막대 금지색) — 시연 S1
- 제한 3: 구역 = 작업 구역의 풍하측 인접 구역, 방위 풍하 방위, 종류 ENTRY_BAN(CO 경보기 없는 인원), 대상 OTHERS, 적용 시점 STEP:6(개방·연결 중), 범위 [팀 설정값], 규칙 R10, 3D 표시 CONE + SIGN「CO 경보기 착용」

## 비상 조치

- 가스 경보(CO 30ppm·LEL 10% 이상): 즉시 작업 중지, 점화원 제거, 풍하측 반대 방향으로 대피, 작업책임자가 원청 상황실에 보고, 재측정 정상 뒤 재개
- 화재: 소화기 초기 진화, 진화 안 되면 대피·원청 소방 연락, 상류 밸브 잠금 유지 확인
- 계통 안 인원 쓰러짐(질식 의심): 가압·투입 즉시 중단, 구조자는 공기호흡기 착용 뒤 진입, 맨몸 진입 금지, 119·원청 구급 연락
- 기밀시험 중 누설·파열음: 가압 중단·압력 배출, 플랜지 정면 접근 금지, 압력 0 확인 뒤 점검

## 기록·보관

- 허가서, 가스 측정 기록, LOTO·맹판 기록, 내부 작업 완료·인원 철수 인계 서명지(5단계), 기밀시험 기록을 원청 안전환경팀이 공사 종료 후 3년 보관(가정)
- 인계 서명지는 R08 순서 판정의 근거 문서로 F5 이력에 남긴다. 이 기록이 산업안전보건법 제64조(혼재작업 조정)·제65조(안전·보건 정보 제공) 이행 기록이 된다
