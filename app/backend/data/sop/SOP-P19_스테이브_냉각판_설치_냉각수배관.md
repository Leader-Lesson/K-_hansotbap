# SOP-P19 스테이브·냉각판 설치와 냉각수 배관 연결 작업표준 — 합성

- 출처: KOSHA GUIDE·산업안전보건기준에 관한 규칙을 바탕으로 해커톤 시연용으로 합성한 문서. 실제 사업장 표준서가 아니며 협력사명은 가상이다.
- 적용 작업: P19 스테이브·냉각판 설치와 냉각수 배관 연결 (기준 일정 작업 하나에만 적용하는 작업별 표준서)
- 문서번호 SOP-P19 · 개정 1 · 제정(가정) 2026-11-09 · 관리 부서: 원청 안전환경팀(가상) · 적용 현장: 광양 2고로 2차 개수(합성)

## 1. 목적과 적용 범위

- 목적: 신 철피 안쪽에 스테이브(냉각반)·냉각판을 단수별로 걸고 철피 밖에서 냉각수 배관을 연결하는 작업에서, 노 내부 밀폐공간 질식, 달비계 추락, 스테이브 인양 중 낙하, 배관 용접 불티 화재, 연결 전 가압에 따른 고압수 분출을 막는다.
- 적용 범위: 스테이브·냉각판 노내 호이스트 인양과 철피 볼트 체결, 냉각수 입·출측 배관 연결 용접, 배관 가볼트 체결, 설치 완료 검사와 압력시험(P33) 인계까지.
- 적용 제외: 철피 본체 용접·비파괴검사(P18, SOP-P18), 압력시험·플러싱 자체(P33, SOP-P33), 노내 호이스트 설치·운영(P31, SOP-P31).

## 2. 작업 개요

- 작업ID: P19
- 협력사(가상): 가상-기계E · 공종: 기계+배관
- 구역: BELLY_BOSH 노복·조안(belly/bosh) — 단수가 올라가며 STACK 하부까지, 배관 연결은 SHELL 철피 외부
- 기준 일정(가정값): 2027-01-06 ~ 2027-02-05 (D55~D85)
- 위험 작업 유형: 화기, 밀폐공간, 고소, 중량물
- 위험 분류 코드(시행령 제53조의2): 4호 추락, 5호 낙하·비래
- 필요 허가: 화기,밀폐공간,고소
- 선행 작업: P18 (철피 용접·비파괴검사)

## 3. 위험 요인과 예상 사고

- 낙하·비래: 스테이브 한 장은 수 톤의 주철·동 주물이다. 노내 호이스트로 올리다 줄걸이가 풀리면 아래 TUYERE·HEARTH 작업자가 맞는다. 철피 볼트·너트·공구 낙하도 같은 경로다.
- 추락: 달비계에서 스테이브 뒷면 체결 중 안전대 미체결, 철피 개구부(맨홀·풍구 구멍) 쪽으로 넘어짐.
- 질식·중독: 노 내부는 하나의 수직 공동이다. 용접 흄·보호가스(CO2)가 고이고, 환기가 끊기면 산소가 준다.
- 화재·폭발: 철피 외부 배관 용접 불티가 아래 비계 발판·보온재·주상 가연물로 떨어진다.
- 고압수 분출: 배관 연결이 끝나지 않은 상태에서 냉각수가 가압되면 플랜지·호스가 튄다.

## 4. 투입 인원과 역할 (기준 18명, 계획서 인원과 맞춘다)

- 작업책임자 1명: 허가서 3종 발급, 단계별 확인 서명, 호이스트 운영사(가상-양중C)·축조 협력사와 인양 시간 협의
- 안전관리자 1명: 산소·가스 측정, 출입자 명부, 환기팬 가동 확인
- 감시인 2명: 노내 출입구(풍구 레벨 맨홀) 상주, 출입 기록, 비상 연락
- 화재감시자 1명: 배관 용접 중 상주, 종료 후 30분 감시, 소화기 관리
- 신호수 2명: 스테이브 인양 신호, 인양 경로 하부 출입 통제
- 기계 설치공 7명: 스테이브·냉각판 위치 맞춤, 철피 볼트 체결, 달비계 운용
- 배관공 2명: 냉각수 배관 맞대기·플랜지 체결
- 용접사 2명: 배관 연결부 용접(자격 보유)

## 5. 투입 장비·자재·보호구

- 장비: 노내 호이스트(P31 가상-양중C 운영), 체인블록 2t 4대, 달비계 2조, 용접기 2대, 환기팬 2대(송기 덕트), 산소·유해가스 복합측정기 2대(연속 측정 1대 고정), 토크렌치, 작업등
- 구조장비: 공기호흡기 2조, 삼각대·구조용 윈치 1조, 들것
- 자재: 스테이브·냉각판, 철피 체결 볼트·너트·와셔, 냉각수 배관·플랜지·가스켓(파이프 랙), 불티비산방지포
- 보호구: 안전모·안전화·보안경, 안전대(2중 걸이), 용접 보안면·방열 장갑, 방진마스크, 휴대용 산소 경보기(작업반장)

## 6. 작업 순서 (상세)

1. 작업허가서(화기·밀폐·고소) 발급 — 작업책임자가 원청 안전환경팀에서 세 허가를 한 번에 받고 허가서 번호를 서로 적어 둔다(상호참조, R29). 작업 단수·높이, 인원, 감시인, 용접 위치를 적고 노내 출입구에 게시한다. 확인: 허가서 번호 3개를 작업일지에 기록.
2. 작업 전 산소·가스 측정 후 진입 (노 내부) — 진입 전 노 내부 상·중·하 3곳에서 O2 18~23.5%, CO 30ppm 미만, LEL 10% 미만을 확인한다. 작업 중 고정 측정기로 연속 측정하고 1일 2회 이상 기록한다. 범위를 벗어나면 전원 퇴출. 확인: 측정값·시각·측정자 기록.
3. 감시인 배치·출입자 명부 기록 — 감시인 2명이 풍구 레벨 맨홀에 상주하며 들어가고 나오는 사람을 명부에 적는다. 감시인은 다른 일을 겸하지 않는다. 확인: 명부와 공기호흡기·삼각대 점검표.
4. 스테이브 인양 신호수 지정·호이스트 하부 출입 통제 — 인양 전 스테이브 중량·줄걸이 용구를 점검하고 신호수 2명과 신호 방법을 정한다. 인양 경로 아래 TUYERE·HEARTH에 사람이 없게 막고, 인양 시간대를 그 구역 협력사(가상-축로I 등)와 미리 맞춘다. 확인: 인양 시간대를 작업일지에 기록.
5. 화재감시자 배치 (배관 용접) — 철피 외부 배관 용접 전 반경 11m 안 가연물을 치우거나 방화포로 덮고, 불티 낙하 구간(아래 비계·주상) 출입을 막는다. 소화기 2대를 손 닿는 곳에 둔다. 확인: 감시자 이름을 화기 허가서에 기재.
6. 달비계·안전대 체결 확인 — 달비계 승강 전 와이어·훅·과부하 방지장치를 점검하고, 작업자는 안전대를 독립 구명줄에 건다. 철피 개구부에는 덮개 또는 난간을 둔다. 확인: 체결 상태를 작업반장이 눈으로 확인 뒤 작업 개시.
7. 냉각수 배관 연결 후 가압 전 인원 철수 확인 — 배관 연결 구간을 모두 마친 뒤 플랜지·호스 주변에 사람이 없음을 확인하고, 압력시험(P33, 가상-배관O)은 이 확인 서명 뒤에만 시작한다. 연결이 남은 배관이 있으면 가압하지 않는다(R08). 확인: 연결 완료·철수 서명지.
8. 설치 완료 검사 (압력시험 P33 인계) — 스테이브 위치·볼트 토크·배관 누락 여부를 검사하고 결과를 P33 협력사와 원청 설비 담당에게 넘긴다. 허가서 3종을 반납한다. 확인: 검사표·인계 서명.

## 적용하는 공통 표준서

- SOP-01 화기작업
- SOP-02 밀폐공간 출입작업
- SOP-03 중량물 인양(크레인)
- 고소 작업은 공통 표준서 없음 — 규칙 제42조~제45조(추락 방지) 적용

## 필수 단계

1. 작업허가서(화기·밀폐·고소) 발급
2. 작업 전 산소·가스 측정 후 진입 (노 내부)
3. 감시인 배치·출입자 명부 기록
4. 스테이브 인양 신호수 지정·호이스트 하부 출입 통제
5. 화재감시자 배치 (배관 용접)
6. 달비계·안전대 체결 확인
7. 냉각수 배관 연결 후 가압 전 인원 철수 확인
8. 설치 완료 검사 (압력시험 P33 인계)

## 판정에 쓰는 기준

- 계획서 절차에 2·4·7 단계가 없으면 F8 "필수 단계 누락" → F2 결함.
- 핵심 단계를 2·4·7로 고른 이유: 빠지면 바로 사망사고로 이어지는 세 가지를 하나씩 막는다. 2(산소·가스 측정)는 노 내부 질식, 4(인양 하부 통제)는 수 톤 스테이브 낙하, 7(가압 전 철수)은 미연결 배관 고압수 분출을 막는 마지막 확인이다. 1·3·5·6·8은 빠져도 공통 표준서 SOP-01·02·03이나 상대 작업(P31·P33) 표준서에서 다시 걸린다.
- 인양 아래 TUYERE·HEARTH 작업은 R16·R18
- 노 내부 용접은 R05(조건부), 연결 완료 전 가압(P33)은 R08(금지, 순서)

## 작업 금지·출입 제한

- 스테이브 인양 중 BELLY_BOSH 아래 TUYERE·HEARTH 진입 금지(R18)
- 노 내부 용접 중 같은 공간 타 업체 출입 통제(R05)
- 배관 연결 완료·철수 서명 전 냉각수 계통 가압(P33) 금지(R08)
- 철피 외부 배관 용접 중 불티 낙하 구간(아래 비계·CASTHOUSE) 출입 통제(R03)

## 비상 조치

- 산소·가스 경보: 전원 즉시 퇴출, 감시인이 명부로 인원 확인, 원청 상황실 보고, 원인 제거·재측정 정상 뒤 재진입
- 인양물 낙하·추락자 발생: 호이스트 정지, 하부 출입 전면 차단, 구조자는 공기호흡기·삼각대 사용, 맨몸 진입 금지, 119·원청 구급 연락
- 화재: 소화기 초기 진화, 진화 안 되면 대피·원청 소방 연락, 용접기 전원 차단
- 냉각수 분출: 상류 밸브 잠금, 분출 구간 접근 금지, 노 내부 침수 여부 확인 뒤 재개

## 기록·보관

- 허가서 3종, 산소·가스 측정 기록, 출입자 명부, 인양 시간대 기록, 연결 완료·철수 서명지(7단계), 설치 검사표를 원청 안전환경팀이 공사 종료 후 3년 보관(가정)
- 연결 완료·철수 서명지는 P33 착수 조건의 근거 문서로 F5 이력에 남긴다
