# SOP-P18 철피 용접·비파괴검사(UT/RT) 작업표준 — 합성

- 출처: KOSHA GUIDE·산업안전보건기준에 관한 규칙을 바탕으로 해커톤 시연용으로 합성한 문서. 실제 사업장 표준서가 아니며 협력사명은 가상이다.
- 적용 작업: P18 철피 용접·비파괴검사(UT/RT) (기준 일정 작업 하나에만 적용하는 작업별 표준서)
- 문서번호 SOP-P18 · 개정 1 · 제정(가정) 2026-11-09 · 관리 부서: 원청 안전환경팀(가상) · 적용 현장: 광양 2고로 2차 개수(합성)

## 1. 목적과 적용 범위

- 목적: 노체 위에 얹은 링블록 사이 둘레 이음부를 높은 곳에서 용접하고 UT·RT로 검사하는 보름 동안, 용접 불티가 아래 비계·주상으로 떨어지는 화재, 비계 위 용접 추락, RT 방사선 피폭을 막고, 철피 외부 비계(P30)와 위아래로 겹치는 상황(시연 S7)을 시간으로 나눈다.
- 적용 범위: 화기·고소 허가, 가스 측정, 화재감시·불티비산방지 덮개, 고소 발판·안전대, 용접 중 하부 통제, RT 관리구역·경보·야간 분리, 30분 감시, 검사 기록·반납까지. 철피 외부(SHELL) 둘레 이음부를 단마다 돌아가며 한다.
- 적용 제외: 링블록 안착·가볼트(P17, SOP-P17), 비계 설치·해체 자체(P30, SOP-P30), 스테이브·냉각판 설치(P19)는 별도 표준서를 따른다.

## 2. 작업 개요

- 작업ID: P18
- 협력사(가상): 가상-철구B · 공종: 용접+비파괴검사
- 구역: SHELL 노체 철피 외부
- 기준 일정(가정값): 2027-01-01 ~ 2027-01-16 (D50~D65)
- 위험 작업 유형: 화기, 고소
- 위험 분류 코드(시행령 제53조의2): 1호 화재·폭발, 4호 추락, 기타(방사선·고온수증기·고압수)
- 필요 허가: 화기,고소,방사선
- 선행 작업: P17

## 3. 위험 요인과 예상 사고

- 화재·낙하 불티: 철피 외부 높은 곳의 용접 불티가 아래 비계 발판(목재·방수포)과 주상(P24 자재)으로 떨어진다. 높이 20m·풍속 4~5m/s 에서 풍하 8m 까지 날린다(규칙 241조의2①2호, R03). 아래에서 비계를 해체(P30)하고 있으면 불티와 낙하물이 겹친다(R17, 시연 S7).
- 추락: 철피 외부 비계·달비계에서 안전대 없이 용접하거나 발판 사이 틈·개구부로 떨어진다. 겨울철 결빙 발판.
- 방사선: RT 촬영 중 관리구역 안에 다른 업체 작업자(P30 비계·P24 주상·P23 노정)가 들어온다. 야간·휴무 시간대로 나누지 않으면 노체 주변 넉넉한 통제가 어렵다(R24).
- 감전·흄: 젖은 비계 위 용접기 홀더 접촉, 좁은 이음부 안쪽 용접 흄.
- 폭발: 철피 안쪽 공간(노 내부)에 가연성 가스가 남아 있을 가능성 — 측정 없이 용접 금지.

## 4. 투입 인원과 역할 (기준 12명, 계획서 인원과 맞춘다)

- 작업책임자 1명: 화기·고소·방사선 허가, 용접 순서·RT 시간대 관리, P30 비계 일정 조정
- 화재감시자 2명: 용접 단마다 상주, 아래층 불티 확인, 종료 후 30분 감시
- 가스 측정 담당 1명(작업책임자 겸임 가능): 철피 안팎 LEL 측정
- 용접사 5명: 둘레 이음부 용접(자격 보유), 예열·층간 온도 관리
- 하부 통제원 1명: 비계 하단·주상 출입 통제
- 비파괴검사원 2명(UT·RT 자격 보유): 검사, RT 관리구역 설정·경보·퇴출 확인

## 5. 투입 장비·자재·보호구

- 장비: 용접기 다수(인버터), 비계·달비계(철피 외부, P30 설치), 고소작업대, 복합 가스측정기(LEL·O2·CO), 예열 장비, UT 검사 장비·RT 장비(선원·경보기·선량계 — 3D 모델 없음, 원문 이름 유지), 풍속계·풍향계, 조명탑(야간 RT 시)
- 자재: 불티비산방지 덮개·방화포(비계 발판·주상 위), 소화기 2대 이상(단마다), 방사선 관리구역 로프·표지·경보기, 출입 통제 안전띠·표지, 케이블 릴(용접 케이블 정리)
- 보호구: 안전모·안전화·보안경, 안전대(2중 걸이), 용접 보안면·방열 장갑·앞치마, 방진·방독 마스크(흄), 절연 장갑(젖은 환경), 개인 선량계(RT 검사원)

## 6. 작업 순서 (상세)

1. 작업허가서(화기·고소) 발급 — 작업책임자가 날마다 용접 단·방위·시간과 RT 예정 시간대를 적어 화기·고소 허가(RT 날은 방사선 허가도)를 받고 번호를 서로 기재한다(R29). 아래 비계(P30)·주상(P24) 일정을 확인해 겹치면 시간을 나눈다. 확인: 허가서 번호·인접 일정 확인 기록.
2. 작업 전 가스 측정 (LEL 10% 미만) — 이음부 철피 안쪽(노 내부 쪽)과 작업 위치에서 LEL을 재고 2시간마다 다시 잰다. 확인: 측정값·시각 기록.
3. 화재감시자 배치·불티비산방지 덮개 설치 (하부 비계·주상) — 용접 단 아래 비계 발판과 주상 쪽에 방지 덮개·방화포를 깔고 가연물(목재 발판·방수포·자재)을 치운다. 감시자를 단마다 두고 소화기 2대를 둔다. 풍하측 8m 까지 본다. 확인: 덮개 설치 사진·감시자 서명.
4. 고소 용접 발판·안전대 체결 확인 — 비계 발판·난간·발끝막이판을 점검하고(결빙 제거) 용접사가 안전대를 걸었는지 반장이 눈으로 확인한다. 확인: 반장 확인 서명.
5. 용접 중 하부 출입 통제 — 용접 단 바로 아래 비계 하단·주상 구간에 안전띠를 치고 통제원이 막는다. 아래에서 비계 해체(P30)는 용접 시간대에 하지 않는다(R03·R17, 시연 S7). 확인: 용접 시간대·통제 기록.
6. RT 촬영 방사선 관리구역 설정·경보·야간 시간대 분리 — RT는 야간·휴무 시간대로 잡고 관리구역 [팀 설정값] 경계에 로프·표지·경보기를 두며 노체 주변 전원 퇴출을 확인한 뒤 촬영한다(R24). UT는 주간에 할 수 있다. 확인: 촬영 시간·경계·퇴출 확인 기록.
7. 작업 종료 후 30분 화재감시 — 감시자가 30분 동안 비계 발판·주상 아래 불티를 확인한다. 확인: 감시 종료 시각.
8. 검사 결과 기록·허가서 반납 — UT·RT 결과(합격·보수 위치)를 기록하고 보수 용접은 다음 날 허가에 넣는다. 허가서를 반납한다. 전 이음부 합격이 나오면 스테이브 설치(P19)·냉각수 배관 협력사와 원청에 인계한다. 확인: 검사 기록·반납 시각.

## 적용하는 공통 표준서

- SOP-01 화기작업
- 고소 작업은 공통 표준서 없음 — 규칙 제42조~제45조(추락 방지) 적용

## 필수 단계

1. 작업허가서(화기·고소) 발급
2. 작업 전 가스 측정 (LEL 10% 미만)
3. 화재감시자 배치·불티비산방지 덮개 설치 (하부 비계·주상)
4. 고소 용접 발판·안전대 체결 확인
5. 용접 중 하부 출입 통제
6. RT 촬영 방사선 관리구역 설정·경보·야간 시간대 분리
7. 작업 종료 후 30분 화재감시
8. 검사 결과 기록·허가서 반납

## 판정에 쓰는 기준

- 계획서 절차에 3·5·6 단계가 없으면 F8 "필수 단계 누락" → F2 결함.
- 핵심 단계를 3·5·6으로 고른 이유: 철피 용접에서 다치는 사람은 대부분 아래·옆의 다른 업체다. 3(화재감시자·불티비산방지 덮개)은 불티가 아래 비계·주상으로 떨어지는 화재를, 5(용접 중 하부 출입 통제)는 그 아래에 사람이 없게 하며(시연 S7, 비계 P30), 6(RT 관리구역·야간 분리)은 보이지 않는 방사선 피폭을 막는다. 셋 다 원청이 계획서에서 확인하지 않으면 옆 업체가 알 길이 없다. 2·4·7은 SOP-01·추락 규칙에서 다시 걸린다.
- 용접 아래 비계 해체(P30)가 있으면 R03(조건부)·R17(금지) — 시연 S7
- RT 촬영 시간 관리구역 안 작업은 R24(금지)

## 작업 금지·출입 제한

- 용접 중 SHELL 하부 CASTHOUSE·비계 하단 출입 통제(R03)
- RT 촬영 시간 방사선 관리구역 내 전 구역 출입 금지(R24)
- 용접 시간대 같은 방위 철피 외부 비계 해체(P30) 금지(R17)
- P17 가볼트 체결 확인 전 본용접 착수 금지
- 용접 종료 후 30분 동안 같은 구역 가연물 반입·무감시 금지(R25)

## 3D 연결 (출입 제한 데이터)

- 구역: SHELL(노체 철피 외부). 용접은 단·방위 순서로 돌아가므로 방위는 계획서의 이음부 단·방위(SAME, `level`에 "상부"가 있으면 3D 상부 작업대). 낙하 영향은 같은 방위 비계 하단과 CASTHOUSE
- 제한 1: 구역 SHELL(비계 하단)·CASTHOUSE, 방위 SAME(용접 단 직하), 종류 ENTRY_BAN, 대상 OTHERS(P30·P24 등), 적용 시점 STEP:5(용접 중, 계획서 BAND 우선), 범위 직하 + 풍하 8m [KOSHA 불티비산표], 규칙 R03, 3D 표시 CONE + SIGN「상부 용접 중 · 불티 낙하」— 시연 S7
- 제한 2: 구역 SHELL, 방위 SAME, 종류 WORK_STOP(비계 해체 금지), 대상 P30, 적용 시점 DURING(용접 시간대), 범위 같은 방위 비계, 규칙 R17, 3D 표시 BANNER「용접 중 · 비계 해체 보류」
- 제한 3: 구역 SHELL·CASTHOUSE·TOP·TUYERE(노체 주변), 방위 ALL, 종류 ENTRY_BAN, 대상 OTHERS(전원), 적용 시점 BAND:22:00-05:00(RT 촬영 시간대, 계획서 시간대를 따른다), 범위 방사선 관리구역 [팀 설정값], 규칙 R24, 3D 표시 TAPE + SIGN「RT 촬영 중 · 출입 금지」
- 제한 4: 구역 SHELL, 방위 SAME, 종류 ENTRY_BAN(가연물 반입 금지), 대상 OTHERS, 적용 시점 STEP:7(종료 후 30분), 범위 반경 11m, 규칙 R25, 3D 표시 SIGN「화재감시 중 30분」
- 착수 조건: 구역 SHELL, 종류 WORK_STOP(이 작업 자체), 대상 P18, 적용 시점 UNTIL_HANDOVER(P17 7단계 가볼트 체결 확인 전까지), 규칙 R08, 3D 표시 BAR_RED(P18 작업 막대 금지색)

## 비상 조치

- 발화(비계 발판·주상): 감시자 초기 진화, 용접기 전원 차단, 1분 안 진화 안 되면 대피·원청 소방 연락, 아래층 작업자 대피 확인
- 추락·매달림: 고소작업대로 접근 구조, 119·원청 구급 연락
- 방사선 사고(선원 미복귀·경계 침입): 검사원이 즉시 촬영 중단·선원 회수, 침입자 선량 기록, 원청 안전환경팀·방사선 안전관리자 보고
- 감전: 용접기 전원 차단 뒤 구조, 맨손 접촉 금지, 원청 구급 연락
- 가스 경보(철피 안쪽 LEL 10% 이상): 용접 중단, 점화원 제거, 노 내부 환기·재측정 정상 뒤 재개

## 기록·보관

- 허가서(화기·고소·방사선 상호참조), 가스 측정 기록, 덮개 설치 사진·감시자 서명, 안전대 확인 서명, 용접 시간대·하부 통제 기록, RT 관리구역·퇴출 확인·촬영 기록, 30분 감시 기록, UT·RT 검사 기록을 원청 안전환경팀이 공사 종료 후 3년 보관(가정)
- 용접 시간대 기록은 비계(P30)와의 시간 분리(R03·R17, 시연 S7) 근거로, 검사 합격 기록은 P19 착수 조건으로 F5 이력에 남긴다
