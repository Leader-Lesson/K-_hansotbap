# SOP-P23 노정 장입설비(벨리스 탑) 설치 작업표준 — 합성

- 출처: KOSHA GUIDE·산업안전보건기준에 관한 규칙을 바탕으로 해커톤 시연용으로 합성한 문서. 실제 사업장 표준서가 아니며 협력사명은 가상이다.
- 적용 작업: P23 노정 장입설비(벨리스 탑) 설치 (기준 일정 작업 하나에만 적용하는 작업별 표준서)
- 문서번호 SOP-P23 · 개정 1 · 제정(가정) 2026-11-09 · 관리 부서: 원청 안전환경팀(가상) · 적용 현장: 광양 2고로 2차 개수(합성)

## 1. 목적과 적용 범위

- 목적: 노정 플랫폼에서 벨리스 탑·호퍼·슈트 같은 장입설비를 크레인으로 올려 조립·용접하는 고소·중량물 작업에서, 노정 개구부 추락, 인양물·공구가 노 내부 수직 공동으로 떨어지는 낙하, 용접 불티 화재, 구동부 시운전 중 끼임을 막는다.
- 적용 범위: 장입설비 부품 크롤러 크레인 인양·노정 안착, 볼트 체결·연결부 용접, 구동부(회전 슈트·게이트) 시운전, 완료 인계까지.
- 적용 제외: 구 장입설비 해체(P09, SOP-P09), 노정 레이더·계장(P29, SOP-P29), 노 내부 축조(P20·P22).

## 2. 작업 개요

- 작업ID: P23
- 협력사(가상): 가상-기계J · 공종: 기계(장비 제작사)
- 구역: TOP 노정 플랫폼(장입설비) — 노 내부 수직 공동의 최상단, 인양은 CRANE_PAD 크레인
- 기준 일정(가정값): 2027-01-06 ~ 2027-02-20 (D55~D100)
- 위험 작업 유형: 화기, 고소, 중량물
- 위험 분류 코드(시행령 제53조의2): 4호 추락, 5호 낙하·비래
- 필요 허가: 화기,고소,중장비
- 선행 작업: P17 (신 철피 링블록 반입·설치)

## 3. 위험 요인과 예상 사고

- 낙하·비래: 노정 개구부는 노 내부 수직 공동의 입구다. 볼트·공구·용접봉 하나가 HEARTH 노저 축조(P20)·STACK 노흉 축조(P22) 작업자 머리 위로 수십 m 떨어진다. 인양 중 부품 줄걸이 이탈도 같은 경로다(시연 S2).
- 추락: 노정 개구부·장입설비 상부에서 안전대 미체결, 덮개 없는 개구부로 떨어짐.
- 화재·폭발: 연결부 용접 불티가 노정 플랫폼 아래 비계·보온재, 노 내부로 떨어진다.
- 끼임: 구동부(회전 슈트·게이트) 시운전 중 조정 인원이 설비 안에 남아 있다.
- 충돌·전도: 크롤러 크레인 붐이 다른 크레인(P17 대형 크레인)·노정 구조물과 닿는다. 풍속 10m/s 이상에서 인양.

## 4. 투입 인원과 역할 (기준 12명, 계획서 인원과 맞춘다)

- 작업책임자 1명: 허가서 3종 발급, 노 내부 작업 업체와 인양 시간 협의 기록, 시운전 전 철수 확인
- 안전관리자(겸 화재감시자) 1명: 용접 중 상주, 종료 후 30분 감시, 개구부 덮개·난간 점검
- 신호수 2명: 크레인 인양 신호(노정 1·지상 1), 인양 경로 하부 출입 통제
- 크레인 운전원 1명: 크롤러 크레인 운전(자격 보유)
- 기계 설치공 5명: 부품 위치 맞춤, 볼트 체결, 구동부 조정
- 용접사 2명: 연결부 용접(자격 보유)

## 5. 투입 장비·자재·보호구

- 장비: 크롤러 크레인 1대(정격은 계획서 기재), 노정 호이스트 1대, 체인블록 5t 4대, 용접기 2대, 고소작업대 1대, 풍속계, 토크렌치, 조명탑(야간)
- 자재: 장입설비 부품(벨리스 탑 본체·호퍼·회전 슈트·게이트), 볼트·너트, 개구부 덮개·난간재, 불티비산방지포, 소화기 2대
- 보호구: 안전모·안전화·보안경, 안전대(2중 걸이), 용접 보안면·방열 장갑, 무전기

## 6. 작업 순서 (상세)

1. 작업허가서(화기·고소·중장비) 발급 — 작업책임자가 세 허가를 한 번에 받고 번호를 서로 적는다(R29). 허가서에 인양 부품·중량·크레인 정격, 용접 위치, 인양 시간대를 적고 노정 입구에 게시한다. 확인: 허가서 번호 3개 기록.
2. 신호수 배치·인양 경로 하부 출입 통제 — 인양 전 신호수 2명과 무전 신호를 통일한다. 인양 경로 아래(CRANE_PAD~TOP, 노 내부 수직선)에 사람이 없게 막고, 노 내부(P20·P22)와 주상(P24)에 인양 시작·종료를 알린다. 풍속 10m/s 이상이면 인양하지 않는다. 확인: 인양 시간대·풍속 기록.
3. 노정 개구부 덮개·난간 확인 (추락 방지) — 작업 전 노정 개구부에 덮개 또는 안전난간이 있는지 확인한다. 부품 안착 때문에 덮개를 떼면 그 시간 동안 개구부 주변 작업자는 안전대를 걸고, 떼어 둔 개구부 아래 노 내부 진입을 막는다. 확인: 개구부 점검표.
4. 안전대 체결 확인 (노정 고소) — 장입설비 상부·플랫폼 가장자리 작업자는 안전대를 부착설비에 건다. 고소작업대는 아웃트리거를 펴고 난간 안에서 작업한다. 확인: 체결 상태를 작업반장이 눈으로 확인 뒤 개시.
5. 화재감시자 배치·소화기 비치 (용접) — 용접 전 반경 11m 안 가연물을 치우거나 방화포로 덮고, 노정 개구부를 방화포로 막아 불티가 노 내부로 떨어지지 않게 한다. 소화기 2대를 손 닿는 곳에 둔다. 확인: 감시자 이름을 허가서에 기재.
6. 노 내부(노저·노흉) 작업 업체와 인양 시간 협의 기록 — 매일 아침 노저 축조(가상-축로I P20)·노흉 축조(P22)·호이스트(가상-양중C P31) 책임자와 인양 시간대를 맞추고, 그 시간에는 노 내부 작업을 멈추거나 방호선반 아래로 들어가게 한다(R16). 확인: 협의 결과를 작업일지에 서명.
7. 구동부 시운전 전 인원 철수 확인·LOTO 해제 — 시운전 전 설비 안·회전 반경에 사람이 없음을 확인하고, 관련 허가서가 모두 반납된 뒤에만 LOTO를 푼다(R22·R23). 시운전 중 접근 금지 표지를 세운다. 확인: 철수 확인·LOTO 해제 시각·사람 기록.
8. 종료 후 30분 화재감시·허가서 반납 — 용접 종료 후 30분 화재감시를 마치고 허가서 3종을 반납한다. 설치 완료를 원청 설비 담당과 계장 협력사(가상-전기M P29)에게 알린다.

## 적용하는 공통 표준서

- SOP-01 화기작업
- SOP-03 중량물 인양(크레인)
- 고소 작업은 공통 표준서 없음 — 규칙 제42조~제45조(추락 방지) 적용

## 필수 단계

1. 작업허가서(화기·고소·중장비) 발급
2. 신호수 배치·인양 경로 하부 출입 통제
3. 노정 개구부 덮개·난간 확인 (추락 방지)
4. 안전대 체결 확인 (노정 고소)
5. 화재감시자 배치·소화기 비치 (용접)
6. 노 내부(노저·노흉) 작업 업체와 인양 시간 협의 기록
7. 구동부 시운전 전 인원 철수 확인·LOTO 해제
8. 종료 후 30분 화재감시·허가서 반납

## 판정에 쓰는 기준

- 계획서 절차에 2·3·7 단계가 없으면 F8 "필수 단계 누락" → F2 결함.
- 핵심 단계를 2·3·7로 고른 이유: 빠지면 바로 사망사고로 이어지는 세 가지다. 2(인양 하부 통제)는 노 내부 수직 공동으로 부품이 떨어지는 낙하(시연 S2), 3(개구부 덮개·난간)은 수십 m 추락, 7(시운전 전 철수)은 구동부 끼임을 막는 마지막 확인이다. 1·4·5·6·8은 빠져도 공통 표준서 SOP-01·03이나 상대 작업(P20·P22·P31) 표준서에서 다시 걸린다.
- 노정 설치 바로 아래 노저 축조(P20)가 있으면 R16(조건부)·R18(금지) — 시연 S2
- 용접 불티 아래 작업은 R03

## 작업 금지·출입 제한

- 설치·인양 중 TOP 직하 STACK·BELLY_BOSH·HEARTH 노 내부 진입 금지 또는 방호선반·시간 분리(R16·R18)
- 용접 중 불티 낙하 구간 하부 출입 통제(R03)
- 구동부 시운전 중 설비 내부·회전 반경 접근 금지(R22)
- 크레인 작업반경이 대형 크레인(P17)과 겹치면 통합 신호(R19)

## 3D 연결 (출입 제한 데이터)

- 구역: TOP(노정 플랫폼). 인양은 CRANE_PAD 크레인에서 TOP까지, 낙하 위험은 TOP 직하 노 내부 전체 (계획서에 인양 시간대가 있으면 그대로)
- 제한 1: 구역 STACK·BELLY_BOSH·HEARTH · 방위 ALL · 종류 LIFT_PATH(직하 노 내부 출입 통제) · 대상 OTHERS · 시점 STEP:2(인양 시간대) · 범위 구역 전체 · 규칙 R18 · 3D 표시 CONE+BAR_RED(인양 시간대 노 내부 작업 막대 금지색)
- 제한 2: 구역 STACK · 방위 ALL · 종류 ENTRY_BAN(불티 낙하 직하 출입 통제) · 대상 OTHERS · 시점 STEP:5(용접 시간대) · 범위 구역 전체 · 규칙 R03 · 3D 표시 SIGN:「노정 용접 중 · 노 내부 낙하물 주의」
- 제한 3: 구역 TOP · 방위 SAME · 종류 ENTRY_BAN(시운전 중 설비 주변 접근 금지) · 대상 OTHERS · 시점 STEP:7 · 범위 회전 반경 [팀 설정값] · 규칙 R22 · 3D 표시 TAPE+SIGN:「시운전 중 · 접근 금지」
- 제한 4: 구역 CRANE_PAD · 방위 ALL · 종류 WORK_STOP(작업반경 중첩 크레인 통합 신호·선회 제한) · 대상 P17 · 시점 DURING · 범위 작업반경 [팀 설정값] · 규칙 R19 · 3D 표시 BANNER

## 비상 조치

- 인양물 낙하·노 내부 낙하물: 크레인 정지, 노 내부 전원 퇴출 지시, 원청 상황실 보고, 부상자는 밀폐공간 구조 절차(감시인·삼각대)로 구조
- 추락자 발생: 작업 중지, 구조 요청, 매달린 상태면 즉시 구조(매달림 증후군), 119·원청 구급 연락
- 화재: 소화기 초기 진화, 노 내부 불티 유입 시 노 내부 작업자에게 즉시 알림, 진화 안 되면 대피·원청 소방 연락
- 강풍(10m/s 이상)·낙뢰: 인양 중지, 부품은 안착·고정 뒤 작업자 철수

## 기록·보관

- 허가서 3종, 인양 시간대·풍속 기록, 노 내부 작업 업체 협의 서명(6단계), 개구부 점검표, 시운전 철수 확인·LOTO 해제 기록을 원청 안전환경팀이 공사 종료 후 3년 보관(가정)
