# SOP-P23 노정 장입설비(벨리스 탑) 설치 작업표준 — 합성

- 출처: KOSHA GUIDE·산업안전보건기준에 관한 규칙을 바탕으로 해커톤 시연용으로 합성한 문서. 실제 사업장 표준서가 아니며 협력사명은 가상이다.
- 적용 작업: P23 노정 장입설비(벨리스 탑) 설치 (기준 일정 작업 하나에만 적용하는 작업별 표준서)

## 작업 개요

- 작업ID: P23
- 협력사(가상): 가상-기계J · 공종: 기계(장비 제작사)
- 구역: TOP 노정 플랫폼(장입설비)
- 기준 일정(가정값): 2027-01-06 ~ 2027-02-20 (D55~D100)
- 위험 작업 유형: 화기, 고소, 중량물
- 위험 분류 코드(시행령 제53조의2): 4호 추락, 5호 낙하·비래
- 필요 허가: 화기,고소,중장비
- 선행 작업: P17

## 적용하는 공통 표준서

- SOP-01 화기작업
- SOP-03 중량물 인양(크레인)
- 고소 작업은 공통 표준서 없음 — 규칙 제42조~제45조(추락 방지) 적용

## 필수 단계

1. 작업허가서(화기·고소·중장비) 발급
2. 신호수 배치·인양 경로 하부 출입 통제
3. 노정 개구부 덮개·난간 확인 (추락 방지)
4. 안전대 체결 확인 (노정 고소)
5. 화재감시자 배치·소화기 비치 (용접)
6. 노 내부(노저·노흉) 작업 업체와 인양 시간 협의 기록
7. 구동부 시운전 전 인원 철수 확인·LOTO 해제
8. 종료 후 30분 화재감시·허가서 반납

## 판정에 쓰는 기준

- 계획서 절차에 2·3·7 단계가 없으면 F8 "필수 단계 누락" → F2 결함.
- 노정 설치 바로 아래 노저 축조(P20)가 있으면 R16(조건부)·R18(금지) — 시연 S2
- 용접 불티 아래 작업은 R03

## 작업 금지·출입 제한

- 설치·인양 중 TOP 직하 STACK·BELLY_BOSH·HEARTH 노 내부 진입 금지 또는 방호선반·시간 분리(R16·R18)
- 용접 중 불티 낙하 구간 하부 출입 통제(R03)
