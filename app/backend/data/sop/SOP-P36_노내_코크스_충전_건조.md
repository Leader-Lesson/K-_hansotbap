# SOP-P36 노내 코크스 충전·건조 작업표준 — 합성

- 출처: KOSHA GUIDE·산업안전보건기준에 관한 규칙을 바탕으로 해커톤 시연용으로 합성한 문서. 실제 사업장 표준서가 아니며 협력사명은 가상이다.
- 적용 작업: P36 노내 코크스 충전·건조 (기준 일정 작업 하나에만 적용하는 작업별 표준서)

## 작업 개요

- 작업ID: P36
- 협력사(가상): 원청-제선 · 공종: 조업(원청 직영)
- 구역: STACK 노흉(shaft)
- 기준 일정(가정값): 2027-03-12 ~ 2027-03-22 (D120~D130)
- 위험 작업 유형: 밀폐공간, 가스계통
- 위험 분류 코드(시행령 제53조의2): 1호 화재·폭발, 8호 질식·중독
- 필요 허가: 원청 조업 절차
- 선행 작업: P22,P33,P34

## 적용하는 공통 표준서

- SOP-02 밀폐공간 출입작업
- SOP-04 가스 배관 연결·기밀시험

## 필수 단계

1. 충전·건조 절차서 승인·협력사 통보
2. 노 내부 축조(P22)·배관(P33·P34) 완료·전원 퇴출 확인 서명
3. 노 내부 잔류 인원·자재 최종 확인 (출입자 명부 대조)
4. 노정·풍구 개구부 폐쇄 확인
5. 건조 가스 투입 전 가스 측정·퍼지
6. 건조 중 노체 주변 CO 측정·출입 통제
7. 건조 완료 기록 (화입 P37 인계)

## 판정에 쓰는 기준

- 계획서 절차에 2·3·6 단계가 없으면 F8 "필수 단계 누락" → F2 결함.
- 노 내부 작업이 남았는데 가스 투입·건조가 시작되면 R07·R08(금지)
- 건조 중 노체 주변 일반 작업은 R10(조건부)

## 작업 금지·출입 제한

- 충전·건조 중 STACK·BELLY_BOSH·TUYERE·HEARTH 노 내부 진입 금지(R07)
- 노체 주변 CO 측정 전 접근 금지(R10)

## 근거 조문

- 산업안전보건기준에 관한 규칙 제619조②4호, 제618조
- 시행령 제53조의2 1·8호
