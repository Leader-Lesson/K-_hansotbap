# SOP-P10 상승관·하강관 가스 배관 절단·보수 작업표준 — 합성

- 출처: KOSHA GUIDE·산업안전보건기준에 관한 규칙을 바탕으로 해커톤 시연용으로 합성한 문서. 실제 사업장 표준서가 아니며 협력사명은 가상이다.
- 적용 작업: P10 상승관·하강관 가스 배관 절단·보수 (기준 일정 작업 하나에만 적용하는 작업별 표준서)
- 문서번호 SOP-P10 · 개정 1 · 제정(가정) 2026-11-09 · 관리 부서: 원청 안전환경팀(가상) · 적용 현장: 광양 2고로 2차 개수(합성)

## 1. 목적과 적용 범위

- 목적: 노정에서 제진기로 내려가는 상승관·하강관(대구경 고로가스 배관)을 높은 곳에서 절단하고 보수 용접하는 두 달 동안, 배관 안 잔류 가스 폭발, 절단 불티의 아래층 낙하 화재, 고소 추락, 풍하측 CO 노출을 막는다.
- 적용 범위: 화기·고소 허가, P05 퍼지 완료·맹판 확인, 가스 측정, 화재감시·불티비산방지, 고소작업대·안전대, 절단·보수 용접, 비파괴검사, 30분 감시, 반납까지. 배관 내화물 보수도 포함한다.
- 적용 제외: 가스 계통 차단·퍼지 자체(P05, SOP-P05), 제진기·가스청정설비 보수(P25, SOP-P25)는 별도 표준서를 따른다. 같은 가스 계통이라 P25 배관 개방과 이 작업의 화기가 겹치면 R04 다(시연 S4).

## 2. 작업 개요

- 작업ID: P10
- 협력사(가상): 가상-제관F · 공종: 제관+내화물
- 구역: DOWNCOMER 상승관·하강관(가스 배관)
- 기준 일정(가정값): 2026-11-17 ~ 2027-01-11 (D5~D60)
- 위험 작업 유형: 화기, 고소, 가스계통
- 위험 분류 코드(시행령 제53조의2): 1호 화재·폭발, 4호 추락, 8호 질식·중독
- 필요 허가: 화기,고소
- 선행 작업: P05

## 3. 위험 요인과 예상 사고

- 폭발: 퍼지가 덜 됐거나 맹판 없이 밸브만 닫힌 배관을 절단하면 안에 남은 고로가스가 불티에 닿는다. 하류 제진기(P25)에서 배관을 열면 가스가 이쪽으로 되돌아온다(R04).
- CO 중독: 절단 개구부에서 나오는 잔류 가스, 배관 내화물 보수를 위해 배관 안에 들어갈 때의 산소 결핍.
- 추락: 상승관·하강관은 노정 높이에서 지상까지 비스듬히 내려온다. 고소작업대·비계 위에서 안전대 없이 절단한다.
- 낙하·화재: 절단 불티·배관 조각이 아래 제진기 구역(GCP)·주상으로 떨어진다(R03). 풍하측으로 불티가 8m 까지 날린다.
- 끼임: 대구경 배관 절단 조각이 예상과 다르게 처지거나 회전한다.

## 4. 투입 인원과 역할 (기준 10명, 계획서 인원과 맞춘다)

- 작업책임자 1명: 화기·고소 허가, P05 인계 확인(퍼지·맹판), 절단 순서 관리
- 화재감시자 1명: 절단 중 상주, 아래층 불티 확인, 종료 후 30분 감시
- 가스 측정 담당 1명(작업책임자 겸임 가능): 배관 안·작업 위치 LEL·O2·CO 측정, 2시간마다 재측정
- 절단·용접공 4명: 산소절단·보수 용접(자격 보유), 절단 조각 임시 고정
- 고소작업대 운전·비계 담당 1명: 고소작업대 이동·안전대 걸이 확인
- 하부 통제원 1명: GCP·주상 풍하측 출입 통제, CO 경보기 확인
- 비파괴검사원 1명(보수 용접 완료 시, 자격 보유)

## 5. 투입 장비·자재·보호구

- 장비: 고소작업대, 비계(배관 둘레 작업발판), 산소절단기(가스 용기 랙) 2조, 용접기 2대, 복합 가스측정기(LEL·O2·CO) 2대, 체인블록(절단 조각 지지), 크롤러 크레인(대형 조각 하강 시), 환기팬(배관 내부 보수 시), 풍속계·풍향계, UT 검사 장비(3D 모델 없음, 원문 이름 유지)
- 자재: 맹판(블라인드 플랜지)·꼬리표, 불티비산방지포·방화포, 소화기 2대 이상, 파이프 랙(보수 자재), 배관 내화물, 출입 통제 안전띠·표지, 와이어로프·샤클
- 보호구: 안전모·안전화·보안경, 안전대(2중 걸이), 용접 보안면·방열 장갑, 휴대용 CO 경보기(전원), 송기마스크 또는 공기호흡기(배관 내부 진입·대피용)

## 6. 작업 순서 (상세)

1. 작업허가서(화기·고소) 발급 — 작업책임자가 날마다 절단·용접 구간(배관 번호·높이)과 시간을 적어 화기·고소 허가를 받고 번호를 서로 기재한다(R29). 같은 가스 계통의 P25 배관 개방 일정이 겹치지 않는지 확인한다. 확인: 허가서 번호·P25 일정 확인 기록.
2. 가스 계통 차단·맹판 확인 (P05 퍼지 완료 확인) — P05 인계 서명지의 퍼지 완료 측정값·맹판 목록을 받고, 절단 구간 양쪽 맹판이 실제로 들어 있고 꼬리표가 있는지 눈으로 확인한다. 밸브만 닫힌 상태면 시작하지 않는다(R04). 확인: 맹판 위치 확인 기록·P05 인계 서명지.
3. 작업 전 가스 측정 (LEL 10% 미만, O2 18~23.5%, CO 30ppm 미만) 기록 — 절단할 배관 안(개구부·드레인)과 작업 위치 호흡 높이에서 잰다. 기준 밖이면 멈추고 퍼지·환기 뒤 다시 잰다. 2시간마다, 절단 재개 때마다 다시 잰다. 확인: 측정값·시각·측정자 기록.
4. 화재감시자 배치·불티비산방지 조치 — 감시자를 두고 소화기 2대를 둔다. 절단 위치 아래 GCP·주상 쪽에 불티비산방지포를 깔고 풍하측 비산 범위(최대 8m)의 가연물을 치운다. 아래층 작업이 있으면 출입을 막는다(R03). 확인: 감시자 서명·하부 통제 기록.
5. 고소 작업대·안전대 체결 확인 — 고소작업대·비계 발판 상태를 점검하고 작업자가 안전대를 구명줄·구조물에 걸었는지 반장이 눈으로 확인한다. 고소작업대 위에서 몸을 밖으로 내밀어 절단하지 않는다. 확인: 반장 확인 서명.
6. 절단·보수 용접 — 절단 조각은 체인블록·크레인으로 먼저 지지한 뒤 자른다. 보수 용접은 자격자가 하고 용접 구간 안쪽 내화물·가스켓 상태를 함께 확인한다. 확인: 절단 조각 번호·용접사 이름 기록.
7. 비파괴검사 — 보수 용접부를 UT 등으로 검사한다. RT를 쓰면 방사선 관리구역 설정·야간 시간대 분리(R24)를 따른다. 확인: 검사 기록.
8. 작업 종료 후 30분 화재감시 — 감시자가 30분 동안 배관 안·아래층 불티를 확인한다. 확인: 감시 종료 시각.
9. 허가서 반납 — 종료 확인 서명 후 허가서를 반납하고 그날 절단 구간·맹판 상태를 P25 협력사와 원청에 알린다. 확인: 반납 시각·통보 기록.

## 적용하는 공통 표준서

- SOP-01 화기작업
- SOP-04 가스 배관 연결·기밀시험
- 고소 작업은 공통 표준서 없음 — 규칙 제42조~제45조(추락 방지) 적용

## 필수 단계

1. 작업허가서(화기·고소) 발급
2. 가스 계통 차단·맹판 확인 (P05 퍼지 완료 확인)
3. 작업 전 가스 측정 (LEL 10% 미만, O2 18~23.5%, CO 30ppm 미만) 기록
4. 화재감시자 배치·불티비산방지 조치
5. 고소 작업대·안전대 체결 확인
6. 절단·보수 용접
7. 비파괴검사
8. 작업 종료 후 30분 화재감시
9. 허가서 반납

## 판정에 쓰는 기준

- 계획서 절차에 2·3·4 단계가 없으면 F8 "필수 단계 누락" → F2 결함.
- 핵심 단계를 2·3·4로 고른 이유: 고로가스 배관에 불을 대는 작업이라 폭발과 화재가 사망 경로다. 2(차단·맹판 확인)는 가스가 되돌아올 길을 막고, 3(가스 측정)은 배관 안에 가스가 남지 않았음을 수치로 확인하며, 4(화재감시자·불티비산방지)는 불티가 아래층 GCP·주상으로 떨어지는 화재를 막는다. 셋 다 빠지면 바로 폭발·화재다. 5·7·8은 추락 규칙·SOP-01 에서 다시 걸린다.
- P05 퍼지 완료 전 절단을 시작하면 R04(금지) — 시연 S4
- 상부 화기 아래 GCP·주상 작업은 R03(조건부), 가스 배관 개방 중 풍하측 일반 작업은 R10(조건부)

## 작업 금지·출입 제한

- 절단 중 DOWNCOMER 하부·풍하측 GCP 출입 통제(R03·R10)
- 가스 계통 개방 중 같은 계통(상승관·하강관·제진기) 타 업체 화기 금지(R04)
- P05 퍼지 완료 측정 게시·맹판 확인 전 절단 착수 금지(R04)
- 같은 계통 P25 배관 개방 시간대에 이 작업 화기 금지 — 시간 분리(R04, 시연 S4)

## 3D 연결 (출입 제한 데이터)

- 구역: DOWNCOMER(상승관·하강관). 3D에서는 GCP 와 함께 GAS 구역으로 그린다. 낙하 영향은 아래 GCP 와 풍하측 CASTHOUSE. 방위는 절단 구간 방위(SAME)
- 제한 1: 구역 GCP·CASTHOUSE(절단 위치 직하·풍하), 방위 SAME, 종류 ENTRY_BAN, 대상 OTHERS, 적용 시점 STEP:6(절단·용접 중), 범위 직하 + 풍하 8m [KOSHA 불티비산표], 규칙 R03·R10, 3D 표시 CONE + SIGN「상부 절단 중 · 불티 낙하」
- 제한 2: 구역 DOWNCOMER·GCP(같은 가스 계통), 방위 ALL, 종류 HOT_WORK_BAN, 대상 OTHERS(P25 등), 적용 시점 DURING(이 작업이 배관을 열어 둔 기간), 범위 계통 전체 + 반경 11m, 규칙 R04, 3D 표시 TAPE + SIGN「가스 배관 개방 중 · 화기 금지」
- 착수 조건: 구역 DOWNCOMER, 종류 WORK_STOP(이 작업 자체 화기), 대상 P10, 적용 시점 UNTIL_HANDOVER(P05 7단계 측정 결과 게시 전까지), 규칙 R04, 3D 표시 BAR_RED(P10 작업 막대 금지색) — 시연 S4
- 제한 3: 구역 DOWNCOMER, 방위 SAME, 종류 ENTRY_BAN(가연물 반입 금지), 대상 OTHERS, 적용 시점 STEP:8(종료 후 30분), 범위 반경 11m, 규칙 R25, 3D 표시 SIGN「화재감시 중 30분」

## 비상 조치

- 가스 경보(LEL 10%·CO 30ppm 이상): 즉시 불꽃을 끄고 점화원 제거, 풍상측 대피, 작업책임자가 원청 상황실 보고, P25 협력사에 배관 개방 여부 확인, 재측정 정상 뒤 재개
- 배관 내 착화·폭발음: 전원 대피, 접근 금지, 원청 소방·상황실 연락, 상류 밸브·맹판 상태 확인
- 추락·매달림: 고소작업대로 접근 구조, 119·원청 구급 연락
- 아래층 화재·낙하물 부상: 하부 작업 중지, 원청 구급 연락, 방지포 보강 전 재개 금지
