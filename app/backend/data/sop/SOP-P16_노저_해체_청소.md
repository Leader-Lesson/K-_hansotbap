# SOP-P16 노저 해체·청소 작업표준 — 합성

- 출처: KOSHA GUIDE·산업안전보건기준에 관한 규칙을 바탕으로 해커톤 시연용으로 합성한 문서. 실제 사업장 표준서가 아니며 협력사명은 가상이다.
- 적용 작업: P16 노저 해체·청소 (기준 일정 작업 하나에만 적용하는 작업별 표준서)
- 문서번호 SOP-P16 · 개정 1 · 제정(가정) 2026-11-09 · 관리 부서: 원청 안전환경팀(가상) · 적용 현장: 광양 2고로 2차 개수(합성)

## 1. 목적과 적용 범위

- 목적: 잔선 발파가 끝난 노저에서 낡은 카본블록·바닥 내화물을 깨어 내고 바닥을 청소해 새 축조(P20)에 넘기는 열흘 동안, 발파 잔류물·불발 화약 접촉, 노 안 가장 깊은 곳의 산소 결핍·CO, 카본블록 붕괴, 잔재 인양 낙하를 막는다.
- 적용 범위: 밀폐공간 허가·측정, P13 발파 완료·불발 확인, 감시인·명부, 카본블록 해체 붕괴 방향 관리, 잔재 반출 호이스트 하부 통제, 바닥 검사·P20 인계, 퇴출·반납까지. 노 내부 최하단 HEARTH 에서 한다.
- 적용 제외: 잔선 천공·발파(P13, SOP-P13), 노저 카본블록 신설 축조(P20, SOP-P20), 노내 호이스트 운영(P31)은 별도 표준서를 따른다.

## 2. 작업 개요

- 작업ID: P16
- 협력사(가상): 가상-해체G · 공종: 해체
- 구역: HEARTH 노상·노저(hearth)
- 기준 일정(가정값): 2026-12-22 ~ 2027-01-01 (D40~D50)
- 위험 작업 유형: 밀폐공간
- 위험 분류 코드(시행령 제53조의2): 5호 낙하·비래, 8호 질식·중독
- 필요 허가: 밀폐공간
- 선행 작업: P13

## 3. 위험 요인과 예상 사고

- 불발 화약: 발파(P13) 뒤 남은 불발 장약이 잔재 속에 섞여 있다가 브레이커·굴삭 중 터진다. P13 발파 책임자의 불발 확인 서명 없이 들어가면 안 된다(R15).
- 질식·중독: 노저는 노 안에서 가장 깊어 무거운 가스가 고이고 환기가 가장 어렵다. 카본블록 분진·발파 가스 잔류. 위층(P14)에서 내려오는 분진.
- 붕괴: 카본블록은 크고 무겁다. 아래쪽을 먼저 빼면 위 블록이 쏟아진다. 붕괴 방향에 서 있던 사람이 깔린다.
- 낙하·비래: 잔재를 노내 호이스트로 올릴 때 아래 사람이 맞는다. 위층 해체(P14) 투하물이 노저로 떨어진다(R16).
- 가스 유입: 노저 작업 중 노체 계통(질소·BFG·송풍)에 가스가 들어오면 노 안 전원이 쓰러진다(R07).

## 4. 투입 인원과 역할 (기준 18명, 계획서 인원과 맞춘다)

- 작업책임자 1명: 밀폐공간 허가, P13 불발 확인 서명 수령, 해체 순서(위→아래)·붕괴 방향 지정, P20 인계
- 안전관리자(측정 담당) 1명: 산소·CO·분진 측정, 환기팬 관리
- 감시인 2명: 풍구 레벨 맨홀·노정 개구부 상주, 명부 기록
- 해체 작업자 8명: 카본블록·바닥 내화물 브레이커 해체, 잔재 분리
- 청소 작업자 2명: 바닥 잔재·분진 제거, 바닥 상태 정리
- 신호수·줄걸이 2명: 노내 호이스트 잔재 인양 신호·줄걸이, 하부 통제
- 장비 운전원 2명(교대): 미니 로더·소형 굴삭기(노저 안 잔재 모으기, 원격 또는 탑승)

## 5. 투입 장비·자재·보호구

- 장비: 브레이커·착암기, 미니 로더·소형 굴삭기(원격 해체 장비), 노내 호이스트(P31 가상-양중C 운영), 체인블록(블록 자세 조정), 환기팬 2대(송기 덕트), 산소·CO 복합측정기 3대(연속 측정 1대 고정), 작업등, 무전기
- 구조장비: 공기호흡기 2조, 삼각대·구조용 윈치, 들것
- 자재: 잔재 인양 백·팔레트, 와이어로프·샤클, 붕괴 위험 구간 표지·안전띠, 출입자 명부, 바닥 검사 체크리스트(P20 인계용)
- 보호구: 안전모·안전화·보안경, 방진마스크(카본 분진), 귀마개, 휴대용 산소·CO 경보기(작업조마다), 안전대(인양 구간·개구부), 방진 보안경·안면보호구(브레이커)

## 6. 작업 순서 (상세)

1. 밀폐공간 작업허가서 발급 — 작업책임자가 밀폐공간 허가를 받고 출입구에 게시한다. 허가서에 인원, 감시인, 측정 계획, 위층 작업(P14) 시간대, 노체 계통 맹판 상태를 적는다. 확인: 허가서 번호.
2. 작업 전 산소·CO 측정 후 진입 — 진입 전 노저 바닥·중간·출입구에서 O2 18~23.5%, CO 30ppm 미만, LEL 10% 미만을 확인한다. 작업 중 연속 측정하고 1일 2회 이상 기록. 확인: 측정값·시각 기록.
3. 발파 잔류물·불발 화약 확인 (P13 완료 확인) — P13 발파 책임자의 "발파 완료·불발 없음" 서명을 받고, 잔재 속에 화약·뇌관 흔적이 없는지 눈으로 확인하며 작업한다. 의심 물체가 나오면 즉시 멈추고 발파 책임자를 부른다(R15). 확인: P13 인계 서명지·일일 확인 기록.
4. 감시인 배치·출입자 명부 기록 — 풍구 레벨 맨홀·노정 개구부에 감시인을 두고 입·퇴장 시각을 적는다. 확인: 감시인 서명·명부.
5. 노저 카본블록 해체 시 붕괴 방향 접근 금지 — 블록은 위에서 아래로, 바깥에서 안으로 해체한다. 붕괴 예상 방향을 그날 지정해 표지·안전띠를 두고 서지 않는다. 장비로 밀 때는 사람이 반대편에 있지 않게 한다. 확인: 붕괴 방향 일일 지정 기록.
6. 잔재 반출 호이스트 하부 출입 통제 — 잔재 백·팔레트를 노내 호이스트로 올릴 때 신호수가 아래를 비운 뒤 올린다. 인양 중 노저 작업은 멈춘다. 중량을 확인한다. 확인: 인양 시간대·중량 기록.
7. 청소 완료 바닥 상태 검사 (축조 P20 인계) — 바닥 잔재·분진을 제거하고 레벨·균열·잔수를 검사해 체크리스트에 적은 뒤 축조 협력사(가상-축로I, P20)와 원청에 인계한다. 확인: 바닥 검사 체크리스트·인계 서명지.
8. 퇴출 확인·허가서 반납 — 명부를 0명으로 맞추고 작업책임자가 서명한 뒤 허가서를 반납한다. 확인: 퇴출 서명·반납 시각.

## 적용하는 공통 표준서

## 필수 단계

1. 밀폐공간 작업허가서 발급
2. 작업 전 산소·CO 측정 후 진입
3. 발파 잔류물·불발 화약 확인 (P13 완료 확인)
4. 감시인 배치·출입자 명부 기록
5. 노저 카본블록 해체 시 붕괴 방향 접근 금지
6. 잔재 반출 호이스트 하부 출입 통제
7. 청소 완료 바닥 상태 검사 (축조 P20 인계)
8. 퇴출 확인·허가서 반납

## 판정에 쓰는 기준

- 계획서 절차에 2·3·4 단계가 없으면 F8 "필수 단계 누락" → F2 결함.
- 핵심 단계를 2·3·4로 고른 이유: 노저 해체의 사망 경로 세 가지를 하나씩 막는다. 2(산소·CO 측정 후 진입)는 노 안 가장 깊은 곳의 질식·중독을, 3(불발 화약 확인)은 잔재 속 장약을 브레이커로 치는 폭발(R15)을, 4(감시인·명부)는 쓰러진 사람을 밖에서 알아채는 유일한 수단이다. 5·6은 붕괴·낙하를 막지만 해체 순서·SOP-03 에서 다시 걸리고, 1·7·8은 SOP-02·인계 절차에서 다시 걸린다.
- 발파(P13) 완료 확인 전 진입은 R15(금지)
- 노저 작업 중 같은 계통 가스·질소 투입은 R07(금지)

## 비상 조치

- 화약·뇌관 의심 물체 발견: 작업 즉시 중지, 접근 금지, P13 발파 책임자·원청 안전환경팀 연락, 처리 확인 뒤 재개
- 산소·CO 경보: 전원 즉시 퇴출, 감시인이 명부 확인, 환기 뒤 재측정 정상 뒤 재진입
- 내부 인원 쓰러짐: 구조자는 공기호흡기 착용·삼각대 사용, 맨몸 진입 금지, 119·원청 구급 연락
- 카본블록 붕괴·매몰: 2차 붕괴 확인 뒤 구조, 원청 구급·상황실 연락
- 위층 낙하물: 노저 작업 중지, 원청이 위층 작업(P14) 협력사와 시간 조정
