# SOP-P16 노저 해체·청소 작업표준 — 합성

- 출처: KOSHA GUIDE·산업안전보건기준에 관한 규칙을 바탕으로 해커톤 시연용으로 합성한 문서. 실제 사업장 표준서가 아니며 협력사명은 가상이다.
- 적용 작업: P16 노저 해체·청소 (기준 일정 작업 하나에만 적용하는 작업별 표준서)

## 작업 개요

- 작업ID: P16
- 협력사(가상): 가상-해체G · 공종: 해체
- 구역: HEARTH 노상·노저(hearth)
- 기준 일정(가정값): 2026-12-22 ~ 2027-01-01 (D40~D50)
- 위험 작업 유형: 밀폐공간
- 위험 분류 코드(시행령 제53조의2): 5호 낙하·비래, 8호 질식·중독
- 필요 허가: 밀폐공간
- 선행 작업: P13

## 적용하는 공통 표준서

- SOP-02 밀폐공간 출입작업

## 필수 단계

1. 밀폐공간 작업허가서 발급
2. 작업 전 산소·CO 측정 후 진입
3. 발파 잔류물·불발 화약 확인 (P13 완료 확인)
4. 감시인 배치·출입자 명부 기록
5. 노저 카본블록 해체 시 붕괴 방향 접근 금지
6. 잔재 반출 호이스트 하부 출입 통제
7. 청소 완료 바닥 상태 검사 (축조 P20 인계)
8. 퇴출 확인·허가서 반납

## 판정에 쓰는 기준

- 계획서 절차에 2·3·4 단계가 없으면 F8 "필수 단계 누락" → F2 결함.
- 발파(P13) 완료 확인 전 진입은 R15(금지)
- 노저 작업 중 같은 계통 가스·질소 투입은 R07(금지)

## 작업 금지·출입 제한

- 해체 중 HEARTH 위 TUYERE 개구부를 통한 투하 금지
- 노저 작업 중 노 내부 계통 가스·질소 투입 금지(R07)

## 근거 조문

- 산업안전보건기준에 관한 규칙 제618조~제623조
- 시행령 제53조의2 5·8호, KOSHA GUIDE H-80
