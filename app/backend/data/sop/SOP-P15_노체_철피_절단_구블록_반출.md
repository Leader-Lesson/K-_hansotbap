# SOP-P15 노체 철피 절단·구 블록 반출 작업표준 — 합성

- 출처: KOSHA GUIDE·산업안전보건기준에 관한 규칙을 바탕으로 해커톤 시연용으로 합성한 문서. 실제 사업장 표준서가 아니며 협력사명은 가상이다.
- 적용 작업: P15 노체 철피 절단·구 블록 반출 (기준 일정 작업 하나에만 적용하는 작업별 표준서)
- 문서번호 SOP-P15 · 개정 1 · 제정(가정) 2026-11-09 · 관리 부서: 원청 안전환경팀(가상) · 적용 현장: 광양 2고로 2차 개수(합성)

## 1. 목적과 적용 범위

- 목적: 낡은 노체 철피를 큰 블록 단위로 잘라 대형 크레인으로 내려 야드로 내보내는 열흘 동안, 안쪽 내화물 해체가 덜 끝난 상태에서 자르는 순서 위반, 절단 중 블록이 예고 없이 떨어지는 낙하, 절단 불티의 아래층 화재, 고소 추락, 블록 인양 경로 아래 주상·크레인 패드의 사고를 막는다.
- 적용 범위: 화기·고소·중장비 허가, P14 내측 해체 완료 확인, 가스 측정·화재감시, 절단 블록 임시 고정 지그, 블록 인양 신호·줄걸이, 인양 경로 하부·주상·야드 통제, 고소 발판·안전대, 반출 차량 유도, 절단면 보호·반납까지. 노체 철피 외부(SHELL) 전 둘레를 돌아가며 한다.
- 적용 제외: 신 철피 링블록 반입·설치(P17, SOP-P17), 야드에서의 스크랩 절단(P32), 비계(P30)는 별도 표준서를 따른다.

## 2. 작업 개요

- 작업ID: P15
- 협력사(가상): 가상-철구B · 공종: 제관+양중
- 구역: SHELL 노체 철피 외부
- 기준 일정(가정값): 2026-12-17 ~ 2026-12-27 (D35~D45)
- 위험 작업 유형: 화기, 고소, 중량물
- 위험 분류 코드(시행령 제53조의2): 1호 화재·폭발, 3호 충돌(양중기·차량), 5호 낙하·비래
- 필요 허가: 화기,고소,중장비
- 선행 작업: P14

## 3. 위험 요인과 예상 사고

- 순서 위반·붕괴: 안쪽 내화물·스테이브 해체(P14)가 덜 끝난 구간의 철피를 자르면 남은 내화물이 노 안 작업자 쪽으로 무너지고, 철피 블록이 예상 밖 하중을 받는다(R08).
- 낙하: 절단이 끝나기 전 블록이 자중으로 찢어져 떨어진다. 임시 고정 지그·크레인 선매달기 없이 마지막 절단선을 자르는 순간이 가장 위험하다.
- 인양 낙하·충돌: 수십~수백 t 블록을 크레인으로 내리는 경로 아래 주상(P24)·크레인 패드·야드에 사람이 있다(R18). 야드 반출 트레일러와 보행자 충돌(R21).
- 화재·폭발: 절단 불티가 아래층 주상·비계 발판으로 떨어진다(R03). 철피 안쪽 잔류 가스·그리스.
- 추락: 철피 외부 비계·고소작업대에서 안전대 없이 절단한다. 블록을 떼어 낸 자리는 큰 개구부가 된다.

## 4. 투입 인원과 역할 (기준 16명, 계획서 인원과 맞춘다)

- 작업책임자 1명: 화기·고소·중장비 허가, P14 완료 서명 확인, 절단 순서·지그 계획 승인
- 화재감시자 2명: 절단 위치마다 상주, 아래층 불티 확인, 종료 후 30분 감시
- 가스 측정 담당 1명(작업책임자 겸임 가능): 철피 안팎 LEL 측정
- 절단공 6명: 산소절단·가스절단, 절단선 표시, 임시 고정 지그 설치
- 크레인 운전원 1명·신호수 1명·줄걸이 2명: 블록 인양(대형 크롤러 크레인), 러그 용접부 점검
- 하부 통제원·유도자 2명: 주상·크레인 패드·야드 인양 경로 통제, 반출 트레일러 유도

## 5. 투입 장비·자재·보호구

- 장비: 대형 크롤러 크레인(블록 인양, P02 조립 크레인), 크롤러 크레인(보조), 트레일러·덤프트럭(블록 반출), 산소절단기(가스 용기 랙) 4조, 비계·고소작업대(철피 외부), 체인블록(블록 자세 조정), 복합 가스측정기(LEL·O2·CO), 풍속계, 무전기
- 자재: 절단 블록 임시 고정 지그·받침·스토퍼, 인양 러그, 와이어로프·샤클(검사 꼬리표), 불티비산방지포·방화포, 소화기 2대 이상(위치마다), 절단면 보호 덮개·개구부 난간, 출입 통제 안전띠·러버콘·표지
- 보호구: 안전모·안전화·보안경, 안전대(2중 걸이), 용접 보안면·방열 장갑·앞치마(절단공), 신호수 조끼·반사 조끼(유도자), 휴대용 CO 경보기(철피 안쪽 접근자)

## 6. 작업 순서 (상세)

1. 작업허가서(화기·고소·중장비) 발급 — 작업책임자가 날마다 절단 블록 번호·방위·단, 인양 계획을 적어 화기·고소·중장비 허가를 받고 번호를 서로 기재한다(R29). 아래 주상(P24)·비계(P30) 일정을 확인한다. 확인: 허가서 번호·인접 일정 확인.
2. 철피 내측 내화물 해체 완료 확인 (P14 완료 서명) — 자를 블록 구간의 안쪽 내화물·스테이브 해체가 끝났다는 P14 협력사(가상-내화H) 작업책임자의 서명을 받고 노 안쪽을 눈으로 확인한다. 서명이 없는 구간은 자르지 않는다(R08). 확인: P14 인계 서명지.
3. 절단 전 가스 측정 (LEL 10% 미만)·화재감시자 배치 — 철피 안쪽·바깥 절단 위치에서 LEL을 재고, 감시자를 두고 소화기 2대를 둔다. 아래층 주상·비계 발판에 방지포를 깔고 가연물을 치운다(R03). 확인: 측정값·감시자 서명.
4. 절단 블록 임시 고정·낙하 방지 지그 설치 — 절단선을 표시한 뒤 블록이 마지막 절단 전까지 떨어지지 않게 지그·스토퍼·받침을 설치하거나 크레인에 먼저 매단다. 마지막 절단선은 크레인 하중을 받은 상태에서만 자른다. 확인: 지그 설치 사진·절단 순서 기록.
5. 블록 인양 신호수 지정·줄걸이 점검 (중량 확인) — 블록 중량·무게중심을 도면으로 확인하고 러그 용접부·와이어·샤클을 점검한다. 신호수를 정하고 무전 채널을 적는다. 확인: 점검표·신호수 이름.
6. 인양 경로 하부·주상·야드 출입 통제 — 인양 경로 아래 주상(CASTHOUSE)·크레인 패드·야드 적치 구간에 안전띠·러버콘을 치고 통제원이 막는다. 주상 개조(P24)·야드 작업은 인양 시간대에 멈춘다(R18). 확인: 인양 시간대·통제 범위 기록.
7. 고소 절단 발판·안전대 체결 확인 — 비계·고소작업대 발판·난간을 점검하고 절단공이 안전대를 걸었는지 반장이 눈으로 확인한다. 블록을 뗀 개구부에는 난간·표지를 둔다. 확인: 반장 확인 서명.
8. 반출 차량 유도자 배치 — 블록을 트레일러에 싣고 야드로 옮길 때 유도자가 통로 보행자를 막고 차량을 유도한다(R21). 확인: 반출 기록.
9. 허가서 반납·절단면 보호 조치 — 날마다 절단면·개구부에 덮개·난간을 두고 30분 화재감시 뒤 허가서를 반납한다. 전 블록 반출이 끝나면 링블록 반입(P17) 협력사(가상-양중C)에 절단면 상태를 인계한다. 확인: 절단면 보호 사진·반납 시각.

## 적용하는 공통 표준서

- SOP-01 화기작업
- SOP-03 중량물 인양(크레인)
- 고소 작업은 공통 표준서 없음 — 규칙 제42조~제45조(추락 방지) 적용

## 필수 단계

1. 작업허가서(화기·고소·중장비) 발급
2. 철피 내측 내화물 해체 완료 확인 (P14 완료 서명)
3. 절단 전 가스 측정 (LEL 10% 미만)·화재감시자 배치
4. 절단 블록 임시 고정·낙하 방지 지그 설치
5. 블록 인양 신호수 지정·줄걸이 점검 (중량 확인)
6. 인양 경로 하부·주상·야드 출입 통제
7. 고소 절단 발판·안전대 체결 확인
8. 반출 차량 유도자 배치
9. 허가서 반납·절단면 보호 조치

## 판정에 쓰는 기준

- 계획서 절차에 3·4·6 단계가 없으면 F8 "필수 단계 누락" → F2 결함.
- 핵심 단계를 3·4·6으로 고른 이유: 철피 절단에서 사람이 죽는 세 순간을 하나씩 막는다. 3(가스 측정·화재감시자)은 불티가 아래층 주상·비계로 떨어지는 화재를, 4(임시 고정 지그)는 마지막 절단선을 자르는 순간 블록이 떨어지는 낙하를, 6(인양 경로·주상·야드 통제)은 수십 t 블록 아래에 사람이 있는 상황을 막는다. 5·7·8은 SOP-03·추락 규칙·유도자 규칙에서, 2는 R08 순서 판정에서 다시 걸린다.
- 블록 인양 경로 아래 인원은 R18(금지), 상부 절단 불티 아래 작업은 R03(조건부)
- 내측 해체(P14) 미완료 상태에서 절단 착수는 R08(금지, 순서), 비계와 겹치면 R17

## 작업 금지·출입 제한

- 블록 인양 중 SHELL 하부 CASTHOUSE·CRANE_PAD 인양 경로 출입 금지(R18)
- 절단 중 노 내부 BELLY_BOSH 진입 금지
- P14 내측 해체 완료 서명이 없는 구간 절단 착수 금지(R08)
- 절단 중 철피 외부 비계 해체(P30) 금지(R17), 직하 주상 가연물 적치 금지(R03)

## 3D 연결 (출입 제한 데이터)

- 구역: SHELL(노체 철피 외부). 절단은 블록 번호 순서로 돌아가므로 방위는 계획서의 블록 방위·단(SAME). 인양 경로는 크레인 쪽(CRANE_PAD) 방위, 낙하 영향은 아래 CASTHOUSE
- 제한 1: 구역 CASTHOUSE·CRANE_PAD, 방위 SAME(인양 경로), 종류 LIFT_PATH, 대상 OTHERS(P24 등), 적용 시점 STEP:6(블록 인양 시간대, 계획서 BAND 우선), 범위 경로 직하 + 선회 반경 [팀 설정값], 규칙 R18, 3D 표시 CONE + TAPE
- 제한 2: 구역 CASTHOUSE, 방위 SAME(절단 블록 직하), 종류 ENTRY_BAN, 대상 OTHERS, 적용 시점 STEP:3~4(절단 중), 범위 직하 + 풍하 8m [KOSHA 불티비산표], 규칙 R03, 3D 표시 CONE + SIGN「상부 절단 중 · 불티 낙하」
- 제한 3: 구역 BELLY_BOSH·STACK(노 내부), 방위 SAME, 종류 ENTRY_BAN, 대상 OTHERS, 적용 시점 DURING, 범위 절단 구간 안쪽, 규칙 R16, 3D 표시 TAPE
- 제한 4: 구역 SHELL, 방위 SAME, 종류 WORK_STOP(비계 해체 금지), 대상 P30, 적용 시점 DURING, 범위 절단 구간 비계, 규칙 R17, 3D 표시 BANNER「절단 중 · 비계 해체 보류」
- 착수 조건: 구역 SHELL, 종류 WORK_STOP(이 작업 자체), 대상 P15, 적용 시점 UNTIL_HANDOVER(P14 9단계 내측 해체 완료 서명 전까지), 규칙 R08, 3D 표시 BAR_RED(P15 작업 막대 금지색)

## 비상 조치

- 블록 예기치 않은 처짐·낙하 징후: 절단 즉시 중단, 절단공 후퇴, 하부 통제 확대, 크레인으로 하중 지지 뒤 재개 판단
- 인양 중 줄걸이 이상: 신호수 정지 신호, 가장 가까운 안전한 곳에 하강, 원청 안전환경팀 보고
- 화재: 감시자 초기 진화, 절단기 밸브 차단, 아래층 불티 확인, 진화 안 되면 대피·원청 소방 연락
- 추락·매달림: 고소작업대로 접근 구조, 119·원청 구급 연락
- 반출 차량 접촉 사고: 차량 정지·시동 끄기, 원청 구급·상황실 연락

## 기록·보관

- 허가서(상호참조), P14 인계 서명지, 가스 측정·감시자 기록, 지그 설치 사진·절단 순서 기록, 인양 점검표·시간대 기록, 하부 통제 기록, 안전대 확인 서명, 반출 기록, 절단면 보호 사진을 원청 안전환경팀이 공사 종료 후 3년 보관(가정)
