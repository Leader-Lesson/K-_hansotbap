# SOP-P15 노체 철피 절단·구 블록 반출 작업표준 — 합성

- 출처: KOSHA GUIDE·산업안전보건기준에 관한 규칙을 바탕으로 해커톤 시연용으로 합성한 문서. 실제 사업장 표준서가 아니며 협력사명은 가상이다.
- 적용 작업: P15 노체 철피 절단·구 블록 반출 (기준 일정 작업 하나에만 적용하는 작업별 표준서)

## 작업 개요

- 작업ID: P15
- 협력사(가상): 가상-철구B · 공종: 제관+양중
- 구역: SHELL 노체 철피 외부
- 기준 일정(가정값): 2026-12-17 ~ 2026-12-27 (D35~D45)
- 위험 작업 유형: 화기, 고소, 중량물
- 위험 분류 코드(시행령 제53조의2): 1호 화재·폭발, 3호 충돌(양중기·차량), 5호 낙하·비래
- 필요 허가: 화기,고소,중장비
- 선행 작업: P14

## 적용하는 공통 표준서

- SOP-01 화기작업
- SOP-03 중량물 인양(크레인)
- 고소 작업은 공통 표준서 없음 — 규칙 제42조~제45조(추락 방지) 적용

## 필수 단계

1. 작업허가서(화기·고소·중장비) 발급
2. 철피 내측 내화물 해체 완료 확인 (P14 완료 서명)
3. 절단 전 가스 측정 (LEL 10% 미만)·화재감시자 배치
4. 절단 블록 임시 고정·낙하 방지 지그 설치
5. 블록 인양 신호수 지정·줄걸이 점검 (중량 확인)
6. 인양 경로 하부·주상·야드 출입 통제
7. 고소 절단 발판·안전대 체결 확인
8. 반출 차량 유도자 배치
9. 허가서 반납·절단면 보호 조치

## 판정에 쓰는 기준

- 계획서 절차에 3·4·6 단계가 없으면 F8 "필수 단계 누락" → F2 결함.
- 블록 인양 경로 아래 인원은 R18(금지), 상부 절단 불티 아래 작업은 R03(조건부)
- 내측 해체(P14) 미완료 상태에서 절단 착수는 R08(금지, 순서), 비계와 겹치면 R17

## 작업 금지·출입 제한

- 블록 인양 중 SHELL 하부 CASTHOUSE·CRANE_PAD 인양 경로 출입 금지(R18)
- 절단 중 노 내부 BELLY_BOSH 진입 금지

## 근거 조문

- 산업안전보건기준에 관한 규칙 제146조①4호(머리 위 통과 금지), 제241조·제241조의2, 제14조
- KOSHA GUIDE M-186
