# SOP-P24 출선장 개조: 탕도·집진 후드·개공기·머드건 작업표준 — 합성

- 출처: KOSHA GUIDE·산업안전보건기준에 관한 규칙을 바탕으로 해커톤 시연용으로 합성한 문서. 실제 사업장 표준서가 아니며 협력사명은 가상이다.
- 적용 작업: P24 출선장 개조: 탕도·집진 후드·개공기·머드건 (기준 일정 작업 하나에만 적용하는 작업별 표준서)

## 작업 개요

- 작업ID: P24
- 협력사(가상): 가상-주상K · 공종: 토목+기계+축로
- 구역: CASTHOUSE 주상·출선장(cast house)
- 기준 일정(가정값): 2026-11-22 ~ 2027-03-07 (D10~D115)
- 위험 작업 유형: 화기, 중량물
- 위험 분류 코드(시행령 제53조의2): 1호 화재·폭발, 3호 충돌(양중기·차량), 5호 낙하·비래
- 필요 허가: 화기,중장비
- 선행 작업: P06

## 적용하는 공통 표준서

- SOP-01 화기작업
- SOP-03 중량물 인양(크레인)

## 필수 단계

1. 작업허가서(화기·중장비) 발급
2. 작업 전 가스 측정·가연물 제거 (탕도 내화물 잔류 유분)
3. 화재감시자 배치·소화기 비치
4. 후드·머드건 인양 신호수 지정·줄걸이 점검
5. 상부 인양 일정 확인 후 하부 작업 착수 (인양 시간대 작업 중지)
6. 차량·장비 반입 유도자 배치
7. 작업 종료 후 30분 화재감시
8. 허가서 반납

## 판정에 쓰는 기준

- 계획서 절차에 3·5 단계가 없으면 F8 "필수 단계 누락" → F2 결함.
- 링블록 인양(P17) 경로 아래 작업은 R18(금지) — 시연 S3
- 출선(P07) 중 주상 작업은 R12(금지), 차량 반입은 R21

## 작업 금지·출입 제한

- 상부 인양(P17·P15) 시간대 CASTHOUSE 작업 중지·출입 금지(R18)
- 출선(P07) 시간대(≤24h) 주상 전면 통제(R12)

## 근거 조문

- 산업안전보건기준에 관한 규칙 제146조①4호, 제241조, 제38조①2호
- 시행령 제53조의2 1·3·5호
