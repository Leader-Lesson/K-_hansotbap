# SOP-P24 출선장 개조: 탕도·집진 후드·개공기·머드건 작업표준 — 합성

- 출처: KOSHA GUIDE·산업안전보건기준에 관한 규칙을 바탕으로 해커톤 시연용으로 합성한 문서. 실제 사업장 표준서가 아니며 협력사명은 가상이다.
- 적용 작업: P24 출선장 개조: 탕도·집진 후드·개공기·머드건 (기준 일정 작업 하나에만 적용하는 작업별 표준서)
- 문서번호 SOP-P24 · 개정 1 · 제정(가정) 2026-11-09 · 관리 부서: 원청 안전환경팀(가상) · 적용 현장: 광양 2고로 2차 개수(합성)

## 1. 목적과 적용 범위

- 목적: 주상(출선장)에서 탕도 내화물 교체, 집진 후드 교체, 개공기·머드건 설치를 넉 달 가까이 이어 가는 화기·중량물 작업에서, 탕도 잔류 유분·가연물 화재, 후드·머드건 인양 중 낙하, 상부 대형 인양(P17 링블록) 경로 아래 작업, 반입 차량과 보행자 충돌을 막는다.
- 적용 범위: 탕도 구 내화물 해체·신설, 집진 후드 절단·교체, 개공기·머드건 기초·본체 설치, 자재·장비 반입, 종료 인계까지.
- 적용 제외: 잔선구 출선(P07, SOP-P07), 슬래그 수재설비(P28, SOP-P28), 링블록 인양 자체(P17, SOP-P17).

## 2. 작업 개요

- 작업ID: P24
- 협력사(가상): 가상-주상K · 공종: 토목+기계+축로
- 구역: CASTHOUSE 주상·출선장(cast house) — 노저 외곽 바닥, 위로 SHELL·TUYERE가 바로 있다
- 기준 일정(가정값): 2026-11-22 ~ 2027-03-07 (D10~D115)
- 위험 작업 유형: 화기, 중량물
- 위험 분류 코드(시행령 제53조의2): 1호 화재·폭발, 3호 충돌(양중기·차량), 5호 낙하·비래
- 필요 허가: 화기,중장비
- 선행 작업: P06 (에너지 격리 LOTO)

## 3. 위험 요인과 예상 사고

- 화재·폭발: 탕도 내화물에 밴 유분·타르, 머드건 유압유, 집진 덕트 안 분진에 절단 불티가 붙는다. 바로 위 TUYERE 풍구 레벨 가스 라인(P34)이 열려 있으면 가스에 닿는다.
- 낙하·비래: 집진 후드·머드건 본체(수 톤) 인양 중 줄걸이 이탈. 위에서 링블록(P17)·구 철피 블록(P15)을 인양할 때 주상은 인양 경로 바로 아래다(시연 S3). 풍구 레벨 용접 불티도 떨어진다.
- 충돌: 자재 트레일러·지게차와 주상 보행자, 크레인 선회 반경 안 인원.
- 고온: 출선(P07) 시간대 용융물 비산, 살수(P08) 수증기.

## 4. 투입 인원과 역할 (기준 16명, 계획서 인원과 맞춘다)

- 작업책임자 1명: 허가서 2종, 상부 인양 일정 확인(5단계), 유도자·감시자 지정
- 화재감시자 1명: 절단·용접 중 상주, 종료 후 30분 감시, 소화기 관리
- 가스측정 담당 1명(작업책임자 겸임 가능): 탕도 내부·후드 안 LEL 측정
- 신호수 2명: 후드·머드건 인양 신호, 인양 경로 하부 통제
- 유도자 1명: 트레일러·지게차 진출입 유도, 보행로 분리
- 토목·축로공 5명: 탕도 해체·내화물 신설, 기초 콘크리트
- 기계 설치공 3명: 개공기·머드건 설치, 후드 교체
- 용접·절단공 2명: 후드 절단, 브래킷 용접(자격 보유)

## 5. 투입 장비·자재·보호구

- 장비: 크롤러 크레인 1대, 지게차 1대, 트레일러(자재 반입), 체인블록 5t 2대, 용접기 2대, 가스 용기 랙(산소절단기), 복합 가스측정기 2대, 고소작업대 1대, 조명탑(야간), 풍속계
- 자재: 개공기 부품·머드건 본체, 집진 후드·덕트, 탕도 내화물(내화벽돌 팔레트·캐스터블), 불티비산방지포, 소화기 4대, 바리케이드·보행로 표지
- 보호구: 안전모·안전화·보안경, 용접 보안면·방열 장갑, 내화복(출선 통제 시간대 인접 작업), 방진마스크, 무전기

## 6. 작업 순서 (상세)

1. 작업허가서(화기·중장비) 발급 — 작업책임자가 두 허가를 받고 번호를 서로 적는다(R29). 허가서에 절단·용접 위치, 인양 부품·중량, 차량 반입 시간을 적고 주상 입구에 게시한다. 하루 8시간을 넘기면 재발급한다(R28). 확인: 허가서 번호 기록.
2. 작업 전 가스 측정·가연물 제거 (탕도 내화물 잔류 유분) — 절단·용접 전 탕도 내부·후드 안·호흡 높이에서 LEL 10% 미만을 확인한다. 반경 11m 안 유분·타르·유압유·분진을 치우거나 방화포로 덮는다. 위 TUYERE 가스 라인 작업(P34)과 겹치면 화기를 하지 않는다(R04). 확인: 측정값·시각·제거 내용 기록.
3. 화재감시자 배치·소화기 비치 — 감시자가 절단·용접 중 상주하고 소화기 2대 이상을 손 닿는 곳에 둔다. 풍구 레벨(위) 작업 불티가 주상으로 떨어지는지도 본다. 확인: 감시자 이름을 허가서에 기재.
4. 후드·머드건 인양 신호수 지정·줄걸이 점검 — 인양물 중량을 도면·명판으로 확인하고 줄걸이 용구·크레인 정격을 대조한다. 신호수 2명과 무전 신호를 통일하고 인양 경로 아래를 막는다. 풍속 10m/s 이상이면 중지. 확인: 점검표·인양 시간대 기록.
5. 상부 인양 일정 확인 후 하부 작업 착수 (인양 시간대 작업 중지) — 매일 아침 대형 인양(가상-양중C P17, 가상-철구B P15) 시간대를 확인하고 그 시간에는 주상 작업을 멈추고 인원을 빼낸다(R18, 시연 S3). 출선(P07) 통제 시간대도 같다(R12). 확인: 확인 결과를 작업일지에 서명.
6. 차량·장비 반입 유도자 배치 — 트레일러·지게차 진출입 때 유도자가 앞장서고, 보행로는 바리케이드로 분리한다. 후진 때는 경보음·유도자 수신호. 확인: 반입 시각·유도자 이름 기록.
7. 작업 종료 후 30분 화재감시 — 절단·용접이 끝난 뒤 30분 동안 감시자가 자리를 지키며 잔불을 확인한다. 탕도 내부는 손전등으로 다시 본다. 확인: 감시 종료 시각 기록.
8. 허가서 반납 — 허가서 2종을 반납하고 다음 날 작업 범위를 원청 안전환경팀에 알린다. 개공기·머드건 설치 완료 때 원청 설비 담당에게 인계한다.

## 적용하는 공통 표준서

- SOP-01 화기작업
- SOP-03 중량물 인양(크레인)

## 필수 단계

1. 작업허가서(화기·중장비) 발급
2. 작업 전 가스 측정·가연물 제거 (탕도 내화물 잔류 유분)
3. 화재감시자 배치·소화기 비치
4. 후드·머드건 인양 신호수 지정·줄걸이 점검
5. 상부 인양 일정 확인 후 하부 작업 착수 (인양 시간대 작업 중지)
6. 차량·장비 반입 유도자 배치
7. 작업 종료 후 30분 화재감시
8. 허가서 반납

## 판정에 쓰는 기준

- 계획서 절차에 3·5 단계가 없으면 F8 "필수 단계 누락" → F2 결함.
- 핵심 단계를 3·5로 고른 이유: 둘 다 빠지면 바로 사망·중대사고로 이어진다. 3(화재감시자)은 유분이 밴 탕도에서 불티가 번지는 것을 바로 잡는 사람이고, 5(상부 인양 시간대 작업 중지)는 수백~천 t 링블록이 머리 위를 지나는 동안 주상에 사람이 없게 하는 유일한 장치다(시연 S3). 1·2·4·6·7·8은 공통 표준서 SOP-01·03이나 상대 작업(P17·P15) 표준서에서 다시 걸린다.
- 링블록 인양(P17) 경로 아래 작업은 R18(금지) — 시연 S3
- 출선(P07) 중 주상 작업은 R12(금지), 차량 반입은 R21

## 작업 금지·출입 제한

- 상부 인양(P17·P15) 시간대 CASTHOUSE 작업 중지·출입 금지(R18)
- 출선(P07) 시간대(≤24h) 주상 전면 통제(R12)
- 절단·용접 중 반경 11m 안 유류·도장 작업 금지(R01), 위 TUYERE 가스 개방(P34)과 겹침 금지(R04)
- 차량 반입 통로 보행 금지, 유도자 없이 후진 금지(R21)

## 비상 조치

- 화재: 소화기 초기 진화, 유압유 화재는 분말 소화기, 진화 안 되면 대피·원청 소방 연락, 위 가스 라인 작업자에게 알림
- 상부 낙하물·인양물 낙하: 주상 전원 대피, 크레인 정지 요청, 원청 상황실 보고
- 차량 충돌·협착: 차량 정지·시동 끄기, 구조 뒤 119·원청 구급 연락
- 출선·살수 시간대 고온 비산: 통제 구역 밖으로 즉시 철수

## 기록·보관
