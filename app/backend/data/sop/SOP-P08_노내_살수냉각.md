# SOP-P08 노내 살수 냉각(quench) 작업표준 — 합성

- 출처: KOSHA GUIDE·산업안전보건기준에 관한 규칙을 바탕으로 해커톤 시연용으로 합성한 문서. 실제 사업장 표준서가 아니며 협력사명은 가상이다.
- 적용 작업: P08 노내 살수 냉각(quench) (기준 일정 작업 하나에만 적용하는 작업별 표준서)
- 문서번호 SOP-P08 · 개정 1 · 제정(가정) 2026-11-09 · 관리 부서: 원청 안전환경팀(가상) · 적용 현장: 광양 2고로 2차 개수(합성)

## 1. 목적과 적용 범위

- 목적: 출선이 끝난 노 안에 물을 뿌려 장입물·내화물을 식히는 일주일 동안, 고온 수증기 분출 화상, 수증기 폭발, 냉각이 덜 된 상태에서 들어간 사람의 화상·질식을 막고, 굴착(P12)이 시작해도 되는 온도·가스 조건을 수치로 넘긴다.
- 적용 범위: 출선 완료 확인, 살수 노즐·배관 설치 점검, 노체 주변·노저 하부 통제, 노정 개구부 증기 배출, 온도 연속 측정, 냉각 완료 판정, 살수 후 가스 측정·인계까지. 원청 직영 작업이지만 노체 주변 협력사 출입을 넓게 막는 구간이라 표준서를 둔다.
- 적용 제외: 잔선구 출선(P07, SOP-P07), 노내 굴착(P12, SOP-P12), 노정 해체(P09)는 별도 표준서를 따른다.

## 2. 작업 개요

- 작업ID: P08
- 협력사(가상): 원청-제선 · 공종: 원청+살수
- 구역: STACK 노흉(shaft)
- 기준 일정(가정값): 2026-11-14 ~ 2026-11-20 (D2~D8)
- 위험 작업 유형: 밀폐공간
- 위험 분류 코드(시행령 제53조의2): 8호 질식·중독, 기타(방사선·고온수증기·고압수)
- 필요 허가: 밀폐공간
- 선행 작업: P07

## 3. 위험 요인과 예상 사고

- 고온 수증기: 물이 수백 도의 장입물에 닿으면 수증기가 노정 개구부·풍구 개구부·잔선구로 뿜어 나온다. 노체 주변·노저 하부에 있던 사람이 화상을 입는다. 수증기 위험의 공식 출처는 아직 확보하지 못했다[확인].
- 수증기 폭발: 출선이 덜 끝나 노저에 용융 잔선이 남은 상태에서 물이 닿으면 폭발적으로 끓는다(R13). 그래서 출선 완료 서명이 첫 단계다.
- 질식·중독: 살수 뒤 노 안은 수증기·CO·수소가 섞인 공기다. 냉각 완료 전에 들어가면 산소 부족·CO 중독, 바닥은 뜨겁다.
- 고압수: 살수 배관 파열·호스 이탈로 고압수가 튄다.
- 타 업체 진입: 종풍 직후라 해체(P09·P11)·주상 개조(P24) 협력사가 노체 주변으로 들어오려 한다(R14).

## 4. 투입 인원과 역할 (기준 8명, 계획서 인원과 맞춘다)

- 살수 책임자(원청 제선) 1명: 출선 완료 확인, 살수 순서·유량 결정, 냉각 완료 판정, P12 인계
- 살수 운전원 2명(교대): 노즐·밸브 조작, 유량·압력 감시
- 온도·가스 측정 담당 1명: 노내 온도 연속 측정 기록, 살수 후 O2·CO 측정
- 배관 담당 2명: 살수 노즐·배관 설치 점검, 누수·파열 대응
- 출입 통제원 2명: 노체 주변·노저 하부·노정 계단 바리케이드, 타 업체 진입 차단

## 5. 투입 장비·자재·보호구

- 장비: 살수 노즐·배관·펌프(노정 개구부 삽입형), 노내 온도계(열전대·방사 온도계) 다점, 복합 가스측정기(O2·CO·LEL) 2대, 환기팬(살수 후 가스 측정 전 환기), 풍향계, 무전기, 조명탑
- 자재: 바리케이드·안전띠·출입 금지 표지(노체 주변·노저 하부·노정 계단), 증기 배출 경로 확보용 개구부 덮개 제거 공구, 측정 결과 게시판
- 보호구: 안전모·안전화·보안경, 방열복·방열 장갑·안면보호구(노정·개구부 접근자), 휴대용 CO 경보기(전원), 공기호흡기(살수 후 첫 진입 점검자)

## 6. 작업 순서 (상세)

1. 출선(P07) 완료 확인 서명 후 살수 착수 — 살수 책임자가 출선 협력사(가상-출선D) 작업책임자의 "출선 완료·살수 착수 가능" 서명을 받고 노저에 용융 잔선이 더 나오지 않음을 확인한 뒤에만 물을 튼다(R13). 확인: 인계 서명지 보관.
2. 살수 노즐·배관 설치 상태 점검 — 노정 개구부에 넣은 노즐 위치·고정, 배관 연결부·호스 결속, 펌프 압력을 점검한다. 호스 이탈 방지 와이어를 건다. 확인: 점검표.
3. 노체 주변·노저 하부 출입 금지 (고온 수증기 분출) — 살수 시작 전 노정(TOP)·노흉~노저(노 내부 전체)·풍구 레벨(TUYERE)·주상(CASTHOUSE) 바리케이드를 치고 통제원이 지킨다. 수증기가 나오는 개구부(노정·풍구·잔선구) 주변은 특히 넓게 막는다(R14). 확인: 통제 범위 사진·통제원 이름.
4. 노정 개구부 증기 배출 경로 확보 — 노정 개구부·블리더 쪽 덮개를 열어 수증기가 위로 빠지게 하고, 배출 방향 풍하측 플랫폼을 비운다. 확인: 개구 상태·풍향 기록.
5. 노내 온도 연속 측정·기록 — 노내 여러 높이의 온도를 연속 측정해 시간별로 기록한다. 온도가 다시 오르면(잔열 재가열) 살수를 늘리고 진입 판단을 미룬다. 확인: 온도 기록지.
6. 냉각 완료 온도 기준 확인 후 출입 허용 — 원청 제선이 정한 냉각 완료 온도 기준 [팀 설정값] 아래로 모든 측정점이 내려가고 일정 시간 유지되면 살수 책임자가 완료를 판정한다. 그 전에는 누구도 노 안으로 들어가지 않는다. 확인: 판정 서명·시각.
7. 살수 후 산소·유해가스 측정 (후속 굴착 P12 인계) — 환기팬을 돌린 뒤 노 내부 상·중·하에서 O2 18~23.5%, CO 30ppm 미만, LEL 10% 미만을 확인한다. 공기호흡기를 쓴 점검자가 첫 진입해 바닥 온도·잔수를 본다. 측정값과 함께 굴착 협력사(가상-해체G)에 인계한다. 확인: 측정값·인계 서명지.

## 적용하는 공통 표준서

- SOP-02 밀폐공간 출입작업

## 필수 단계

1. 출선(P07) 완료 확인 서명 후 살수 착수
2. 살수 노즐·배관 설치 상태 점검
3. 노체 주변·노저 하부 출입 금지 (고온 수증기 분출)
4. 노정 개구부 증기 배출 경로 확보
5. 노내 온도 연속 측정·기록
6. 냉각 완료 온도 기준 확인 후 출입 허용
7. 살수 후 산소·유해가스 측정 (후속 굴착 P12 인계)

## 판정에 쓰는 기준

- 계획서 절차에 1·3·6 단계가 없으면 F8 "필수 단계 누락" → F2 결함.
- 핵심 단계를 1·3·6으로 고른 이유: 살수의 사망 사고는 순서와 출입에서 난다. 1(출선 완료 서명 후 착수)은 용융 잔선 위에 물을 뿌리는 수증기 폭발(R13)을 막는 순서 확인이고, 3(노체 주변·노저 하부 출입 금지)은 수증기가 뿜어 나오는 일주일 동안 다른 협력사가 노체에 접근하지 못하게 하며(R14), 6(냉각 완료 기준 확인 후 출입 허용)은 뜨겁고 산소 없는 노 안에 사람이 들어가는 시점을 수치로 묶는다. 2·4·5·7은 운전 기록·인계 절차에서 다시 걸린다.
- 출선 완료 전 살수는 R13(금지, 순서)
- 살수 중 노체 주변·노저 하부 작업은 R14(금지)

## 작업 금지·출입 제한

- 살수 중 STACK·BELLY_BOSH·TUYERE·HEARTH·CASTHOUSE 출입 금지(R14)
- 냉각 완료 온도 확인 전 노 내부 진입 금지
- 출선 완료 인계 서명 전 살수 착수 금지(R13)
- 살수 기간 노정(TOP) 개구부 주변 해체 작업(P09) 착수 금지 — 수증기 배출 경로

## 3D 연결 (출입 제한 데이터)

- 구역: STACK(노흉)이 살수 위치이고 영향 범위는 노 내부 전체(STACK·BELLY_BOSH·TUYERE·HEARTH)와 CASTHOUSE, 수증기 배출구인 TOP. 방위 ALL
- 제한 1: 구역 STACK·BELLY_BOSH·TUYERE·HEARTH·CASTHOUSE, 방위 ALL, 종류 ENTRY_BAN, 대상 OTHERS(전원), 적용 시점 DURING(살수 기간 전체), 범위 구역 전체, 규칙 R14, 3D 표시 TAPE + SIGN「노내 살수 중 · 고온 수증기 · 출입 금지」
- 제한 2: 구역 TOP, 방위 ALL, 종류 WORK_STOP(노정 해체 착수 보류), 대상 P09, 적용 시점 STEP:4(증기 배출 중), 범위 개구부 주변 [팀 설정값], 규칙 R14, 3D 표시 CONE + SIGN「증기 배출구」
- 제한 3: 구역 STACK·BELLY_BOSH·TUYERE·HEARTH(노 내부), 방위 ALL, 종류 ENTRY_BAN, 대상 OTHERS(P12 굴착 포함), 적용 시점 UNTIL_HANDOVER(6단계 냉각 완료 판정·7단계 측정 인계 서명 전까지), 범위 노 내부 전체, 규칙 R14, 3D 표시 BAR_RED(P12 작업 막대 금지색)
- 착수 조건: 구역 HEARTH, 종류 WORK_STOP(이 작업 자체), 대상 P08, 적용 시점 UNTIL_HANDOVER(P07 출선 완료 서명 전까지), 규칙 R13, 3D 표시 BAR_RED(P08 작업 막대 금지색)

## 비상 조치

- 수증기 급분출·폭발음: 살수 즉시 중단, 노체 주변 전원 대피, 원청 상황실 보고, 출선 잔류 여부 재확인 뒤 재개 판단
- 화상자 발생: 냉각 뒤 원청 구급·119 연락, 통제 범위 확대
- 배관 파열·호스 이탈: 펌프 정지, 접근 금지, 압력 0 확인 뒤 복구
- 가스 경보(살수 후 진입 점검 중): 즉시 퇴출, 환기 연장 뒤 재측정

## 기록·보관

- 출선 완료 인계 서명지, 배관 점검표, 통제 범위 기록, 온도 연속 기록, 냉각 완료 판정 서명, 살수 후 가스 측정·P12 인계 서명지를 원청 안전환경팀이 공사 종료 후 3년 보관(가정)
- 인계 서명지 두 장(P07→P08, P08→P12)은 R13·R14 순서 판정의 근거 문서로 F5 이력에 남긴다
