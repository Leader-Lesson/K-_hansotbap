# SOP-P06 에너지 격리(LOTO): 송풍·냉각수·질소·전기 작업표준 — 합성

- 출처: KOSHA GUIDE·산업안전보건기준에 관한 규칙을 바탕으로 해커톤 시연용으로 합성한 문서. 실제 사업장 표준서가 아니며 협력사명은 가상이다.
- 적용 작업: P06 에너지 격리(LOTO): 송풍·냉각수·질소·전기 (기준 일정 작업 하나에만 적용하는 작업별 표준서)
- 문서번호 SOP-P06 · 개정 1 · 제정(가정) 2026-11-09 · 관리 부서: 원청 안전환경팀(가상) · 적용 현장: 광양 2고로 2차 개수(합성)

## 1. 목적과 적용 범위

- 목적: 해체 협력사가 노체에 손대기 전에 송풍·냉각수·질소·전기 네 에너지원을 끊고 잠가, 이후 넉 달 동안 누군가 밸브를 열거나 차단기를 올려 작업 중인 사람이 끼이거나 질식·감전하는 일을 막는다. 격리 목록 하나로 모든 협력사가 같은 상태를 보게 한다.
- 적용 범위: 격리 대상 목록 작성, 정전 허가, 차단·잠금·꼬리표, 잔류 에너지 방출 확인, 시운전 시도, 목록 공유, 해제 조건 관리(관련 허가 전부 반납 뒤). 공사 전 기간에 걸친 상태 관리 작업이다.
- 적용 제외: 가스 계통 차단·퍼지 자체(P05, SOP-P05), 개별 배관 연결·기밀시험(SOP-04), 전기·계장 설치(P29)는 별도 표준서를 따른다.

## 2. 작업 개요

- 작업ID: P06
- 협력사(가상): 원청-정비 · 공종: 원청 정비+전기
- 구역: ALL 전 구역
- 기준 일정(가정값): 2026-11-13 ~ 2026-11-15 (D1~D3)
- 위험 작업 유형: 가스계통
- 위험 분류 코드(시행령 제53조의2): 2호 끼임, 8호 질식·중독
- 필요 허가: 정전
- 선행 작업: P04

## 3. 위험 요인과 예상 사고

- 끼임·동력 기동: 격리되지 않은 장입 컨베이어·권상기·송풍기가 내부 작업 중 움직인다. 시운전 시도 없이 "차단했다"고 믿은 회로가 살아 있다(R22).
- 질식: 질소 공급 밸브가 잠기지 않았거나 꼬리표만 달려 있어 누군가 열면 노 내부·배관 안 작업자에게 질소가 들어간다(R07).
- 감전: 정전 허가 없이 차단기를 다루거나, 검전 없이 "정전됐다"고 보고 작업한다. 해제 때 회로에 남은 작업자(R23).
- 잔류 에너지: 냉각수 배관 잔압·고온수, 송풍 덕트 압력이 남아 플랜지를 열 때 분출한다.
- 해제 오류: 관련 허가가 다 반납되기 전 한 협력사 요청으로 해제해 다른 협력사 작업 구간에 통전·가압된다.

## 4. 투입 인원과 역할 (기준 6명, 계획서 인원과 맞춘다)

- 격리 책임자(원청 정비) 1명: 격리 목록 작성·승인, 해제 조건 판단, 협력사 공유
- 전기 담당(원청 전기, 자격 보유) 2명: 차단기 개방·잠금·검전, 정전 허가
- 기계 담당 2명: 송풍·냉각수·질소 밸브 폐쇄·잠금, 잔압 방출·배수, 시운전 시도 입회
- 기록·게시 담당 1명: 격리 목록 게시·배포, 꼬리표 번호 대장, 허가 반납 대조

## 5. 투입 장비·자재·보호구

- 장비: 검전기·절연 저항계, 압력계(잔압 확인), 복합 가스측정기(질소 라인 개방 시 O2), 무전기, 발전기(격리 후 가설 전원용)
- 자재: 잠금장치(밸브·차단기용)·다중 잠금 허브·개인 자물쇠, 꼬리표(번호·날짜·담당), 격리 목록 게시판, 케이블 릴(가설 전원)
- 보호구: 안전모·안전화·보안경, 절연 장갑·절연화(전기 담당), 방열 장갑(냉각수 배수), 휴대용 O2 경보기(질소 라인 작업)

## 6. 작업 순서 (상세)

1. 격리 대상 에너지원 목록 작성 (송풍·냉각수·질소·전기) — 격리 책임자가 계통도를 보고 송풍(열풍·냉풍), 냉각수(스테이브·풍구·냉각판), 질소(퍼지·실링), 전기(장입설비·권상·조명·계장) 별로 차단 지점·잠금 방법·확인 방법을 목록으로 만든다. 가스 계통은 P05 LOTO 번호를 그대로 옮겨 적는다. 확인: 목록 승인 서명.
2. 정전 작업허가서 발급 (회로·설비 ID 기재) — 전기 담당이 회로·설비 ID별로 정전 허가를 받는다. 활선 가능성이 있는 회로는 별도 표시한다. 확인: 허가서 번호 기록.
3. 차단기 개방·밸브 잠금 및 꼬리표 부착 (잠금 번호 기재) — 목록 순서대로 차단기를 열고 밸브를 닫은 뒤 잠금장치·꼬리표(번호·날짜·담당)를 건다. 여러 협력사가 걸리는 지점은 다중 잠금 허브를 쓴다. 잠금 번호를 목록에 적는다. 확인: 지점별 사진·번호.
4. 잔류 에너지 방출 확인 (압력 0 확인·검전) — 냉각수·송풍 배관은 드레인을 열어 압력계 0을 확인하고 배수한다. 전기 회로는 검전기로 무전압을 확인한다. 질소 라인은 개방 지점 O2를 잰다. 확인: 압력·검전 결과 기록.
5. 격리 상태 시운전 시도 (시동 불가 확인) — 잠근 상태에서 기동 버튼·밸브 개방을 시도해 움직이지 않음을 확인한다(설비 주변에 사람이 없는 상태에서). 움직이면 격리 지점을 다시 찾는다(R22). 확인: 시운전 시도 결과 기록.
6. 격리 목록 협력사 공유·게시 — 완성된 격리 목록(지점·번호·담당·해제 조건)을 현장 게시판과 허가 시스템에 올리고 모든 협력사 작업책임자에게 배포한다. 협력사는 자기 작업 전 이 목록과 대조한다(P11 2단계 등). 확인: 배포 수신 기록.
7. 해제 전 관련 허가서 전부 반납 확인 — 해제 요청이 오면 그 회로·배관에 걸린 모든 협력사 허가서가 반납됐는지 대장에서 대조한다. 하나라도 남아 있으면 해제하지 않는다(R23). 확인: 대조표 서명.
8. 해제 통전·가압 전 설비 주변 인원 철수 확인 — 해제 직전 설비·배관 주변과 내부에 사람이 없음을 눈으로 확인하고 주변 협력사에 통전·가압 시각을 알린 뒤 잠금을 푼다. 확인: 철수 확인·해제 시각·담당 기록.

## 적용하는 공통 표준서

- SOP-04 가스 배관 연결·기밀시험

## 필수 단계

1. 격리 대상 에너지원 목록 작성 (송풍·냉각수·질소·전기)
2. 정전 작업허가서 발급 (회로·설비 ID 기재)
3. 차단기 개방·밸브 잠금 및 꼬리표 부착 (잠금 번호 기재)
4. 잔류 에너지 방출 확인 (압력 0 확인·검전)
5. 격리 상태 시운전 시도 (시동 불가 확인)
6. 격리 목록 협력사 공유·게시
7. 해제 전 관련 허가서 전부 반납 확인
8. 해제 통전·가압 전 설비 주변 인원 철수 확인

## 판정에 쓰는 기준

- 계획서 절차에 3·4·7 단계가 없으면 F8 "필수 단계 누락" → F2 결함.
- 핵심 단계를 3·4·7로 고른 이유: 격리가 "실제로 끊겼는가"와 "함부로 다시 켜지지 않는가"를 보장하는 단계다. 3(잠금·꼬리표)이 없으면 차단은 말뿐이고 누구나 다시 열 수 있다. 4(잔압·검전)는 끊었다고 믿은 에너지가 남아 있는 감전·분출을 막는 유일한 확인이다. 7(해제 전 허가 전부 반납 확인)은 한 협력사 요청으로 다른 협력사 작업 구간에 통전·가압되는 사고(R23)를 막는다. 1·2·5·6·8은 허가·목록 절차에서 다시 걸린다.
- 관련 허가서 반납 전 LOTO 해제·통전이 있으면 R23(금지, 순서)
- 격리된 설비를 시운전하면서 내부 작업이 있으면 R22(금지)

## 작업 금지·출입 제한

- 격리 해제 시 그 회로·배관에 걸린 모든 협력사 작업 중지
- 관련 허가서가 반납되지 않은 설비는 통전·가압 금지(R23)
- 시운전 시도(5단계) 중 해당 설비 내부·접촉 작업 금지(R22)
- 격리 목록에 없는 밸브·차단기 조작 금지 — 협력사는 자기 잠금만 풀 수 있다

## 3D 연결 (출입 제한 데이터)

- 구역: ALL(전 구역). 3D는 구역 모델 없이 목록으로 표시하고, 격리 지점이 있는 구역(TUYERE 송풍·냉각수, TOP 장입설비 전기, DOWNCOMER 질소·가스, STOVE 열풍)에 제한을 나눠 건다
- 제한 1: 구역 = 격리 대상 설비 구역(TUYERE·TOP·DOWNCOMER·STOVE), 방위 SAME(설비 위치), 종류 WORK_STOP(내부·접촉 작업 중지), 대상 OTHERS, 적용 시점 STEP:5(시운전 시도 중), 범위 설비 주변 [팀 설정값], 규칙 R22, 3D 표시 SIGN「시운전 시도 중 · 접촉 금지」
- 제한 2: 구역 = 해제 대상 회로·배관이 지나는 구역, 방위 ALL, 종류 WORK_STOP(관련 협력사 작업 중지), 대상 그 계통에 허가가 걸린 작업 전부, 적용 시점 STEP:8(해제 통전·가압), 범위 계통 전체, 규칙 R23, 3D 표시 BAR_RED(미반납 허가 작업 막대 금지색) + BANNER「LOTO 해제 예정 · 허가 반납 확인」
- 제한 3: 구역 = 질소 격리 지점이 있는 DOWNCOMER·TUYERE, 방위 SAME, 종류 GAS_IN_BAN, 대상 OTHERS(노 내부·배관 내부 작업 P12~P22), 적용 시점 UNTIL_HANDOVER(격리 유지 기간 전체), 범위 계통 전체, 규칙 R07, 3D 표시 SIGN「질소 격리 중 · 밸브 조작 금지」

## 비상 조치

- 격리 설비 예기치 않은 기동·가압: 즉시 비상 정지, 내부·접촉 작업자 대피 확인, 격리 지점 재확인 뒤 재잠금, 원청 안전환경팀 보고
- 감전: 회로 차단 뒤 구조, 맨손 접촉 금지, 119·원청 구급 연락
- 잔압 분출·고온수 화상: 드레인 폐쇄, 화상자 냉각·원청 구급 연락
- 잠금장치 훼손·꼬리표 분실 발견: 해당 지점 재격리 전 그 계통 작업 전부 중지, 격리 책임자 보고
