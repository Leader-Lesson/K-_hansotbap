# SOP-P30 비계 설치·해체(노 내부·외부) 작업표준 — 합성

- 출처: KOSHA GUIDE·산업안전보건기준에 관한 규칙을 바탕으로 해커톤 시연용으로 합성한 문서. 실제 사업장 표준서가 아니며 협력사명은 가상이다.
- 적용 작업: P30 비계 설치·해체(노 내부·외부) (기준 일정 작업 하나에만 적용하는 작업별 표준서)

## 작업 개요

- 작업ID: P30
- 협력사(가상): 가상-비계N · 공종: 비계
- 구역: ALL 전 구역
- 기준 일정(가정값): 2026-11-15 ~ 2027-03-17 (D3~D125)
- 위험 작업 유형: 고소
- 위험 분류 코드(시행령 제53조의2): 4호 추락, 5호 낙하·비래, 7호 붕괴
- 필요 허가: 고소
- 선행 작업: P06

## 적용하는 공통 표준서

- 고소 작업은 공통 표준서 없음 — 규칙 제42조~제45조(추락 방지) 적용

## 필수 단계

1. 비계 조립도·작업계획 승인 (구간·일정)
2. 하부 출입통제 (관리감독자 배치, 설치·해체 구간)
3. 낙하물 방지망 설치 (10m 이내마다)
4. 안전대 부착설비 선행 설치
5. 작업발판 폭 40cm 이상·안전난간 설치
6. 노 내부 해체 시 산소농도 측정 후 입장·감시인 배치
7. 인접 인양·화기 작업 시간대 확인 (인양·용접 중 비계 작업 중지)
8. 설치 완료 검사·사용 표지 부착

## 판정에 쓰는 기준

- 계획서 절차에 2·3·4 단계가 없으면 F8 "필수 단계 누락" → F2 결함.
- 비계 설치·해체와 하부·인접 작업이 겹치면 R17(금지), 상부 해체 아래는 R16
- 링블록 인양(P17) 반경 안 비계는 R20(조건부), 철피 용접(P18) 아래 해체는 R03 — 시연 S7

## 작업 금지·출입 제한

- 비계 설치·해체 중 그 구역 하부·인접 타 업체 출입 금지(R17)
- 노흉 축조(P22) 완료 전 노흉 내부 비계 해체 금지
- 링블록 인양(P17) 시간대 SHELL 비계 작업 중지(R20)

## 근거 조문

- 산업안전보건기준에 관한 규칙 제14조, 제20조 13호, 제42조~제45조, 제56조~제62조(비계)
- 시행령 제53조의2 4·5·7호, BlueScope 2026-10-29 비계 설치 중 추락(공개 사례)
