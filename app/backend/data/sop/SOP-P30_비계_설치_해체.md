# SOP-P30 비계 설치·해체(노 내부·외부) 작업표준 — 합성

- 출처: KOSHA GUIDE·산업안전보건기준에 관한 규칙을 바탕으로 해커톤 시연용으로 합성한 문서. 실제 사업장 표준서가 아니며 협력사명은 가상이다.
- 적용 작업: P30 비계 설치·해체(노 내부·외부) (기준 일정 작업 하나에만 적용하는 작업별 표준서)
- 문서번호 SOP-P30 · 개정 1 · 제정(가정) 2026-11-09 · 관리 부서: 원청 안전환경팀(가상) · 적용 현장: 광양 2고로 2차 개수(합성)

## 1. 목적과 적용 범위

- 목적: 공사 기간 내내 노 내부·철피 외부·열풍로·주상에서 비계를 세우고 허무는 고소 작업에서, 비계 작업자 추락, 아래로 떨어지는 부재·클램프 낙하, 과적재·지지 불량 붕괴를 막고, 인접 인양·용접 작업과 같은 시간에 겹치는 일을 막는다(시연 S7).
- 적용 범위: 비계 조립도 승인, 설치(기초·기둥·발판·난간·방지망), 사용 중 점검, 해체·반출, 노 내부 비계의 밀폐공간 절차까지.
- 적용 제외: 달비계(서스펜디드 플랫폼) 운용 — 각 작업 표준서(P22·P26 등), 노내 호이스트(P31, SOP-P31).

## 2. 작업 개요

- 작업ID: P30
- 협력사(가상): 가상-비계N · 공종: 비계
- 구역: ALL 전 구역 — 구간마다 STACK·BELLY_BOSH 노 내부, SHELL 철피 외부, STOVE, CASTHOUSE
- 기준 일정(가정값): 2026-11-15 ~ 2027-03-17 (D3~D125)
- 위험 작업 유형: 고소
- 위험 분류 코드(시행령 제53조의2): 4호 추락, 5호 낙하·비래, 7호 붕괴
- 필요 허가: 고소
- 선행 작업: P06 (에너지 격리 LOTO)

## 3. 위험 요인과 예상 사고

- 추락: 난간·발판이 아직 없는 설치 초기, 발판을 먼저 떼어 낸 해체 끝 무렵이 가장 위험하다. 안전대 부착설비 없이 올라간다(BlueScope 2026-10-29 공개 사례, 비계 설치 중 추락).
- 낙하·비래: 파이프·클램프·발판을 던져 내리다 아래 작업자를 맞힌다. 노 내부 비계는 수직 공동 바닥(HEARTH)까지 그대로 떨어진다.
- 붕괴: 벽 이음 부족, 과적재(내화벽돌 팔레트를 비계 위에 쌓음), 기초 침하.
- 인접 작업 겹침: 철피 용접(P18) 불티가 아래 비계 해체 작업자에게 떨어진다(시연 S7). 링블록 인양(P17) 경로 안 비계 작업.
- 질식: 노 내부 비계 해체는 밀폐공간이다. 축조 완료 전 해체하면 축조 인원과 섞인다.

## 4. 투입 인원과 역할 (기준 12명, 계획서 인원과 맞춘다)

- 작업책임자(비계 관리감독자) 1명: 조립도 승인 신청, 하부 출입통제 지휘, 인접 작업 시간대 확인, 완료 검사
- 안전관리자 1명: 안전대 부착설비·발판·난간 점검, 노 내부 산소 측정
- 하부 통제·감시 2명: 설치·해체 구간 아래 출입 통제, 노 내부 작업 시 감시인
- 비계공 8명: 조립·해체(비계 기능 자격 보유), 부재 인양·하강

## 5. 투입 장비·자재·보호구

- 장비: 체인블록 1t 2대·윈치(부재 인양·하강), 산소·유해가스 측정기 1대(노 내부), 수평기·토크렌치, 작업등
- 자재: 비계 파이프·클램프·발판(폭 40cm 이상)·안전난간재, 낙하물 방지망·방호선반, 안전대 부착설비(수직 구명줄·와이어), 벽 이음재, 사용 표지·출입 금지 표지
- 보호구: 안전모(턱끈)·안전화·보안경, 안전대(2중 걸이), 공구 낙하 방지 끈, 무전기

## 6. 작업 순서 (상세)

1. 비계 조립도·작업계획 승인 (구간·일정) — 구간별 조립도(높이·폭·벽 이음·허용 적재 하중)와 설치·해체 일정을 원청 안전환경팀에 내고 승인을 받는다. 일정은 인접 작업(용접·인양·축조) 일정과 겹치지 않게 잡는다. 확인: 승인 번호·구간 기록.
2. 하부 출입통제 (관리감독자 배치, 설치·해체 구간) — 설치·해체 중 그 구간 아래와 인접 통로를 바리케이드로 막고 통제 인원이 선다. 노 내부 비계는 아래층 전체(BELLY_BOSH~HEARTH)를 막는다. 확인: 통제 구간·시각 기록.
3. 낙하물 방지망 설치 (10m 이내마다) — 높이 10m 이내마다 방지망 또는 방호선반을 설치하고 2m 이상 내민다. 부재는 던지지 않고 윈치·체인블록으로 내린다. 확인: 방지망 위치 점검표.
4. 안전대 부착설비 선행 설치 — 기둥을 세우기 전 수직 구명줄 또는 부착 와이어를 먼저 걸고, 비계공은 올라가는 순간부터 안전대를 건다. 해체 때는 마지막까지 남긴다. 확인: 부착설비 점검표·체결 확인.
5. 작업발판 폭 40cm 이상·안전난간 설치 — 발판은 폭 40cm 이상, 틈 3cm 이하로 깔고 상·중 난간과 발끝막이판을 둔다. 발판 위 적재는 승인 하중 이내(내화벽돌 팔레트 적재 금지). 확인: 발판·난간 점검표.
6. 노 내부 해체 시 산소농도 측정 후 입장·감시인 배치 — 노 내부 비계 해체 전 O2 18~23.5%, CO 30ppm 미만을 확인하고 감시인을 출입구에 둔다. 축조(P22) 완료·퇴출 서명 뒤에만 노흉 비계를 해체한다. 확인: 측정값·감시인·축조 완료 서명 확인.
7. 인접 인양·화기 작업 시간대 확인 (인양·용접 중 비계 작업 중지) — 매일 아침 링블록 인양(P17)·철피 용접(P18)·장입설비 인양(P23) 시간대를 확인하고 그 시간에는 해당 구간 비계 작업을 멈춘다(R03·R20, 시연 S7). 확인: 확인 결과를 작업일지에 서명.
8. 설치 완료 검사·사용 표지 부착 — 관리감독자가 조립도대로 되었는지 검사하고 "사용 가능" 표지(허용 하중·검사일)를 붙인다. 미완성 비계에는 "사용 금지" 표지. 확인: 검사표·표지 사진.

## 적용하는 공통 표준서

- 고소 작업은 공통 표준서 없음 — 규칙 제42조~제45조(추락 방지) 적용

## 필수 단계

1. 비계 조립도·작업계획 승인 (구간·일정)
2. 하부 출입통제 (관리감독자 배치, 설치·해체 구간)
3. 낙하물 방지망 설치 (10m 이내마다)
4. 안전대 부착설비 선행 설치
5. 작업발판 폭 40cm 이상·안전난간 설치
6. 노 내부 해체 시 산소농도 측정 후 입장·감시인 배치
7. 인접 인양·화기 작업 시간대 확인 (인양·용접 중 비계 작업 중지)
8. 설치 완료 검사·사용 표지 부착

## 판정에 쓰는 기준

- 계획서 절차에 2·3·4 단계가 없으면 F8 "필수 단계 누락" → F2 결함.
- 핵심 단계를 2·3·4로 고른 이유: 비계 사망 사고의 두 유형(추락·낙하)을 설치 첫 순간부터 막는 단계다. 4(부착설비 선행 설치)는 난간이 아직 없는 비계공 본인의 추락을, 2(하부 출입통제)·3(방지망)은 아래 타 업체 작업자가 부재에 맞는 사고를 막는다. 5·8은 완성 뒤 사용자 안전, 6은 SOP-02, 7은 상대 작업(P17·P18) 표준서에서 다시 걸린다.
- 비계 설치·해체와 하부·인접 작업이 겹치면 R17(금지), 상부 해체 아래는 R16
- 링블록 인양(P17) 반경 안 비계는 R20(조건부), 철피 용접(P18) 아래 해체는 R03 — 시연 S7

## 작업 금지·출입 제한

- 비계 설치·해체 중 그 구역 하부·인접 타 업체 출입 금지(R17)
- 노흉 축조(P22) 완료 전 노흉 내부 비계 해체 금지
- 링블록 인양(P17) 시간대 SHELL 비계 작업 중지(R20)
- 철피 용접(P18) 중 그 아래 SHELL 비계 해체 금지(R03)

## 비상 조치

- 추락자 발생: 작업 중지, 매달린 상태면 즉시 구조(매달림 증후군), 아래 출입 차단, 119·원청 구급 연락
- 부재 낙하·하부 부상자: 작업 중지, 하부 통제 인원이 구조 요청, 원청 상황실 보고
- 비계 흔들림·침하: 전원 하강, 사용 금지 표지, 관리감독자 점검 뒤 보강
- 노 내부 산소 경보: 전원 퇴출, 감시인이 인원 확인, 재측정 정상 뒤 재진입

## 기록·보관

- 조립도 승인서, 하부 통제 기록, 방지망·부착설비·발판 점검표, 노 내부 산소 측정 기록, 인접 작업 시간대 확인 서명(7단계), 완료 검사표를 원청 안전환경팀이 공사 종료 후 3년 보관(가정)
- 인접 작업 시간대 확인 서명은 산업안전보건법 제64조(혼재작업 조정) 이행 기록이며 F5 이력에 남긴다
