# SOP-P14 노흉·노복 내화물·스테이브 해체 작업표준 — 합성

- 출처: KOSHA GUIDE·산업안전보건기준에 관한 규칙을 바탕으로 해커톤 시연용으로 합성한 문서. 실제 사업장 표준서가 아니며 협력사명은 가상이다.
- 적용 작업: P14 노흉·노복 내화물·스테이브 해체 (기준 일정 작업 하나에만 적용하는 작업별 표준서)
- 문서번호 SOP-P14 · 개정 1 · 제정(가정) 2026-11-09 · 관리 부서: 원청 안전환경팀(가상) · 적용 현장: 광양 2고로 2차 개수(합성)

## 1. 목적과 적용 범위

- 목적: 노 안에서 위(노흉)부터 아래(노복)로 내려오며 낡은 내화물을 깨고 스테이브(냉각 패널)를 떼어 내는 한 달 동안, 해체물이 아래층 작업자에게 떨어지는 낙하, 부분 해체 벽면의 붕괴, 달비계 추락, 밀폐공간 산소 결핍을 막고, 철피 절단(P15)이 시작해도 되는 "내측 해체 완료" 상태를 넘긴다.
- 적용 범위: 밀폐공간 허가·측정, 상부 해체 시 하부 통제·방호선반, 감시인·명부, 달비계·안전대, 스테이브 탈거 인양, 붕괴 구간 접근 금지, 잔재 투하 구간 노저 출입 금지, 퇴출·반납까지. 노저 발파(P13)와 같은 노 안에서 겹치는 기간이 있다.
- 적용 제외: 노저 잔선 발파(P13, SOP-P13), 노저 해체·청소(P16), 비계 설치·해체 자체(P30, SOP-P30), 철피 절단(P15, SOP-P15)은 별도 표준서를 따른다.

## 2. 작업 개요

- 작업ID: P14
- 협력사(가상): 가상-내화H · 공종: 내화물 해체
- 구역: BELLY_BOSH 노복·조안(belly/bosh)
- 기준 일정(가정값): 2026-11-27 ~ 2026-12-22 (D15~D40)
- 위험 작업 유형: 밀폐공간, 고소
- 위험 분류 코드(시행령 제53조의2): 5호 낙하·비래, 7호 붕괴, 8호 질식·중독
- 필요 허가: 밀폐공간,고소
- 선행 작업: P12

## 3. 위험 요인과 예상 사고

- 낙하·비래: 깬 내화물 덩어리·볼트·스테이브 조각이 노 안을 그대로 떨어진다. 아래층 노저(P13 발파·P16 청소)에 사람이 있으면 피할 데가 없다. 방호선반·출입 금지 없이 위아래 동시 작업은 금지다(R16).
- 붕괴: 반만 해체된 내화물 벽면은 지지력을 잃고 한꺼번에 무너진다. 벽면 아래 서 있던 작업자가 깔린다.
- 추락: 달비계·작업발판에서 안전대 없이 해머·브레이커를 휘두른다. 스테이브를 뗀 자리의 개구부.
- 질식·중독: 노 안 분진·산소 결핍, 아래 노저 발파(P13) 가스가 올라온다.
- 스테이브 탈거: 수백 kg 스테이브를 떼어 매달 때 줄걸이 불량·회전.

## 4. 투입 인원과 역할 (기준 28명, 계획서 인원과 맞춘다)

- 작업책임자 1명: 밀폐공간·고소 허가, 해체 순서(위→아래)·붕괴 구간 지정, P15 인계 서명
- 안전관리자(측정 담당) 1명: 산소·CO·분진 측정, 환기팬 관리
- 감시인 2명: 노정 개구부·풍구 레벨 출입구 상주, 명부 기록
- 해체 작업자 16명: 브레이커·해머로 내화물 해체, 잔재 정리(달비계 위·발판 위)
- 스테이브 탈거·줄걸이 4명: 볼트 해체, 스테이브 매달기·하강
- 신호수 2명: 노내 호이스트 인양 신호, 잔재 투하 신호
- 하부 통제원·방호선반 담당 2명: 아래층 출입 통제, 방호선반·방지망 설치 상태 확인

## 5. 투입 장비·자재·보호구

- 장비: 달비계(서스펜디드 플랫폼) 여러 조, 비계·작업발판(P30 설치), 노내 호이스트(P31 가상-양중C 운영), 체인블록(스테이브 탈거), 브레이커·착암기, 환기팬 2대(송기 덕트), 산소·CO 복합측정기 3대, 작업등, 무전기
- 구조장비: 공기호흡기 2조, 삼각대·구조용 윈치, 들것
- 자재: 방호선반·낙하물 방지망(10m 이내마다, 2m 이상 돌출, 20~30°, 규칙 제14조), 잔재 투하 슈트, 와이어로프·샤클, 붕괴 위험 구간 표지·안전띠, 출입자 명부
- 보호구: 안전모·안전화·보안경, 안전대(2중 걸이), 방진마스크, 귀마개, 휴대용 산소·CO 경보기(작업조마다), 방진 보안경·안면보호구(브레이커)

## 6. 작업 순서 (상세)

1. 밀폐공간 작업허가서 발급 — 작업책임자가 P12 굴착 퇴출·인계 기록을 확인하고 밀폐공간·고소 허가를 받는다. 허가서에 해체 단수·높이, 인원, 감시인, 측정 계획, 아래층 작업(P13·P16) 시간대를 적는다. 확인: 허가서 번호.
2. 작업 전 산소·유해가스 측정 후 진입 — 진입 전 노 내부 상·중·하에서 O2 18~23.5%, CO 30ppm 미만, LEL 10% 미만을 확인한다. 노저 발파(P13) 뒤에는 발파 가스 측정 결과를 받은 뒤 들어간다. 작업 중 연속 측정. 확인: 측정값·시각 기록.
3. 상부 해체 시 하부 출입 통제·방호선반 설치 — 해체 높이 아래에 방호선반·방지망을 설치하고(규칙 제14조) 아래층(TUYERE·HEARTH) 출입을 막는다. 방호선반이 없는 구간은 아래층 작업을 시간으로 나눈다(R16). 확인: 방호선반 설치 사진·하부 통제 기록.
4. 감시인 배치·출입자 명부 기록 — 노정 개구부·풍구 레벨 출입구에 감시인을 두고 입·퇴장 시각을 적는다. 확인: 감시인 서명·명부.
5. 달비계·안전대 체결 확인 (고소 해체) — 달비계 와이어·훅·과부하 방지장치를 점검하고 작업자는 안전대를 독립 구명줄에 2중으로 건다. 브레이커 사용 중 반동에 대비해 발판 난간을 확인한다. 확인: 반장 눈 확인 뒤 개시.
6. 스테이브 탈거 인양 신호수 지정 — 스테이브마다 중량을 확인하고 체인블록·호이스트로 먼저 매단 뒤 볼트를 푼다. 신호수가 하강 경로 아래를 비운 뒤 내린다. 확인: 신호수 이름·탈거 번호 기록.
7. 내화물 붕괴 위험 구간 접근 금지 (부분 해체 벽면 하부) — 반만 해체된 벽면 아래에 표지·안전띠를 두고 서지 않는다. 벽면은 위에서부터 끝까지 내린 뒤 다음 구간으로 간다. 확인: 붕괴 위험 구간 일일 지정 기록.
8. 해체 잔재 투하 구간 노저 출입 금지 — 잔재를 아래로 떨어뜨리는 구간·시간대를 정하고 그동안 노저(HEARTH) 출입을 막는다. 노저 작업(P13·P16)과 시간을 나눈다. 확인: 투하 시간대·통제 기록.
9. 작업 종료 퇴출 확인·허가서 반납 — 명부를 0명으로 맞추고 작업책임자가 서명한다. 해체가 끝나면 "철피 내측 내화물 해체 완료" 서명을 철피 절단 협력사(가상-철구B, P15)와 원청에 넘긴다. 확인: 퇴출 서명·P15 인계 서명지.

## 필수 단계

1. 밀폐공간 작업허가서 발급
2. 작업 전 산소·유해가스 측정 후 진입
3. 상부 해체 시 하부 출입 통제·방호선반 설치
4. 감시인 배치·출입자 명부 기록
5. 달비계·안전대 체결 확인 (고소 해체)
6. 스테이브 탈거 인양 신호수 지정
7. 내화물 붕괴 위험 구간 접근 금지 (부분 해체 벽면 하부)
8. 해체 잔재 투하 구간 노저 출입 금지
9. 작업 종료 퇴출 확인·허가서 반납

## 판정에 쓰는 기준

- 계획서 절차에 2·3·5 단계가 없으면 F8 "필수 단계 누락" → F2 결함.
- 핵심 단계를 2·3·5로 고른 이유: 노 안 해체의 사망 사고 세 유형(질식·낙하·추락)을 하나씩 막는다. 2(산소·가스 측정)는 분진·발파 가스가 고인 노 안의 중독을, 3(하부 통제·방호선반)은 해체물이 아래층 노저 작업자에게 떨어지는 낙하(R16, 규칙 제14조)를, 5(달비계 안전대)는 브레이커 반동에 의한 추락을 막는다. 7·8은 3의 연장이고 1·4·6·9는 SOP-02·SOP-03 에서 다시 걸린다.
- 해체 아래 작업이 있고 방호선반·출입금지 기재가 없으면 R16(금지)
- 비계 해체와 겹치면 R17(금지)

- 내측 해체 완료 서명 전 철피 절단(P15) 착수 금지(R08)
