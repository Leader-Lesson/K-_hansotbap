# SOP-P14 노흉·노복 내화물·스테이브 해체 작업표준 — 합성

- 출처: KOSHA GUIDE·산업안전보건기준에 관한 규칙을 바탕으로 해커톤 시연용으로 합성한 문서. 실제 사업장 표준서가 아니며 협력사명은 가상이다.
- 적용 작업: P14 노흉·노복 내화물·스테이브 해체 (기준 일정 작업 하나에만 적용하는 작업별 표준서)

## 작업 개요

- 작업ID: P14
- 협력사(가상): 가상-내화H · 공종: 내화물 해체
- 구역: BELLY_BOSH 노복·조안(belly/bosh)
- 기준 일정(가정값): 2026-11-27 ~ 2026-12-22 (D15~D40)
- 위험 작업 유형: 밀폐공간, 고소
- 위험 분류 코드(시행령 제53조의2): 5호 낙하·비래, 7호 붕괴, 8호 질식·중독
- 필요 허가: 밀폐공간,고소
- 선행 작업: P12

## 적용하는 공통 표준서

- SOP-02 밀폐공간 출입작업
- 고소 작업은 공통 표준서 없음 — 규칙 제42조~제45조(추락 방지) 적용

## 필수 단계

1. 밀폐공간 작업허가서 발급
2. 작업 전 산소·유해가스 측정 후 진입
3. 상부 해체 시 하부 출입 통제·방호선반 설치
4. 감시인 배치·출입자 명부 기록
5. 달비계·안전대 체결 확인 (고소 해체)
6. 스테이브 탈거 인양 신호수 지정
7. 내화물 붕괴 위험 구간 접근 금지 (부분 해체 벽면 하부)
8. 해체 잔재 투하 구간 노저 출입 금지
9. 작업 종료 퇴출 확인·허가서 반납

## 판정에 쓰는 기준

- 계획서 절차에 2·3·5 단계가 없으면 F8 "필수 단계 누락" → F2 결함.
- 해체 아래 작업이 있고 방호선반·출입금지 기재가 없으면 R16(금지)
- 비계 해체와 겹치면 R17(금지)

## 작업 금지·출입 제한

- 해체 중 BELLY_BOSH 아래 TUYERE·HEARTH 노 내부 진입 금지(R16)
- 노정~노흉 상부에서 투하물 발생 구간 출입 금지

## 근거 조문

- 산업안전보건기준에 관한 규칙 제14조②·③(낙하물 방지망), 제42조·제43조, 제618조~제623조
- 시행령 제53조의2 5·7호
