# SOP-P11 풍구·냉각기·송풍지관 철거 작업표준 — 합성

- 출처: KOSHA GUIDE·산업안전보건기준에 관한 규칙을 바탕으로 해커톤 시연용으로 합성한 문서. 실제 사업장 표준서가 아니며 협력사명은 가상이다.
- 적용 작업: P11 풍구·냉각기·송풍지관 철거 (기준 일정 작업 하나에만 적용하는 작업별 표준서)
- 문서번호 SOP-P11 · 개정 1 · 제정(가정) 2026-11-09 · 관리 부서: 원청 안전환경팀(가상) · 적용 현장: 광양 2고로 2차 개수(합성)

## 1. 목적과 적용 범위

- 목적: 풍구 레벨 플랫폼에서 풍구·풍구 냉각기·송풍지관을 떼어 내리는 작업에서, 격리되지 않은 송풍·냉각수가 살아 있어 생기는 분출·끼임, 볼트 용단 불티 화재, 무거운 냉각기·지관 인양 중 아래 주상으로의 낙하를 막고, 철거 뒤 환상관·노체에 생긴 개구부를 막아 둔 상태로 넘긴다.
- 적용 범위: 화기·중장비 허가, P06 격리 목록 대조, 냉각수 잔압 제거·배수, 화재감시, 풍구·냉각기 인양, 주상 하부 통제, 철거품 반출, 개구부 막음·반납까지. 풍구 레벨 전 둘레를 돌아가며 한다.
- 적용 제외: 풍구·냉각기 신설(P21, SOP-P21), 환상관 내화물(P27, SOP-P27), 주상 개조(P24)는 별도 표준서를 따른다.

## 2. 작업 개요

- 작업ID: P11
- 협력사(가상): 가상-기계E · 공종: 기계 정비
- 구역: TUYERE 풍구 레벨(풍구·환상관·송풍지관)
- 기준 일정(가정값): 2026-11-17 ~ 2026-11-27 (D5~D15)
- 위험 작업 유형: 화기, 중량물
- 위험 분류 코드(시행령 제53조의2): 2호 끼임, 5호 낙하·비래
- 필요 허가: 화기,중장비
- 선행 작업: P06

## 3. 위험 요인과 예상 사고

- 끼임·분출: 송풍이나 냉각수가 격리되지 않은 채 플랜지를 풀면 압력이 분출하고 지관이 튄다. 격리 목록(P06)과 대조하지 않으면 어느 밸브가 살아 있는지 모른다(R22·R23).
- 낙하·비래: 풍구 냉각기·송풍지관은 수백 kg~수 t 이다. 풍구 레벨 플랫폼에서 체인블록·크레인으로 내리다 떨어지면 바로 아래 주상(CASTHOUSE)의 개조 작업자(P24)가 맞는다(R16·R18).
- 화재: 볼트 용단·절단 불티가 플랫폼 그레이팅 아래 주상으로 떨어진다. 풍구 레벨에는 그리스·유압유가 많다.
- 고온수 화상: 냉각수 배관에 남은 고온수가 배수 중 튄다.
- 개구부: 풍구를 뺀 자리로 노 내부 가스·분진이 나오고, 공구·볼트가 노 내부로 떨어진다.

## 4. 투입 인원과 역할 (기준 10명, 계획서 인원과 맞춘다)

- 작업책임자 1명: 화기·중장비 허가, P06 격리 목록 대조·서명, 철거 순서 관리
- 화재감시자 1명: 용단 중 상주, 그레이팅 아래 불티 확인, 종료 후 30분 감시
- 기계 정비공 4명: 플랜지 볼트 해체·용단, 풍구·냉각기 탈거, 개구부 막음
- 인양 신호수 1명·줄걸이 1명: 체인블록·크레인 인양 신호, 줄걸이 점검
- 하부 통제원 1명: 환상관 아래 주상 출입 통제
- 유도자·반출 담당 1명: 지게차·반출 차량 유도, 철거품 적치

## 5. 투입 장비·자재·보호구

- 장비: 체인블록(3t) 여러 조, 크롤러 크레인 또는 노정 호이스트(대형 지관 하강 시), 지게차(3t, 철거품 반출), 산소절단기(가스 용기 랙) 2조, 복합 가스측정기(LEL·CO), 압력계(잔압 확인), 토크렌치·임팩트 렌치
- 자재: 맹판·개구부 덮개(풍구 구멍·환상관 플랜지용), 와이어로프·샤클(검사 꼬리표), 불티비산방지포·방화포, 소화기 2대 이상, 배수 호스·드럼, 출입 통제 안전띠·표지, 철거품 팔레트
- 보호구: 안전모·안전화·보안경, 용접 보안면·방열 장갑(용단), 방열 장갑·안면보호구(배수), 휴대용 CO 경보기(풍구 개구부 작업자), 안전대(플랫폼 가장자리·개구부 작업)

## 6. 작업 순서 (상세)

1. 작업허가서(화기·중장비) 발급 — 작업책임자가 그날 철거할 풍구 번호·방위, 용단 구간, 인양 계획을 적어 화기·중장비 허가를 받고 번호를 서로 기재한다. 아래 주상(P24) 작업 일정을 확인한다. 확인: 허가서 번호·P24 일정 확인 기록.
2. 송풍·냉각수 LOTO 확인 (P06 격리 목록 대조) — P06 격리 목록에서 그날 철거 풍구의 송풍지관·냉각수 공급·회수 밸브 잠금 번호를 찾아 현장 잠금장치·꼬리표와 대조한다. 목록에 없거나 잠금이 없으면 원청 정비에 격리를 요청하고 기다린다(R22·R23). 확인: 대조표 서명.
3. 냉각수 배관 잔압 제거·배수 확인 — 냉각기 드레인을 열어 압력계 0을 확인하고 물을 뺀다. 고온수는 식힌 뒤 배수한다. 송풍지관은 환상관 쪽 압력 0을 확인한다. 확인: 압력·배수 기록.
4. 화재감시자 배치 (볼트 절단·용단) — 녹슨 볼트 용단 전 감시자를 두고, 그레이팅 아래로 불티가 떨어지지 않게 방지포를 깔고 주변 그리스·유압유를 닦는다. 소화기 2대. 종료 후 30분 감시. 확인: 감시자 서명.
5. 풍구·냉각기 인양 신호수 지정·줄걸이 점검 — 풍구·냉각기·지관마다 중량을 확인하고 체인블록 정격·와이어·샤클을 점검한다. 신호수를 정한다. 플랜지 볼트를 다 풀기 전에 먼저 매단다. 확인: 점검표·신호수 이름.
6. 환상관 아래 주상 하부 출입 통제 — 탈거·하강 중 바로 아래 주상(CASTHOUSE)에 사람이 없게 통제원이 막고, 주상 개조(P24) 작업은 그 시간대에 멈춘다(R16·R18). 확인: 인양 시간대·통제 기록.
7. 철거품 반출 경로 확보·유도자 배치 — 철거품을 팔레트에 묶어 지게차·차량으로 옮길 때 통로를 비우고 유도자가 보행자를 막는다(R21). 확인: 반출 기록.
8. 철거 완료 개구부 막음 확인·허가서 반납 — 풍구를 뺀 구멍과 환상관·냉각수 플랜지에 덮개·맹판을 달아 노 내부로 떨어지거나 가스가 나오지 않게 하고 사진을 남긴다. 30분 감시 뒤 허가서를 반납하고 P21·P27 협력사에 개구부 상태를 알린다. 확인: 개구부 막음 사진·반납 시각.

## 적용하는 공통 표준서

- SOP-01 화기작업
- SOP-03 중량물 인양(크레인)

## 필수 단계

1. 작업허가서(화기·중장비) 발급
2. 송풍·냉각수 LOTO 확인 (P06 격리 목록 대조)
3. 냉각수 배관 잔압 제거·배수 확인
4. 화재감시자 배치 (볼트 절단·용단)
5. 풍구·냉각기 인양 신호수 지정·줄걸이 점검
6. 환상관 아래 주상 하부 출입 통제
7. 철거품 반출 경로 확보·유도자 배치
8. 철거 완료 개구부 막음 확인·허가서 반납

## 판정에 쓰는 기준

- 계획서 절차에 2·4·6 단계가 없으면 F8 "필수 단계 누락" → F2 결함.
- 핵심 단계를 2·4·6으로 고른 이유: 이 작업에서 사람이 죽는 세 경로를 하나씩 막는다. 2(격리 목록 대조)는 살아 있는 송풍·냉각수 플랜지를 여는 분출·끼임을, 4(화재감시자)는 그리스·유압유가 많은 풍구 레벨에서 용단 불티 화재를, 6(주상 하부 통제)은 수 t 냉각기·지관이 바로 아래 주상 개조(P24) 작업자에게 떨어지는 낙하를 막는다. 3·5·7은 운전 기록·SOP-03·유도자 규칙에서 다시 걸린다.
- LOTO 확인 없이 송풍·냉각수 계통을 열면 R22·R23(금지)
- 풍구 레벨 철거 아래 주상 작업은 R16(조건부), 인양 경로는 R18(금지)

## 작업 금지·출입 제한

- 철거 중 TUYERE 바로 아래 CASTHOUSE 출입 금지(R16·R18)
- 환상관 개구부 주변 출입 통제
- P06 격리 목록 대조 서명 전 플랜지 해체 착수 금지(R22·R23)
- 풍구 레벨 용단 중 그레이팅 아래 주상 가연물(P24 자재) 적치 금지(R03)

## 3D 연결 (출입 제한 데이터)

- 구역: TUYERE(풍구 레벨 외곽 플랫폼). 철거는 풍구 번호 순서로 돌아가므로 방위는 계획서의 풍구 번호·방위(SAME). 낙하 영향은 바로 아래 CASTHOUSE
- 제한 1: 구역 CASTHOUSE, 방위 SAME(철거 풍구 직하), 종류 LIFT_PATH, 대상 OTHERS(P24 등), 적용 시점 STEP:6(탈거·하강 시간대), 범위 직하 + [팀 설정값], 규칙 R16·R18, 3D 표시 CONE + SIGN「풍구 철거 중 · 상부 낙하물」
- 제한 2: 구역 TUYERE, 방위 SAME, 종류 ENTRY_BAN, 대상 OTHERS, 적용 시점 DURING, 범위 철거 풍구 주변 [팀 설정값], 규칙 R30, 3D 표시 TAPE
- 제한 3: 구역 CASTHOUSE, 방위 SAME(직하), 종류 ENTRY_BAN(가연물 적치 금지), 대상 OTHERS, 적용 시점 STEP:4(용단 중), 범위 직하 + 풍하 8m, 규칙 R03, 3D 표시 SIGN「불티 낙하 구간」
- 착수 조건: 구역 TUYERE, 종류 WORK_STOP(이 작업 자체), 대상 P11, 적용 시점 UNTIL_HANDOVER(P06 격리 목록 게시 전까지), 규칙 R22·R23, 3D 표시 BAR_RED(P11 작업 막대 금지색)

## 비상 조치

- 플랜지 분출·고온수 유출: 즉시 물러나 밸브 상태 확인(조작은 원청 정비만), 화상자 냉각·원청 구급 연락, 격리 목록 재확인 뒤 재개
- 인양물 낙하: 하부 통제 유지, 주상 작업자 안부 확인, 원청 안전환경팀 보고, 재개 전 줄걸이 전수 점검
- 화재: 감시자 초기 진화, 절단기 밸브 차단, 그레이팅 아래 불티 확인, 진화 안 되면 대피·원청 소방 연락
- 풍구 개구부 CO 경보: 개구부 즉시 덮고 풍상측 대피, 재측정 정상 뒤 재개

## 기록·보관

- 허가서, P06 격리 목록 대조표, 잔압·배수 기록, 감시자 서명, 인양 점검표·시간대 기록, 하부 통제 기록, 반출 기록, 개구부 막음 사진을 원청 안전환경팀이 공사 종료 후 3년 보관(가정)
- 인양 시간대 기록은 주상 개조(P24)와의 시간 분리(R16·R18) 근거로, 개구부 막음 사진은 P21·P27 착수 조건으로 F5 이력에 남긴다
