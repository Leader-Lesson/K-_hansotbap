# SOP-P11 풍구·냉각기·송풍지관 철거 작업표준 — 합성

- 출처: KOSHA GUIDE·산업안전보건기준에 관한 규칙을 바탕으로 해커톤 시연용으로 합성한 문서. 실제 사업장 표준서가 아니며 협력사명은 가상이다.
- 적용 작업: P11 풍구·냉각기·송풍지관 철거 (기준 일정 작업 하나에만 적용하는 작업별 표준서)

## 작업 개요

- 작업ID: P11
- 협력사(가상): 가상-기계E · 공종: 기계 정비
- 구역: TUYERE 풍구 레벨(풍구·환상관·송풍지관)
- 기준 일정(가정값): 2026-11-17 ~ 2026-11-27 (D5~D15)
- 위험 작업 유형: 화기, 중량물
- 위험 분류 코드(시행령 제53조의2): 2호 끼임, 5호 낙하·비래
- 필요 허가: 화기,중장비
- 선행 작업: P06

## 적용하는 공통 표준서

- SOP-01 화기작업
- SOP-03 중량물 인양(크레인)

## 필수 단계

1. 작업허가서(화기·중장비) 발급
2. 송풍·냉각수 LOTO 확인 (P06 격리 목록 대조)
3. 냉각수 배관 잔압 제거·배수 확인
4. 화재감시자 배치 (볼트 절단·용단)
5. 풍구·냉각기 인양 신호수 지정·줄걸이 점검
6. 환상관 아래 주상 하부 출입 통제
7. 철거품 반출 경로 확보·유도자 배치
8. 철거 완료 개구부 막음 확인·허가서 반납

## 판정에 쓰는 기준

- 계획서 절차에 2·4·6 단계가 없으면 F8 "필수 단계 누락" → F2 결함.
- LOTO 확인 없이 송풍·냉각수 계통을 열면 R22·R23(금지)
- 풍구 레벨 철거 아래 주상 작업은 R16(조건부), 인양 경로는 R18(금지)

## 작업 금지·출입 제한

- 철거 중 TUYERE 바로 아래 CASTHOUSE 출입 금지(R16·R18)
- 환상관 개구부 주변 출입 통제

## 근거 조문

- 산업안전보건기준에 관한 규칙 제14조, 제38조①5호, 제146조, 제241조
