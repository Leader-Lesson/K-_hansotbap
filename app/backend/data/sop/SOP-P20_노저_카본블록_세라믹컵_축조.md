# SOP-P20 노저 카본블록·세라믹컵 축조(연와정초) 작업표준 — 합성

- 출처: KOSHA GUIDE·산업안전보건기준에 관한 규칙을 바탕으로 해커톤 시연용으로 합성한 문서. 실제 사업장 표준서가 아니며 협력사명은 가상이다.
- 적용 작업: P20 노저 카본블록·세라믹컵 축조(연와정초) (기준 일정 작업 하나에만 적용하는 작업별 표준서)
- 문서번호 SOP-P20 · 개정 1 · 제정(가정) 2026-11-09 · 관리 부서: 원청 안전환경팀(가상) · 적용 현장: 광양 2고로 2차 개수(합성)

## 1. 목적과 적용 범위

- 목적: 노 최하단(노저)에서 카본블록을 깔고 세라믹컵을 쌓는 밀폐공간 작업에서 질식, 가열 장비 CO 중독, 위층 인양물·낙하물 사고를 막고, 노저 작업이 끝나기 전에 질소·가스 라인이 연결되는 일을 막는다.
- 적용 범위: 연와정초(첫 벽돌 놓기)부터 카본블록 반입·배열·접착, 세라믹컵 축조, 몰탈 가열·양생, 완료 퇴출 확인까지.
- 적용 제외: 노저 해체·청소(P16, SOP-P16), 풍구 레벨 내화물(P21, SOP-P21), 노내 호이스트 운영(P31, SOP-P31).

## 2. 작업 개요

- 작업ID: P20
- 협력사(가상): 가상-축로I · 공종: 축로(내화물)
- 구역: HEARTH 노상·노저(hearth) — 노 내부 최하단, 반입은 풍구 레벨 개구부와 노내 호이스트 승강로
- 기준 일정(가정값): 2027-01-21 ~ 2027-02-15 (D70~D95)
- 위험 작업 유형: 밀폐공간
- 위험 분류 코드(시행령 제53조의2): 5호 낙하·비래, 8호 질식·중독
- 필요 허가: 밀폐공간
- 선행 작업: P16 (노저 해체·청소), P18 (철피 용접)

## 3. 위험 요인과 예상 사고

- 질식·중독: 노저는 노 내부 수직 공동의 바닥이라 무거운 가스가 고인다. 접착 몰탈 가열 장비(가스 버너·히터)에서 CO가 나오고, 노 내부로 이어진 질소·가스 배관에 맹판이 없으면 불활성가스가 바닥부터 찬다(현대제철 2013 공개 사례).
- 낙하·비래: 위층(TOP 장입설비 설치 P23, STACK 호이스트 P31)의 볼트·공구·자재가 수직 공동을 그대로 떨어진다. 카본블록(수백 kg) 반입 중 줄걸이 이탈.
- 끼임: 카본블록을 자리에 밀어 넣을 때 손·발이 블록 사이에 낀다.
- 화상: 몰탈 가열 장비 표면, 가열된 블록 면.

## 4. 투입 인원과 역할 (기준 18명, 계획서 인원과 맞춘다)

- 작업책임자 1명: 허가서, 출입자 명부, 맹판 점검, 완료·퇴출 확인 서명
- 안전관리자 1명: 산소·CO 측정(가열 장비 사용 중 수시), 환기팬·구조장비 점검
- 감시인 2명: 노저 출입구(풍구 레벨 맨홀) 상주, 출입 기록, 비상 연락
- 축로공 10명: 카본블록 배열·접착, 세라믹컵 축조, 줄눈
- 가열 장비 운전 1명: 몰탈 가열, 연료 가스 용기 관리(노 외부)
- 신호수·인양 3명: 노내 호이스트 반입 신호, 승강로 하부 출입 통제

## 5. 투입 장비·자재·보호구

- 장비: 산소·유해가스 복합측정기 3대(연속 측정 1대 고정), 환기팬 2대(송기 덕트를 노저 바닥까지), 노내 호이스트(P31 가상-양중C 운영), 체인블록 2t 2대, 몰탈 가열 장비(가스 용기 랙은 노 외부), 작업등
- 구조장비: 공기호흡기 2조, 삼각대·구조용 윈치 1조, 들것
- 자재: 카본블록, 세라믹컵 연와(내화벽돌 팔레트), 접착 몰탈, 맹판(배관 차단용)
- 보호구: 안전모·안전화·보안경, 방진마스크, 방열 장갑, 휴대용 산소·CO 경보기(작업반장·가열 장비 운전자)

## 6. 작업 순서 (상세)

1. 밀폐공간 작업허가서 발급 — 작업책임자가 밀폐공간 허가를 받고 노저 출입구에 게시한다. 허가서에 작업 범위(단수), 인원, 감시인, 측정 계획, 가열 장비 사용 여부를 적는다. 확인: 허가서 번호 기록.
2. 작업 전 산소농도 측정 (18~23.5%·가연성가스·CO) — 진입 전 노저 바닥·허리 높이·출입구 3곳에서 O2 18~23.5%, LEL 10% 미만, CO 30ppm 미만을 확인한다. 바닥이 가장 위험하므로 바닥 값을 먼저 본다. 범위를 벗어나면 환기 뒤 다시 잰다. 확인: 측정값·시각·측정자 기록.
3. 감시인 출입구 상주·구조장비 비치 — 감시인 2명이 출입구를 지키며 출입자 명부를 쓴다. 공기호흡기·삼각대를 출입구 옆에 둔다. 감시인은 다른 일을 겸하지 않는다. 확인: 명부·장비 점검표.
4. 불활성가스 유입 가능 배관 맹판 설치 확인 — 노 내부로 이어지는 질소·가스·송풍 배관에 맹판이 있고 꼬리표가 걸려 있는지 매일 작업 전 확인한다. 라인 복구(P34)는 노저 작업 완료 전 시작하지 않는다. 확인: 맹판 위치 점검표.
5. 환기팬 연속 가동 — 송기 덕트를 노저 바닥까지 내려 환기팬을 작업 내내 돌린다. 가열 장비 사용 중에는 배기도 함께 한다. 확인: 가동 시각 기록.
6. 카본블록 반입 인양 하부 출입 통제 — 노내 호이스트로 블록을 내릴 때 승강로 아래와 반입 개구부 아래에 사람이 없게 신호수가 막는다. 위층(P23·P31) 인양 시간대와 겹치지 않게 전날 맞춘다. 확인: 인양 시간대를 작업일지에 기록.
7. 접착 몰탈·가열 장비 사용 시 CO 측정 — 가열 장비를 켜기 전과 켜는 동안 30분마다 CO를 잰다. 30ppm 이상이면 장비를 끄고 환기 뒤 재측정한다. 연료 가스 용기는 노 외부에 둔다. 확인: CO 측정값 기록.
8. 출입자 명부 기록·작업 종료 퇴출 확인 — 매일 종료 때 명부를 0명으로 맞춘다. 전체 축조 완료 때 작업책임자가 "노저 축조 완료·인원 철수" 서명을 배관 협력사(가상-배관O)와 원청 안전환경팀에 전달한다. 이 서명이 P34 착수 조건의 하나다.

## 적용하는 공통 표준서

- SOP-02 밀폐공간 출입작업

## 필수 단계

1. 밀폐공간 작업허가서 발급
2. 작업 전 산소농도 측정 (18~23.5%·가연성가스·CO)
3. 감시인 출입구 상주·구조장비 비치
4. 불활성가스 유입 가능 배관 맹판 설치 확인
5. 환기팬 연속 가동
6. 카본블록 반입 인양 하부 출입 통제
7. 접착 몰탈·가열 장비 사용 시 CO 측정
8. 출입자 명부 기록·작업 종료 퇴출 확인

## 판정에 쓰는 기준

- 계획서 절차에 2·3·4 단계가 없으면 F8 "필수 단계 누락" → F2 결함.
- 핵심 단계를 2·3·4로 고른 이유: 노저 밀폐공간 사망 사고의 세 고리를 끊는 단계다. 2(산소·CO 측정)는 바닥에 고인 가스를, 3(감시인·구조장비)은 쓰러진 사람을 꺼낼 수단을, 4(맹판 확인)는 축조 중 불활성가스 유입(현대제철 2013)을 막는다. 1·5·6·7·8은 빠져도 공통 표준서 SOP-02나 상대 작업(P31 인양, P34 연결) 표준서에서 다시 걸린다.
- 노정 장입설비 설치(P23) 바로 아래 축조는 R16(조건부) — 시연 S2
- 축조 중 같은 계통 질소·가스 라인 연결(P34)은 R07·R08(금지)

## 작업 금지·출입 제한

- 축조 중 HEARTH 위 TOP·STACK 인양·해체 금지 또는 방호선반(R16)
- 노저 작업 완료·퇴출 확인 전 질소·가스 라인 연결(P34) 금지(R07·R08)
- 블록 반입 시간대 승강로·반입 개구부 하부 출입 통제(R18)
- 가열 장비 사용 중 CO 측정 없이 노저 진입 금지(R27 결함)

## 3D 연결 (출입 제한 데이터)

- 구역: HEARTH(노저 내부). 반입 경로는 TUYERE 개구부와 STACK 승강로를 지난다 (계획서에 반입 시간대가 있으면 그대로)
- 제한 1: 구역 TOP·STACK · 방위 ALL · 종류 WORK_STOP(직상부 인양·해체 작업 중지 또는 방호선반) · 대상 P23·P30·P31 · 시점 DURING · 범위 구역 전체 · 규칙 R16 · 3D 표시 SIGN:「노저 축조 중 · 상부 낙하물 주의」
- 제한 2: 구역 HEARTH · 방위 SAME · 종류 LIFT_PATH(반입 인양 하부 출입 통제) · 대상 OTHERS · 시점 STEP:6(블록 반입 시간대) · 범위 구역 전체 · 규칙 R18 · 3D 표시 CONE(인양 시간대에만 러버콘)
- 제한 3(계통): 구역 HEARTH·TUYERE · 방위 ALL · 종류 GAS_IN_BAN(노체 계통 N2·BFG·송풍 투입 금지) · 대상 P34 · 시점 UNTIL_HANDOVER(8단계 서명 전까지) · 범위 — · 규칙 R08 · 3D 표시 BAR_RED(P34 작업 막대 금지색)

## 비상 조치

- 산소·CO 경보: 전원 즉시 퇴출, 가열 장비 정지, 감시인이 명부로 인원 확인, 원청 상황실 보고, 원인 제거·재측정 정상 뒤 재진입
- 인원 쓰러짐(질식 의심): 구조자는 공기호흡기 착용 뒤 진입, 삼각대·윈치로 인양, 맨몸 진입 금지, 119·원청 구급 연락
- 위층 낙하물 발생: 아래 작업 중지, 원청이 상부 작업(P23·P31) 협력사와 시간 조정

## 기록·보관

- 허가서, 산소·CO 측정 기록, 출입자 명부, 맹판 점검표, 인양 시간대 기록, 완료·철수 서명지를 원청 안전환경팀이 공사 종료 후 3년 보관(가정)
- 완료·철수 서명지는 P34 착수 조건의 근거 문서로 F5 이력에 남긴다
