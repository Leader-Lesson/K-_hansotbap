# SOP-P22 노복~노흉 내화물 축조·캐스터블 작업표준 — 합성

- 출처: KOSHA GUIDE·산업안전보건기준에 관한 규칙을 바탕으로 해커톤 시연용으로 합성한 문서. 실제 사업장 표준서가 아니며 협력사명은 가상이다.
- 적용 작업: P22 노복~노흉 내화물 축조·캐스터블 (기준 일정 작업 하나에만 적용하는 작업별 표준서)

## 작업 개요

- 작업ID: P22
- 협력사(가상): 가상-축로I · 공종: 축로(내화물)
- 구역: STACK 노흉(shaft)
- 기준 일정(가정값): 2027-02-05 ~ 2027-03-02 (D85~D110)
- 위험 작업 유형: 밀폐공간, 고소
- 위험 분류 코드(시행령 제53조의2): 4호 추락, 5호 낙하·비래, 8호 질식·중독
- 필요 허가: 밀폐공간,고소
- 선행 작업: P19

## 적용하는 공통 표준서

- SOP-02 밀폐공간 출입작업
- 고소 작업은 공통 표준서 없음 — 규칙 제42조~제45조(추락 방지) 적용

## 필수 단계

1. 밀폐공간 작업허가서 발급
2. 작업 전 산소농도 측정·연속 측정
3. 감시인 출입구 상주·구조장비 비치
4. 환기팬 연속 가동 (캐스터블 양생 열·수증기)
5. 달비계 안전대 체결 확인
6. 자재 인양 시 하부 출입 통제
7. 불활성가스 유입 가능 배관 맹판 설치 확인
8. 축조 완료·인원 철수 확인 서명 (라인 연결 P34 인계)

## 판정에 쓰는 기준

- 계획서 절차에 2·5·7 단계가 없으면 F8 "필수 단계 누락" → F2 결함.
- 축조 완료 전 질소·가스 라인 연결(P34)이 시작되면 R08·R07(금지) — 시연 S1 핵심 장면
- 축조 중 노흉 비계 해체(P30)는 R17·R16(금지)

## 작업 금지·출입 제한

- 축조 중 STACK 노 내부 타 업체 진입 금지 — 비계 해체(P30)는 축조 완료 후(R17)
- 축조 완료·퇴출 확인 전 질소·가스 라인 연결(P34) 금지(R08·R07)

## 근거 조문

- 산업안전보건기준에 관한 규칙 제619조②4호, 제618조~제625조, 제42조~제45조(추락 방지)
- 현대제철 2013 — 내화물 작업 종료 전 아르곤 배관 연결(공개 사례)
