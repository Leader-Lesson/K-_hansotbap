# SOP-P22 노복~노흉 내화물 축조·캐스터블 작업표준 — 합성

- 출처: KOSHA GUIDE·산업안전보건기준에 관한 규칙을 바탕으로 해커톤 시연용으로 합성한 문서. 실제 사업장 표준서가 아니며 협력사명은 가상이다.
- 적용 작업: P22 노복~노흉 내화물 축조·캐스터블 (기준 일정 작업 하나에만 적용하는 작업별 표준서)
- 문서번호 SOP-P22 · 개정 1 · 제정(가정) 2026-11-09 · 관리 부서: 원청 안전환경팀(가상) · 적용 현장: 광양 2고로 2차 개수(합성)

## 1. 목적과 적용 범위

- 목적: 노 내부(노복~노흉)에서 내화 벽돌을 쌓고 캐스터블을 치는 밀폐공간·고소 작업에서 질식, 추락, 낙하물 사고를 막고, 축조가 끝나기 전에 가스·질소 라인이 연결되는 일을 막는다.
- 적용 범위: 스테이브 앞면 내화물 축조, 캐스터블 타설·양생, 축조용 달비계 운용, 자재 인양(노내 호이스트 사용), 완료 인계까지.
- 적용 제외: 노저 카본블록 축조(P20, SOP-P20), 풍구 레벨 내화물(P21, SOP-P21), 비계 설치·해체 자체(P30, SOP-P30).

## 2. 작업 개요

- 작업ID: P22
- 협력사(가상): 가상-축로I · 공종: 축로(내화물)
- 구역: STACK 노흉(shaft) — 노복·조안(BELLY_BOSH)에서 위로 올라가며 축조
- 기준 일정(가정값): 2027-02-05 ~ 2027-03-02 (D85~D110)
- 위험 작업 유형: 밀폐공간, 고소
- 위험 분류 코드(시행령 제53조의2): 4호 추락, 5호 낙하·비래, 8호 질식·중독
- 필요 허가: 밀폐공간,고소
- 선행 작업: P19 (스테이브·냉각판 설치)

## 3. 위험 요인과 예상 사고

- 질식·중독: 노 내부는 하나의 수직 공동이다. 캐스터블 양생 열·수증기로 산소가 줄고, 연결된 질소·가스 배관에서 불활성가스가 들어오면 전원이 쓰러진다(현대제철 2013 공개 사례).
- 추락: 달비계·작업발판에서 안전대 미체결 상태로 작업, 노정 개구부 쪽 추락.
- 낙하·비래: 위층(TOP 노정 장입설비 P23)의 볼트·공구, 노내 호이스트 인양 자재가 아래 작업자에게 떨어진다.
- 붕괴: 양생 전 캐스터블 하중, 지지 비계 과적재.

## 4. 투입 인원과 역할 (기준 22명, 계획서 인원과 맞춘다)

- 작업책임자 1명: 허가서, 출입자 명부, 완료·철수 확인 서명(8단계)
- 안전관리자 1명: 산소·가스 측정, 환기팬·구조장비 점검
- 감시인 2명: 노내 출입구(풍구 레벨 맨홀·노정) 상주, 출입 기록, 비상 연락
- 축로공 14명: 벽돌 축조, 줄눈, 캐스터블 타설
- 믹서·펌프 운전 2명: 캐스터블 혼합·압송(노 외부)
- 신호수·인양 2명: 노내 호이스트 자재 인양 신호, 하부 출입 통제

## 5. 투입 장비·자재·보호구

- 장비: 산소·유해가스 복합측정기 3대(연속 측정 1대 고정), 환기팬 2대(송기 덕트), 캐스터블 믹서·펌프, 달비계(서스펜디드 플랫폼) 2조, 노내 호이스트(P31 가상-양중C 운영), 작업등
- 구조장비: 공기호흡기 2조, 삼각대·구조용 윈치 1조, 들것
- 자재: 내화 벽돌, 캐스터블, 모르타르, 앵커, 맹판(배관 차단용)
- 보호구: 안전모·안전화·보안경, 안전대(2중 걸이), 방진마스크, 휴대용 산소 경보기(작업반장)

## 6. 작업 순서 (상세)

1. 밀폐공간 작업허가서 발급 — 작업책임자가 밀폐공간·고소 허가를 받고 출입구에 게시한다. 허가서에 작업 범위(단수·높이), 인원, 감시인, 측정 계획을 적는다. 확인: 허가서 번호 기록.
2. 작업 전 산소농도 측정·연속 측정 — 진입 전 노 내부 상·중·하 3곳에서 O2 18~23.5%, CO 30ppm 미만, LEL 10% 미만을 확인한다. 작업 중에는 고정 측정기로 연속 측정하고 1일 2회 이상 기록한다. 범위를 벗어나면 즉시 전원 퇴출. 확인: 측정값·시각·측정자 기록.
3. 감시인 출입구 상주·구조장비 비치 — 감시인 2명이 출입구를 지키며 출입자 명부를 쓴다. 공기호흡기·삼각대를 출입구 옆에 둔다. 감시인은 다른 일을 겸하지 않는다. 확인: 명부·장비 점검표.
4. 환기팬 연속 가동 (캐스터블 양생 열·수증기) — 송기 덕트를 작업 높이까지 내려 환기팬을 작업 내내 돌린다. 양생 중에도 끄지 않는다. 확인: 가동 시각 기록.
5. 달비계 안전대 체결 확인 — 달비계 승강 전 와이어·훅·과부하 방지장치를 점검하고, 작업자는 안전대를 독립 구명줄에 건다. 확인: 체결 상태를 작업반장이 눈으로 확인 뒤 작업 개시.
6. 자재 인양 시 하부 출입 통제 — 노내 호이스트로 벽돌·캐스터블을 올릴 때 인양 경로 아래에 사람이 없게 신호수가 막는다. 인양 중 아래층 작업은 멈춘다. 확인: 인양 시간대를 작업일지에 기록.
7. 불활성가스 유입 가능 배관 맹판 설치 확인 — 노 내부로 이어지는 질소·가스·송풍 배관에 맹판이 있고 꼬리표가 걸려 있는지 매일 작업 전 확인한다. 라인 복구(P34)는 축조 완료 전 시작하지 않는다. 확인: 맹판 위치 점검표.
8. 축조 완료·인원 철수 확인 서명 (라인 연결 P34 인계) — 마지막 작업자가 나온 뒤 출입자 명부를 0명으로 맞추고, 작업책임자가 "축조 완료·인원 철수" 서명을 배관 협력사(가상-배관O)와 원청 안전환경팀에 전달한다. 이 서명이 있어야 P34가 시작된다.

## 적용하는 공통 표준서

- SOP-02 밀폐공간 출입작업
- 고소 작업은 공통 표준서 없음 — 규칙 제42조~제45조(추락 방지) 적용

## 필수 단계

1. 밀폐공간 작업허가서 발급
2. 작업 전 산소농도 측정·연속 측정
3. 감시인 출입구 상주·구조장비 비치
4. 환기팬 연속 가동 (캐스터블 양생 열·수증기)
5. 달비계 안전대 체결 확인
6. 자재 인양 시 하부 출입 통제
7. 불활성가스 유입 가능 배관 맹판 설치 확인
8. 축조 완료·인원 철수 확인 서명 (라인 연결 P34 인계)

## 판정에 쓰는 기준

- 계획서 절차에 2·5·7 단계가 없으면 F8 "필수 단계 누락" → F2 결함.
- 핵심 단계를 2·5·7로 고른 이유: 이 작업의 사망 사고 유형 세 가지(질식·추락·불활성가스 유입)를 하나씩 막는 단계다. 2는 산소 결핍, 5는 추락, 7은 축조 중 가스 유입을 막는다. 1·3·4·6·8은 빠져도 공통 표준서 SOP-02나 상대 작업(P31 인양, P34 연결)의 표준서에서 다시 걸린다.
- 축조 완료 전 질소·가스 라인 연결(P34)이 시작되면 R08·R07(금지) — 시연 S1 핵심 장면
- 축조 중 노흉 비계 해체(P30)는 R17·R16(금지)

## 작업 금지·출입 제한

- 축조 중 STACK 노 내부 타 업체 진입 금지 — 비계 해체(P30)는 축조 완료 후(R17)
- 축조 완료·퇴출 확인 전 질소·가스 라인 연결(P34) 금지(R08·R07)
- 자재 인양 시간대 노 내부 하부(BELLY_BOSH·TUYERE·HEARTH) 출입 통제(R18)

## 3D 연결 (출입 제한 데이터)

- 구역: STACK(노흉 내부). 축조 진행 단수에 따라 BELLY_BOSH에서 STACK으로 올라간다 (계획서에 주차별 높이가 있으면 그대로)
- 작업 중 제한 1: STACK 전 방위, 타 업체 진입 금지, 기간 = 축조 기간 전체. 3D 표시: 노흉 내부 안전띠 + 「축조 중 · 타 업체 출입 금지」
- 작업 중 제한 2: HEARTH·TUYERE·BELLY_BOSH 노 내부 하부 전 방위, 인양 시간대 출입 통제(R18). 3D 표시: 인양 시간대에만 러버콘
- 계통 제한: 노체 계통(N2·BFG·송풍) 가스 투입 금지, 기간 = 축조 기간 전체 + 8단계 서명 전까지. 3D 표시: TUYERE P34 작업 막대 금지색(R08)

## 비상 조치

- 산소·가스 경보: 전원 즉시 퇴출, 감시인이 명부로 인원 확인, 원청 상황실 보고, 원인 제거·재측정 정상 뒤 재진입
- 추락·부상자 발생: 감시인이 구조 요청, 구조자는 공기호흡기 착용·삼각대 사용, 맨몸 진입 금지
- 위층 낙하물 발생: 아래 작업 중지, 원청이 상부 작업(P23) 협력사와 시간 조정

## 기록·보관

- 허가서, 산소·가스 측정 기록, 출입자 명부, 맹판 점검표, 완료·철수 서명지를 원청 안전환경팀이 공사 종료 후 3년 보관(가정)
- 완료·철수 서명지는 P34 착수 조건의 근거 문서로 F5 이력에 남긴다

## 근거 조문

- 산업안전보건기준에 관한 규칙 제619조②4호, 제618조~제625조, 제42조~제45조(추락 방지)
- 현대제철 2013 — 내화물 작업 종료 전 아르곤 배관 연결(공개 사례)
