# SOP-P37 화입(blow-in) 작업표준 — 합성

- 출처: KOSHA GUIDE·산업안전보건기준에 관한 규칙을 바탕으로 해커톤 시연용으로 합성한 문서. 실제 사업장 표준서가 아니며 협력사명은 가상이다.
- 적용 작업: P37 화입(blow-in) (기준 일정 작업 하나에만 적용하는 작업별 표준서)

## 작업 개요

- 작업ID: P37
- 협력사(가상): 원청-제선 · 공종: 조업(원청 직영)
- 구역: ALL 전 구역
- 기준 일정(가정값): 2027-03-23 ~ 2027-03-23 (D131~D131)
- 위험 작업 유형: 가스계통
- 위험 분류 코드(시행령 제53조의2): 1호 화재·폭발, 8호 질식·중독
- 필요 허가: 원청 조업 절차
- 선행 작업: P35,P36

## 적용하는 공통 표준서

- SOP-04 가스 배관 연결·기밀시험

## 필수 단계

1. 화입 절차서 승인·전 협력사 통보 (화입 시각·통제 구역)
2. 선행 작업(승온 P35·건조 P36) 완료 확인 서명
3. 모든 작업허가서 반납·LOTO 해제 기록 확인
4. 노체·가스 계통 전 구역 인원 철수 확인
5. 가스 계통 누설 최종 점검
6. 화입 중 전 구역 출입 통제 (조업 인원 외 금지)
7. 화입 후 CO·가스 측정 후 구역별 출입 허용

## 판정에 쓰는 기준

- 계획서 절차에 3·4·6 단계가 없으면 F8 "필수 단계 누락" → F2 결함.
- 허가서 반납 전 LOTO 해제·통전은 R23(금지)
- 내부 작업이 남은 계통에 가스 투입은 R07, 방산 중 상부 작업은 R11

## 작업 금지·출입 제한

- 화입 당일 ALL 전 구역 협력사 출입 금지
- 화입 후 측정 완료 전 노체·가스 설비 접근 금지

## 근거 조문

- 산업안전보건기준에 관한 규칙 제20조 9호, 제38조①5호, 제619조
- 시행령 제53조의2 1·8호
