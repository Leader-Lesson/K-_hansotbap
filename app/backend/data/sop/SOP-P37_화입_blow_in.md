# SOP-P37 화입(blow-in) 작업표준 — 합성

- 출처: KOSHA GUIDE·산업안전보건기준에 관한 규칙을 바탕으로 해커톤 시연용으로 합성한 문서. 실제 사업장 표준서가 아니며 협력사명은 가상이다.
- 적용 작업: P37 화입(blow-in) (기준 일정 작업 하나에만 적용하는 작업별 표준서)
- 문서번호 SOP-P37 · 개정 1 · 제정(가정) 2026-11-09 · 관리 부서: 원청 안전환경팀(가상) · 적용 현장: 광양 2고로 2차 개수(합성)

## 1. 목적과 적용 범위

- 목적: 개수 공사를 마친 고로에 열풍을 넣어 코크스에 불을 붙이고 조업을 다시 시작하는 화입 당일, 노체·가스 계통·열풍로·제진기 어느 곳에도 협력사 인원이 남아 있지 않게 하고, 반납되지 않은 허가·풀리지 않은 LOTO가 없는 상태에서 가스가 흐르게 하며, 화입 직후 발생 가스(CO)가 가라앉기 전 구역에 사람이 들어가는 일을 막는다.
- 적용 범위: 화입 절차서 승인·전 협력사 통보, 선행 작업(P35·P36) 완료 확인, 모든 허가 반납·LOTO 해제 기록 확인, 전 구역 인원 철수 확인, 가스 계통 최종 누설 점검, 화입 중 전 구역 출입 통제, 화입 후 CO·가스 측정 뒤 구역별 출입 허용까지.
- 적용 제외: 열풍로 승온·기밀시험(P35, SOP-P35), 코크스 충전·건조(P36, SOP-P36), 화입 뒤 정상 조업 절차(조업 매뉴얼).

## 2. 작업 개요

- 작업ID: P37
- 협력사(가상): 원청-제선 · 공종: 조업(원청 직영)
- 구역: ALL 전 구역 — 노체(TOP~HEARTH), CASTHOUSE, TUYERE, DOWNCOMER·GCP 가스 계통, STOVE 열풍로, 주변 YARD·CRANE_PAD까지 통제
- 기준 일정(가정값): 2027-03-23 ~ 2027-03-23 (D131~D131)
- 위험 작업 유형: 가스계통
- 위험 분류 코드(시행령 제53조의2): 1호 화재·폭발, 8호 질식·중독
- 필요 허가: 원청 조업 절차
- 선행 작업: P35 (열풍로 승온·기밀시험·퍼지), P36 (노내 코크스 충전·건조)

## 3. 위험 요인과 예상 사고

- 질식·중독: 화입 뒤 노정·블리더·풍구·출선구에서 CO가 많이 나온다(R11). 통제가 풀리기 전 노체 주변·노정·가스 계통 가까이 들어간 사람이 쓰러진다. 가스 계통(DOWNCOMER·GCP·STOVE) 안에 사람이 남아 있으면 가스가 흐르는 순간 사망한다.
- 화재·폭발: 반납되지 않은 화기 허가(마무리 용접)가 가스가 흐르는 계통 옆에 남아 있다. 기밀시험 뒤 다시 푼 플랜지에서 가스가 샌다. 풀리지 않은 LOTO를 강제로 풀어 밸브·차단기 순서가 꼬인다(R23).
- 고온·비산: 첫 출선·슬래그 배출 때 주상(CASTHOUSE)·수재설비(SLAG) 비산, 풍구 레벨 열풍 누출.
- 혼재: 화입 당일 마무리를 못 끝낸 협력사가 구역에 남아 있으려 한다. 전 협력사 통보·철수 확인이 없으면 통제가 뚫린다.

## 4. 투입 인원과 역할 (기준 12명, 계획서 인원과 맞춘다)

- 화입 총괄(조업 책임자) 1명: 절차서 승인, 전 협력사 통보, 선행 완료·허가 반납·LOTO 해제·인원 철수 확인 뒤 화입 결정
- 허가·LOTO 확인 담당 1명(원청 안전환경팀): 미반납 허가·미해제 LOTO 목록 0건 확인, 구역별 출입 허용 판정
- 가스 안전 담당 2명: 가스 계통 최종 누설 점검, 화입 후 구역별 CO·가스 측정
- 조업 운전원 4명: 송풍·열풍·가스 밸브 조작, 장입, 제어실 감시
- 구역 통제 4명: 노체 주변·가스 계통·열풍로·주상 출입구 바리케이드·표지, 조업 인원 외 출입 차단, 철수 확인 순찰

## 5. 투입 장비·자재·보호구

- 장비: 복합 가스측정기(LEL·O2·CO) 4대, 고정식 CO 검지기(TOP·TUYERE·CASTHOUSE·GCP), 가스 검지기(누설 점검), 비눗물 분무기, 무전기(전 통제 인원), 조명탑(야간 화입 대비)
- 자재: 바리케이드·「화입 중 · 전 구역 출입 금지」 배너·표지, 허가 반납 대장·LOTO 해제 대장, 구역별 출입 허용 표지
- 보호구: 안전모·안전화·보안경, 휴대용 CO 경보기(전원), 공기호흡기 2조(비상), 내화복·안면보호구(첫 출선 주상 인원), 방열 장갑

## 6. 작업 순서 (상세)

1. 화입 절차서 승인·전 협력사 통보 (화입 시각·통제 구역) — 화입 총괄이 화입 시각, 송풍·가스 투입 순서, 통제 구역(전 구역)과 해제 조건을 적은 절차서를 승인받고 전 협력사에 전날까지 문서로 통보한다. 협력사별 수신·철수 예정 서명을 받는다. 확인: 통보 대장·수신 서명.
2. 선행 작업(승온 P35·건조 P36) 완료 확인 서명 — 열풍로 승온·기밀시험 결과 인계서(P35)와 건조 완료 인계서(P36)를 받고, 두 담당자의 완료 서명을 절차서에 붙인다. 하나라도 없으면 화입을 시작하지 않는다(R08). 확인: 인계서 2건 보관.
3. 모든 작업허가서 반납·LOTO 해제 기록 확인 — 원청 안전환경팀 허가 대장에서 미반납 허가가 0건인지, P06 격리 목록의 LOTO가 모두 "관련 허가 반납 뒤 해제"로 기록됐는지 확인한다(R23). 남은 허가가 있으면 그 협력사에 철수·반납을 요구하고, 반납 전에는 LOTO를 풀지 않는다. 확인: 미반납 0건 확인 서명·LOTO 해제 대장.
4. 노체·가스 계통 전 구역 인원 철수 확인 — 구역 통제 인원이 노체(TOP~HEARTH)·TUYERE·CASTHOUSE·DOWNCOMER·GCP·STOVE·SLAG를 순찰하며 협력사 인원이 없음을 무전으로 보고하고, 모든 밀폐공간 출입자 명부가 0명인지 대조한다. 확인: 구역별 철수 확인 시각·보고자 기록.
5. 가스 계통 누설 최종 점검 — 가스 투입 직전 기밀시험 뒤 다시 손댄 플랜지·밸브가 있는지 확인하고 비눗물·가스 검지기로 점검한다. 누설이 있으면 가스 투입을 미루고 보수·재점검한다. 확인: 점검 위치·결과 기록.
6. 화입 중 전 구역 출입 통제 (조업 인원 외 금지) — 송풍 개시부터 첫 출선 뒤 측정 완료까지 전 구역 출입구를 바리케이드·배너로 막고 조업 인원만 출입한다. 노정·블리더 주변은 방산 가스 때문에 조업 인원도 CO 경보기 없이 접근하지 않는다(R11). 확인: 통제 구역·시각·통제 인원 기록.
7. 화입 후 CO·가스 측정 후 구역별 출입 허용 — 화입 뒤 구역마다 CO 30ppm 미만·LEL 10% 미만을 확인하고, 측정값이 기준 이내인 구역부터 차례로 출입 허용 표지를 바꾼다. 노정·가스 계통은 마지막에 푼다. 확인: 구역별 측정값·허용 시각·판정자 기록.

## 적용하는 공통 표준서

- SOP-04 가스 배관 연결·기밀시험

## 필수 단계

1. 화입 절차서 승인·전 협력사 통보 (화입 시각·통제 구역)
2. 선행 작업(승온 P35·건조 P36) 완료 확인 서명
3. 모든 작업허가서 반납·LOTO 해제 기록 확인
4. 노체·가스 계통 전 구역 인원 철수 확인
5. 가스 계통 누설 최종 점검
6. 화입 중 전 구역 출입 통제 (조업 인원 외 금지)
7. 화입 후 CO·가스 측정 후 구역별 출입 허용

## 판정에 쓰는 기준

- 계획서 절차에 3·4·6 단계가 없으면 F8 "필수 단계 누락" → F2 결함.
- 핵심 단계를 3·4·6으로 고른 이유: 셋 다 빠지면 바로 다수 사망사고로 이어진다. 3(허가 반납·LOTO 해제 확인)은 아직 일하는 사람이 있는 계통에 에너지가 들어가는 것을 문서로 막고, 4(전 구역 인원 철수 확인)는 그것을 눈으로 다시 확인하는 마지막 장치이며, 6(화입 중 전 구역 통제)은 가스가 흐르기 시작한 뒤 누군가 들어가는 것을 막는다. 2·5·7은 SOP-04와 R08·R11에서 다시 걸리고, 1은 기록이다.
- 허가서 반납 전 LOTO 해제·통전은 R23(금지)
- 내부 작업이 남은 계통에 가스 투입은 R07, 방산 중 상부 작업은 R11

## 작업 금지·출입 제한

- 미반납 허가·미해제 LOTO가 남은 상태에서 송풍·가스 투입 금지(R23)
- 화입 중·직후 노정·블리더 주변 접근 금지(R11)

## 3D 연결 (출입 제한 데이터)

- 구역: ALL(전 구역). 화입 당일 하루이며 해제는 구역별 측정 뒤 차례로 한다
- 제한 1(착수 조건): 구역 ALL · 방위 ALL · 종류 GAS_IN_BAN(선행 완료·허가 반납·LOTO 해제 전 송풍·가스 투입 금지) · 대상 P37 · 시점 UNTIL_HANDOVER(P35·P36 완료 서명 및 미반납 허가 0건 확인 전까지) · 범위 — · 규칙 R08 · 3D 표시 BAR_RED(P37 작업 막대 금지색)
- 제한 2: 구역 ALL · 방위 ALL · 종류 WORK_STOP(동일 계통 미반납 허가 작업 중지·철수) · 대상 OTHERS · 시점 STEP:3 · 범위 — · 규칙 R23 · 3D 표시 BANNER(미반납 허가 협력사 꼬리표)
- 제한 3: 구역 ALL · 방위 ALL · 종류 ENTRY_BAN(화입 중 전 구역 협력사 출입 금지) · 대상 OTHERS · 시점 STEP:6(송풍 개시~측정 완료) · 범위 전 구역 · 규칙 R07 · 3D 표시 TAPE+BANNER:「화입 중 · 전 구역 출입 금지」
- 제한 4: 구역 TOP·DOWNCOMER · 방위 ALL · 종류 ENTRY_BAN(화입 직후 방산 가스 구역 접근 금지) · 대상 OTHERS · 시점 STEP:7(측정 완료 전까지) · 범위 구역 전체 · 규칙 R11 · 3D 표시 SIGN:「방산 중 · CO · 접근 금지」

## 비상 조치

- CO·가스 경보(30ppm·LEL 10% 이상): 그 구역 전원 퇴출, 풍하측 반대 방향 대피, 누출 지점 확인·차단, 재측정 정상 뒤 재개
- 통제 구역 안 인원 발견: 즉시 무전 보고, 조업 운전원이 가스·송풍 절차를 멈출 수 있는지 판단, 구조자는 공기호흡기 착용 뒤 접근, 맨몸 진입 금지, 119·원청 구급 연락
- 누설 화재·폭발 징후: 상류 밸브 차단, 소화기 초기 진화, 진화 안 되면 대피·원청 소방 연락, 조업 비상 절차로 전환
- 첫 출선 비산·고온: 주상 통제 구역 밖으로 철수, 내화복 착용 인원만 접근

## 기록·보관

- 절차서·통보 대장·수신 서명, P35·P36 인계서, 미반납 허가 0건 확인 서명·LOTO 해제 대장, 구역별 철수 확인 기록, 누설 점검 기록, 통제·측정·구역별 출입 허용 기록을 원청 안전환경팀이 공사 종료 후 3년 보관(가정)
- 이 기록 전체가 산업안전보건법 제64조(혼재작업 조정)·제65조(안전·보건 정보 제공) 이행 기록이며 개수 공사 F5 이력의 마지막 장이 된다
