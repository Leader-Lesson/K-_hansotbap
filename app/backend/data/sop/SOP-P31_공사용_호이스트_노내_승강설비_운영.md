# SOP-P31 공사용 호이스트·노내 승강설비 운영 작업표준 — 합성

- 출처: KOSHA GUIDE·산업안전보건기준에 관한 규칙을 바탕으로 해커톤 시연용으로 합성한 문서. 실제 사업장 표준서가 아니며 협력사명은 가상이다.
- 적용 작업: P31 공사용 호이스트·노내 승강설비 운영 (기준 일정 작업 하나에만 적용하는 작업별 표준서)
- 문서번호 SOP-P31 · 개정 1 · 제정(가정) 2026-11-09 · 관리 부서: 원청 안전환경팀(가상) · 적용 현장: 광양 2고로 2차 개수(합성)

## 1. 목적과 적용 범위

- 목적: 노정 개구부에서 노 내부로 내려가는 공사용 호이스트·승강설비를 석 달 넘게 운영하면서, 승강로 아래로 떨어지는 자재·부품 낙하, 정격 초과 탑승·적재로 인한 추락·붕괴, 노정 승강 출입구 추락, 점검 중 운행으로 인한 끼임을 막고, 노 내부 작업(축조·해체) 인원과 인양 시간이 겹치지 않게 한다.
- 적용 범위: 호이스트 설치 검사·정격 표지, 일일 점검, 운전원 지정·신호, 인원 탑승·자재 적재 운행, 노 내부 작업 업체와 인양 시간 조정, 운영 종료·전원 차단까지.
- 적용 제외: 호이스트로 올리는 자재 자체의 작업(P20·P22 축조 등 각 표준서), 노정 호이스트·크레인 인양(P23, SOP-P23), 비계(P30, SOP-P30).

## 2. 작업 개요

- 작업ID: P31
- 협력사(가상): 가상-양중C · 공종: 호이스트
- 구역: STACK 노흉(shaft) — 승강로는 TOP 개구부에서 STACK·BELLY_BOSH를 지나 HEARTH까지
- 기준 일정(가정값): 2026-11-27 ~ 2027-03-02 (D15~D110)
- 위험 작업 유형: 고소, 중량물
- 위험 분류 코드(시행령 제53조의2): 3호 충돌(양중기·차량), 5호 낙하·비래
- 필요 허가: 중장비
- 선행 작업: P12 (노내 장입물·코크스 굴착 배출)

## 3. 위험 요인과 예상 사고

- 낙하·비래: 승강로는 노 내부 수직 공동 한가운데다. 적재함에서 튀어나온 벽돌·공구 하나가 HEARTH 노저 작업자까지 수십 m 떨어진다. 와이어 파단 시 케이지 자체가 떨어진다.
- 추락: 노정 승강 출입구에 난간·덮개가 없을 때, 케이지가 없는 층에서 문을 열 때.
- 끼임·충돌: 와이어·브레이크 점검 중 다른 사람이 운행 버튼을 누른다. 케이지와 비계·축조 발판 사이에 사람이 낀다.
- 붕괴: 탑승 인원·적재 하중 초과, 편하중.

## 4. 투입 인원과 역할 (기준 4명, 계획서 인원과 맞춘다)

- 운영 책임자(겸 운전원) 1명: 설치 검사 입회, 일일 점검 기록, 노 내부 작업 업체와 인양 시간 조정 기록
- 운전원 1명: 호이스트 운전(자격 보유), 신호 수신, 적재 하중 확인
- 신호수·하부 통제 2명: 노정 승강 출입구와 하부 착지층 신호, 승강로 하부 출입 통제, 탑승 인원 확인

## 5. 투입 장비·자재·보호구

- 장비: 공사용 호이스트(노내 승강설비) 1기, 과부하 방지장치·낙하 방지장치(설치 검사 때 확인), 윈치(비상 하강용), 작업등, 무전기
- 자재: 정격 하중·탑승 인원 표지, 승강 출입구 난간·덮개재, 승강로 하부 출입 금지 표지·바리케이드, 일일 점검표
- 보호구: 안전모(턱끈)·안전화·보안경, 안전대(노정 출입구 주변 작업), 공구 낙하 방지 끈

## 6. 작업 순서 (상세)

1. 호이스트 설치 검사·정격 하중 표지 — 설치 뒤 원청 설비 담당과 함께 와이어·브레이크·과부하 방지장치·낙하 방지장치·비상정지를 검사하고 합격 뒤에만 운행한다. 케이지 안과 각 층 출입구에 정격 하중·탑승 인원 표지를 붙인다. 확인: 검사 기록·표지 사진.
2. 운전원 지정·신호 방법 통일 — 운전원은 자격 보유자 1명으로 지정하고, 노정·하부 신호수와 무전 신호(출발·정지·비상)를 통일한다. 신호 없이 움직이지 않는다. 확인: 운전원·신호수 이름 게시.
3. 승강로 하부 출입 통제 (낙하물 방지) — 운행 중 승강로 바로 아래(STACK~HEARTH 수직선)에 사람이 없게 바리케이드·표지를 두고 하부 신호수가 막는다. 적재물은 그물·덮개로 덮어 튀어나오지 않게 한다. 확인: 통제 상태를 운행 시작 전 확인.
4. 탑승 인원·적재 하중 초과 금지 확인 — 운전원이 매 운행 탑승 인원과 적재물을 눈으로 세고 정격 이내인지 확인한다. 사람과 중량물을 함께 싣지 않는다. 과부하 경보가 울리면 내린다. 확인: 과부하 경보 발생 시 기록.
5. 노정 개구부 승강 출입구 난간·덮개 확인 — 매일 운행 전 노정 승강 출입구 난간·게이트와 케이지 없는 층의 문 잠금을 확인한다. 케이지가 그 층에 있을 때만 문이 열려야 한다. 확인: 출입구 점검표.
6. 일일 와이어·브레이크 점검 기록 — 매일 운행 전 와이어 소선 끊김·마모, 브레이크 작동, 비상정지, 과부하 방지장치를 점검한다. 점검 중에는 전원을 끄고 "점검 중" 표지를 걸어 운행을 막는다(R22). 확인: 일일 점검표 서명.
7. 노 내부 작업 업체 인양 시간 조정 기록 — 매일 아침 노 내부 작업 협력사(가상-축로I P20·P22, 가상-내화H·가상-해체G 해체)와 인양 시간대를 맞추고, 그 시간에는 승강로 주변 노 내부 작업을 멈추거나 하부 통제 안으로 들어가게 한다(R16·R18). 확인: 조정 결과를 작업일지에 서명.
8. 운영 종료·전원 차단 확인 — 하루 운영 종료 때 케이지를 정 위치에 두고 전원을 끄고 잠근다. 노정 출입구 게이트를 잠근다. 전체 운영 종료 때 해체 전 노 내부 작업이 끝났는지 확인한다. 확인: 종료 시각·잠금 확인 기록.

## 적용하는 공통 표준서

- SOP-03 중량물 인양(크레인)
- 고소 작업은 공통 표준서 없음 — 규칙 제42조~제45조(추락 방지) 적용

## 필수 단계

1. 호이스트 설치 검사·정격 하중 표지
2. 운전원 지정·신호 방법 통일
3. 승강로 하부 출입 통제 (낙하물 방지)
4. 탑승 인원·적재 하중 초과 금지 확인
5. 노정 개구부 승강 출입구 난간·덮개 확인
6. 일일 와이어·브레이크 점검 기록
7. 노 내부 작업 업체 인양 시간 조정 기록
8. 운영 종료·전원 차단 확인

## 판정에 쓰는 기준

- 계획서 절차에 3·4 단계가 없으면 F8 "필수 단계 누락" → F2 결함.
- 핵심 단계를 3·4로 고른 이유: 둘 다 빠지면 바로 사망사고로 이어진다. 3(승강로 하부 통제)은 수직 공동 아래 타 업체 작업자가 낙하물에 맞는 사고를, 4(정격 초과 금지)는 과적으로 케이지·와이어가 버티지 못해 탑승자가 떨어지는 사고를 막는다. 1·2·5·6·8은 설비 자체 점검으로 양중기 규칙에서 다시 걸리고, 7은 상대 작업(P20·P22) 표준서에서 걸린다.
- 승강로 아래 인원은 R18(금지), 점검 중 운행은 R22(금지)
- 노 내부 작업과 겹치면 R16

## 작업 금지·출입 제한

- 호이스트 운행 중 승강로 하부(STACK~HEARTH) 출입 금지(R18)
- 와이어·브레이크 점검 중 운행 금지(R22)
- 사람과 중량 자재 동시 탑승 금지, 정격 초과 적재 금지
- 노 내부 작업 업체와 맞춘 인양 시간대 밖 자재 인양 금지(R16)

## 비상 조치

- 낙하물 발생: 즉시 정지, 하부 전원 대피 지시, 원청 상황실 보고, 부상자는 밀폐공간 구조 절차로 구조
- 케이지 정지(층간 멈춤): 운전원이 비상 하강 절차(윈치)로 내리고, 탑승자는 문을 열지 않는다, 원청 설비 담당 연락
- 와이어 이상·과부하 경보: 운행 중지, "사용 금지" 표지, 점검·수리 뒤 재검사
- 끼임·추락자 발생: 비상정지·전원 차단, 구조 요청, 119·원청 구급 연락

## 기록·보관

- 설치 검사 기록, 일일 점검표, 과부하 경보 기록, 하부 통제 기록, 노 내부 작업 업체 인양 시간 조정 서명(7단계), 종료·잠금 기록을 원청 안전환경팀이 공사 종료 후 3년 보관(가정)
- 인양 시간 조정 서명은 산업안전보건법 제64조(혼재작업 조정) 이행 기록이며 F5 이력에 남긴다
