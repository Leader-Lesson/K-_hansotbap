# SOP-P31 공사용 호이스트·노내 승강설비 운영 작업표준 — 합성

- 출처: KOSHA GUIDE·산업안전보건기준에 관한 규칙을 바탕으로 해커톤 시연용으로 합성한 문서. 실제 사업장 표준서가 아니며 협력사명은 가상이다.
- 적용 작업: P31 공사용 호이스트·노내 승강설비 운영 (기준 일정 작업 하나에만 적용하는 작업별 표준서)

## 작업 개요

- 작업ID: P31
- 협력사(가상): 가상-양중C · 공종: 호이스트
- 구역: STACK 노흉(shaft)
- 기준 일정(가정값): 2026-11-27 ~ 2027-03-02 (D15~D110)
- 위험 작업 유형: 고소, 중량물
- 위험 분류 코드(시행령 제53조의2): 3호 충돌(양중기·차량), 5호 낙하·비래
- 필요 허가: 중장비
- 선행 작업: P12

## 적용하는 공통 표준서

- SOP-03 중량물 인양(크레인)
- 고소 작업은 공통 표준서 없음 — 규칙 제42조~제45조(추락 방지) 적용

## 필수 단계

1. 호이스트 설치 검사·정격 하중 표지
2. 운전원 지정·신호 방법 통일
3. 승강로 하부 출입 통제 (낙하물 방지)
4. 탑승 인원·적재 하중 초과 금지 확인
5. 노정 개구부 승강 출입구 난간·덮개 확인
6. 일일 와이어·브레이크 점검 기록
7. 노 내부 작업 업체 인양 시간 조정 기록
8. 운영 종료·전원 차단 확인

## 판정에 쓰는 기준

- 계획서 절차에 3·4 단계가 없으면 F8 "필수 단계 누락" → F2 결함.
- 승강로 아래 인원은 R18(금지), 점검 중 운행은 R22(금지)
- 노 내부 작업과 겹치면 R16

## 작업 금지·출입 제한

- 호이스트 운행 중 승강로 하부(STACK~HEARTH) 출입 금지(R18)
- 와이어·브레이크 점검 중 운행 금지(R22)

## 근거 조문

- 산업안전보건기준에 관한 규칙 제38조①11호, 제132조~제137조(양중기), 제146조
- 시행령 제53조의2 3·5호
