# SOP-P21 풍구 레벨 내화물·풍구·냉각기 신설 작업표준 — 합성

- 출처: KOSHA GUIDE·산업안전보건기준에 관한 규칙을 바탕으로 해커톤 시연용으로 합성한 문서. 실제 사업장 표준서가 아니며 협력사명은 가상이다.
- 적용 작업: P21 풍구 레벨 내화물·풍구·냉각기 신설 (기준 일정 작업 하나에만 적용하는 작업별 표준서)
- 문서번호 SOP-P21 · 개정 1 · 제정(가정) 2026-11-09 · 관리 부서: 원청 안전환경팀(가상) · 적용 현장: 광양 2고로 2차 개수(합성)

## 1. 목적과 적용 범위

- 목적: 풍구 레벨에서 내화물을 쌓고 풍구·냉각기를 철피 구멍에 끼워 넣는 작업에서, 노 내부 밀폐공간 질식, 냉각기 인양 중 낙하, 삽입 중 손 끼임, 환상관 개구부 추락을 막고, 풍구 레벨 작업이 끝나기 전에 송풍·질소 라인이 연결되는 일을 막는다.
- 적용 범위: 풍구 레벨 내화물 축조, 풍구·냉각기(대·중·소) 노내 호이스트·체인블록 인양과 삽입, 볼트 체결, 완료 퇴출 확인까지.
- 적용 제외: 노저 축조(P20, SOP-P20), 환상관 내화물(P27, SOP-P27), 송풍지관·라인 연결(P34, SOP-P34).

## 2. 작업 개요

- 작업ID: P21
- 협력사(가상): 가상-축로I · 공종: 축로+기계
- 구역: TUYERE 풍구 레벨(풍구·환상관·송풍지관) — 노 내부 하부 외곽 플랫폼, 삽입은 철피 바깥에서
- 기준 일정(가정값): 2027-02-10 ~ 2027-02-25 (D90~D105)
- 위험 작업 유형: 밀폐공간, 중량물
- 위험 분류 코드(시행령 제53조의2): 2호 끼임, 5호 낙하·비래
- 필요 허가: 밀폐공간,중장비
- 선행 작업: P20 (노저 카본블록 축조)

## 3. 위험 요인과 예상 사고

- 끼임: 냉각기(대형은 수백 kg)를 철피 구멍에 밀어 넣을 때 플랜지와 철피 사이에 손이 낀다. 신호 없이 체인블록을 당기면 바로 사고다.
- 낙하·비래: 풍구·냉각기 인양 중 줄걸이 이탈, 아래 HEARTH 노저에서 마무리 중인 작업자에게 떨어진다.
- 추락: 풍구 레벨 플랫폼과 환상관 사이 개구부, 송풍지관이 빠진 구멍으로 떨어진다.
- 질식·중독: 노 내부 쪽(내화물 축조)은 밀폐공간이다. 질소·가스 배관 맹판이 빠져 있으면 불활성가스가 들어온다.

## 4. 투입 인원과 역할 (기준 14명, 계획서 인원과 맞춘다)

- 작업책임자 1명: 허가서 2종, 출입자 명부, 완료·퇴출 확인 서명
- 안전관리자 1명: 산소·가연성가스 측정, 개구부 덮개 점검
- 감시인 2명: 노 내부 쪽 출입구 상주, 출입 기록, 비상 연락
- 축로공 5명: 풍구 레벨 내화물 축조, 줄눈
- 기계 설치공 3명: 풍구·냉각기 삽입, 볼트 체결(손 위치는 신호수가 확인)
- 신호수·인양 2명: 호이스트·체인블록 인양 신호, 하부 출입 통제

## 5. 투입 장비·자재·보호구

- 장비: 노내 호이스트(P31 가상-양중C 운영), 체인블록 3t 4대, 산소·유해가스 복합측정기 2대, 환기팬 1대(노 내부 쪽), 토크렌치, 작업등
- 구조장비: 공기호흡기 1조, 삼각대·구조용 윈치 1조, 들것
- 자재: 풍구·냉각기(대·중·소), 풍구 레벨 내화벽돌(내화벽돌 팔레트), 개구부 덮개·난간재, 맹판(배관 차단용)
- 보호구: 안전모·안전화·보안경, 안전대(개구부 주변), 방진마스크, 끼임 방지 장갑, 휴대용 산소 경보기(작업반장)

## 6. 작업 순서 (상세)

1. 밀폐공간·중장비 작업허가서 발급 — 작업책임자가 두 허가를 한 번에 받고 번호를 서로 적는다(R29). 허가서에 작업 범위(풍구 번호), 인원, 감시인, 인양 장비를 적고 플랫폼 입구에 게시한다. 확인: 허가서 번호 기록.
2. 작업 전 산소농도·가연성가스 측정 — 노 내부 쪽 진입 전 O2 18~23.5%, LEL 10% 미만, CO 30ppm 미만을 확인한다. 2시간마다 다시 잰다. 질소·가스 배관 맹판이 있는지도 함께 본다. 확인: 측정값·시각·측정자 기록.
3. 감시인 배치·출입자 명부 기록 — 감시인 2명이 노 내부 쪽 출입구를 지키며 명부를 쓴다. 공기호흡기·삼각대를 출입구 옆에 둔다. 확인: 명부·장비 점검표.
4. 풍구·냉각기 호이스트 인양 시 하부 출입 통제 — 인양 전 아래 HEARTH 노저 작업자를 내보내고 인양 경로 아래를 막는다. 인양 시간대를 노저(P20 마무리)·호이스트 운영사(P31)와 전날 맞춘다. 확인: 인양 시간대를 작업일지에 기록.
5. 신호수 지정·줄걸이 점검 — 냉각기 중량을 명판으로 확인하고 줄걸이 용구·체인블록 정격을 대조한다. 신호수 1명이 신호를 전담하고 무전 신호를 통일한다. 확인: 점검표·신호수 이름.
6. 환상관 개구부 추락 방지 덮개 확인 — 송풍지관이 빠진 구멍과 플랫폼 개구부에 덮개 또는 난간이 있는지 매일 작업 전 확인한다. 덮개를 떼고 작업할 때는 안전대를 건다. 확인: 개구부 점검표.
7. 냉각기 끼임 방지 (삽입 중 손 위치·신호 확인) — 삽입은 신호수 구령에만 움직인다. 플랜지 면 사이에 손을 넣지 않고 정렬봉·지렛대를 쓴다. 손이 보이지 않으면 멈춘다. 확인: 작업반장이 삽입마다 손 위치 확인.
8. 작업 종료 퇴출 확인·허가서 반납 — 명부를 0명으로 맞추고 허가서 2종을 반납한다. 전체 완료 때 "풍구 레벨 작업 완료·인원 철수" 서명을 배관 협력사(가상-배관O)와 원청 안전환경팀에 전달한다. 이 서명이 P34 착수 조건의 하나다.

## 적용하는 공통 표준서

- SOP-02 밀폐공간 출입작업
- SOP-03 중량물 인양(크레인)

## 필수 단계

1. 밀폐공간·중장비 작업허가서 발급
2. 작업 전 산소농도·가연성가스 측정
3. 감시인 배치·출입자 명부 기록
4. 풍구·냉각기 호이스트 인양 시 하부 출입 통제
5. 신호수 지정·줄걸이 점검
6. 환상관 개구부 추락 방지 덮개 확인
7. 냉각기 끼임 방지 (삽입 중 손 위치·신호 확인)
8. 작업 종료 퇴출 확인·허가서 반납

## 판정에 쓰는 기준

- 계획서 절차에 2·4 단계가 없으면 F8 "필수 단계 누락" → F2 결함.
- 핵심 단계를 2·4로 고른 이유: 둘 다 빠지면 바로 사망사고로 이어진다. 2(산소·가연성가스 측정)는 노 내부 쪽 질식·불활성가스 유입을, 4(인양 하부 통제)는 수백 kg 냉각기가 아래 노저 작업자에게 떨어지는 사고를 막는다. 끼임(7)·추락(6)은 중상 사고라 다음 순위로 두고, 1·3·5·8은 공통 표준서 SOP-02·03에서 다시 걸린다.
- 풍구 레벨 작업 완료 전 송풍·질소 라인 연결(P34)은 R08(금지, 순서)
- 인양 아래 노저 작업은 R16·R18, 냉각기 삽입 중 끼임은 R22

## 작업 금지·출입 제한

- 인양 중 TUYERE 아래 HEARTH 진입 금지(R16·R18)
- 풍구 레벨 작업 완료·퇴출 확인 전 질소·가스·송풍 라인 연결(P34) 금지(R08)
- 노 내부 쪽 축조 중 같은 공간 타 업체 화기 금지(R05)
- 냉각기 삽입 중 체인블록 조작은 신호수 구령에만(R22)

## 3D 연결 (출입 제한 데이터)

- 구역: TUYERE(풍구 레벨 플랫폼과 노 내부 하부 외곽). 작업 풍구 번호·방위는 계획서를 따른다 (없으면 구역 전체)
- 제한 1: 구역 HEARTH · 방위 ALL · 종류 LIFT_PATH(인양 경로 하부 출입 통제) · 대상 OTHERS · 시점 STEP:4(풍구·냉각기 인양 시간대) · 범위 구역 전체 · 규칙 R18 · 3D 표시 CONE(인양 시간대에만 러버콘)
- 제한 2: 구역 TUYERE · 방위 SAME · 종류 HOT_WORK_BAN(노 내부 쪽 밀폐 작업 중 타 업체 화기 금지) · 대상 OTHERS · 시점 DURING · 범위 구역 전체 · 규칙 R05 · 3D 표시 TAPE+SIGN:「풍구 레벨 축조 중 · 화기 금지」
- 제한 3(계통): 구역 TUYERE · 방위 ALL · 종류 GAS_IN_BAN(송풍·N2·BFG 라인 연결 금지) · 대상 P34 · 시점 UNTIL_HANDOVER(8단계 서명 전까지) · 범위 — · 규칙 R08 · 3D 표시 BAR_RED(P34 작업 막대 금지색)

## 비상 조치

- 산소·가스 경보: 노 내부 쪽 전원 즉시 퇴출, 감시인이 명부로 인원 확인, 원청 상황실 보고, 재측정 정상 뒤 재진입
- 끼임 사고: 체인블록 역방향으로 하중 해제, 구조 뒤 119·원청 구급 연락, 장비 그대로 두고 원청 보고
- 인양물 낙하·추락자 발생: 인양 정지, 하부 출입 전면 차단, 구조자는 삼각대·공기호흡기 사용

## 기록·보관

- 허가서 2종, 산소·가스 측정 기록, 출입자 명부, 줄걸이 점검표, 개구부 점검표, 인양 시간대 기록, 완료·철수 서명지를 원청 안전환경팀이 공사 종료 후 3년 보관(가정)
- 완료·철수 서명지는 P34 착수 조건의 근거 문서로 F5 이력에 남긴다
