# SOP-P28 슬래그 수재설비 보수 작업표준 — 합성

- 출처: KOSHA GUIDE·산업안전보건기준에 관한 규칙을 바탕으로 해커톤 시연용으로 합성한 문서. 실제 사업장 표준서가 아니며 협력사명은 가상이다.
- 적용 작업: P28 슬래그 수재설비 보수 (기준 일정 작업 하나에만 적용하는 작업별 표준서)
- 문서번호 SOP-P28 · 개정 1 · 제정(가정) 2026-11-09 · 관리 부서: 원청 안전환경팀(가상) · 적용 현장: 광양 2고로 2차 개수(합성)

## 1. 목적과 적용 범위

- 목적: 주상 외측 슬래그 수재설비(수재 슈트·조립조·탈수기·펌프)를 보수·교체하는 화기·중량물 작업에서, 수재수 계통 잔압·배수 미비로 인한 물 분출, 절단·용접 불티 화재, 설비 인양 중 낙하, 반입 차량과 보행자 충돌을 막는다.
- 적용 범위: 수재수 계통 LOTO·배수, 슈트·탈수기·펌프 절단·용접·교체, 설비 크레인 인양, 자재 차량 반입, 종료 인계까지.
- 적용 제외: 출선장 개조(P24, SOP-P24), 잔선구 출선(P07, SOP-P07), 전기·계장(P29, SOP-P29).

## 2. 작업 개요

- 작업ID: P28
- 협력사(가상): 가상-주상K · 공종: 기계+토목
- 구역: SLAG 슬래그 수재설비 — 주상 외측, 출선(P07) 통제 구역에 인접
- 기준 일정(가정값): 2026-11-22 ~ 2027-02-20 (D10~D100)
- 위험 작업 유형: 화기, 중량물
- 위험 분류 코드(시행령 제53조의2): 1호 화재·폭발, 3호 충돌(양중기·차량)
- 필요 허가: 화기,중장비
- 선행 작업: P06 (에너지 격리 LOTO)

## 3. 위험 요인과 예상 사고

- 고압수 분출: 수재수 펌프·배관에 잔압이 남은 채 플랜지를 풀면 물이 튄다. 조립조에 물이 남아 있으면 절단 중 수증기.
- 화재·폭발: 탈수기 벨트·유압유·펌프 윤활유에 절단 불티가 붙는다. 인접 주상(P24) 도장·유류 작업과 11m 안이면 서로 위험하다.
- 낙하·비래: 탈수기 드럼·펌프(수 톤) 인양 중 줄걸이 이탈, 크레인 선회 반경 안 인원.
- 충돌: 자재 트레일러·지게차와 보행자, 좁은 수재설비 통로.
- 고온 비산: 출선(P07) 시간대 용융물·슬래그 비산이 수재 슈트 쪽으로 온다.

## 4. 투입 인원과 역할 (기준 10명, 계획서 인원과 맞춘다)

- 작업책임자 1명: 허가서 2종, LOTO·배수 확인 서명, 출선 통제 시간대 확인
- 화재감시자 1명: 절단·용접 중 상주, 종료 후 30분 감시, 소화기 관리
- 신호수 1명: 설비 인양 신호, 인양 경로 하부 통제
- 유도자 1명: 트레일러·지게차 유도, 보행로 분리
- 기계공 3명: 슈트·탈수기·펌프 탈거·설치, 볼트 체결
- 용접·절단공 2명: 절단·브래킷 용접(자격 보유)
- 크레인 운전원 1명: 크롤러 크레인 운전(자격 보유)

## 5. 투입 장비·자재·보호구

- 장비: 크롤러 크레인 1대, 지게차 1대, 체인블록 3t 2대, 용접기 1대, 가스 용기 랙(산소절단기), 복합 가스측정기 1대, 압력계(잔압 확인), 조명탑(야간), 풍속계
- 자재: 교체 슈트·탈수기 부품·펌프, 가스켓·볼트, LOTO 잠금장치·꼬리표, 불티비산방지포, 소화기 2대, 바리케이드·보행로 표지
- 보호구: 안전모·안전화·보안경, 용접 보안면·방열 장갑, 방수 장갑(배수 작업), 무전기

## 6. 작업 순서 (상세)

1. 작업허가서(화기·중장비) 발급 — 작업책임자가 두 허가를 받고 번호를 서로 적는다(R29). 허가서에 절단·용접 위치, 인양 설비·중량, 차량 반입 시간, 출선(P07) 통제 시간대를 적고 수재설비 입구에 게시한다. 확인: 허가서 번호 기록.
2. 수재수 계통 LOTO·배수 확인 — P06 격리 목록과 LOTO 번호를 대조하고 수재수 펌프 전원·상류 밸브가 잠겨 있는지 확인한다. 드레인 밸브를 열어 압력계가 0인지 보고, 조립조·배관 안 물을 뺀 뒤 플랜지를 푼다. 확인: LOTO 번호·압력 0 확인 시각 기록.
3. 작업 전 가스 측정·가연물 제거 — 절단·용접 전 작업 위치에서 LEL 10% 미만을 확인하고 반경 11m 안 유압유·윤활유·벨트·폐기물을 치우거나 방화포로 덮는다. 확인: 측정값·제거 내용 기록.
4. 화재감시자 배치·소화기 비치 — 감시자가 절단·용접 중 상주하고 소화기 2대를 손 닿는 곳에 둔다. 불티가 조립조·배수로로 튀는지 본다. 확인: 감시자 이름을 허가서에 기재.
5. 설비 인양 신호수 지정·하부 출입 통제 — 인양물 중량·줄걸이 용구·크레인 정격을 대조하고 신호수와 무전 신호를 통일한다. 인양 경로 아래와 선회 반경 안에 사람이 없게 막는다. 풍속 10m/s 이상 중지. 확인: 점검표·인양 시간대 기록.
6. 차량 반입 유도자 배치·보행로 분리 — 트레일러·지게차 진출입 때 유도자가 앞장서고 보행로는 바리케이드로 분리한다. 후진 때는 경보음·유도자 수신호. 확인: 반입 시각·유도자 이름 기록.
7. 작업 종료 후 30분 화재감시 — 절단·용접이 끝난 뒤 30분 동안 감시자가 자리를 지키며 잔불을 확인한다. 벨트·유압 배관 주변을 다시 본다. 확인: 감시 종료 시각 기록.
8. 허가서 반납 — 허가서 2종을 반납하고, 교체 완료 설비는 원청 설비 담당에게 인계한다. LOTO 해제는 관련 허가가 모두 반납된 뒤 원청 정비가 한다(R23).

## 적용하는 공통 표준서

- SOP-01 화기작업
- SOP-03 중량물 인양(크레인)

## 필수 단계

1. 작업허가서(화기·중장비) 발급
2. 수재수 계통 LOTO·배수 확인
3. 작업 전 가스 측정·가연물 제거
4. 화재감시자 배치·소화기 비치
5. 설비 인양 신호수 지정·하부 출입 통제
6. 차량 반입 유도자 배치·보행로 분리
7. 작업 종료 후 30분 화재감시
8. 허가서 반납

## 판정에 쓰는 기준

- 계획서 절차에 4·5 단계가 없으면 F8 "필수 단계 누락" → F2 결함.
- 핵심 단계를 4·5로 고른 이유: 둘 다 빠지면 바로 사망·중대사고로 이어진다. 4(화재감시자)는 유압유·벨트가 있는 설비에서 불티가 번지는 것을 바로 잡는 사람이고, 5(인양 신호수·하부 통제)는 수 톤 설비가 사람 머리 위를 지나지 않게 하는 장치다. 1·2·3·6·7·8은 공통 표준서 SOP-01·03에서 다시 걸리거나 사고가 즉시 나지 않는다.
- 인양 경로 아래 인원은 R18(금지), 차량과 보행자는 R21(조건부)
- 출선(P07) 통제 구역에 인접 — R12

## 작업 금지·출입 제한

- 인양 중 SLAG 하부 출입 금지(R18)
- 출선(P07) 시간대 주상 외측 접근 금지(R12)
- 절단·용접 중 반경 11m 안 유류·도장 작업 금지(R01)
- 차량 반입 통로 보행 금지, 유도자 없이 후진 금지(R21)

## 비상 조치

- 화재: 소화기 초기 진화, 유압유 화재는 분말 소화기, 진화 안 되면 대피·원청 소방 연락
- 고압수 분출: 상류 밸브 잠금 확인, 분출 구간 접근 금지, 전기 설비 침수 여부 확인 뒤 재개
- 인양물 낙하·차량 충돌: 크레인·차량 정지, 부상자 구조, 119·원청 구급 연락, 원청 상황실 보고
