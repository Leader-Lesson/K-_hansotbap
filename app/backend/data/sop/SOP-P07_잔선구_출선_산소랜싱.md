# SOP-P07 잔선구 출선(salamander tapping, 산소 랜싱) 작업표준 — 합성

- 출처: KOSHA GUIDE·산업안전보건기준에 관한 규칙을 바탕으로 해커톤 시연용으로 합성한 문서. 실제 사업장 표준서가 아니며 협력사명은 가상이다.
- 적용 작업: P07 잔선구 출선(salamander tapping, 산소 랜싱) (기준 일정 작업 하나에만 적용하는 작업별 표준서)

## 작업 개요

- 작업ID: P07
- 협력사(가상): 가상-출선D · 공종: 출선 전문
- 구역: HEARTH 노상·노저(hearth)
- 기준 일정(가정값): 2026-11-13 ~ 2026-11-14 (D1~D2)
- 위험 작업 유형: 화기
- 위험 분류 코드(시행령 제53조의2): 1호 화재·폭발, 5호 낙하·비래
- 필요 허가: 화기
- 선행 작업: P04

## 적용하는 공통 표준서

- SOP-01 화기작업

## 필수 단계

1. 화기작업허가서 발급 (산소 랜싱 시간·구간)
2. 출선 시간대 공지 (종풍 후 24시간 이내, 구멍당 최대 4시간)
3. 노저·주상·출선구 주변 전면 출입 통제 (바리케이드·감시원)
4. 산소 랜스·호스 누설 점검
5. 내화복·안면보호구 착용 확인
6. 용융물 비산 방향 하부·주상 작업 중지 확인
7. 출선 완료 후 살수(P08) 착수 신호 인계

## 판정에 쓰는 기준

- 계획서 절차에 3·6 단계가 없으면 F8 "필수 단계 누락" → F2 결함.
- 출선 중 노저·주상·출선구 주변 모든 작업은 R12(금지) — P09 노정 해체 앞당김이 시연 S5
- 출선 완료 전 살수가 시작되면 R13(금지, 순서)

## 작업 금지·출입 제한

- 출선 시간대(≤24h) HEARTH·CASTHOUSE·SLAG 전 구역 타 업체 출입 금지(R12)
- 출선 중 상부(TOP·STACK) 해체·인양 작업 착수 금지

## 근거 조문

- 산업안전보건기준에 관한 규칙 제20조 9호, 제241조(화재위험작업)
- 시행령 제53조의2 1·5호, ispatguru 종풍 직후 출선 제한(참고)
