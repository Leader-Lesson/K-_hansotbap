# SOP-P34 질소·가스·송풍 라인 복구 연결 작업표준 — 합성

- 출처: KOSHA GUIDE·산업안전보건기준에 관한 규칙을 바탕으로 해커톤 시연용으로 합성한 문서. 실제 사업장 표준서가 아니며 협력사명은 가상이다.
- 적용 작업: P34 질소·가스·송풍 라인 복구 연결 (기준 일정 작업 하나에만 적용하는 작업별 표준서)

## 작업 개요

- 작업ID: P34
- 협력사(가상): 가상-배관O · 공종: 배관(가스)
- 구역: TUYERE 풍구 레벨(풍구·환상관·송풍지관)
- 기준 일정(가정값): 2027-03-04 ~ 2027-03-12 (D112~D120)
- 위험 작업 유형: 화기, 가스계통
- 위험 분류 코드(시행령 제53조의2): 1호 화재·폭발, 8호 질식·중독
- 필요 허가: 화기
- 선행 작업: P20,P21,P22

## 적용하는 공통 표준서

- SOP-01 화기작업
- SOP-04 가스 배관 연결·기밀시험

## 필수 단계

1. 작업허가서(화기·가스) 발급
2. 상류 차단밸브 잠금·LOTO 번호 기재
3. 맹판 설치 확인 (연결 전까지 유지)
4. 작업 전 가스 측정 (LEL 10% 미만·O2 18~23.5%)
5. 연결 대상 계통 내부 작업 완료·인원 철수 확인 (노저·풍구·노흉 축조 P20·P21·P22, 환상관 P27)
6. 화재감시자 배치 (연결부 용접)
7. 볼트 체결·연결부 용접
8. 질소 가압 기밀시험 (누설 확인)
9. 맹판 제거·LOTO 해제 기록
10. 허가서 반납

## 판정에 쓰는 기준

- 계획서 절차에 4·5 단계가 없으면 F8 "필수 단계 누락" → F2 결함.
- 노흉 축조(P22) 완료 전 연결을 시작하면 R08(순서 위반, 금지)·R07(금지) — 시연 S1 핵심 장면
- 같은 구역 화기와 가스 개방이 겹치면 R04(금지)

## 작업 금지·출입 제한

- 연결 대상 계통 내부(HEARTH·TUYERE·STACK) 작업 완료·퇴출 확인 전 착수 금지(R08·R07)
- 연결 중 TUYERE 반경 11m 타 업체 화기 금지(R04)

## 근거 조문

- 산업안전보건기준에 관한 규칙 제619조②4호, 제241조②5호
- KOSHA GUIDE P-35-2012, 현대제철 2013(공개 사례), HSG250 para 22 허가 상호참조
