# SOP-P34 질소·가스·송풍 라인 복구 연결 작업표준 — 합성

- 출처: KOSHA GUIDE·산업안전보건기준에 관한 규칙을 바탕으로 해커톤 시연용으로 합성한 문서. 실제 사업장 표준서가 아니며 협력사명은 가상이다.
- 적용 작업: P34 질소·가스·송풍 라인 복구 연결 (기준 일정 작업 하나에만 적용하는 작업별 표준서)
- 문서번호 SOP-P34 · 개정 1 · 제정(가정) 2026-11-09 · 관리 부서: 원청 안전환경팀(가상) · 적용 현장: 광양 2고로 2차 개수(합성)

## 1. 목적과 적용 범위

- 목적: 고로 개수 마무리 단계에서 풍구 레벨의 질소(N2)·고로가스(BFG)·송풍 라인을 다시 연결할 때, 연결 대상 계통 안에 사람이 남아 있거나 가스가 남아 있는 상태에서 작업하는 사고를 막는다.
- 적용 범위: 풍구 레벨 환상관·송풍지관·질소 퍼지 라인·가스 라인의 플랜지 연결, 볼트 체결, 연결부 용접, 질소 가압 기밀시험, 맹판 제거까지.
- 적용 제외: 열풍로 승온과 가스 계통 기밀시험(P35, SOP-P35), 화입(P37)은 별도 표준서를 따른다.

## 2. 작업 개요

- 작업ID: P34
- 협력사(가상): 가상-배관O · 공종: 배관(가스)
- 구역: TUYERE 풍구 레벨(풍구·환상관·송풍지관)
- 기준 일정(가정값): 2027-03-04 ~ 2027-03-12 (D112~D120)
- 위험 작업 유형: 화기, 가스계통
- 위험 분류 코드(시행령 제53조의2): 1호 화재·폭발, 8호 질식·중독
- 필요 허가: 화기
- 선행 작업: P20,P21,P22 (노저·풍구 레벨·노흉 축조 완료), P27 (환상관 내화물)

## 3. 위험 요인과 예상 사고

- 질식·중독: 연결 대상 계통(노 내부 HEARTH·TUYERE·STACK, 환상관) 안에 축조 인원이 남아 있는데 질소가 들어가면 산소 결핍으로 쓰러진다. 공개 사례: 현대제철 2013, 내화물 작업 종료 전 아르곤 배관 연결로 5명 사망.
- 화재·폭발: 연결부 용접 불티가 잔류 고로가스(BFG, CO 포함)나 11m 안 가연물에 닿는다.
- 가스 누출: 기밀시험 없이 라인을 살리면 플랜지에서 CO가 새어 풍구 레벨 작업자에게 닿는다.
- 끼임·낙하: 대구경 플랜지 정렬 중 손 끼임, 볼트·공구 낙하(아래층 CASTHOUSE 작업자).

## 4. 투입 인원과 역할 (기준 8명, 계획서 인원과 맞춘다)

- 작업책임자 1명: 허가서 발급·단계별 확인 서명, 원청 안전환경팀과 연결 시점 협의
- 화재감시자 1명: 용접 중 상주, 종료 후 30분 감시, 소화기 2대 관리
- 가스측정 담당 1명(작업책임자 겸임 가능): 작업 전·2시간마다·용접 재개 때 측정, 기록
- 배관공 4명: 플랜지 면 청소·가스켓·볼트 체결·맹판 설치와 제거
- 용접사 2명: 연결부 용접(자격 보유)

## 5. 투입 장비·자재·보호구

- 장비: 복합 가스측정기(LEL·O2·CO) 2대, 용접기 2대, 질소 가압 장비(레귤레이터·압력계), 토크렌치, 체인블록 1t, 이동식 비계(플랜지 높이 작업)
- 자재: 가스켓(규격별), 볼트·너트, 맹판(블라인드 플랜지), LOTO 잠금장치·꼬리표, 불티비산방지포
- 보호구: 안전모·안전화·보안경, 용접 보안면·방열 장갑, 송기마스크 또는 공기호흡기(가스 측정 이상 시 대피용), 휴대용 CO 경보기(전원)

## 6. 작업 순서 (상세)

1. 작업허가서(화기·가스) 발급 — 작업책임자가 원청 안전환경팀에서 화기·가스 허가를 받는다. 허가서에 작업 장소(풍구 번호·플랜지 번호), 시간, 감시자 이름, 연결 대상 계통을 적고 작업 구역 입구에 게시한다. 확인: 허가서 번호를 작업일지에 기록.
2. 상류 차단밸브 잠금·LOTO 번호 기재 — 질소·BFG·송풍 상류 밸브를 닫고 잠금장치를 건다. LOTO 번호를 허가서와 작업일지에 적는다. 확인: 잠금 사진 1장.
3. 맹판 설치 확인 (연결 전까지 유지) — 상류 쪽 플랜지에 맹판이 들어 있는지 눈으로 확인하고 꼬리표를 건다. 맹판은 8단계 전까지 제거하지 않는다. 확인: 맹판 위치·수량 기록.
4. 작업 전 가스 측정 (LEL 10% 미만·O2 18~23.5%) — 연결부 양쪽 배관 안과 작업 위치 호흡 높이에서 LEL·O2·CO를 잰다. LEL 10% 이상이거나 O2가 범위를 벗어나면 작업을 멈추고 환기·퍼지 뒤 다시 잰다. 2시간마다, 용접 재개 때마다 다시 잰다. 확인: 측정값·시각·측정자를 허가서에 기록.
5. 연결 대상 계통 내부 작업 완료·인원 철수 확인 (노저·풍구·노흉 축조 P20·P21·P22, 환상관 P27) — 축조 협력사(가상-축로I·가상-축로L)의 작업책임자에게 "축조 완료·인원 철수 확인" 서명을 받는다. 노 내부 출입자 명부가 0명인지 확인한다. 서명이 없으면 연결을 시작하지 않는다. 확인: 인계 서명지 보관.
6. 화재감시자 배치 (연결부 용접) — 용접 전 반경 11m 안 가연물을 치우거나 방화포로 덮고, 아래층(CASTHOUSE) 출입을 막는다. 소화기 2대를 손 닿는 곳에 둔다. 확인: 감시자 이름을 허가서에 기재.
7. 볼트 체결·연결부 용접 — 플랜지 면 청소, 가스켓 교체, 대각선 순서로 토크 체결. 용접은 자격자가 하고 불티비산방지포를 아래에 깐다. 확인: 토크 값·용접사 이름 기록.
8. 질소 가압 기밀시험 (누설 확인) — 원청 설비 담당이 정한 시험 압력으로 질소를 넣고 비눗물·검지기로 플랜지·용접부 누설을 확인한다. 누설이 있으면 압력을 빼고 7단계로 돌아간다. 확인: 시험 압력·유지 시간·결과 기록.
9. 맹판 제거·LOTO 해제 기록 — 기밀시험 합격 뒤 맹판을 빼고, 잠금을 푼 시각·사람을 기록한다. 해제는 모든 관련 허가가 반납된 뒤에만 한다(R23).
10. 허가서 반납 — 작업 종료 후 30분 화재감시를 마치고 허가서를 반납한다. 연결 완료를 원청 안전환경팀과 화입 담당(P36·P37)에게 알린다.

## 적용하는 공통 표준서

- SOP-01 화기작업
- SOP-04 가스 배관 연결·기밀시험

## 필수 단계

1. 작업허가서(화기·가스) 발급
2. 상류 차단밸브 잠금·LOTO 번호 기재
3. 맹판 설치 확인 (연결 전까지 유지)
4. 작업 전 가스 측정 (LEL 10% 미만·O2 18~23.5%)
5. 연결 대상 계통 내부 작업 완료·인원 철수 확인 (노저·풍구·노흉 축조 P20·P21·P22, 환상관 P27)
6. 화재감시자 배치 (연결부 용접)
7. 볼트 체결·연결부 용접
8. 질소 가압 기밀시험 (누설 확인)
9. 맹판 제거·LOTO 해제 기록
10. 허가서 반납

## 판정에 쓰는 기준

- 계획서 절차에 4·5 단계가 없으면 F8 "필수 단계 누락" → F2 결함.
- 핵심 단계를 4·5로 고른 이유: 둘 다 빠지면 바로 사망사고로 이어지는 단계다. 4(가스 측정)는 잔류 가스 폭발·CO 중독을, 5(내부 인원 철수 확인)는 질소 유입 질식(현대제철 2013)을 막는 마지막 확인이다. 나머지 단계는 빠져도 다른 단계·공통 표준서에서 걸리거나 사고가 즉시 나지 않는다.
- 노흉 축조(P22) 완료 전 연결을 시작하면 R08(순서 위반, 금지)·R07(금지) — 시연 S1 핵심 장면
- 같은 구역 화기와 가스 개방이 겹치면 R04(금지)

## 작업 금지·출입 제한

- 연결 대상 계통 내부(HEARTH·TUYERE·STACK) 작업 완료·퇴출 확인 전 착수 금지(R08·R07)
- 연결 중 TUYERE 반경 11m 타 업체 화기 금지(R04)
- 용접 중 아래층 CASTHOUSE 연결부 직하 출입 통제(R03, 불티 낙하)

## 3D 연결 (출입 제한 데이터)

- 구역: TUYERE(풍구 레벨 외곽 플랫폼). 연결 작업 위치는 계획서의 풍구 번호·방위를 따른다 (계획서에 없으면 구역 전체)
- 작업 중 제한 1: TUYERE 전 방위, 타 업체 화기작업 금지, 범위 반경 11m [규칙 241조의2], 기간 = 연결 작업 시간 전체. 3D 표시: 풍구 레벨 안전띠 + 「가스 연결 중 · 화기 금지」 표지
- 작업 중 제한 2: CASTHOUSE 연결부 직하 방위, 출입 통제, 기간 = 용접 시간대. 3D 표시: 주상 해당 방위 러버콘
- 착수 조건 제한: HEARTH·TUYERE·STACK 노 내부에 타 업체 인원이 있으면 이 작업 시작 불가(R08). 3D 표시: 노 내부 인원 0명 확인 전 TUYERE 작업 막대를 금지색으로

## 비상 조치

- 가스 경보(CO 30ppm·LEL 10% 이상): 즉시 작업 중지, 풍하측 반대 방향 대피, 작업책임자가 원청 상황실에 보고, 재측정 정상 뒤 재개
- 화재: 소화기 초기 진화, 진화 안 되면 대피·원청 소방 연락, 상류 밸브 잠금 유지 확인
- 인원 쓰러짐(질식 의심): 구조자는 공기호흡기 착용 뒤 진입, 맨몸 진입 금지, 119·원청 구급 연락

## 기록·보관

- 허가서, 가스 측정 기록, LOTO 기록, 인계 서명지(5단계), 기밀시험 기록을 원청 안전환경팀이 공사 종료 후 3년 보관(가정)
- 이 기록이 산업안전보건법 제64조(혼재작업 조정)·제65조(안전·보건 정보 제공) 이행 기록이 된다
