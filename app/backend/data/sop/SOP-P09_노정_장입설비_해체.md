# SOP-P09 노정 장입설비(벨리스 탑·호퍼) 해체 작업표준 — 합성

- 출처: KOSHA GUIDE·산업안전보건기준에 관한 규칙을 바탕으로 해커톤 시연용으로 합성한 문서. 실제 사업장 표준서가 아니며 협력사명은 가상이다.
- 적용 작업: P09 노정 장입설비(벨리스 탑·호퍼) 해체 (기준 일정 작업 하나에만 적용하는 작업별 표준서)
- 문서번호 SOP-P09 · 개정 1 · 제정(가정) 2026-11-09 · 관리 부서: 원청 안전환경팀(가상) · 적용 현장: 광양 2고로 2차 개수(합성)

## 1. 목적과 적용 범위

- 목적: 노정 플랫폼(지상 수십 m)에서 벨리스 탑·호퍼·슈트를 절단해 크레인으로 내리는 작업에서, 노정 잔류가스 중독, 절단 불티가 노 내부·아래층으로 떨어지는 화재, 노정 개구부 추락, 해체 부재 인양 중 낙하를 막는다.
- 적용 범위: 화기·고소·중장비 허가, 노정 잔류가스 측정, 화재감시, 개구부 보호, 부재 절단·인양, 하부·노 내부 통제, 개구부 보호 상태 인계까지.
- 적용 제외: 노정 장입설비 신설(P23, SOP-P23), 상승관·하강관 절단(P10, SOP-P10)은 별도 표준서를 따른다. 종풍·방산(P04·P05)이 끝나고 P06 격리가 된 뒤에만 시작한다.

## 2. 작업 개요

- 작업ID: P09
- 협력사(가상): 가상-기계E · 공종: 기계 정비+양중
- 구역: TOP 노정 플랫폼(장입설비)
- 기준 일정(가정값): 2026-11-15 ~ 2026-11-26 (D3~D14)
- 위험 작업 유형: 화기, 고소, 중량물, 가스계통
- 위험 분류 코드(시행령 제53조의2): 4호 추락, 5호 낙하·비래, 8호 질식·중독
- 필요 허가: 화기,고소,중장비
- 선행 작업: P06

## 3. 위험 요인과 예상 사고

- 질식·중독: 종풍 직후 노정과 장입설비 내부(호퍼·시일 밸브 공간)에 고로가스(CO)가 남아 있다. 블리더 방산(P05)이 끝나지 않았거나 측정 없이 들어가면 중독된다(R11).
- 추락: 벨리스 탑을 들어내면 노정에 큰 개구부가 생긴다. 덮개·난간 없이 작업하면 노 내부(수십 m)로 떨어진다.
- 낙하·비래: 절단 부재(수 t~수십 t)를 크레인으로 내리는 동안 아래 노 내부·노체 주변에 사람이 있으면 피할 수 없다. 절단 볼트·공구가 개구부로 떨어져 노 내부 작업자(P08 살수·P12 굴착)에게 닿는다(R16·R18).
- 화재: 절단 불티가 노 내부 잔류 코크스·가스, 노정 케이블·그리스에 닿는다.
- 혼재: 출선(P07) 시간대에 해체를 앞당기면 노체 주변 통제와 충돌한다(R12, 시연 S5).

## 4. 투입 인원과 역할 (기준 14명, 계획서 인원과 맞춘다)

- 작업책임자 1명: 화기·고소·중장비 허가, 노정 가스 측정 확인, 해체 순서·인양 계획 관리
- 화재감시자 1명: 절단 중 상주, 종료 후 30분 감시, 소화기 관리
- 가스 측정 담당 1명(작업책임자 겸임 가능): 노정·설비 내부 CO·LEL 측정
- 절단공(산소절단) 4명: 볼트·부재 절단, 임시 고정
- 크레인 운전원 1명·신호수 1명·줄걸이 2명: 해체 부재 인양(크롤러 크레인 250t)
- 고소 작업자·개구부 보호 2명: 덮개·난간 설치, 안전대 체결 확인
- 하부 통제원 1명: 노 내부·노체 주변 인양 경로 아래 출입 통제

## 5. 투입 장비·자재·보호구

- 장비: 크롤러 크레인(보조 크레인 250t급), 노정 호이스트, 체인블록(5t, 부재 임시 지지), 산소절단기(가스 용기 랙) 4조, 복합 가스측정기(CO·LEL·O2) 2대, 고소작업대, 풍속계, 무전기, 조명탑
- 자재: 개구부 덮개(하중 확인)·임시 난간·안전난간대, 와이어로프·샤클(검사 꼬리표), 불티비산방지포·방화포, 소화기 2대 이상, 출입 통제 안전띠·표지, 장입설비 부품 적치대
- 보호구: 안전모·안전화·보안경, 안전대(2중 걸이, 노정 전원), 용접 보안면·방열 장갑(절단공), 휴대용 CO 경보기(전원), 공기호흡기(설비 내부 진입·대피용)

## 6. 작업 순서 (상세)

1. 작업허가서 발급 (화기·고소·중장비) — 작업책임자가 화기·고소·중장비 허가를 함께 받고 번호를 서로 적는다(R29). 출선(P07)·살수(P08) 시간대와 겹치지 않는지 일정표로 확인한다(R12·R14). 확인: 허가서 번호·일정 확인 기록.
2. 노정 잔류가스 측정 (CO 30ppm 미만·LEL 10% 미만) 후 진입 — 노정 플랫폼과 호퍼·시일 밸브 내부 등 장입설비 안 공간에서 CO·LEL·O2를 잰다. 기준 밖이면 들어가지 않고 환기 뒤 다시 잰다. 절단 재개 때마다 다시 잰다. 확인: 측정값·시각·측정자 기록.
3. 화재감시자 배치 (절단 중 상주, 종료 후 30분 감시) — 절단 위치마다 감시자를 두고 소화기 2대를 둔다. 개구부 아래로 불티가 떨어지지 않게 방지포를 깐다. 종료 후 30분 감시. 확인: 감시자 서명.
4. 노정 개구부 덮개·난간 설치 (추락 방지) — 부재를 들어낸 자리에 즉시 하중 확인된 덮개 또는 임시 난간을 설치한다. 덮개를 열고 작업할 때는 안전대를 걸고 감시자가 옆에 선다. 확인: 개구부 목록·보호 상태 사진.
5. 해체 부재 인양 신호수 지정·줄걸이 점검 — 부재마다 중량·무게중심을 확인하고 와이어·샤클·러그를 점검한다. 신호수를 정하고 무전 채널을 적는다. 절단 완료 전 부재는 체인블록·크레인으로 먼저 지지한다. 확인: 점검표·신호수 이름.
6. 인양 경로 하부·노 내부 출입 통제 — 부재를 내리는 경로 아래(노체 주변 SHELL·CASTHOUSE·CRANE_PAD)와 노정 개구부 아래 노 내부(STACK 이하)에 사람이 없게 통제원이 막는다. 노 내부 작업(P08·P12)은 인양 시간대에 멈춘다(R16·R18). 확인: 인양 시간대·통제 범위 기록.
7. 안전대 체결 확인 (노정 고소) — 노정 플랫폼 전원이 안전대를 구명줄·구조물에 걸었는지 작업반장이 작업 전·개구부 작업 전마다 눈으로 확인한다. 확인: 반장 확인 서명.
8. 해체 완료·개구부 보호 상태 인계 기록 — 해체가 끝난 노정 개구부의 덮개·난간 상태, 남은 부재, 측정값을 원청 안전환경팀과 후속 작업(P10·P23·P30) 협력사에 인계한다. 허가서를 반납한다. 확인: 인계 서명지·개구부 보호 사진.

## 적용하는 공통 표준서

- SOP-01 화기작업
- SOP-03 중량물 인양(크레인)
- SOP-04 가스 배관 연결·기밀시험
- 고소 작업은 공통 표준서 없음 — 규칙 제42조~제45조(추락 방지) 적용

## 필수 단계

1. 작업허가서 발급 (화기·고소·중장비)
2. 노정 잔류가스 측정 (CO 30ppm 미만·LEL 10% 미만) 후 진입
3. 화재감시자 배치 (절단 중 상주, 종료 후 30분 감시)
4. 노정 개구부 덮개·난간 설치 (추락 방지)
5. 해체 부재 인양 신호수 지정·줄걸이 점검
6. 인양 경로 하부·노 내부 출입 통제
7. 안전대 체결 확인 (노정 고소)
8. 해체 완료·개구부 보호 상태 인계 기록

## 판정에 쓰는 기준

- 계획서 절차에 2·4·6 단계가 없으면 F8 "필수 단계 누락" → F2 결함.
- 핵심 단계를 2·4·6으로 고른 이유: 노정 해체의 사망 사고 세 유형을 하나씩 막는다. 2(잔류가스 측정 후 진입)는 종풍 직후 노정의 CO 중독을, 4(개구부 덮개·난간)는 장입설비를 들어낸 자리로 노 내부 수십 m 추락을, 6(인양 경로 하부·노 내부 통제)은 부재·공구가 아래 노 내부 작업자에게 떨어지는 낙하를 막는다. 셋 다 빠지면 바로 사망이고 다른 단계가 대신하지 못한다. 3·5·7은 SOP-01·SOP-03·추락 규칙에서 다시 걸린다.
- 블리더 방산 중 노정 작업은 R11(금지), 출선(P07) 중 착수는 R12(금지) — 시연 S5
- 노정 해체 아래 노 내부 작업이 있으면 R16(조건부)·R18(금지)

## 작업 금지·출입 제한

- 해체 중 TOP 바로 아래 STACK 노 내부 진입 금지(R16·R18)

- 노정 잔류가스 측정 결과 게시 전 노정 플랫폼 진입 금지
- 출선(P07)·살수(P08) 시간대 착수 금지(R12·R14), 블리더 방산 중 착수 금지(R11)

## 3D 연결 (출입 제한 데이터)

- 구역: TOP(노정 플랫폼). 낙하 영향은 노 내부 STACK·BELLY_BOSH·TUYERE·HEARTH 전체, 인양 경로는 SHELL·CASTHOUSE·CRANE_PAD 쪽 방위(SAME)
- 제한 1: 구역 STACK·BELLY_BOSH·TUYERE·HEARTH(노 내부), 방위 ALL, 종류 ENTRY_BAN, 대상 OTHERS(P08·P12 등), 적용 시점 DURING(해체 기간 전체, 인양 시간대는 특히), 범위 노 내부 전체, 규칙 R16·R18, 3D 표시 TAPE + SIGN「노정 해체 중 · 노 내부 출입 금지」
- 제한 2: 구역 SHELL·CASTHOUSE·CRANE_PAD, 방위 SAME(인양 경로), 종류 LIFT_PATH, 대상 OTHERS, 적용 시점 STEP:6(부재 인양 시간대), 범위 경로 직하 + 선회 반경 [팀 설정값], 규칙 R18, 3D 표시 CONE
- 제한 3: 구역 TOP, 방위 ALL, 종류 ENTRY_BAN, 대상 OTHERS(허가 인원 외), 적용 시점 DURING, 범위 플랫폼 전체, 규칙 R11·R30, 3D 표시 TAPE + SIGN「장입설비 해체 중 · 개구부 주의」
- 착수 조건: 구역 TOP, 종류 WORK_STOP(이 작업 자체), 대상 P09, 적용 시점 UNTIL_HANDOVER(P05 방산·P07 출선 완료 전까지), 규칙 R11·R12, 3D 표시 BAR_RED(P09 작업 막대 금지색) — 시연 S5

## 비상 조치

- CO 경보: 노정 전원 풍상측 대피, 쓰러진 사람은 공기호흡기 구조자만 접근, 119·원청 구급 연락
- 개구부 추락·매달림: 구조용 고소작업대·노정 호이스트로 접근, 매달린 작업자 10분 안 구조 목표 [팀 설정값], 119 연락
- 부재 낙하·줄걸이 파단: 하부 통제 유지, 노 내부 작업자 안부 확인, 원청 안전환경팀 보고, 재개 전 줄걸이 전수 점검
- 화재: 감시자 초기 진화, 절단기 밸브 차단, 노 내부 낙하 불티 확인, 진화 안 되면 대피·원청 소방 연락
