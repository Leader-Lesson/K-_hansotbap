# SOP-P13 노저 잔선(약 2천t) 천공·화약 장약·파쇄 작업표준 — 합성

- 출처: KOSHA GUIDE·산업안전보건기준에 관한 규칙을 바탕으로 해커톤 시연용으로 합성한 문서. 실제 사업장 표준서가 아니며 협력사명은 가상이다.
- 적용 작업: P13 노저 잔선(약 2천t) 천공·화약 장약·파쇄 (기준 일정 작업 하나에만 적용하는 작업별 표준서)

## 1. 목적과 적용 범위

- 목적: 출선 뒤에도 노저에 굳어 남은 잔선(약 2천 t)을 천공기로 뚫고 화약을 넣어 깨는 한 달 동안, 발파 경계 안에 남은 사람의 사망, 밀폐된 노저에서의 산소 결핍·CO·발파 후 가스 중독, 불발 화약 접촉, 파쇄물 인양 낙하를 막는다.
- 적용 범위: 발파 계획·화약류 허가, 밀폐공간 허가·측정, 천공 분진 억제, 장약 중 노체 전 구역 출입 금지·경보, 대피 확인 후 점화, 발파 후 측정·불발 확인, 파쇄물 반출 인양 통제, 화약 잔량 반납까지. 노 내부 최하단 HEARTH 에서 한다.
- 적용 제외: 노저 해체·청소(P16, SOP-P16), 위층 내화물·스테이브 해체(P14, SOP-P14), 노내 호이스트 운영(P31)은 별도 표준서를 따른다. 화약류 취급 자체는 화약류 관리 법령과 발파 책임자의 절차서를 따른다.

- 작업ID: P13
- 협력사(가상): 가상-내화H · 공종: 내화물 해체+화약
- 구역: HEARTH 노상·노저(hearth)
- 기준 일정(가정값): 2026-11-24 ~ 2026-12-22 (D12~D40)
- 위험 작업 유형: 화기, 밀폐공간
- 위험 분류 코드(시행령 제53조의2): 1호 화재·폭발, 5호 낙하·비래, 8호 질식·중독
- 필요 허가: 화기,밀폐공간,발파
- 선행 작업: P12

## 3. 위험 요인과 예상 사고

- 발파 비산·폭풍: 발파 경계 [팀 설정값] 안에 남아 있던 사람(위층 해체 P14, 주상 P24, 풍구 레벨 P11·P27)이 비산 파편·폭풍에 맞는다. 노 내부는 수직 공동이라 폭풍이 위로 올라간다(R15).
- 질식·중독: 노저는 노 안에서 가장 깊고 환기가 어렵다. 천공 분진, 발파 후 가스(CO·질소산화물)가 고인다. 측정 없이 들어가면 쓰러진다.
- 불발 화약: 발파 후 터지지 않은 장약을 천공·파쇄 중 건드린다.
- 화재·폭발: 천공·절단 화기와 화약이 같은 공간에 있다. 밀폐공간 안 화기는 R05.
- 낙하·비래: 파쇄물(수 t 덩어리)을 노내 호이스트로 올리다 떨어지면 아래 노저 작업자가 맞는다. 위층 해체물이 노저로 떨어진다(R16).

## 4. 투입 인원과 역할 (기준 12명, 계획서 인원과 맞춘다)

- 작업책임자 1명: 발파 계획·화약류 허가, 밀폐공간 허가, 경계 설정, 대피·점화 지휘
- 발파 책임자(화약류 취급 자격) 1명: 장약·결선·점화, 불발 확인, 화약 잔량 관리
- 화약 취급 보조 2명: 화약 운반·장약 보조(자격 또는 감독 아래)
- 안전관리자(측정 담당) 1명: 산소·CO·발파 후 가스 측정, 환기팬 관리
- 감시인·경계 통제원 3명: 노 내부 출입구, 노체 주변 발파 경계 지점, 경보 가동·대피 확인
- 천공·파쇄 작업자 3명: 잔선 천공기 운전, 살수, 파쇄물 정리
- 인양 신호수 1명: 파쇄물 노내 호이스트 인양 신호, 하부 통제

## 5. 투입 장비·자재·보호구

- 장비: 잔선 천공기(3D 모델 없음, 원문 이름 유지), 발파 장비(발파기·결선·저항계 — 3D 모델 없음), 환기팬 2대(송기 덕트), 산소·CO 복합측정기 3대(연속 측정 1대 고정), 살수 장비(분진 억제), 노내 호이스트(P31 가상-양중C 운영), 발파 경보 사이렌·무전기, 작업등
- 구조장비: 공기호흡기 2조, 삼각대·구조용 윈치, 들것
- 자재: 화약·뇌관(법정 보관함·운반함), 발파 매트·방호망, 발파 경계 표지·바리케이드·안전띠, 출입자 명부, 화약 수불 대장
- 보호구: 안전모·안전화·보안경, 방진마스크(천공), 귀마개, 휴대용 산소·CO 경보기(작업조마다), 안전대(인양 구간), 내열 장갑(잔선 열)

## 6. 작업 순서 (상세)

1. 발파 작업계획서·화약류 사용 허가 (발파 경계 설정) — 작업책임자와 발파 책임자가 장약량·천공 배치·발파 시각·경계 범위 [팀 설정값]·경보·대피 경로를 적은 발파 계획서를 원청 승인받고 화약류 사용 허가를 받는다. 경계 안에 드는 작업(P14·P24·P27·P30 등)을 목록으로 적어 통보한다. 확인: 승인 번호·통보 수신 기록.
2. 밀폐공간 허가·작업 전 산소·CO 측정 — 밀폐공간 허가를 받고 진입 전 노저 바닥·중간·출입구에서 O2 18~23.5%, CO 30ppm 미만, LEL 10% 미만을 확인한다. 천공 중 연속 측정. 확인: 허가서 번호·측정값 기록.
3. 천공 시 분진 억제 살수·방진마스크 착용 — 천공 중 물을 뿌려 분진을 누르고 작업자는 방진마스크를 쓴다. 살수량이 많으면 바닥 물 고임·수증기를 확인한다. 확인: 반장 눈 확인.
4. 장약 중 노체 전 구역 출입 금지·경보 체계 가동 — 화약을 들이는 순간부터 노체 전 구역(노 내부·풍구 레벨·주상·노정)과 발파 경계 안 출입을 막고 경보 사이렌·무전으로 알린다. 경계 지점마다 통제원이 선다. 장약 중 모든 화기·전기 작업 중지. 확인: 경계 통제 사진·경보 가동 시각.
5. 발파 대피 신호·대피 완료 확인 후 점화 — 대피 신호 뒤 통제원들이 경계 안 전원 대피를 명부·눈으로 확인해 발파 책임자에게 보고한다. 모든 지점 보고가 끝난 뒤에만 점화한다(법 제64조①5호). 확인: 지점별 대피 확인 시각·점화 시각.
6. 발파 후 가스 측정·불발 확인 후 진입 — 발파 뒤 환기팬을 돌리고 [팀 설정값] 분 이상 기다린 뒤 O2·CO·LEL을 재고, 발파 책임자가 불발 장약 유무를 확인한 뒤에만 들어간다. 불발이 있으면 발파 책임자만 처리한다. 확인: 측정값·불발 확인 서명.
7. 파쇄물 반출 인양 하부 출입 통제 — 깨진 잔선 덩어리를 노내 호이스트로 올릴 때 신호수가 아래에 사람이 없게 막고 중량을 확인한다. 인양 중 노저 작업은 멈춘다. 확인: 인양 시간대·중량 기록.
8. 화약 잔량 반납·기록 — 그날 쓰고 남은 화약·뇌관을 수불 대장에 적고 법정 보관함에 반납한다. 잔량 불일치 시 즉시 원청 보고. 확인: 수불 대장 서명.

## 적용하는 공통 표준서

- SOP-01 화기작업
- SOP-02 밀폐공간 출입작업

## 필수 단계

1. 발파 작업계획서·화약류 사용 허가 (발파 경계 설정)
2. 밀폐공간 허가·작업 전 산소·CO 측정
3. 천공 시 분진 억제 살수·방진마스크 착용
4. 장약 중 노체 전 구역 출입 금지·경보 체계 가동
5. 발파 대피 신호·대피 완료 확인 후 점화
6. 발파 후 가스 측정·불발 확인 후 진입
7. 파쇄물 반출 인양 하부 출입 통제
8. 화약 잔량 반납·기록

## 판정에 쓰는 기준

- 계획서 절차에 4·5·6 단계가 없으면 F8 "필수 단계 누락" → F2 결함.
- 핵심 단계를 4·5·6으로 고른 이유: 발파의 사망 사고는 "터질 때 사람이 있었다"와 "터진 뒤 들어갔다" 두 가지다. 4(장약 중 전 구역 출입 금지·경보)와 5(대피 완료 확인 후 점화)는 노체 전체와 발파 경계 안에 사람이 없음을 두 번 확인하고(법 제64조①5호), 6(발파 후 가스 측정·불발 확인)은 발파 가스와 불발 화약이 남은 노저에 들어가는 시점을 묶는다. 1·2·3·7·8은 허가·SOP-02·SOP-03·화약 관리 절차에서 다시 걸린다.
- 발파 경계 안 모든 작업은 R15(금지)
- 밀폐공간 안 화기(천공·절단)는 R05(조건부)
