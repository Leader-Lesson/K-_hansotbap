# SOP-P33 냉각수 계통 압력시험·플러싱 작업표준 — 합성

- 출처: KOSHA GUIDE·산업안전보건기준에 관한 규칙을 바탕으로 해커톤 시연용으로 합성한 문서. 실제 사업장 표준서가 아니며 협력사명은 가상이다.
- 적용 작업: P33 냉각수 계통 압력시험·플러싱 (기준 일정 작업 하나에만 적용하는 작업별 표준서)
- 문서번호 SOP-P33 · 개정 1 · 제정(가정) 2026-11-09 · 관리 부서: 원청 안전환경팀(가상) · 적용 현장: 광양 2고로 2차 개수(합성)

## 1. 목적과 적용 범위

- 목적: 새로 설치한 스테이브·냉각판 냉각수 계통에 물을 채워 압력시험을 하고 플러싱(세척)하는 작업에서, 연결이 끝나지 않은 배관 가압으로 인한 고압수 분출, 가압 중 플랜지·호스 접근, 플러싱 배수가 노 내부 축조 구간으로 들어가는 침수를 막는다.
- 적용 범위: 압력시험 계획서 승인, 배관 연결 완료 확인, 가압 구간 출입 금지, 단계별 가압·누설 점검, 플러싱·배수, 감압·결과 인계까지.
- 적용 제외: 스테이브·배관 설치 자체(P19, SOP-P19), 질소·가스·송풍 라인 연결(P34, SOP-P34), 노 내부 축조(P22, SOP-P22).

## 2. 작업 개요

- 작업ID: P33
- 협력사(가상): 가상-배관O · 공종: 배관
- 구역: BELLY_BOSH 노복·조안(belly/bosh) — 냉각수 배관은 SHELL 철피 외부를 따라 돌고, 노 내부(STACK·BELLY_BOSH)에는 축조(P22)가 진행 중이다
- 기준 일정(가정값): 2027-02-20 ~ 2027-03-07 (D100~D115)
- 위험 작업 유형: 없음(일반위험)
- 위험 분류 코드(시행령 제53조의2): 기타(방사선·고온수증기·고압수)
- 필요 허가: 일반위험
- 선행 작업: P19 (스테이브·냉각판 설치와 냉각수 배관 연결)

## 3. 위험 요인과 예상 사고

- 고압수 분출: 연결이 빠진 배관·가볼트만 체결된 플랜지·임시 호스에 시험 압력이 걸리면 물과 함께 플랜지·볼트가 튀어 사람을 맞힌다(R08 순서 위반).
- 비산·타격: 가압 중 누설 지점에 얼굴을 대고 보다 분출수에 맞는다. 압력계·안전밸브 교정 불량으로 과압.
- 침수·감전: 플러싱 배수가 노 내부 축조 구간(P22)으로 흘러 양생 중 캐스터블을 망치고, 노 내부 작업등·전동공구에 닿는다. 겨울철 배수 결빙으로 통로 미끄러짐.
- 질식 간접 위험: 배수가 노 내부에 고이면 밀폐공간 산소·습도 조건이 바뀐다.

## 4. 투입 인원과 역할 (기준 6명, 계획서 인원과 맞춘다)

- 작업책임자 1명: 계획서 승인, P19 연결 완료 확인 서명 수령, 가압 구간 출입 금지 지휘, 결과 인계
- 압력시험 담당 1명: 가압 펌프·압력계 조작, 단계별 압력·유지 시간 기록
- 배관공 3명: 플랜지·호스 최종 점검, 누설 점검(감압 뒤), 플러싱 배수 경로 설치
- 감시·통제 1명: 가압 구간 바리케이드·표지, 노 내부 축조 협력사에 배수 시간 알림

## 5. 투입 장비·자재·보호구

- 장비: 가압 펌프(발전기·콤프레서 구동), 교정된 압력계 2개·안전밸브, 플러싱 펌프, 배수 호스·임시 배수조, 체인블록 1t 1대(임시 배관 설치), 작업등
- 자재: 가스켓·볼트(누설 보수용), 맹판(미연결 분기 차단), 바리케이드·「가압 중 접근 금지」 표지, 결빙 방지 모래
- 보호구: 안전모·안전화·보안경(안면 보호구), 방수 장갑·방수복, 안전대(SHELL 외부 배관 점검)

## 6. 작업 순서 (상세)

1. 압력시험 계획서 승인 (시험 압력·유지 시간·계통 범위) — 시험 압력·유지 시간·계통 범위(스테이브 단수·분기)·배수 경로를 적은 계획서를 원청 설비 담당과 안전환경팀에 내고 승인을 받는다. 시험 압력은 설계 기준에 따라 원청 설비 담당이 정한다. 확인: 승인 번호 기록.
2. 스테이브 냉각수 배관 연결 완료 확인 (누락 배관 없음, P19 완료) — 설치 협력사(가상-기계E)의 "배관 연결 완료·인원 철수" 서명을 받고, 도면과 대조해 미연결 분기가 없는지 눈으로 확인한다. 미연결 분기는 맹판으로 막는다. 서명이 없으면 가압하지 않는다(R08). 확인: 서명지·대조 점검표.
3. 가압 구간 출입 금지 (플랜지·호스 접근 금지, 표지) — 가압 전 시험 구간의 플랜지·호스·펌프 주변을 바리케이드로 막고 「가압 중 접근 금지」 표지를 세운다. 노 내부·철피 외부 다른 협력사에 가압 시간을 알린다. 확인: 통제 구간·알림 시각 기록.
4. 안전밸브·압력계 교정 확인 — 압력계 2개의 교정 성적서와 안전밸브 설정 압력(시험 압력 이하 [팀 설정값])을 확인한다. 교정 기한이 지난 계기는 쓰지 않는다. 확인: 성적서 번호 기록.
5. 단계별 가압·누설 점검 기록 — 시험 압력까지 단계를 나눠 올리고 단계마다 유지하며 압력 강하를 본다. 누설 점검은 감압 뒤 접근해서 한다. 누설이 있으면 압력을 빼고 보수 뒤 다시 올린다. 확인: 단계별 압력·시각·결과 기록.
6. 플러싱 배수 경로 확보 (노 내부 작업 구간 침수 방지) — 플러싱 배수는 호스로 임시 배수조·배수로까지 끌고, 노 내부(STACK·BELLY_BOSH 축조 P22)와 통로로 흐르지 않게 막는다. 배수 전 축조 협력사(가상-축로I)에 시간을 알린다. 겨울철 결빙 구간에 모래를 뿌린다. 확인: 배수 경로 사진·알림 기록.
7. 시험 완료 감압 확인 후 출입 허용 — 압력계가 0인 것을 두 계기로 확인하고 드레인을 연 뒤 바리케이드를 푼다. 확인: 감압 확인 시각·사람 기록.
8. 결과 기록·인계 — 시험 압력·유지 시간·누설 보수 내역·플러싱 결과를 기록해 원청 설비 담당과 충전·건조(P36) 담당에게 넘긴다. 이 기록이 P36 착수 조건의 하나다.

## 적용하는 공통 표준서

- 해당 없음(일반위험)

## 필수 단계

1. 압력시험 계획서 승인 (시험 압력·유지 시간·계통 범위)
2. 스테이브 냉각수 배관 연결 완료 확인 (누락 배관 없음, P19 완료)
3. 가압 구간 출입 금지 (플랜지·호스 접근 금지, 표지)
4. 안전밸브·압력계 교정 확인
5. 단계별 가압·누설 점검 기록
6. 플러싱 배수 경로 확보 (노 내부 작업 구간 침수 방지)
7. 시험 완료 감압 확인 후 출입 허용
8. 결과 기록·인계

## 판정에 쓰는 기준

- 계획서 절차에 2·3 단계가 없으면 F8 "필수 단계 누락" → F2 결함.
- 핵심 단계를 2·3으로 고른 이유: 둘 다 빠지면 고압수·플랜지 비산으로 바로 중대사고가 난다. 2(연결 완료 확인)는 열린 배관에 압력이 걸리는 순서 위반(R08)을, 3(가압 구간 출입 금지)은 터질 수 있는 플랜지 옆에 사람이 서 있는 상황을 막는다. 4·5·7은 시험 절차의 품질 단계이고, 6은 상대 작업(P22) 보호, 1·8은 기록이다.
- 배관 연결(P19) 완료 전 가압은 R08(금지, 순서)
- 가압 중 배관 주변 작업은 R22(금지)

## 작업 금지·출입 제한

- 가압 중 BELLY_BOSH 배관 주변 출입 금지(R22)
- 노 내부 축조(P22) 구간으로 플러싱 배수 유입 금지
- P19 연결 완료·철수 서명 전 가압 금지(R08)
- 감압 확인 전 플랜지·호스 접근·누설 점검 금지

## 3D 연결 (출입 제한 데이터)

- 구역: BELLY_BOSH(냉각수 배관 계통, 철피 외부 SHELL를 따라 돈다). 시험 구간은 계획서의 단수·분기를 따른다 (없으면 구역 전체)
- 제한 1: 구역 BELLY_BOSH·SHELL · 방위 SAME · 종류 ENTRY_BAN(가압 구간 플랜지·호스 접근 금지) · 대상 OTHERS · 시점 STEP:5(가압 시간대) · 범위 배관 주변 [팀 설정값] · 규칙 R22 · 3D 표시 TAPE+SIGN:「가압 중 · 접근 금지」
- 제한 2(착수 조건): 구역 BELLY_BOSH · 방위 ALL · 종류 WORK_STOP(연결 완료 전 가압 금지) · 대상 P33 · 시점 UNTIL_HANDOVER(P19 연결 완료·철수 서명 전까지) · 범위 — · 규칙 R08 · 3D 표시 BAR_RED(P33 작업 막대 금지색)
- 제한 3: 구역 STACK·BELLY_BOSH · 방위 ALL · 종류 WORK_STOP(플러싱 배수 시간대 노 내부 구간 통보·배수 유입 차단) · 대상 P22 · 시점 STEP:6(배수 시간대) · 범위 구역 전체 · 규칙 R10 · 3D 표시 SIGN:「플러싱 배수 중 · 노 내부 침수 주의」

## 비상 조치

- 고압수 분출·플랜지 비산: 펌프 정지·드레인 개방, 부상자 구조, 119·원청 구급 연락, 원청 상황실 보고
- 노 내부 침수: 플러싱 중지, 축조 협력사에 즉시 알림, 배수 뒤 전기 설비 점검
- 과압(안전밸브 작동): 가압 중지, 계기 재확인, 원청 설비 담당 보고 뒤 재개
- 결빙·미끄러짐 부상: 구간 통제, 모래 살포, 구급 연락

## 기록·보관

- 계획서 승인서, P19 연결 완료 서명지, 가압 구간 통제 기록, 계기 교정 성적서, 단계별 가압·누설 기록, 배수 경로 기록, 감압 확인 기록, 결과 인계서를 원청 안전환경팀이 공사 종료 후 3년 보관(가정)
- 결과 인계서는 P36 착수 조건의 근거 문서로 F5 이력에 남긴다
