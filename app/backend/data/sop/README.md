- `index.csv`: 표준서 ID·제목·파일·작업 유형·적용 WBS·**필수 단계 목록**(`;` 구분). F8이 마크다운을 파싱하지 않고 이 표만 읽어도 매칭·누락 판정을 할 수 있다
- 각 마크다운의 `## 필수 단계` 번호 목록이 index.csv 의 필수 단계와 같다
