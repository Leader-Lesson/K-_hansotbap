# SOP-03 중량물 인양(크레인) 작업표준 — 합성

- 출처: KOSHA GUIDE M-186(이동식 크레인 양중작업 안전), 산업안전보건기준에 관한 규칙 제38조·제146조 를 바탕으로 해커톤 시연용으로 합성한 문서. 실제 사업장 표준서가 아니다.
- 적용 작업 유형: `heavy_lift`
- 적용 작업 예(기준 일정): P02 크레인 조립, P09 장입설비 해체, P15 구 블록 반출, P17 링블록 반입, P19 스테이브 설치, P21 풍구 신설, P23 장입설비 설치, P24·P25·P28 설비 교체, P31 호이스트

## 필수 단계

1. 중장비 작업계획서 작성 (인양물·크레인 제원·작업반경·경로 도면)
2. 인양물 중량 확인, 줄걸이 용구(와이어·샤클) 점검
3. 신호수 지정, 신호 방법 통일 (무전 채널 기재)
4. 인양 경로 하부 출입통제 — 하물이 작업자 머리 위를 지나지 않게 경로 설정
5. 작업반경 내 인원 철수 확인 (인접 구역 다른 업체 포함)
6. 지반·아웃트리거 확인
7. 풍속 확인 — 순간풍속 10m/s 이상이면 중지
8. 인양 종료 후 통제 구역 해제

## 판정에 쓰는 기준

- 계획서 절차에 3·4·5 단계가 없으면 F8 "필수 단계 누락" → F2 결함
- 인양 경로·작업반경 안에 다른 업체의 인원 작업이 겹치면 R18(금지), 고소작업이 겹치면 R20(조건부)

## 근거 조문

- 산업안전보건기준에 관한 규칙 제38조(사전조사·작업계획서), 제146조(크레인 작업 시의 조치) 제1항 제4호
- 산업안전보건법 시행령 제53조의2 제3호(충돌)·제5호(낙하·비래)
