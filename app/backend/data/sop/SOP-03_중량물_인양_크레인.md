# SOP-03 중량물 인양(크레인) 작업표준 — 합성

- 출처: KOSHA GUIDE M-186(이동식 크레인 양중작업 안전), 산업안전보건기준에 관한 규칙 제38조·제146조 를 바탕으로 해커톤 시연용으로 합성한 문서. 실제 사업장 표준서가 아니다.
- 적용 작업 유형: `heavy_lift`
- 적용 작업 예(기준 일정): P02 크레인 조립, P09 장입설비 해체, P15 구 블록 반출, P17 링블록 반입, P19 스테이브 설치, P21 풍구 신설, P23 장입설비 설치, P24·P25·P28 설비 교체, P31 호이스트
- 문서번호 SOP-03 · 개정 1 · 제정(가정) 2026-11-09 · 관리 부서: 원청 안전환경팀(가상) · 적용 현장: 광양 2고로 2차 개수(합성)

## 1. 목적과 적용 범위

- 목적: 대형 크롤러 크레인·보조 크레인·노정 호이스트·노내 호이스트·체인블록으로 철피 링블록, 장입설비 부재, 스테이브, 풍구·냉각기 같은 중량물을 올리고 내릴 때, 하물이 사람 머리 위를 지나거나 떨어지고, 크레인끼리·크레인과 차량이 부딪치고, 크레인이 넘어지는 사고를 막는다.
- 적용 범위: 크레인·호이스트·체인블록을 쓰는 모든 인양 — 줄걸이, 인양 경로 설정, 하부 통제, 안착·해제까지. 작업별 표준서(SOP-P02·P09·P11·P15·P17·P19·P21·P23·P24·P25·P28·P31)가 이 표준서를 공통 단계로 끌어다 쓴다.
- 적용 제외: 크레인 자체의 조립·해체와 기초 지내력은 SOP-P02 를 따른다. 차량(덤프트럭·트레일러·지게차) 운행만 있는 작업은 유도자 배치(R21)만 적용한다.

## 2. 작업 개요 (적용 작업 유형·적용 작업 예)

- 적용 작업 유형: 중량물(`heavy_lift`) — 계획서 위험 유형에 중량물이 있거나 작업명에 인양·크레인·반입·링블록·호이스트·양중·설치 낱말이 있을 때
- 적용 작업 예(기준 일정): P02, P09, P11, P15, P17, P19, P21, P23, P24, P25, P28, P31
- 구역: 인양 위치마다 다르다 — SHELL·TOP·TUYERE·CASTHOUSE·GCP·SLAG·CRANE_PAD·YARD, 노내 호이스트는 STACK 승강로. 인양 경로 아래 구역이 모두 통제 대상이다
- 위험 분류 코드(시행령 제53조의2): 3호 충돌(양중기·차량), 5호 낙하·비래, 6호 전도·무너짐
- 필요 허가: 중장비(중장비 작업계획서 승인)
- 겹치면 안 되는 작업: 인양 경로 아래·작업반경 안 인원 작업(R18), 작업반경 안 고소작업(R20), 반경이 겹치는 다른 크레인(R19), 차량 통로의 보행자(R21)

## 3. 위험 요인과 예상 사고

- 낙하·비래: 줄걸이 와이어·샤클 파단, 중량 오판으로 정격 초과, 하물 회전 중 걸림. 하물이 작업자 머리 위를 지나는 순간 떨어지면 피할 수 없다(규칙 제146조①4호).
- 충돌·협착: 하물과 구조물 사이, 선회하는 카운터웨이트와 사람 사이 끼임. 반경이 겹치는 크레인 두 대의 붐·하물 접촉.
- 전도: 아웃트리거 미전개·지반 침하·정격 초과·풍속 10m/s 이상에서 크레인이 넘어진다.
- 노 내부 인양: 노내 호이스트로 올리는 자재가 아래층(BELLY_BOSH·TUYERE·HEARTH) 작업자에게 떨어진다. 노 내부는 하나의 수직 공동이다.

## 4. 투입 인원과 역할 (기준 최소 5명 역할, 계획서 인원과 맞춘다)

- 작업책임자(인양 책임자) 1명: 중장비 작업계획서 작성·승인, 인양 전 점검 회의, 중지 권한
- 크레인 운전원 1명(크레인마다): 자격 보유, 정격 하중표·풍속계 확인, 신호수 신호에만 따른다
- 신호수 1명(크레인마다, 사각지대가 있으면 중계 신호수 추가): 지정 표식 착용, 무전 채널 통일, 신호수 외 신호 금지
- 줄걸이 작업자 2명: 와이어·샤클 점검, 중량·무게중심 확인, 유도 로프
- 하부 통제원 1명 이상: 인양 경로 아래 구역 출입 통제, 안전띠·러버콘 설치

## 5. 투입 장비·자재·보호구

- 장비: 대형 크롤러 크레인 또는 크롤러 크레인(보조 크레인), 노정 호이스트, 노내 호이스트, 체인블록, 윈치, 풍속계, 무전기
- 자재: 와이어로프·샤클·슬링 벨트(검사 꼬리표 부착), 유도 로프, 받침목·아웃트리거 패드, 출입 통제 안전띠·러버콘·표지, 인양 경로도
- 보호구: 안전모·안전화·보안경, 신호수 조끼·수신호 장갑, 안전대(고소 줄걸이·해제 작업)

## 6. 작업 순서 (상세)

1. 중장비 작업계획서 작성 — 인양물 명세(중량·치수·무게중심), 크레인 제원·정격 하중, 작업반경, 인양 경로 도면, 하부 통제 범위, 신호 체계를 적어 원청 승인을 받는다(규칙 제38조). 반경이 겹치는 다른 크레인이 있으면 통합 신호 체계·선회 제한을 함께 적는다(R19). 확인: 승인 번호 기록.
2. 인양물 중량·줄걸이 용구 점검 — 도면·계근으로 중량을 확인하고 정격 하중의 범위 안인지 본다. 와이어·샤클·슬링은 검사 꼬리표·손상 여부를 눈으로 점검하고 불량품은 현장에서 뺀다. 확인: 점검표.
3. 신호수 지정·신호 방법 통일 — 신호수를 지정해 표식을 착용시키고 무전 채널을 적는다. 수신호·무전 신호를 작업 전 회의에서 맞춘다. 신호수 외에는 신호하지 않는다. 확인: 신호수 이름·채널을 계획서에 기재.
4. 인양 경로 하부 출입통제 — 하물이 작업자 머리 위를 지나지 않게 경로를 정하고(규칙 제146조①4호), 경로 아래 구역에 안전띠·러버콘을 치고 통제원을 둔다. 아래층 다른 업체 작업은 인양 시간대에 멈춘다(R18). 확인: 통제 구역·시간대 기록.
5. 작업반경 내 인원 철수 확인 — 크레인 선회 반경(붐 길이+α [팀 설정값]) 안에 다른 업체 인원이 없는지 통제원이 눈으로 확인하고 신호수에게 알린 뒤 인양을 시작한다. 반경 안 비계·고소작업은 중지(R20). 확인: 철수 확인 시각 기록.
6. 지반·아웃트리거 확인 — 아웃트리거를 완전히 펴고 패드·받침목을 깐다. 지반 침하·균열, 매설물 위 설치 여부를 확인한다. 크롤러는 지내력 확인된 패드 위에서만 선회한다. 확인: 운전원·책임자 점검 서명.
7. 풍속 확인(10m/s 이상 중지) — 인양 전과 작업 중 풍속계로 순간풍속을 확인한다. 10m/s 이상이면 인양을 멈추고 하물을 내려놓는다. 확인: 풍속·시각 기록.
8. 인양 종료 후 구역 해제 — 하물 안착·고정을 확인한 뒤 줄걸이를 풀고 통제 구역을 해제해 아래층 작업 재개를 알린다. 확인: 해제 시각·통보 대상 기록.

## 필수 단계

1. 중장비 작업계획서 작성
2. 인양물 중량·줄걸이 용구 점검
3. 신호수 지정·신호 방법 통일
4. 인양 경로 하부 출입통제
5. 작업반경 내 인원 철수 확인
6. 지반·아웃트리거 확인
7. 풍속 확인(10m/s 이상 중지)
8. 인양 종료 후 구역 해제

## 판정에 쓰는 기준

- 계획서 절차에 3·4·5 단계가 없으면 F8 "필수 단계 누락" → F2 결함
- 핵심 단계를 3·4·5로 고른 이유: 셋 다 "사람과 하물을 떼어 놓는" 단계다. 3(신호수)은 운전원이 보지 못하는 곳의 사람을 대신 보는 눈이고, 4(하부 출입통제)는 하물이 떨어져도 맞을 사람이 없게 하며, 5(작업반경 철수 확인)는 선회·충돌 범위 안 사람을 비운다. 셋 중 하나만 빠져도 낙하·충돌이 바로 사망으로 이어진다. 1·2·6·7·8은 장비·환경 조건이라 운전원 점검에서 다시 걸린다.
- 인양 경로·작업반경 안에 다른 업체의 인원 작업이 겹치면 R18(금지), 고소작업이 겹치면 R20(조건부)

## 작업 금지·출입 제한

- 인양 시간대 인양 경로 아래 구역(하물이 지나는 모든 층) 타 업체 출입 금지(R18)
- 크레인 작업반경(붐 길이+α [팀 설정값]) 안 비계·고소작업대 작업 중지(R20)
- 반경이 겹치는 두 크레인은 통합 신호 체계·선회 제한 없이 동시 가동 금지(R19)
- 하물 반입·반출 차량 통로에 유도자 없이 보행자 통행 금지(R21)

## 3D 연결 (출입 제한 데이터)

- 구역: 인양 위치의 구역ID와 인양 경로 아래 구역(수직 순서가 낮은 구역) 전부. 예: SHELL 인양이면 아래 CASTHOUSE·CRANE_PAD, TOP 인양이면 노 내부 STACK 이하, 노내 호이스트면 BELLY_BOSH·TUYERE·HEARTH
- 제한 1: 구역 = 인양 경로 아래 구역, 방위 SAME(인양 방위), 종류 LIFT_PATH, 대상 OTHERS, 적용 시점 DURING(계획서에 시간대별 위치 표가 있으면 그 BAND), 범위 경로 직하 + [팀 설정값], 규칙 R18, 3D 표시 CONE + TAPE
- 제한 2: 구역 = 인양 위치 구역, 방위 ALL, 종류 WORK_STOP(비계·고소작업 중지), 대상 고소작업(P30 등), 적용 시점 DURING, 범위 작업반경 붐 길이+α [팀 설정값], 규칙 R20, 3D 표시 TAPE + SIGN「인양 중 · 고소작업 중지」
- 제한 3: 구역 = 인양 위치 구역, 방위 ALL, 종류 WORK_STOP(다른 크레인 선회 제한), 대상 크레인 작업(P02·P17·P23 등), 적용 시점 DURING, 범위 작업반경 중첩 구간, 규칙 R19, 3D 표시 SIGN「통합 신호 · 선회 제한」

## 비상 조치

- 하물 흔들림·걸림: 신호수가 즉시 정지 신호, 하물을 가장 가까운 안전한 곳에 내려놓은 뒤 원인 제거
- 줄걸이 파단·낙하: 하부 통제원이 접근 금지 유지, 부상자 발생 시 원청 구급 연락, 작업책임자가 원청 안전환경팀에 보고하고 재개 전 전체 줄걸이 재점검
- 돌풍·크레인 기울어짐: 운전원은 하물을 내리고 붐을 접는다, 반경 안 전원 대피
- 크레인 전도 위험(지반 침하): 즉시 작업 중지·대피, 원청 설비 담당과 지반 보강 뒤 재개

## 기록·보관

- 중장비 작업계획서, 줄걸이 점검표, 신호수·통제원 지정 기록, 풍속 기록, 구역 해제 통보 기록을 원청 안전환경팀이 공사 종료 후 3년 보관(가정)
- 인양 시간대 기록은 아래층 작업과의 시간 분리(R18) 근거로 F5 이력에 남긴다
