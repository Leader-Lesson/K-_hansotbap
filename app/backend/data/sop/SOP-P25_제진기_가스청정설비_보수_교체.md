# SOP-P25 제진기·가스청정설비 보수·교체 작업표준 — 합성

- 출처: KOSHA GUIDE·산업안전보건기준에 관한 규칙을 바탕으로 해커톤 시연용으로 합성한 문서. 실제 사업장 표준서가 아니며 협력사명은 가상이다.
- 적용 작업: P25 제진기·가스청정설비 보수·교체 (기준 일정 작업 하나에만 적용하는 작업별 표준서)

## 작업 개요

- 작업ID: P25
- 협력사(가상): 가상-제관F · 공종: 제관+양중
- 구역: GCP 제진기·가스청정설비
- 기준 일정(가정값): 2026-11-22 ~ 2027-02-20 (D10~D100)
- 위험 작업 유형: 화기, 밀폐공간, 고소, 중량물, 가스계통
- 위험 분류 코드(시행령 제53조의2): 1호 화재·폭발, 5호 낙하·비래, 8호 질식·중독
- 필요 허가: 화기,밀폐공간,중장비
- 선행 작업: P05

## 적용하는 공통 표준서

- SOP-01 화기작업
- SOP-02 밀폐공간 출입작업
- SOP-03 중량물 인양(크레인)
- SOP-04 가스 배관 연결·기밀시험
- 고소 작업은 공통 표준서 없음 — 규칙 제42조~제45조(추락 방지) 적용

## 필수 단계

1. 작업허가서(화기·밀폐·중장비) 발급
2. 가스 계통 차단·맹판 확인 (BFG 유입 차단)
3. 작업 전 가스 측정 (LEL 10% 미만·O2 18~23.5%·CO 30ppm 미만) 기록
4. 화재감시자 배치·불티비산방지 조치
5. 제진기 내부 진입 시 감시인 배치·환기
6. 교체품 인양 신호수 지정·하부 출입 통제
7. 야간 인양 조명·유도자 확보
8. 작업 종료 후 30분 화재감시·허가서 반납

## 판정에 쓰는 기준

- 계획서 절차에 2·3·4 단계가 없으면 F8 "필수 단계 누락" → F2 결함.
- 하강관 화기(P10) 중 가스청정 계통 배관 개방은 R04(금지) — 시연 S4
- 제진기 내부 작업 중 가스 투입·기밀시험(P35)은 R07·R08(금지)

## 작업 금지·출입 제한

- 제진기 내부 작업 중 같은 계통 가스 투입·기밀시험(P35) 금지(R07·R08)
- 교체품 인양 중 GCP 하부 출입 금지(R18)

## 근거 조문

- 산업안전보건기준에 관한 규칙 제241조②5호, 제618조~제623조, 제146조
- KOSHA GUIDE P-35-2012, H-80
