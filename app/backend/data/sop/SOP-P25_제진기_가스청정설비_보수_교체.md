# SOP-P25 제진기·가스청정설비 보수·교체 작업표준 — 합성

- 출처: KOSHA GUIDE·산업안전보건기준에 관한 규칙을 바탕으로 해커톤 시연용으로 합성한 문서. 실제 사업장 표준서가 아니며 협력사명은 가상이다.
- 적용 작업: P25 제진기·가스청정설비 보수·교체 (기준 일정 작업 하나에만 적용하는 작업별 표준서)
- 문서번호 SOP-P25 · 개정 1 · 제정(가정) 2026-11-09 · 관리 부서: 원청 안전환경팀(가상) · 적용 현장: 광양 2고로 2차 개수(합성)

## 1. 목적과 적용 범위

- 목적: 고로가스(BFG, CO 포함)가 흐르던 제진기·가스청정설비(GCP)의 내부 보수와 부품 교체에서, 잔류 가스 폭발·CO 중독, 제진기 내부 밀폐공간 질식, 교체품 인양 중 낙하, 야간 인양 중 충돌을 막고, 보수가 끝나기 전에 가스가 다시 투입되는 일을 막는다.
- 적용 범위: 가스 계통 차단·맹판 확인, 제진기 내부 진입 청소·보수, 덕트·밸브·부품 절단·용접·교체, 교체품 크레인 인양(주·야간), 완료 인계까지.
- 적용 제외: 상승관·하강관 절단·보수(P10, SOP-P10), 가스 차단·퍼지 자체(P05, SOP-P05), 승온·기밀시험(P35, SOP-P35).

## 2. 작업 개요

- 작업ID: P25
- 협력사(가상): 가상-제관F · 공종: 제관+양중
- 구역: GCP 제진기·가스청정설비 — 노체에서 떨어진 가스 계통 하류, 상류는 DOWNCOMER
- 기준 일정(가정값): 2026-11-22 ~ 2027-02-20 (D10~D100)
- 위험 작업 유형: 화기, 밀폐공간, 고소, 중량물, 가스계통
- 위험 분류 코드(시행령 제53조의2): 1호 화재·폭발, 5호 낙하·비래, 8호 질식·중독
- 필요 허가: 화기,밀폐공간,중장비
- 선행 작업: P05 (가스 계통 차단·블리더 방산·질소 퍼지)

## 3. 위험 요인과 예상 사고

- 화재·폭발: 제진기·덕트 안 더스트에 흡착된 BFG가 절단 열에 풀린다. 상류 DOWNCOMER 하강관 화기(P10)와 이쪽 플랜지 개방이 같은 시간에 겹치면 가스가 불티에 닿는다(시연 S4).
- 질식·중독: 제진기 내부는 밀폐공간이다. 잔류 CO, 퍼지 질소가 남아 있고 더스트가 산소를 소모한다. 맹판 없이 상류 밸브 하나로 막으면 가스가 샌다.
- 낙하·비래: 교체 덕트·밸브(수 톤) 인양 중 줄걸이 이탈, 고소 작업 공구 낙하.
- 충돌: 야간 인양 때 조명 부족으로 크레인·트레일러와 인원 충돌.
- 추락: 제진기 상부 플랫폼·덕트 위 고소 작업.

## 4. 투입 인원과 역할 (기준 14명, 계획서 인원과 맞춘다)

- 작업책임자 1명: 허가서 3종, 가스 차단·맹판 확인 서명, P10·P35와 허가 상호참조
- 가스측정 담당 1명: 작업 전·2시간마다·내부 진입 전 LEL·O2·CO 측정, 기록
- 감시인 2명: 제진기 내부 진입 때 맨홀 상주, 출입자 명부, 구조장비 관리
- 화재감시자 1명: 절단·용접 중 상주, 종료 후 30분 감시
- 신호수·유도자 2명: 인양 신호, 야간 조명·차량 유도
- 제관공 4명: 덕트·부품 절단·맞춤·볼트 체결
- 용접사 2명: 연결부 용접(자격 보유)
- 크레인 운전원 1명: 크롤러 크레인 운전(자격 보유)

## 5. 투입 장비·자재·보호구

- 장비: 크롤러 크레인 1대, 체인블록 5t 2대, 용접기 2대, 가스 용기 랙(산소절단기), 복합 가스측정기(LEL·O2·CO) 3대(내부 연속 1대), 환기팬 2대(송기 덕트), 고소작업대 1대, 조명탑 2대(야간 인양), 풍속계
- 구조장비: 공기호흡기 2조, 삼각대·구조용 윈치 1조, 들것
- 자재: 교체 덕트·밸브·부품, 맹판(블라인드 플랜지), 가스켓·볼트, LOTO 잠금장치·꼬리표, 불티비산방지포, 소화기 4대
- 보호구: 안전모·안전화·보안경, 안전대(2중 걸이), 용접 보안면·방열 장갑, 방진마스크(더스트), 송기마스크 또는 공기호흡기(내부 진입·비상), 휴대용 CO 경보기(전원)

## 6. 작업 순서 (상세)

1. 작업허가서(화기·밀폐·중장비) 발급 — 작업책임자가 세 허가를 한 번에 받고 번호를 서로 적는다(R29). 허가서에 작업 설비 ID, 절단·용접 위치, 내부 진입 범위, 인양 부품·시간대를 적고 GCP 입구에 게시한다. 하강관 화기(P10) 허가 번호도 적는다. 확인: 허가서 번호 3개 기록.
2. 가스 계통 차단·맹판 확인 (BFG 유입 차단) — P05 퍼지 완료 기록과 LOTO 번호를 대조하고, 상류(DOWNCOMER 쪽)·하류 플랜지에 맹판이 들어 있는지 눈으로 확인한 뒤 꼬리표를 건다. 밸브만 닫힌 상태로는 진입·화기를 하지 않는다. 확인: 맹판 위치·수량·LOTO 번호 기록.
3. 작업 전 가스 측정 (LEL 10% 미만·O2 18~23.5%·CO 30ppm 미만) 기록 — 제진기 내부 상·중·하, 덕트 안, 호흡 높이에서 잰다. 하나라도 벗어나면 환기·퍼지 뒤 다시 잰다. 2시간마다, 절단 재개 때마다, 내부 재진입 때마다 반복한다. 확인: 측정값·시각·측정자를 허가서에 기록.
4. 화재감시자 배치·불티비산방지 조치 — 절단·용접 전 반경 11m 안 더스트·유분을 치우고 방화포를 깐다. 열린 플랜지·맨홀을 방화포로 덮어 불티가 설비 안으로 들어가지 않게 한다. 소화기 2대 이상. 확인: 감시자 이름을 허가서에 기재.
5. 제진기 내부 진입 시 감시인 배치·환기 — 진입 전 환기팬을 돌려 송기하고 감시인 2명이 맨홀에 상주하며 명부를 쓴다. 공기호흡기·삼각대를 맨홀 옆에 둔다. 내부 연속 측정기 경보 시 전원 퇴출. 확인: 명부·장비 점검표·환기 가동 시각.
6. 교체품 인양 신호수 지정·하부 출입 통제 — 인양물 중량·줄걸이 용구·크레인 정격을 대조하고 신호수와 무전 신호를 통일한다. 인양 경로 아래와 작업반경 안에 사람이 없게 막는다. 풍속 10m/s 이상 중지. 확인: 점검표·인양 시간대 기록.
7. 야간 인양 조명·유도자 확보 — 야간 인양은 조명탑 2대로 인양 경로·착지점·보행로를 밝히고, 유도자가 트레일러·크레인 이동을 앞장서 안내한다. 조명이 꺼지면 인양을 멈춘다. 확인: 조명 점등·유도자 이름 기록.
8. 작업 종료 후 30분 화재감시·허가서 반납 — 절단·용접 종료 후 30분 감시를 마치고 허가서 3종을 반납한다. 내부 작업이 모두 끝나면 "GCP 내부 작업 완료·인원 철수" 서명을 원청 조업(P35 승온·기밀시험 담당)에 전달한다. 이 서명 전에는 가스를 넣지 않는다.

## 적용하는 공통 표준서

- SOP-01 화기작업
- SOP-02 밀폐공간 출입작업
- SOP-03 중량물 인양(크레인)
- SOP-04 가스 배관 연결·기밀시험
- 고소 작업은 공통 표준서 없음 — 규칙 제42조~제45조(추락 방지) 적용

## 필수 단계

1. 작업허가서(화기·밀폐·중장비) 발급
2. 가스 계통 차단·맹판 확인 (BFG 유입 차단)
3. 작업 전 가스 측정 (LEL 10% 미만·O2 18~23.5%·CO 30ppm 미만) 기록
4. 화재감시자 배치·불티비산방지 조치
5. 제진기 내부 진입 시 감시인 배치·환기
6. 교체품 인양 신호수 지정·하부 출입 통제
7. 야간 인양 조명·유도자 확보
8. 작업 종료 후 30분 화재감시·허가서 반납

## 판정에 쓰는 기준

- 계획서 절차에 2·3·4 단계가 없으면 F8 "필수 단계 누락" → F2 결함.
- 핵심 단계를 2·3·4로 고른 이유: 가스 설비 화기의 사망 사고 고리를 순서대로 끊는 단계다. 2(맹판 확인)는 BFG가 작업 구간으로 다시 흘러드는 길을 막고, 3(가스 측정)은 그래도 남은 가스·CO를 잡아내며, 4(화재감시자·불티 차단)는 불티가 더스트·가스에 닿는 마지막 순간을 지킨다. 1·5·6·7·8은 공통 표준서 SOP-02·03·04나 상대 작업(P10·P35) 표준서에서 다시 걸린다.
- 하강관 화기(P10) 중 가스청정 계통 배관 개방은 R04(금지) — 시연 S4
- 제진기 내부 작업 중 가스 투입·기밀시험(P35)은 R07·R08(금지)

## 작업 금지·출입 제한

- 제진기 내부 작업 중 같은 계통 가스 투입·기밀시험(P35) 금지(R07·R08)
- 교체품 인양 중 GCP 하부 출입 금지(R18)
- 플랜지 개방·맹판 작업 중 같은 계통(DOWNCOMER·GCP) 11m 안 화기 금지(R04)
- 내부 진입 중 맨홀 주변 타 업체 화기 금지(R05)

## 3D 연결 (출입 제한 데이터)

- 구역: GCP(제진기·가스청정설비). 상류 DOWNCOMER와 같은 가스 계통이다 (계획서에 설비 ID·방위가 있으면 그대로)
- 제한 1: 구역 DOWNCOMER·GCP · 방위 ALL · 종류 HOT_WORK_BAN(같은 계통 플랜지 개방 중 화기 금지) · 대상 OTHERS(P10 포함) · 시점 STEP:2(플랜지 개방·맹판 작업 시간대) · 범위 11m [규칙 241조②5호] · 규칙 R04 · 3D 표시 TAPE+SIGN:「가스 계통 개방 중 · 화기 금지」
- 제한 2: 구역 GCP · 방위 SAME · 종류 LIFT_PATH(교체품 인양 하부 출입 통제) · 대상 OTHERS · 시점 STEP:6 · 범위 작업반경 [팀 설정값] · 규칙 R18 · 3D 표시 CONE
- 제한 3: 구역 GCP · 방위 SAME · 종류 HOT_WORK_BAN(내부 진입 중 맨홀 주변 타 업체 화기 금지) · 대상 OTHERS · 시점 STEP:5 · 범위 구역 전체 · 규칙 R05 · 3D 표시 SIGN:「제진기 내부 작업 중」
- 제한 4(계통): 구역 GCP · 방위 ALL · 종류 GAS_IN_BAN(가스 투입·기밀시험 금지) · 대상 P35 · 시점 UNTIL_HANDOVER(8단계 서명 전까지) · 범위 — · 규칙 R08 · 3D 표시 BAR_RED(P35 작업 막대 금지색)

## 비상 조치

- 가스 경보(CO 30ppm·LEL 10% 이상): 즉시 작업 중지, 화기 소화, 풍하측 반대 방향 대피, 내부 인원 퇴출, 원청 상황실 보고, 재측정 정상 뒤 재개
- 화재: 소화기 초기 진화, 진화 안 되면 대피·원청 소방 연락, 상류 맹판·LOTO 유지 확인
- 내부 인원 쓰러짐(질식 의심): 구조자는 공기호흡기 착용 뒤 진입, 삼각대·윈치로 인양, 맨몸 진입 금지, 119·원청 구급 연락
- 인양물 낙하·야간 충돌: 크레인 정지, 조명 확보, 부상자 구조, 원청 보고

## 기록·보관

- 허가서 3종, 맹판·LOTO 기록, 가스 측정 기록, 출입자 명부, 인양 시간대 기록, 30분 감시 기록, 완료·철수 서명지(8단계)를 원청 안전환경팀이 공사 종료 후 3년 보관(가정)
- 완료·철수 서명지는 P35 착수 조건의 근거 문서로 F5 이력에 남긴다
