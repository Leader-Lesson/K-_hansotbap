# SOP-P02 대형 크레인 기초 파일·크레인 조립 작업표준 — 합성

- 출처: KOSHA GUIDE·산업안전보건기준에 관한 규칙을 바탕으로 해커톤 시연용으로 합성한 문서. 실제 사업장 표준서가 아니며 협력사명은 가상이다.
- 적용 작업: P02 대형 크레인 기초 파일·크레인 조립 (기준 일정 작업 하나에만 적용하는 작업별 표준서)
- 문서번호 SOP-P02 · 개정 1 · 제정(가정) 2026-11-09 · 관리 부서: 원청 안전환경팀(가상) · 적용 현장: 광양 2고로 2차 개수(합성)

## 1. 목적과 적용 범위

- 목적: 철피 링블록(수백~천 t 급)을 들어 올릴 대형 크롤러 크레인을 노체 옆 야드에 세우는 과정에서, 기초 지내력 부족으로 인한 전도, 붐·카운터웨이트 인양 중 낙하, 붐 위 고소 조립 중 추락을 막는다.
- 적용 범위: 크레인 기초 파일 시공과 지내력 확인, 보조 크레인을 쓴 대형 크레인 조립(트랙·상부체·붐·카운터웨이트), 하중시험까지. 종풍(D0) 전에 끝나는 사전 작업이다.
- 적용 제외: 조립이 끝난 크레인의 인양 작업은 SOP-03·SOP-P17 를 따른다. 야드 동선·펜스는 SOP-P01.

## 2. 작업 개요

- 작업ID: P02
- 협력사(가상): 가상-양중C · 공종: 토목+양중
- 구역: CRANE_PAD 대형 크레인 기초·인양 구역
- 기준 일정(가정값): 2026-09-28 ~ 2026-11-09 (D-45~D-3)
- 위험 작업 유형: 고소, 중량물
- 위험 분류 코드(시행령 제53조의2): 3호 충돌(양중기·차량), 5호 낙하·비래, 6호 전도·무너짐
- 필요 허가: 중장비
- 선행 작업: P01

## 3. 위험 요인과 예상 사고

- 전도·무너짐: 파일 기초 지내력이 모자라거나 침하하면 조립 중 또는 이후 인양 중 크레인이 넘어진다. 조립 중 카운터웨이트 순서를 틀려도 균형을 잃는다.
- 낙하·비래: 보조 크레인으로 붐 섹션·카운터웨이트(수십 t)를 올리다 줄걸이가 풀리거나 핀 체결 전 하중이 걸린다.
- 추락: 붐 상부에서 핀을 박는 작업자가 안전대 없이 붐 위를 걷는다. 트랙·상부체 승강 중 미끄러짐.
- 충돌: 트레일러 수십 대가 부재를 싣고 들어오며 조립 구역 인원·보조 크레인과 교차한다. 강풍에 붐이 흔들려 구조물과 부딪친다.

## 4. 투입 인원과 역할 (기준 16명, 계획서 인원과 맞춘다)

- 작업책임자 1명: 중장비 작업계획서, 지내력 시험 결과 확인, 조립 순서 승인, 하중시험 입회
- 크레인 조립 감독(제작사 기술자) 1명: 조립 순서·토크·핀 체결 확인
- 보조 크레인 운전원 2명: 조립용 크롤러 크레인 2대(자격 보유)
- 신호수 2명: 보조 크레인마다 1명, 무전 채널 통일
- 조립공·줄걸이 6명: 붐 섹션 연결, 핀 체결(고소), 카운터웨이트 적재, 줄걸이
- 토목공 2명: 파일 기초·패드 시공, 침하 계측
- 유도자·통제원 2명: 트레일러 유도, 조립 구역 펜스 출입 통제

## 5. 투입 장비·자재·보호구

- 장비: 대형 크롤러 크레인(조립 대상), 보조 크레인(크롤러 크레인 250t급) 2대, 트레일러(다축)·덤프트럭(부재 반입), 파일 항타 장비, 풍속계, 지내력 시험 장비(평판재하), 발전기, 조명탑
- 자재: 붐 섹션·카운터웨이트·트랙(제작사 부재), 와이어로프·샤클(검사 꼬리표), 크레인 패드·받침목, 펜스·안전띠·표지, 침하 계측 핀
- 보호구: 안전모·안전화·보안경, 안전대(2중 걸이, 붐 상부 작업), 신호수 조끼, 반사 조끼(유도자), 절단·그라인딩 보안면(현장 가공 시)

## 6. 작업 순서 (상세)

1. 중장비 작업계획서 작성 (크레인 제원·조립 순서·지반 지내력) — 크레인 제원·정격, 조립 순서(제작사 매뉴얼), 보조 크레인 배치·작업반경, 부재 반입 경로, 지반 지내력 요구값을 적어 원청 승인을 받는다(규칙 제38조). 확인: 승인 번호 기록.
2. 파일 기초 지내력 시험 결과 확인 — 파일 시공 후 평판재하 시험 등으로 지내력을 재고 크레인 제작사가 요구하는 값 이상임을 작업책임자가 확인한다. 조립 중·이후 침하 계측 핀을 두고 날마다 읽는다. 확인: 시험 성적서·계측 기록.
3. 조립 구역 출입 통제 펜스·표지 설치 — 조립 반경(붐 길이+α [팀 설정값]) 둘레에 펜스·안전띠를 치고 게이트 하나로만 드나든다. 통제원이 출입자를 기록한다. 확인: 펜스 설치 사진·통제원 이름.
4. 신호수 지정 (조립용 보조 크레인 인양) — 보조 크레인마다 신호수를 정하고 무전 채널을 적는다. 두 대가 함께 들 때는 주 신호수 한 명이 지휘한다(R19). 확인: 신호수 이름·채널 기재.
5. 붐·카운터웨이트 인양 시 하부 출입 통제 — 부재를 들어 올리는 동안 인양 경로 아래와 트레일러 하역 구간에 사람이 없게 통제원이 막는다. 부재가 머리 위를 지나지 않게 경로를 정한다(R18). 확인: 인양 시간대 기록.
6. 고소 조립 작업 안전대 체결 (붐 상부 핀 체결) — 붐 위·상부체 위에서 핀을 박는 작업자는 안전대를 붐 구명줄에 걸고 2중 걸이로 이동한다. 승강은 사다리·고소작업대로만 한다. 확인: 체결 상태를 조립 감독이 눈으로 확인 뒤 작업 개시.
7. 풍속 확인 (10m/s 이상 조립 중지) — 붐 기립·카운터웨이트 적재 전과 작업 중 풍속을 잰다. 순간풍속 10m/s 이상이면 조립을 멈추고 부재를 내려놓는다. 확인: 풍속·시각 기록.
8. 조립 완료 후 하중시험·검사 기록 — 제작사 절차에 따라 하중시험을 하고 안전장치(과부하 방지·모멘트 리미터)를 점검한다. 원청 입회 아래 검사 기록을 남긴 뒤에만 인양 작업(P17)에 쓴다. 확인: 하중시험 성적서·검사표.

## 적용하는 공통 표준서

- SOP-03 중량물 인양(크레인)
- 고소 작업은 공통 표준서 없음 — 규칙 제42조~제45조(추락 방지) 적용

## 필수 단계

1. 중장비 작업계획서 작성 (크레인 제원·조립 순서·지반 지내력)
2. 파일 기초 지내력 시험 결과 확인
3. 조립 구역 출입 통제 펜스·표지 설치
4. 신호수 지정 (조립용 보조 크레인 인양)
5. 붐·카운터웨이트 인양 시 하부 출입 통제
6. 고소 조립 작업 안전대 체결 (붐 상부 핀 체결)
7. 풍속 확인 (10m/s 이상 조립 중지)
8. 조립 완료 후 하중시험·검사 기록

## 판정에 쓰는 기준

- 계획서 절차에 4·5·7 단계가 없으면 F8 "필수 단계 누락" → F2 결함.
- 핵심 단계를 4·5·7로 고른 이유: 조립 중 사망 사고는 부재 낙하와 크레인 전도에서 난다. 4(신호수)와 5(하부 출입 통제)는 수십 t 부재가 떨어져도 맞을 사람이 없게 하고, 7(풍속 확인)은 기립 중인 붐이 바람에 넘어가는 것을 막는 유일한 수치 기준이다. 1·2·3·6·8은 빠져도 제작사 감독·원청 검사에서 다시 걸린다.
- 보조 크레인 인양 경로 아래 인원이 있으면 R18(금지)
- 인접 크레인과 작업반경이 겹치면 R19(조건부), 반입 차량과 보행자는 R21

## 작업 금지·출입 제한

- 크레인 조립 반경(붐 길이+α [팀 설정값]) 내 타 업체 출입 금지
- 붐·카운터웨이트 인양 경로 하부(CRANE_PAD·YARD 접경) 출입 금지(R18)
- 지내력 시험 결과 확인 전 크레인 본체 반입·적재 금지
- 하중시험·검사 기록 전 이 크레인으로 인양 작업(P17) 착수 금지

## 3D 연결 (출입 제한 데이터)

- 구역: CRANE_PAD(대형 크레인 기초·인양 구역). 3D에는 대형 크레인이 고정 배치되어 있고 구역 모델은 없어 목록 '지상·기타'로 표시한다. 인양 경로는 YARD 접경 방위(SAME)
- 제한 1: 구역 CRANE_PAD, 방위 ALL, 종류 ENTRY_BAN, 대상 OTHERS, 적용 시점 DURING, 범위 조립 반경 붐 길이+α [팀 설정값], 규칙 R18, 3D 표시 TAPE + SIGN「크레인 조립 중 · 출입 금지」
- 제한 2: 구역 CRANE_PAD·YARD(접경), 방위 SAME(인양 경로), 종류 LIFT_PATH, 대상 OTHERS, 적용 시점 STEP:5, 범위 경로 직하 + [팀 설정값], 규칙 R18, 3D 표시 CONE
- 제한 3: 구역 CRANE_PAD, 방위 SAME(부재 반입 통로), 종류 ENTRY_BAN(보행자), 대상 OTHERS, 적용 시점 DURING(트레일러 반입 시간대), 범위 통로 폭, 규칙 R21, 3D 표시 SIGN「트레일러 반입 · 유도자 통제」

## 비상 조치

- 부재 낙하·줄걸이 파단: 통제 구역 접근 금지 유지, 부상자 발생 시 원청 구급 연락, 재개 전 전체 줄걸이·핀 재점검
- 크레인 기울어짐·침하 감지: 즉시 작업 중지, 부재 하강, 반경 안 전원 대피, 원청 설비 담당·제작사와 보강 뒤 재개
- 돌풍: 붐 기립 중단, 카운터웨이트 적재 중단, 부재 지면 안착
- 붐 상부 추락·매달림: 구조용 고소작업대 접근, 매달린 작업자 10분 안 구조 목표 [팀 설정값], 119·원청 구급 연락
