# SOP-P02 대형 크레인 기초 파일·크레인 조립 작업표준 — 합성

- 출처: KOSHA GUIDE·산업안전보건기준에 관한 규칙을 바탕으로 해커톤 시연용으로 합성한 문서. 실제 사업장 표준서가 아니며 협력사명은 가상이다.
- 적용 작업: P02 대형 크레인 기초 파일·크레인 조립 (기준 일정 작업 하나에만 적용하는 작업별 표준서)

## 작업 개요

- 작업ID: P02
- 협력사(가상): 가상-양중C · 공종: 토목+양중
- 구역: CRANE_PAD 대형 크레인 기초·인양 구역
- 기준 일정(가정값): 2026-09-28 ~ 2026-11-09 (D-45~D-3)
- 위험 작업 유형: 고소, 중량물
- 위험 분류 코드(시행령 제53조의2): 3호 충돌(양중기·차량), 5호 낙하·비래, 6호 전도·무너짐
- 필요 허가: 중장비
- 선행 작업: P01

## 적용하는 공통 표준서

- SOP-03 중량물 인양(크레인)
- 고소 작업은 공통 표준서 없음 — 규칙 제42조~제45조(추락 방지) 적용

## 필수 단계

1. 중장비 작업계획서 작성 (크레인 제원·조립 순서·지반 지내력)
2. 파일 기초 지내력 시험 결과 확인
3. 조립 구역 출입 통제 펜스·표지 설치
4. 신호수 지정 (조립용 보조 크레인 인양)
5. 붐·카운터웨이트 인양 시 하부 출입 통제
6. 고소 조립 작업 안전대 체결 (붐 상부 핀 체결)
7. 풍속 확인 (10m/s 이상 조립 중지)
8. 조립 완료 후 하중시험·검사 기록

## 판정에 쓰는 기준

- 계획서 절차에 4·5·7 단계가 없으면 F8 "필수 단계 누락" → F2 결함.
- 보조 크레인 인양 경로 아래 인원이 있으면 R18(금지)
- 인접 크레인과 작업반경이 겹치면 R19(조건부), 반입 차량과 보행자는 R21

## 작업 금지·출입 제한

- 크레인 조립 반경(붐 길이+α [팀 설정값]) 내 타 업체 출입 금지
- 붐·카운터웨이트 인양 경로 하부(CRANE_PAD·YARD 접경) 출입 금지(R18)

## 근거 조문

- 산업안전보건기준에 관한 규칙 제38조①11호·별표4(중량물 취급·건설기계 작업계획서), 제146조(크레인 작업 시 조치)
- KOSHA GUIDE M-186(이동식 크레인 안전), 시행령 제53조의2 3·5·6호
