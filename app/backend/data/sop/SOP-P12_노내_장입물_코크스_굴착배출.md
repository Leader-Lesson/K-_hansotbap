# SOP-P12 노내 장입물·코크스 굴착 배출 작업표준 — 합성

- 출처: KOSHA GUIDE·산업안전보건기준에 관한 규칙을 바탕으로 해커톤 시연용으로 합성한 문서. 실제 사업장 표준서가 아니며 협력사명은 가상이다.
- 적용 작업: P12 노내 장입물·코크스 굴착 배출 (기준 일정 작업 하나에만 적용하는 작업별 표준서)
- 문서번호 SOP-P12 · 개정 1 · 제정(가정) 2026-11-09 · 관리 부서: 원청 안전환경팀(가상) · 적용 현장: 광양 2고로 2차 개수(합성)

## 1. 목적과 적용 범위

- 목적: 살수로 식힌 노 안에 남은 장입물·코크스를 원격 해체 장비와 사람이 함께 파내어 배출하는 두 주 동안, 코크스 잔열에서 계속 나오는 CO 중독, 장입물 경사면 붕괴 매몰, 원격 장비·배출 설비에 끼이는 사고를 막는다.
- 적용 범위: 밀폐공간 허가, 산소·CO 측정, 환기·연속 측정, 감시인, 원격 굴착 장비 투입 시 인원 철수, 붕괴 구간 접근 금지, 배출 호퍼·컨베이어 접촉 금지, 명부·퇴출 확인까지. 노흉(STACK)에서 시작해 노복·풍구 레벨 높이까지 내려간다.
- 적용 제외: 노저 잔선 천공·발파(P13, SOP-P13), 내화물·스테이브 해체(P14, SOP-P14), 노내 호이스트 운영(P31)은 별도 표준서를 따른다.

## 2. 작업 개요

- 작업ID: P12
- 협력사(가상): 가상-해체G · 공종: 해체(원격 장비)
- 구역: STACK 노흉(shaft)
- 기준 일정(가정값): 2026-11-20 ~ 2026-12-02 (D8~D20)
- 위험 작업 유형: 밀폐공간
- 위험 분류 코드(시행령 제53조의2): 7호 붕괴, 8호 질식·중독
- 필요 허가: 밀폐공간,중장비
- 선행 작업: P08

## 3. 위험 요인과 예상 사고

- CO 중독: 살수로 겉은 식어도 코크스 더미 속은 뜨겁다. 파헤칠 때마다 속에서 CO가 새로 나온다. 환기를 끄거나 연속 측정이 없으면 농도가 조용히 오른다.
- 산소 결핍: 노 안은 하나의 수직 공동이라 아래쪽에 무거운 가스가 고인다. 살수 잔수에서 나오는 수증기도 산소를 밀어낸다.
- 붕괴·매몰: 파낸 경사면 아래 서 있으면 장입물이 무너져 묻힌다. 굴착 깊이가 늘수록 경사면이 높아진다.
- 끼임·충돌: 원격 굴착 장비(미니 로더·소형 굴삭기) 작업 반경 안의 사람, 배출 호퍼·컨베이어 가동 중 걸림 제거(R22).
- 낙하: 노정 개구부(P09 해체 뒤)에서 공구·자재가 떨어진다. 노정 작업과 겹치면 R16.

## 4. 투입 인원과 역할 (기준 20명, 계획서 인원과 맞춘다)

- 작업책임자 1명: 밀폐공간·중장비 허가, 굴착 순서·경사면 관리, 퇴출 확인 서명
- 안전관리자(측정 담당) 1명: 산소·CO 측정, 환기팬·연속 측정기 관리
- 감시인 2명: 노정 개구부·풍구 레벨 출입구 상주, 명부 기록, 원격 장비 투입 시 인원 철수 확인
- 원격 장비 운전원 2명(교대): 미니 로더·소형 굴삭기 원격 조작(노 외부 또는 안전 위치)
- 굴착·정리 작업자 10명: 수작업 굴착, 배출 호퍼 투입, 경사면 정리(장비 정지 중에만)
- 배출 설비 운전원 2명: 호퍼·컨베이어·노정 호이스트 가동·정지(노 외부)
- 신호수·하부 통제 2명: 배출 인양 신호, 노 내부 하부 출입 통제

## 5. 투입 장비·자재·보호구

- 장비: 미니 로더·소형 굴삭기(원격 해체 장비), 배출 호퍼·컨베이어 또는 노정 호이스트·윈치(배출), 노내 호이스트(P31 가상-양중C 운영), 환기팬 2대(송기 덕트), 산소·CO 복합측정기 3대(연속 측정 1대 고정), 작업등·조명탑, 무전기
- 구조장비: 공기호흡기 2조, 삼각대·구조용 윈치, 들것
- 자재: 붕괴 위험 구간 표시 안전띠·표지, 출입자 명부, 장비 작업 반경 표시 러버콘, 배출 백·팔레트
- 보호구: 안전모·안전화·보안경, 방진마스크(코크스 분진), 휴대용 산소·CO 경보기(작업조마다 1개 이상), 안전대(노정 개구부·경사면 상부), 반사 조끼(장비 운전 시 식별)

## 6. 작업 순서 (상세)

1. 밀폐공간 작업허가서 발급 — 작업책임자가 P08 살수 후 측정·인계 서명지를 받고 밀폐공간·중장비 허가를 받는다. 허가서에 출입 인원, 감시인, 측정 계획, 원격 장비 투입 시간대를 적고 출입구에 게시한다. 확인: 허가서 번호·P08 인계 확인.
2. 작업 전 산소·CO 측정 (O2 18~23.5%·CO 30ppm 미만) 후 진입 — 진입 전 노 내부 상·중·하와 코크스 더미 표면 가까이에서 잰다. 기준 밖이면 들어가지 않고 환기 뒤 다시 잰다. 확인: 측정값·시각·측정자 기록.
3. 환기팬 연속 가동·연속 측정 (코크스 잔열 CO 발생) — 송기 덕트를 굴착 높이까지 내리고 환기팬을 작업 내내 돌린다. 고정 측정기로 연속 측정하고 굴착으로 더미를 파헤칠 때마다 값을 본다. 1일 2회 이상 기록. 확인: 가동·측정 기록.
4. 감시인 배치 (노정 개구부·출입구) — 노정 개구부와 풍구 레벨 출입구에 감시인을 두고 명부를 쓴다. 감시인은 내부와 무전을 유지하고 다른 일을 겸하지 않는다. 확인: 감시인 서명.
5. 원격 굴착 장비 투입 시 노내 인원 철수 확인 — 미니 로더·굴삭기를 움직이기 전 감시인이 명부와 무전으로 노 안에 사람이 없음을 확인하고 운전원에게 알린다. 장비 가동 중 노 내부 진입 금지. 사람이 들어갈 때는 장비를 멈추고 키를 뺀다. 확인: 철수 확인 시각·운전원 보고 기록.
6. 장입물 붕괴 위험 구간 접근 금지 (경사면 하부) — 파낸 경사면 아래쪽에 안전띠·표지를 두고 서지 않는다. 경사면 높이가 [팀 설정값] 을 넘으면 장비로 먼저 깎아 낮춘다. 확인: 경사면 상태 일일 점검 기록.
7. 배출 호퍼·컨베이어 가동 중 접촉 금지 — 가동 중 걸림 제거·청소 금지. 걸리면 운전원이 정지·잠금(LOTO)한 뒤 작업자가 접근한다(R22). 확인: 정지·잠금 기록.
8. 출입자 명부 기록·작업 종료 퇴출 확인 — 입·퇴장 시각을 기록하고 종료 시 명부를 0명으로 맞춘 뒤 작업책임자가 서명한다. 굴착이 노저까지 끝나면 P13·P14 협력사에 노 내부 상태를 인계한다. 확인: 명부·퇴출 서명.

## 적용하는 공통 표준서

- SOP-02 밀폐공간 출입작업

## 필수 단계

1. 밀폐공간 작업허가서 발급
2. 작업 전 산소·CO 측정 (O2 18~23.5%·CO 30ppm 미만) 후 진입
3. 환기팬 연속 가동·연속 측정 (코크스 잔열 CO 발생)
4. 감시인 배치 (노정 개구부·출입구)
5. 원격 굴착 장비 투입 시 노내 인원 철수 확인
6. 장입물 붕괴 위험 구간 접근 금지 (경사면 하부)
7. 배출 호퍼·컨베이어 가동 중 접촉 금지
8. 출입자 명부 기록·작업 종료 퇴출 확인

## 판정에 쓰는 기준

- 계획서 절차에 2·4·6 단계가 없으면 F8 "필수 단계 누락" → F2 결함.
- 핵심 단계를 2·4·6으로 고른 이유: 이 작업의 사망 사고 세 유형(중독·구조 실패·매몰)을 하나씩 막는다. 2(산소·CO 측정 후 진입)는 코크스 잔열 CO 중독을, 4(감시인)는 안에서 쓰러진 사람을 밖에서 알아채는 유일한 수단이고, 6(붕괴 구간 접근 금지)은 경사면 매몰을 막는다. 3은 2의 연장이고 5·7은 장비 운전 규칙(R22)에서, 1·8은 SOP-02 허가 절차에서 다시 걸린다.
- 살수(P08) 냉각 완료 전 진입은 R14(금지)
- 상부 해체 아래 굴착은 R16, 배출 설비 가동 중 접촉 작업은 R22(금지)

## 작업 금지·출입 제한

- 굴착 중 STACK·BELLY_BOSH·HEARTH 노 내부 타 업체 진입 금지(붕괴·CO)
- 노정 개구부 투하 구간 주변 출입 금지
- 원격 장비 가동 중 노 내부 전원 출입 금지(5단계)
- P08 냉각 완료·측정 인계 서명 전 진입 금지(R14)
- 굴착 중 노정(TOP) 해체·설치 작업과 동시 진행 금지 — 낙하물(R16)

## 3D 연결 (출입 제한 데이터)

- 구역: STACK(노흉 내부)에서 시작해 굴착이 진행되며 BELLY_BOSH·TUYERE 높이로 내려간다. 노 내부는 하나의 공동이라 제한은 노 내부 전체에 건다
- 제한 1: 구역 STACK·BELLY_BOSH·TUYERE·HEARTH, 방위 ALL, 종류 ENTRY_BAN, 대상 OTHERS(명부 외 전원), 적용 시점 DURING, 범위 노 내부 전체, 규칙 R27·R30, 3D 표시 TAPE + SIGN「노내 굴착 중 · CO · 출입 금지」
- 제한 2: 구역 STACK·BELLY_BOSH·TUYERE·HEARTH, 방위 ALL, 종류 ENTRY_BAN(전원, 자기 인원 포함), 대상 ALL, 적용 시점 STEP:5(원격 장비 가동 중), 범위 노 내부 전체, 규칙 R22, 3D 표시 CONE + SIGN「원격 장비 가동 중」
- 제한 3: 구역 TOP, 방위 ALL, 종류 WORK_STOP(노정 해체·설치 보류), 대상 P09·P23·P30, 적용 시점 DURING, 범위 개구부 주변, 규칙 R16, 3D 표시 BANNER「아래 노 내부 작업 중 · 낙하물 주의」
- 착수 조건: 구역 STACK, 종류 WORK_STOP(이 작업 자체), 대상 P12, 적용 시점 UNTIL_HANDOVER(P08 7단계 측정 인계 서명 전까지), 규칙 R14, 3D 표시 BAR_RED(P12 작업 막대 금지색)

## 비상 조치

- 산소·CO 경보: 전원 즉시 퇴출, 감시인이 명부로 인원 확인, 환기 강화·원인 제거·재측정 정상 뒤 재진입
- 내부 인원 쓰러짐: 감시인은 들어가지 않고 구조 요청, 구조자는 공기호흡기 착용·삼각대 사용, 맨몸 진입 금지, 119·원청 구급 연락
- 경사면 붕괴·매몰: 장비 즉시 정지, 2차 붕괴 위험 확인 뒤 구조, 원청 구급·상황실 연락
- 배출 설비 끼임: 비상 정지·LOTO 뒤 구조, 원청 구급 연락
- 노정 낙하물: 아래 작업 중지, 원청이 상부 작업 협력사와 시간 조정

## 기록·보관

- 허가서, P08 인계 서명지, 산소·CO 측정 기록(연속 측정 포함), 감시인·명부, 원격 장비 투입 시 철수 확인 기록, 경사면 점검 기록, 설비 정지·잠금 기록, 퇴출 서명을 원청 안전환경팀이 공사 종료 후 3년 보관(가정)
