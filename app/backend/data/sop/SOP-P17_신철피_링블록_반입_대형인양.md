# SOP-P17 신 철피 링블록 반입·설치(대형 인양) 작업표준 — 합성

- 출처: KOSHA GUIDE·산업안전보건기준에 관한 규칙을 바탕으로 해커톤 시연용으로 합성한 문서. 실제 사업장 표준서가 아니며 협력사명은 가상이다.
- 적용 작업: P17 신 철피 링블록 반입·설치(대형 인양) (기준 일정 작업 하나에만 적용하는 작업별 표준서)
- 문서번호 SOP-P17 · 개정 1 · 제정(가정) 2026-11-09 · 관리 부서: 원청 안전환경팀(가상) · 적용 현장: 광양 2고로 2차 개수(합성)

## 1. 목적과 적용 범위

- 목적: 야드에서 선조립한 철피 링블록(수백~천 t 급)을 트레일러로 옮겨 대형 크롤러 크레인으로 노체 위에 차례로 얹는 일주일 동안, 인양 경로 아래 주상·크레인 패드·야드에 있던 사람의 낙하 사고, 작업반경 안 비계·고소작업과의 충돌, 돌풍에 의한 블록 흔들림·크레인 전도, 안착 뒤 가볼트 전 줄걸이 해제로 인한 블록 전도를 막는다.
- 적용 범위: 중장비 작업계획서, 줄걸이·중량 확인, 신호 체계, 인양 경로 하부 전면 통제, 작업반경 철수, 풍속, 안착·가볼트·줄걸이 해제, 구역 해제 통보까지. 공사 전체에서 가장 큰 인양이며 시연 S3(P17↔P24 인양 경로 아래 출선장 개조)의 작업이다.
- 적용 제외: 크레인 조립·하중시험(P02, SOP-P02), 야드 선조립(P03, SOP-P03), 안착 뒤 철피 용접·비파괴검사(P18, SOP-P18)는 별도 표준서를 따른다.

## 2. 작업 개요

- 작업ID: P17
- 협력사(가상): 가상-양중C · 공종: 양중+제관
- 구역: SHELL 노체 철피 외부
- 기준 일정(가정값): 2026-12-27 ~ 2027-01-03 (D45~D52)
- 위험 작업 유형: 고소, 중량물
- 위험 분류 코드(시행령 제53조의2): 3호 충돌(양중기·차량), 5호 낙하·비래, 6호 전도·무너짐
- 필요 허가: 중장비,고소
- 선행 작업: P15,P02,P03

## 3. 위험 요인과 예상 사고

- 낙하·비래: 링블록이 인양 경로 아래 사람 머리 위를 지난다. 러그·줄걸이가 끊기면 수백 t 이 떨어지고 피할 수 없다. 경로 아래 주상에서는 출선장 개조(P24)가 넉 달 내내 진행 중이다(R18, 시연 S3).
- 충돌: 작업반경 안 비계(P30)·고소작업대 위 작업자와 선회하는 블록·붐이 부딪친다(R20). 보조 크레인과 작업반경이 겹친다(R19). 트레일러 반입 통로의 보행자(R21).
- 전도·무너짐: 정격 초과·풍속 10m/s 이상·지반 침하로 크레인이 넘어진다. 안착한 블록이 가볼트 전에 줄걸이를 풀면 넘어진다.
- 추락: 블록 위에서 줄걸이를 풀거나 가볼트를 박는 작업자가 안전대 없이 철피 상단에 선다.
- 끼임: 블록을 아래 철피 위에 맞춰 내릴 때 손·발이 플랜지 사이에 낀다.

## 4. 투입 인원과 역할 (기준 20명, 계획서 인원과 맞춘다)

- 인양 책임자 1명: 중장비 작업계획서, 인양 전 회의, 풍속·중지 판단, 구역 해제 통보
- 대형 크롤러 크레인 운전원 1명·보조 크레인 운전원 1명: 자격 보유, 정격·풍속 확인
- 주 신호수 1명·중계 신호수 2명: 지상·블록 안착 높이·크레인 쪽, 무전 채널 통일
- 줄걸이 작업자 4명: 러그·와이어·샤클 점검, 유도 로프, 안착 뒤 해제
- 제관공 4명: 블록 안착 맞춤, 가볼트·임시 고정(고소, 안전대)
- 하부 통제원 4명: 주상·크레인 패드·야드 인양 경로 전면 통제
- 유도자 2명: 트레일러 반입·회차 유도

## 5. 투입 장비·자재·보호구

- 장비: 대형 크롤러 크레인(1,600t급, P02 조립·하중시험 완료), 보조 크레인(크롤러 크레인 250t급), 트레일러(다축)·SPMT(블록 반입), 체인블록(안착 맞춤), 고소작업대(블록 상단 접근), 풍속계, 무전기(채널 통일), 조명탑
- 자재: 인양 러그·와이어로프·샤클(검사 꼬리표, 정격 표시), 유도 로프, 가볼트·임시 고정 지그, 받침목·크레인 패드, 출입 통제 안전띠·러버콘·표지(주상·크레인 패드·야드), 인양 경로도·시간대표
- 보호구: 안전모·안전화·보안경, 안전대(2중 걸이, 블록 상단 작업자), 신호수 조끼·수신호 장갑, 반사 조끼(통제원·유도자), 절단 방지 장갑(줄걸이)

## 6. 작업 순서 (상세)

1. 중장비 작업계획서 작성 (링블록 중량·크레인 정격·인양 경로도) — 인양 책임자가 블록별 중량(P03 치수 검사 기록)·무게중심, 크레인 정격 대비 하중률, 작업반경, 인양 경로도, 하부 통제 범위, 시간대별 위치(오전 인양·오후 가볼트 등), 신호 체계를 적어 원청 승인을 받는다(규칙 제38조). P02 하중시험 성적서를 첨부한다. 확인: 승인 번호.
2. 줄걸이 용구 점검·블록 중량 확인 (정격 하중 대비) — 러그 용접부·와이어·샤클을 점검하고 정격 표시를 확인한다. 블록 중량과 줄걸이 각도를 계산해 크레인 정격 안인지 다시 본다. 확인: 점검표·하중률 기록.
3. 신호수 지정·무전 신호 통일 — 주 신호수 한 명이 지휘하고 중계 신호수가 사각을 메운다. 무전 채널·비상 정지 신호를 인양 전 회의에서 맞춘다. 보조 크레인과 반경이 겹치면 통합 신호로 한다(R19). 확인: 신호수 이름·채널 기재.
4. 인양 경로 하부 전면 출입 통제 (주상·크레인 패드·야드) — 블록이 지나는 경로 아래 주상(CASTHOUSE)·크레인 패드·야드 전체에 안전띠·러버콘을 치고 통제원이 선다. 주상 개조(P24)·야드 작업은 인양 시간대에 멈춘다. 하물이 사람 머리 위를 지나지 않게 경로를 지킨다(R18, 규칙 제146조①4호). 확인: 통제 범위·인양 시간대 기록.
5. 작업반경 내 인원 철수 확인 (비계·고소 작업 중지) — 선회 반경(붐 길이+α [팀 설정값]) 안 비계(P30)·고소작업대 작업을 멈추고 인원 철수를 통제원이 확인해 주 신호수에게 알린 뒤 인양을 시작한다(R20). 확인: 철수 확인 시각.
6. 풍속 확인 (10m/s 이상 인양 중지) — 인양 전과 인양 중 붐 끝 높이 풍속을 확인한다. 순간풍속 10m/s 이상이면 인양을 멈추고 블록을 내려놓는다. 확인: 풍속·시각 기록.
7. 블록 안착 후 가볼트 체결 확인 전 줄걸이 해제 금지 — 블록을 아래 철피 위에 맞춰 내리고 제관공이 가볼트·임시 고정을 체결했음을 인양 책임자가 확인한 뒤에만 줄걸이를 푼다. 맞춤 중 플랜지 사이에 손을 넣지 않는다. 확인: 가볼트 체결 확인 서명.
8. 인양 종료 후 구역 해제 통보 — 줄걸이를 풀고 크레인 붐을 안전 위치로 돌린 뒤 통제 구역을 해제해 주상·야드 작업 재개를 알린다. 전 블록 안착이 끝나면 용접(P18) 협력사에 인계한다. 확인: 해제 시각·통보 대상 기록.

## 필수 단계

1. 중장비 작업계획서 작성 (링블록 중량·크레인 정격·인양 경로도)
2. 줄걸이 용구 점검·블록 중량 확인 (정격 하중 대비)
3. 신호수 지정·무전 신호 통일
4. 인양 경로 하부 전면 출입 통제 (주상·크레인 패드·야드)
5. 작업반경 내 인원 철수 확인 (비계·고소 작업 중지)
6. 풍속 확인 (10m/s 이상 인양 중지)
7. 블록 안착 후 가볼트 체결 확인 전 줄걸이 해제 금지
8. 인양 종료 후 구역 해제 통보

## 판정에 쓰는 기준

- 계획서 절차에 3·4·5 단계가 없으면 F8 "필수 단계 누락" → F2 결함.
- 핵심 단계를 3·4·5로 고른 이유: 수백 t 블록 아래와 옆에 사람이 없게 하는 세 단계다. 3(신호수·신호 통일)은 운전원이 보지 못하는 곳의 사람을 대신 보고 멈추게 하며, 4(인양 경로 하부 전면 통제)는 블록이 떨어져도 맞을 사람이 없게 하고(시연 S3, 주상 개조 P24), 5(작업반경 철수·고소작업 중지)는 선회하는 블록·붐에 부딪힐 비계 작업자를 비운다. 셋 중 하나만 빠져도 바로 사망이다. 1·2·6·7·8은 장비·절차 조건이라 운전원·인양 책임자 점검에서 다시 걸린다.
- 인양 경로 아래 출선장 개조(P24)가 있으면 R18(금지) — 시연 S3
- 작업반경 안 비계 설치(P30)는 R20(조건부), 인접 크레인은 R19

## 작업 금지·출입 제한

- 인양 시간대 SHELL·CASTHOUSE·CRANE_PAD 인양 경로 하부 전원 출입 금지(R18)
- 작업반경 내 비계 설치(P30)·고소 작업 중지(R20)
- 풍속 10m/s 이상 인양 금지, 가볼트 체결 확인 전 줄걸이 해제 금지
- P15 구 블록 반출·P03 치수 검사·P02 하중시험 기록 전 착수 금지
- 트레일러 반입 통로 유도자 없이 보행 금지(R21)

## 3D 연결 (출입 제한 데이터)

- 구역: SHELL(노체 철피 외부)에 안착, 인양 경로는 CRANE_PAD(크레인 측, 노체 남측 가정)→SHELL, 경로 아래 CASTHOUSE. 방위는 계획서의 블록 방위·시간대별 위치 표(SAME, 예: 오전 남측 인양·오후 남측·동측 가볼트)
- 제한 1: 구역 CASTHOUSE·CRANE_PAD·SHELL, 방위 SAME(인양 경로), 종류 LIFT_PATH, 대상 OTHERS(P24·P30 등), 적용 시점 DURING(계획서 시간대별 위치 표의 인양 BAND, 없으면 작업일 전체), 범위 경로 직하 + 선회 반경 붐 길이+α [팀 설정값], 규칙 R18, 3D 표시 CONE + TAPE + SIGN「대형 인양 중 · 전면 출입 금지」— 시연 S3
- 제한 2: 구역 SHELL, 방위 ALL, 종류 WORK_STOP(비계·고소작업 중지), 대상 P30 등 고소작업, 적용 시점 STEP:5~7(인양~안착), 범위 작업반경 [팀 설정값], 규칙 R20, 3D 표시 BANNER「인양 중 · 비계 작업 중지」
- 제한 3: 구역 CRANE_PAD, 방위 ALL, 종류 WORK_STOP(다른 크레인 선회 제한), 대상 보조 크레인·P23 노정 크레인, 적용 시점 DURING, 범위 반경 중첩 구간, 규칙 R19, 3D 표시 SIGN「통합 신호 · 선회 제한」
- 제한 4: 구역 YARD·CRANE_PAD, 방위 SAME(반입 통로), 종류 ENTRY_BAN(보행자), 대상 OTHERS, 적용 시점 DURING(트레일러 반입 시간대), 범위 통로 폭, 규칙 R21, 3D 표시 SIGN「트레일러 반입 · 유도자 통제」
- 착수 조건: 구역 SHELL, 종류 WORK_STOP(이 작업 자체), 대상 P17, 적용 시점 UNTIL_HANDOVER(P15 절단면 인계·P02 하중시험·P03 치수 검사 기록 전까지), 규칙 R08, 3D 표시 BAR_RED(P17 작업 막대 금지색)

## 비상 조치

- 블록 흔들림·걸림: 주 신호수가 즉시 정지 신호, 유도 로프로 자세 잡기, 안 되면 가장 가까운 안전한 곳에 내려놓기
- 줄걸이·러그 이상 징후: 인양 중단·하강, 하부 통제 유지, 원청 안전환경팀 보고, 전수 재점검 전 재개 금지
- 돌풍(10m/s 이상): 인양 중단, 블록 지면 또는 철피 위 안착, 붐 안전 위치
- 크레인 기울어짐·지반 침하 감지: 즉시 중지·블록 하강, 반경 안 전원 대피, 원청 설비 담당·제작사와 보강 뒤 재개
- 블록 상단 추락·매달림: 고소작업대로 접근 구조, 119·원청 구급 연락
