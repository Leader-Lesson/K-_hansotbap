# SOP-02 밀폐공간 출입작업 표준 — 합성

- 출처: KOSHA GUIDE H-80(밀폐공간 작업 프로그램), 산업안전보건기준에 관한 규칙 제618조~제626조 를 바탕으로 해커톤 시연용으로 합성한 문서. 실제 사업장 표준서가 아니다.
- 적용 작업 유형: `confined`
- 적용 작업 예(기준 일정): P08 노내 살수, P12 노내 굴착, P13 잔선 천공, P14 내화물 해체, P16 노저 청소, P20·P21·P22 축조, P26 열풍로 보수, P27 환상관 내화물

## 필수 단계

1. 밀폐공간 작업허가서 발급 (출입 인원·시간·감시인 기재)
2. 작업 전 산소·유해가스 측정 — O2 18~23.5%, CO 30ppm 미만, 가연성가스 LEL 10% 미만, 측정값 기록
3. 불활성가스(질소·아르곤) 유입 가능 배관의 맹판·차단 확인 (같은 계통 라인 연결 작업이 겹치지 않는지 확인)
4. 환기 실시 및 작업 중 연속 측정
5. 감시인 배치 (출입구 상주, 출입자와 연락 수단 유지)
6. 구조장비 비치 (공기호흡기·삼각대·구조용 로프)
7. 출입자 명부 기록 (입장·퇴장 시각)
8. 작업 종료 후 전원 퇴출 확인, 허가서 반납

## 판정에 쓰는 기준

- 계획서 절차에 2·3·5 단계가 없으면 F8 "필수 단계 누락" → F2 결함(R27)
- 밀폐공간 작업이 끝나기 전 같은 계통에 가스 라인 연결·투입이 시작되면 R07·R08(금지)

## 근거 조문

- 산업안전보건기준에 관한 규칙 제618조(정의·적정공기), 제619조(밀폐공간 작업 프로그램), 제619조의2(측정), 제620조(환기), 제623조(감시인), 제625조(대피용 기구)
- OSHA 1910.146(d)(11), (f)(15) (참고)
