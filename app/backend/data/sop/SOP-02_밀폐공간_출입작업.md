# SOP-02 밀폐공간 출입작업 표준 — 합성

- 출처: KOSHA GUIDE H-80(밀폐공간 작업 프로그램), 산업안전보건기준에 관한 규칙 제618조~제626조 를 바탕으로 해커톤 시연용으로 합성한 문서. 실제 사업장 표준서가 아니다.
- 적용 작업 유형: `confined`
- 적용 작업 예(기준 일정): P08 노내 살수, P12 노내 굴착, P13 잔선 천공, P14 내화물 해체, P16 노저 청소, P20·P21·P22 축조, P26 열풍로 보수, P27 환상관 내화물
- 문서번호 SOP-02 · 개정 1 · 제정(가정) 2026-11-09 · 관리 부서: 원청 안전환경팀(가상) · 적용 현장: 광양 2고로 2차 개수(합성)

## 1. 목적과 적용 범위

- 목적: 노 내부(노정~노저 하나의 수직 공동), 열풍로·제진기·배관 내부처럼 환기가 안 되고 출입구가 좁은 곳에서 산소 결핍·CO 중독·불활성가스 유입으로 쓰러지는 사고를 막고, 안에 사람이 남은 채 가스·질소 라인이 살아나는 일을 막는다.
- 적용 범위: 밀폐공간 진입이 필요한 모든 작업 — 살수 뒤 점검, 굴착·해체, 내화물 축조, 열풍로·환상관 내화물, 제진기 보수. 작업별 표준서(SOP-P08·P12·P13·P14·P16·P20·P21·P22·P26·P27)가 이 표준서를 공통 단계로 끌어다 쓴다.
- 적용 제외: 밀폐공간 안에서 하는 화기는 SOP-01 허가와 상호참조한다. 같은 계통 가스 라인 연결(P34·P35)은 SOP-04를 따른다.

## 2. 작업 개요 (적용 작업 유형·적용 작업 예)

- 적용 작업 유형: 밀폐공간(`confined`) — 계획서 위험 유형에 밀폐공간이 있거나 작업명에 축조·내화물·연와·캐스터블·노내·노 내부·밀폐·굴착 낱말이 있을 때
- 적용 작업 예(기준 일정): P08, P12, P13, P14, P16, P20, P21, P22, P26, P27 (P19 스테이브 설치·P25 제진기 보수·P36 코크스 충전도 밀폐공간을 포함해 이 표준서를 참조한다)
- 구역: 노 내부 STACK·BELLY_BOSH·TUYERE·HEARTH, 열풍로 STOVE, 제진기 GCP, 가스 배관 DOWNCOMER 내부
- 위험 분류 코드(시행령 제53조의2): 8호 질식·중독 (작업에 따라 4호 추락, 5호 낙하·비래, 7호 붕괴가 더해진다)
- 필요 허가: 밀폐공간
- 겹치면 안 되는 작업: 같은 계통 가스 라인 연결·밸브 조작·가스 투입(R07·R08), 같은 공간 안 화기(R05 조건부), 질소 퍼지 중 개구부 주변 작업(R09)

## 3. 위험 요인과 예상 사고

- 산소 결핍: 노 내부는 하나의 수직 공동이라 아래쪽에 무거운 가스가 고이고, 코크스 잔열·캐스터블 양생·녹슨 철피가 산소를 먹는다. O2 18% 미만이면 판단력이 떨어지고 짧은 시간에 의식을 잃는다.
- 불활성가스 유입: 노 내부로 이어지는 질소·고로가스·송풍 배관이 맹판 없이 연결돼 있으면 밸브 하나로 질소가 들어와 전원이 쓰러진다(현대제철 2013 공개 사례).
- CO 중독: 종풍 뒤 잔류 고로가스, 코크스 잔열에서 나오는 CO. 30ppm 이상이면 장시간 작업 불가.
- 구조 중 2차 재해: 쓰러진 동료를 맨몸으로 구하러 들어간 사람이 함께 쓰러진다. 밀폐공간 사망의 상당수가 구조자다.
- 낙하물·추락: 노정 개구부에서 떨어지는 공구·자재, 좁은 출입구·사다리 승강 중 추락.

## 4. 투입 인원과 역할 (기준 최소 5명 역할, 계획서 인원과 맞춘다)

- 작업책임자 1명: 밀폐공간 작업허가서 발급, 불활성가스 유입 가능성 검토(배관 계통도 대조), 전원 퇴출 확인 서명
- 안전관리자(측정 담당) 1명: 진입 전·작업 중 산소·CO·LEL 측정과 기록, 환기팬 점검
- 감시인 1명 이상(출입구마다): 출입구 상주, 출입자 명부 기록, 내부와 연락 유지, 비상 연락. 다른 일을 겸하지 않는다
- 내부 작업자: 2명 이상 조를 이뤄 들어간다. 휴대용 산소·CO 경보기를 1명 이상 지닌다
- 구조 담당 1명(감시인 겸임 가능): 공기호흡기·삼각대 사용법 숙지, 구조 훈련 이수

## 5. 투입 장비·자재·보호구

- 장비: 산소·유해가스 복합측정기(O2·CO·LEL) 2대 이상(연속 측정용 1대 고정), 환기팬·송기 덕트(작업 높이까지), 작업등·조명탑, 무전기
- 구조장비: 공기호흡기 2조 이상, 삼각대·구조용 윈치, 구조용 로프·안전벨트, 들것
- 자재: 맹판(블라인드 플랜지)·꼬리표, LOTO 잠금장치, 출입 통제 안전띠·표지, 출입자 명부
- 보호구: 안전모·안전화·보안경, 안전대(개구부·사다리 승강), 방진마스크, 휴대용 산소·CO 경보기

## 6. 작업 순서 (상세)

1. 밀폐공간 작업허가서 발급 — 작업책임자가 원청 안전환경팀에서 밀폐공간 허가를 받는다. 허가서에 출입 인원·시간, 감시인 이름, 측정 계획, 연결된 배관 계통과 맹판 위치를 적고 출입구에 게시한다. 화기가 함께 있으면 화기 허가 번호를 적는다(R05·R29). 확인: 허가서 번호 기록.
2. 작업 전 산소·유해가스 측정(O2 18~23.5%·CO 30ppm 미만·LEL 10% 미만) — 진입 전 출입구·중간·바닥 3곳 이상에서 잰다. 하나라도 범위를 벗어나면 들어가지 않고 환기 뒤 다시 잰다. 확인: 측정값·시각·측정자를 허가서에 기록.
3. 불활성가스(질소) 유입 가능 배관 맹판·차단 확인 — 공간 안으로 이어지는 질소·고로가스·송풍·냉각수 배관을 계통도로 찾아 맹판 또는 이중 차단·LOTO가 되어 있는지 눈으로 확인하고 꼬리표를 건다. 같은 계통에 라인 연결 작업(P34·P35)이 겹쳐 있지 않은지 일정표를 대조한다(R07·R08). 확인: 맹판 위치·수량 점검표.
4. 환기 실시·연속 측정 — 환기팬을 진입 전부터 돌리고 작업 내내 끄지 않는다. 송기 덕트를 작업 높이까지 내린다. 고정 측정기로 연속 측정하고 1일 2회 이상 기록한다. 산소로 환기하지 않는다(규칙 제241조). 확인: 가동 시각·측정 기록.
5. 감시인 배치 — 출입구마다 감시인을 두고 이름을 허가서에 적는다. 감시인은 내부 작업자와 무전·육성으로 연락을 유지하고 이상 시 즉시 퇴출을 지시한다. 확인: 감시인 서명.
6. 구조장비(공기호흡기·삼각대) 비치 — 공기호흡기·삼각대·구조용 로프·들것을 출입구 옆에 두고 작업 전 점검한다. 구조자는 공기호흡기 없이 들어가지 않는다. 확인: 장비 점검표.
7. 출입자 명부 기록 — 들어가는 사람·나오는 사람의 이름과 시각을 감시인이 적는다. 교대 때 명부 인원과 실제 인원을 맞춘다. 확인: 명부.
8. 작업 종료 후 전원 퇴출 확인 — 마지막 작업자가 나온 뒤 명부를 0명으로 맞추고 작업책임자가 서명한다. 이 서명이 같은 계통 라인 연결(SOP-04 5단계)의 착수 조건이 된다. 확인: 퇴출 확인 서명지, 허가서 반납.

## 필수 단계

1. 밀폐공간 작업허가서 발급
2. 작업 전 산소·유해가스 측정(O2 18~23.5%·CO 30ppm 미만·LEL 10% 미만)
3. 불활성가스(질소) 유입 가능 배관 맹판·차단 확인
4. 환기 실시·연속 측정
5. 감시인 배치
6. 구조장비(공기호흡기·삼각대) 비치
7. 출입자 명부 기록
8. 작업 종료 후 전원 퇴출 확인

## 판정에 쓰는 기준

- 계획서 절차에 2·3·5 단계가 없으면 F8 "필수 단계 누락" → F2 결함(R27)
- 핵심 단계를 2·3·5로 고른 이유: 밀폐공간 사망의 세 경로를 하나씩 막는다. 2(산소·가스 측정)는 들어가기 전 공기가 안전한지 아는 유일한 방법이고, 3(맹판·차단 확인)은 작업 중 질소·가스가 밀려드는 것을 막으며(현대제철 2013), 5(감시인)는 쓰러진 사람을 밖에서 알아채고 구조를 부르는 사람이다. 규칙 제619조②3·4호·제623조가 셋을 직접 요구한다. 1·4·6·7·8은 빠져도 허가 절차나 감시인이 다시 챙긴다.
- 밀폐공간 작업이 끝나기 전 같은 계통에 가스 라인 연결·투입이 시작되면 R07·R08(금지)

## 작업 금지·출입 제한

- 작업 중 그 공간과 같은 계통(노체 N2·BFG·송풍, 열풍로 가스, 제진기 가스)의 라인 연결·밸브 조작·가스 투입 금지(R07) — 전원 퇴출 확인 서명 전까지(R08)
- 작업 중 출입구는 명부에 적힌 사람만 통과 — 타 업체 진입 금지
- 같은 공간 안 화기는 밀폐 허가에 화기 허가 번호가 상호참조되고 연속 가스 측정이 있을 때만(R05)
- 질소 퍼지 중인 개구부·맨홀 반경 [팀 설정값 5m] 안 작업 금지(R09)

## 3D 연결 (출입 제한 데이터)

- 구역: 적용 작업의 구역ID를 따른다 (노 내부 작업이면 STACK·BELLY_BOSH·TUYERE·HEARTH 중 계획서 구역, 열풍로면 STOVE, 제진기면 GCP). 노 내부는 하나의 공동이라 계통 제한은 노 내부 전체에 건다
- 제한 1: 구역 = 작업 구역, 방위 ALL, 종류 ENTRY_BAN, 대상 OTHERS(명부에 없는 인원), 적용 시점 DURING, 범위 구역 전체, 규칙 R27(단일 결함 근거)·R30(혼재), 3D 표시 TAPE + SIGN「밀폐공간 작업 중 · 허가 인원 외 출입 금지」
- 제한 2: 구역 = 같은 계통 전체(노 내부면 HEARTH·TUYERE·BELLY_BOSH·STACK, 열풍로면 STOVE, 제진기면 GCP·DOWNCOMER), 방위 ALL, 종류 GAS_IN_BAN, 대상 가스 라인 연결·투입 작업(P34·P35·P36·P37), 적용 시점 UNTIL_HANDOVER(8단계 퇴출 확인 서명 전까지), 범위 계통 전체, 규칙 R07·R08, 3D 표시 BAR_RED(해당 연결 작업 막대 금지색) + BANNER「내부 작업 중 · 가스 투입 금지」
- 제한 3: 구역 = 작업 구역, 방위 SAME, 종류 HOT_WORK_BAN(상호참조·연속 측정 없을 때), 대상 OTHERS, 적용 시점 DURING, 범위 같은 공간, 규칙 R05, 3D 표시 SIGN「밀폐공간 내 화기 · 허가 상호참조 필요」

## 비상 조치

- 산소·가스 경보: 전원 즉시 퇴출, 감시인이 명부로 인원을 확인하고 원청 상황실에 보고, 원인 제거·재측정 정상 뒤 재진입
- 내부 인원 쓰러짐: 감시인은 들어가지 않고 구조 요청. 구조자는 공기호흡기 착용·삼각대 사용, 맨몸 진입 금지. 119·원청 구급 연락
- 배관에서 가스 유입 의심(쉿 소리·경보 급상승): 전원 퇴출 뒤 상류 밸브 잠금 확인, 그 계통의 연결 작업(P34·P35)을 즉시 중지시킨다

## 기록·보관

- 허가서, 산소·가스 측정 기록, 맹판·차단 점검표, 출입자 명부, 전원 퇴출 확인 서명지를 원청 안전환경팀이 공사 종료 후 3년 보관(가정)
- 전원 퇴출 확인 서명지는 같은 계통 라인 연결 작업의 착수 조건 근거로 F5 이력에 남긴다

## 근거 조문

- OSHA 1910.146(d)(11), (f)(15) (참고)
