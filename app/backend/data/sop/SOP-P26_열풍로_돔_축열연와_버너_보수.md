# SOP-P26 열풍로 돔·축열 연와·버너 보수 작업표준 — 합성

- 출처: KOSHA GUIDE·산업안전보건기준에 관한 규칙을 바탕으로 해커톤 시연용으로 합성한 문서. 실제 사업장 표준서가 아니며 협력사명은 가상이다.
- 적용 작업: P26 열풍로 돔·축열 연와·버너 보수 (기준 일정 작업 하나에만 적용하는 작업별 표준서)
- 문서번호 SOP-P26 · 개정 1 · 제정(가정) 2026-11-09 · 관리 부서: 원청 안전환경팀(가상) · 적용 현장: 광양 2고로 2차 개수(합성)

## 1. 목적과 적용 범위

- 목적: 열풍로 안에서 돔·축열 연와를 보수하고 버너를 교체하는 밀폐공간·고소·화기 작업에서, 잔류 가스(BFG·COG) 중독·폭발, 돔 달비계 추락, 연와 반입 중 낙하를 막고, 내부 보수가 끝나기 전에 승온·가스 투입(P35)이 시작되는 일을 막는다(시연 S6).
- 적용 범위: 열풍로 가스 차단·맹판 확인, 내부 진입 연와 해체·축조, 돔 내부 달비계 운용, 버너 절단·용접·교체, 연와 반입 호이스트 운용, 완료·퇴출 확인 서명까지.
- 적용 제외: 열풍 본관·환상관 내화물(P27, SOP-P27), 승온·기밀시험·퍼지(P35, SOP-P35), 비계 설치·해체(P30, SOP-P30).

## 2. 작업 개요

- 작업ID: P26
- 협력사(가상): 가상-축로L · 공종: 축로+기계
- 구역: STOVE 열풍로 — 노체 옆 별도 구조물, 내부(연소실·축열실·돔)와 외부(버너 플랫폼)
- 기준 일정(가정값): 2026-11-17 ~ 2027-02-25 (D5~D105)
- 위험 작업 유형: 화기, 밀폐공간, 고소
- 위험 분류 코드(시행령 제53조의2): 4호 추락, 8호 질식·중독
- 필요 허가: 화기,밀폐공간,고소
- 선행 작업: P06 (에너지 격리 LOTO)

## 3. 위험 요인과 예상 사고

- 질식·중독: 열풍로 내부는 높이 수십 m의 밀폐공간이다. BFG·COG 잔류 CO, 연와 분진, 질소 퍼지 가스가 남아 있다. 맹판 없이 밸브만 닫혀 있으면 가스가 샌다. 보수가 남았는데 승온·가스 투입(P35)이 시작되면 안에 있는 전원이 쓰러진다(시연 S6).
- 추락: 돔 내부 달비계(수십 m 높이)에서 안전대 미체결, 축열실 격자 연와 위 보행.
- 낙하·비래: 돔 해체 연와 조각, 반입 호이스트 연와 팔레트가 아래 작업자에게 떨어진다.
- 화재·폭발: 버너 용접 불티가 잔류 가스·보온재에 닿는다.

## 4. 투입 인원과 역할 (기준 16명, 계획서 인원과 맞춘다)

- 작업책임자 1명: 허가서 3종, 가스 차단·맹판 확인, P35와 허가 상호참조, 완료·퇴출 확인 서명(8단계)
- 안전관리자 1명: 산소·CO 측정·연속 측정, 환기팬·구조장비 점검
- 감시인 2명: 열풍로 맨홀 상주, 출입자 명부, 비상 연락
- 화재감시자 1명: 버너 용접 중 상주, 종료 후 30분 감시
- 축로공 7명: 돔·축열 연와 해체·축조, 줄눈
- 기계공 2명: 버너 탈거·교체, 볼트 체결
- 용접사 1명: 버너 연결부 용접(자격 보유)
- 신호수·인양 1명: 연와 반입 호이스트 신호, 하부 출입 통제

## 5. 투입 장비·자재·보호구

- 장비: 산소·유해가스 복합측정기 3대(내부 연속 1대 고정), 환기팬 2대(송기 덕트), 달비계(서스펜디드 플랫폼) 1조, 호이스트(연와 반입), 체인블록 3t 2대, 용접기 1대, 가스 용기 랙(산소절단기), 작업등
- 구조장비: 공기호흡기 2조, 삼각대·구조용 윈치 1조, 들것
- 자재: 축열 연와·돔 연와(내화벽돌 팔레트), 모르타르, 버너 부품·가스켓, 맹판(블라인드 플랜지), LOTO 잠금장치·꼬리표, 불티비산방지포, 소화기 2대
- 보호구: 안전모·안전화·보안경, 안전대(2중 걸이), 방진마스크, 용접 보안면·방열 장갑, 휴대용 CO·산소 경보기(작업반장), 송기마스크(비상)

## 6. 작업 순서 (상세)

1. 작업허가서(화기·밀폐·고소) 발급 — 작업책임자가 세 허가를 한 번에 받고 번호를 서로 적는다(R29). 허가서에 열풍로 번호, 내부 작업 범위(돔·축열실), 용접 위치, 인원, 감시인을 적고 맨홀 옆에 게시한다. 확인: 허가서 번호 3개 기록.
2. 열풍로 가스(BFG·COG) 차단·맹판 확인 (승온 P35와 허가 상호 참조) — P06 격리 목록과 LOTO 번호를 대조하고 BFG·COG·열풍 밸브 뒤 플랜지에 맹판이 있는지 눈으로 확인한 뒤 꼬리표를 건다. 승온·기밀시험(P35) 절차서에 이 허가 번호가 적혀 있는지 원청 조업과 확인한다. 확인: 맹판 위치·수량·LOTO 번호 기록.
3. 작업 전 산소·CO 측정 후 진입·연속 측정 — 진입 전 연소실 바닥·축열실 중단·돔 상부 3곳에서 O2 18~23.5%, CO 30ppm 미만, LEL 10% 미만을 확인한다. 작업 중 고정 측정기로 연속 측정하고 1일 2회 이상 기록한다. 범위를 벗어나면 전원 퇴출. 확인: 측정값·시각·측정자 기록.
4. 감시인 배치·출입자 명부 기록 — 감시인 2명이 맨홀을 지키며 명부를 쓴다. 공기호흡기·삼각대를 맨홀 옆에 둔다. 감시인은 다른 일을 겸하지 않는다. 확인: 명부·장비 점검표.
5. 돔 내부 달비계·안전대 체결 확인 — 달비계 승강 전 와이어·훅·과부하 방지장치를 점검하고 작업자는 안전대를 독립 구명줄에 건다. 축열실 격자 연와 위에는 발판을 깔고 이동한다. 확인: 체결 상태를 작업반장이 눈으로 확인 뒤 개시.
6. 버너 용접 화재감시자 배치 — 용접 전 반경 11m 안 보온재·가연물을 치우거나 방화포로 덮고, 열린 맨홀·버너 구멍을 방화포로 막아 불티가 내부로 들어가지 않게 한다. 내부 인원이 있는 동안 내부 쪽 용접은 하지 않는다(R05). 확인: 감시자 이름을 허가서에 기재.
7. 연와 반입 호이스트 하부 출입 통제 — 연와 팔레트를 올릴 때 승강 경로 아래에 사람이 없게 신호수가 막는다. 반입 중 아래층 작업은 멈춘다. 확인: 반입 시간대를 작업일지에 기록.
8. 보수 완료·전원 퇴출 확인 서명 후 승온(P35) 허용 — 마지막 작업자가 나온 뒤 명부를 0명으로 맞추고 내부 자재·공구를 회수했는지 확인한다. 작업책임자가 "열풍로 내부 보수 완료·인원 철수" 서명을 원청 조업(P35 담당)과 원청 안전환경팀에 전달한다. 이 서명이 있어야 P35가 시작된다.

## 적용하는 공통 표준서

- SOP-01 화기작업
- SOP-02 밀폐공간 출입작업
- 고소 작업은 공통 표준서 없음 — 규칙 제42조~제45조(추락 방지) 적용

## 필수 단계

1. 작업허가서(화기·밀폐·고소) 발급
2. 열풍로 가스(BFG·COG) 차단·맹판 확인 (승온 P35와 허가 상호 참조)
3. 작업 전 산소·CO 측정 후 진입·연속 측정
4. 감시인 배치·출입자 명부 기록
5. 돔 내부 달비계·안전대 체결 확인
6. 버너 용접 화재감시자 배치
7. 연와 반입 호이스트 하부 출입 통제
8. 보수 완료·전원 퇴출 확인 서명 후 승온(P35) 허용

## 판정에 쓰는 기준

- 계획서 절차에 2·3·8 단계가 없으면 F8 "필수 단계 누락" → F2 결함.
- 핵심 단계를 2·3·8로 고른 이유: 열풍로 안 사람을 가스로부터 지키는 세 겹이다. 2(맹판·허가 상호참조)는 가스가 들어올 길을 막고, 3(산소·CO 측정)은 남은 가스를 잡아내며, 8(완료·퇴출 서명)은 사람이 다 나온 뒤에만 승온(P35)이 시작되게 하는 유일한 장치다(시연 S6). 추락(5)은 중상 사고라 다음 순위이고, 1·4·6·7은 공통 표준서 SOP-01·02에서 다시 걸린다.
- 내부 보수가 남았는데 승온·기밀시험(P35)이 시작되면 R07·R08(금지) — 시연 S6
- 내부 용접은 R05(조건부)

## 작업 금지·출입 제한

- 열풍로 내부 작업 중 STOVE 가스 투입·승온·기밀시험(P35) 금지(R07·R08)
- 돔 고소 작업 하부 출입 통제(R16)
- 내부 인원이 있는 동안 STOVE 반경 11m 타 업체 화기 금지(R05)
- 연와 반입 시간대 호이스트 승강 경로 하부 출입 통제(R18)

## 비상 조치

- 산소·CO 경보: 전원 즉시 퇴출, 감시인이 명부로 인원 확인, 원청 상황실 보고, 맹판·LOTO 상태 재확인, 재측정 정상 뒤 재진입
- 인원 쓰러짐(질식 의심): 구조자는 공기호흡기 착용 뒤 진입, 삼각대·윈치로 인양, 맨몸 진입 금지, 119·원청 구급 연락
- 추락자 발생: 달비계 정지, 매달린 상태면 즉시 구조, 구조 요청·원청 보고
- 화재: 소화기 초기 진화, 내부 인원 퇴출, 진화 안 되면 대피·원청 소방 연락

## 기록·보관

- 허가서 3종, 맹판·LOTO 기록, 산소·CO 측정 기록, 출입자 명부, 달비계 점검표, 반입 시간대 기록, 완료·철수 서명지(8단계)를 원청 안전환경팀이 공사 종료 후 3년 보관(가정)
- 완료·철수 서명지는 P35 착수 조건의 근거 문서로 F5 이력에 남긴다
