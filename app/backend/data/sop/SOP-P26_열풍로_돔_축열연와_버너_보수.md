# SOP-P26 열풍로 돔·축열 연와·버너 보수 작업표준 — 합성

- 출처: KOSHA GUIDE·산업안전보건기준에 관한 규칙을 바탕으로 해커톤 시연용으로 합성한 문서. 실제 사업장 표준서가 아니며 협력사명은 가상이다.
- 적용 작업: P26 열풍로 돔·축열 연와·버너 보수 (기준 일정 작업 하나에만 적용하는 작업별 표준서)

## 작업 개요

- 작업ID: P26
- 협력사(가상): 가상-축로L · 공종: 축로+기계
- 구역: STOVE 열풍로
- 기준 일정(가정값): 2026-11-17 ~ 2027-02-25 (D5~D105)
- 위험 작업 유형: 화기, 밀폐공간, 고소
- 위험 분류 코드(시행령 제53조의2): 4호 추락, 8호 질식·중독
- 필요 허가: 화기,밀폐공간,고소
- 선행 작업: P06

## 적용하는 공통 표준서

- SOP-01 화기작업
- SOP-02 밀폐공간 출입작업
- 고소 작업은 공통 표준서 없음 — 규칙 제42조~제45조(추락 방지) 적용

## 필수 단계

1. 작업허가서(화기·밀폐·고소) 발급
2. 열풍로 가스(BFG·COG) 차단·맹판 확인 (승온 P35와 허가 상호 참조)
3. 작업 전 산소·CO 측정 후 진입·연속 측정
4. 감시인 배치·출입자 명부 기록
5. 돔 내부 달비계·안전대 체결 확인
6. 버너 용접 화재감시자 배치
7. 연와 반입 호이스트 하부 출입 통제
8. 보수 완료·전원 퇴출 확인 서명 후 승온(P35) 허용

## 판정에 쓰는 기준

- 계획서 절차에 2·3·8 단계가 없으면 F8 "필수 단계 누락" → F2 결함.
- 내부 보수가 남았는데 승온·기밀시험(P35)이 시작되면 R07·R08(금지) — 시연 S6
- 내부 용접은 R05(조건부)

## 작업 금지·출입 제한

- 열풍로 내부 작업 중 STOVE 가스 투입·승온·기밀시험(P35) 금지(R07·R08)
- 돔 고소 작업 하부 출입 통제

## 근거 조문

- 산업안전보건기준에 관한 규칙 제619조②4호, 제618조~제625조, 제241조, 제42조
