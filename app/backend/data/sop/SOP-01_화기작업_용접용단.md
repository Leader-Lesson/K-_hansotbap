# SOP-01 화기작업(용접·용단·절단·그라인딩) 작업표준 — 합성

- 출처: KOSHA GUIDE A-G-14-2026(화재감시자 업무 지침), 산업안전보건기준에 관한 규칙 제241조·제241조의2 를 바탕으로 해커톤 시연용으로 합성한 문서. 실제 사업장 표준서가 아니다.
- 적용 작업 유형: `hot_work`
- 적용 작업 예(기준 일정): P03 링블록 선조립 용접, P09 장입설비 해체, P10 하강관 절단·보수, P15 철피 절단, P18 철피 용접, P23 장입설비 설치, P32 스크랩 절단
- 문서번호 SOP-01 · 개정 1 · 제정(가정) 2026-11-09 · 관리 부서: 원청 안전환경팀(가상) · 적용 현장: 광양 2고로 2차 개수(합성)

## 1. 목적과 적용 범위

- 목적: 개수 공사 전 기간에 걸쳐 여러 협력사가 하는 용접·용단·가스절단·그라인딩에서 불티에 의한 화재·폭발과, 불티가 아래층 작업자에게 떨어지는 사고를 막는다.
- 적용 범위: 노체·노정·주상·가스 설비·야드 어디서든 불꽃·불티·고열이 생기는 작업 전부. 작업별 표준서(SOP-P03·P09·P10·P15·P18·P23·P32 등)가 이 표준서를 공통 단계로 끌어다 쓴다.
- 적용 제외: 가스 계통 안에서 하는 용접·연결은 SOP-04(가스 배관 연결·기밀시험)를 함께 따른다. 밀폐공간 안의 화기는 SOP-02 허가와 상호참조한다.

## 2. 작업 개요 (적용 작업 유형·적용 작업 예)

- 적용 작업 유형: 화기(`hot_work`) — 계획서 위험 유형에 화기가 있거나 작업명에 용접·용단·절단·그라인딩·화기 낱말이 있을 때
- 적용 작업 예(기준 일정): P03, P09, P10, P15, P18, P23, P32 (작업별 표준서가 화기를 포함하는 P07·P11·P13·P19·P24·P25·P26·P28·P34 도 이 표준서를 참조한다)
- 구역: 작업마다 다르다 — 계획서의 구역 낱말을 따른다 (YARD·TOP·DOWNCOMER·SHELL·TUYERE·CASTHOUSE·GCP·STOVE·SLAG)
- 위험 분류 코드(시행령 제53조의2): 1호 화재·폭발, 5호 낙하·비래(불티·용융 금속 낙하)
- 필요 허가: 화기
- 겹치면 안 되는 작업: 11m 안 인화성 물질 사용(R01), 같은 계통 가스 배관 개방·퍼지(R04), 아래층 작업(R03)

## 3. 위험 요인과 예상 사고

- 화재: 불티가 11m 안 보온재·목재 발판·방수포·폐기물에 닿아 발화한다. 작업 종료 직후 감시 없이 자리를 비운 사이 잔불이 번진다.
- 폭발: 종풍 뒤 잔류 고로가스(BFG, CO 포함)나 11m 안 도장·세정 용제 증기에 불티가 닿는다.
- 낙하·비래: 노정·철피 외부 같은 높은 곳의 불티·용융 금속이 그레이팅·개구부 아래 주상·노 내부 작업자에게 떨어진다. KOSHA 불티비산표 기준 높이 20m·풍속 4~5m/s 에서 풍하 8m 까지 날린다.
- 중독: 아연 도금재·도장면 용접 흄, 환기 안 되는 곳의 CO.

## 4. 투입 인원과 역할 (기준 최소 4명 역할, 계획서 인원과 맞춘다)

- 작업책임자 1명: 화기작업허가서 발급·게시, 가스 측정 결과 확인, 단계별 확인 서명
- 화재감시자 1명(작업 장소마다): 작업 중 상주, 종료 후 30분 감시, 소화기 사용 훈련 이수, 다른 일을 겸하지 않는다
- 용접·절단 작업자: 자격 보유(용접사·가스절단), 작업 전 장비 점검
- 가스측정 담당 1명(작업책임자 겸임 가능): LEL 측정·기록, 2시간마다 재측정
- 하부 통제 1명(개구부·그레이팅 아래에 다른 작업이 있을 때): 아래층 출입 통제·불티받이 확인

## 5. 투입 장비·자재·보호구

- 장비: 용접기(인버터), 가스 용기(산소·LPG 세트, 가스절단기), 그라인더, 복합 가스측정기(LEL·O2·CO), 소화기 2대 이상(작업 장소마다)
- 자재: 방화포·불연 덮개, 불티비산방지포·불티받이, 개구부 덮개, 출입 통제 안전띠·표지
- 보호구: 안전모·안전화·보안경, 용접 보안면·차광 보안경, 방열 장갑·앞치마, 방진·방독 마스크(도장면·도금재 용접), 안전대(고소)

## 6. 작업 순서 (상세)

1. 화기작업허가서 발급·게시 — 작업책임자가 원청 안전환경팀에서 화기 허가를 받는다. 허가서에 작업 장소(구역·방위·단), 시간(1일 8시간 이내, R28), 감시자 이름, 아래층 작업 유무를 적고 작업 구역 입구에 게시한다. 밀폐공간·가스 허가가 함께 있으면 허가 번호를 서로 적는다(R29). 확인: 허가서 번호를 작업일지에 기록.
2. 작업 전 가스 측정(LEL 10% 미만) — 작업 위치 호흡 높이와 배관·설비 내부에서 가연성가스 LEL을 잰다. 10% 이상이면 작업하지 않고 환기·퍼지 뒤 다시 잰다. 2시간마다, 작업 재개 때마다 다시 잰다. 확인: 측정값·시각·측정자를 허가서에 기록.
3. 반경 11m 내 가연물 제거 또는 방화포 설치 — 보온재·목재 발판·방수포·폐기물·도장 용제를 11m 밖으로 치운다. 치울 수 없는 것은 방화포·불연 덮개로 덮는다. 11m 안에 도장·세정·유류 취급 작업이 있으면 시간을 나누거나 옮긴다(R01). 확인: 제거·덮개 상태를 감시자가 눈으로 확인.
4. 화재감시자 배치 — 작업 장소마다 1명을 두고 이름을 허가서에 적는다. 감시자는 작업 중 자리를 비우지 않고 다른 일을 겸하지 않는다. 확인: 감시자 서명.
5. 소화기 비치 — 작업 장소마다 소화기 2대 이상을 손 닿는 곳에 두고 압력 게이지를 확인한다. 가연물이 많으면 소화전 호스를 편다. 확인: 소화기 위치·수량 기록.
6. 불티비산방지 조치 — 개구부·그레이팅 아래로 불티가 떨어지지 않게 불티받이·덮개를 깔고, 아래층에 작업이 있으면 출입을 막는다(R03). 바람이 강한 날은 풍하측 비산 거리(최대 8m, KOSHA 불티비산표)를 더한다. 확인: 하부 통제 담당 이름 기재.
7. 작업 종료 후 30분 화재감시 — 작업이 끝나도 감시자가 30분 동안 자리를 지키며 잔불·연기를 확인한다. 30분 안에는 가연물을 다시 들이지 않는다(R25). 확인: 감시 종료 시각 기록.
8. 허가서 반납 — 30분 감시가 끝나면 작업책임자와 감시자가 종료 확인 서명을 하고 허가서를 반납한다. 확인: 반납 시각 기록.

## 필수 단계

1. 화기작업허가서 발급·게시
2. 작업 전 가스 측정(LEL 10% 미만)
3. 반경 11m 내 가연물 제거 또는 방화포 설치
4. 화재감시자 배치
5. 소화기 비치
6. 불티비산방지 조치
7. 작업 종료 후 30분 화재감시
8. 허가서 반납

## 판정에 쓰는 기준

- 계획서 절차에 2·4·7 단계가 없으면 F8 "필수 단계 누락" → F2 결함(R26)
- 핵심 단계를 2·4·7로 고른 이유: 화기 사망사고 세 가지 경로를 하나씩 막는 단계다. 2(가스 측정)는 잔류 가스 폭발을, 4(화재감시자)는 작업 중 발화를 눈으로 잡는 유일한 수단이고, 7(30분 감시)은 작업자가 떠난 뒤 잔불이 번지는 지연 화재를 막는다. 1·3·5·6·8은 빠져도 허가 발급 과정이나 감시자가 다시 걸러 낸다.
- 같은 구역·시간에 가스 배관 개방·퍼지 작업이 있으면 R04(금지), 밀폐공간 출입이 있으면 R05(조건부)

## 작업 금지·출입 제한

- 화기 반경 11m 안 도장·세정·유류 취급 등 인화성 물질 사용 작업 금지(R01)
- 같은 계통(배관·설비) 가스 개방·퍼지가 끝나고 LEL 10% 미만이 게시되기 전 화기 금지(R04)
- 불티 낙하 범위 아래층(직하 구역) 타 업체 출입 통제 — 덮개·출입 통제 기재가 없으면 R03 금지
- 작업 종료 후 30분 동안 같은 구역에 가연물 반입·무감시 상태 금지(R25)

## 3D 연결 (출입 제한 데이터)

- 구역: 적용 작업의 구역ID를 따른다 (계획서 구역 낱말 → zones.csv, 예: P18 철피 용접이면 SHELL). 방위는 계획서 작업위치의 방위(SAME)
- 제한 1: 구역 = 작업 구역, 방위 SAME, 종류 WORK_STOP(인화성 물질 사용·가스 개방 작업 중지), 대상 OTHERS, 적용 시점 DURING, 범위 반경 11m(규칙 241조의2), 규칙 R01·R04, 3D 표시 TAPE + SIGN「화기작업 중 · 인화성 작업 금지」
- 제한 2: 구역 = 작업 구역 바로 아래 구역(수직 순서 한 단계 아래, 예: TOP 이면 STACK, SHELL 이면 CASTHOUSE), 방위 SAME, 종류 ENTRY_BAN, 대상 OTHERS, 적용 시점 DURING, 범위 직하 + 풍하 8m [KOSHA 불티비산표], 규칙 R03, 3D 표시 CONE
- 제한 3: 구역 = 작업 구역, 방위 SAME, 종류 ENTRY_BAN(가연물 반입 금지), 대상 OTHERS, 적용 시점 STEP:7(종료 후 30분), 범위 반경 11m, 규칙 R25, 3D 표시 SIGN「화재감시 중 30분」

## 비상 조치

- 발화: 감시자가 소화기로 초기 진화, 작업자는 용접기·가스 밸브를 잠근다. 1분 안에 꺼지지 않으면 전원 대피·원청 소방 연락
- 가스 경보(LEL 10% 이상): 즉시 불꽃을 끄고 점화원 제거, 풍상측으로 대피, 재측정 정상 뒤 재개
- 아래층 화상·낙하물 부상: 하부 작업 중지, 원청 구급 연락, 불티받이·덮개 보강 전 재개 금지

## 기록·보관

- 화기작업허가서, 가스 측정 기록, 감시자 서명, 30분 감시 종료 시각을 원청 안전환경팀이 공사 종료 후 3년 보관(가정)
- 이 기록이 산업안전보건법 제64조(혼재작업 조정)·규칙 제241조(화재위험작업 준수사항) 이행 기록이 된다
