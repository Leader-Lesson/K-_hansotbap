# SOP-01 화기작업(용접·용단·절단·그라인딩) 작업표준 — 합성

- 출처: KOSHA GUIDE A-G-14-2026(화재감시자 업무 지침), 산업안전보건기준에 관한 규칙 제241조·제241조의2 를 바탕으로 해커톤 시연용으로 합성한 문서. 실제 사업장 표준서가 아니다.
- 적용 작업 유형: `hot_work`
- 적용 작업 예(기준 일정): P03 링블록 선조립 용접, P09 장입설비 해체, P10 하강관 절단·보수, P15 철피 절단, P18 철피 용접, P23 장입설비 설치, P32 스크랩 절단

## 필수 단계

1. 화기작업허가서 발급·게시 (작업 장소·시간·감시자 이름 기재)
2. 작업 전 가스 측정 — 가연성가스 LEL 10% 미만 확인, 측정값 기록
3. 반경 11m 내 가연물 제거, 제거할 수 없으면 방화포·불연 덮개 설치
4. 화재감시자 배치 (작업 중 상주, 소화 훈련 이수)
5. 소화기 비치 (작업 장소마다 2대 이상)
6. 불티비산방지 조치 — 개구부·그레이팅 아래로 불티가 떨어지지 않게 덮개 설치, 하부 출입통제
7. 작업 종료 후 30분 화재감시
8. 허가서 반납 및 종료 확인 서명

## 판정에 쓰는 기준

- 계획서 절차에 2·4·7 단계가 없으면 F8 "필수 단계 누락" → F2 결함(R26)
- 같은 구역·시간에 가스 배관 개방·퍼지 작업이 있으면 R04(금지), 밀폐공간 출입이 있으면 R05(조건부)

## 근거 조문

- 산업안전보건기준에 관한 규칙 제241조(화재위험작업 시의 준수사항), 제241조의2(화재감시자)
- KOSHA GUIDE A-G-14-2026 "최소 30분간 화재 감시"
- OSHA 1910.252(a)(2)(iii)(B) (참고)
