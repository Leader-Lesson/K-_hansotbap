# SOP-P03 신 철피 링블록·스테이브 지상 선조립과 배관·전기 의장 작업표준 — 합성

- 출처: KOSHA GUIDE·산업안전보건기준에 관한 규칙을 바탕으로 해커톤 시연용으로 합성한 문서. 실제 사업장 표준서가 아니며 협력사명은 가상이다.
- 적용 작업: P03 신 철피 링블록·스테이브 지상 선조립과 배관·전기 의장 (기준 일정 작업 하나에만 적용하는 작업별 표준서)

## 작업 개요

- 작업ID: P03
- 협력사(가상): 가상-철구B · 공종: 철구·제관+용접+비파괴검사
- 구역: YARD 조립장·자재 야드
- 기준 일정(가정값): 2026-06-15 ~ 2026-12-17 (D-150~D35)
- 위험 작업 유형: 화기, 고소, 중량물
- 위험 분류 코드(시행령 제53조의2): 1호 화재·폭발, 4호 추락, 5호 낙하·비래, 기타(방사선·고온수증기·고압수)
- 필요 허가: 화기,고소,방사선
- 선행 작업: P01

## 적용하는 공통 표준서

- SOP-01 화기작업
- SOP-03 중량물 인양(크레인)
- 고소 작업은 공통 표준서 없음 — 규칙 제42조~제45조(추락 방지) 적용

## 필수 단계

1. 화기작업허가서 발급 (용접·절단 구간·시간 기재)
2. 작업 전 가스 측정 (LEL 10% 미만, 선조립장 주변 유류·도장 작업 확인)
3. 가연물 제거·방화포 설치 (반경 11m 내 도장·보온재)
4. 화재감시자 배치 (용접 중 상주, 종료 후 30분 감시)
5. 링블록 조립 인양 신호수 지정·줄걸이 점검
6. 인양 경로 하부 출입 통제
7. 고소 용접 발판·안전대 체결 확인
8. 비파괴검사(RT) 방사선 관리구역 설정·야간 시간대 분리
9. 조립 완료 치수 검사 기록·허가서 반납

## 판정에 쓰는 기준

- 계획서 절차에 2·4·8 단계가 없으면 F8 "필수 단계 누락" → F2 결함.
- 반경 11m 안에 도장·세정(인화성) 작업이 있으면 R01(금지), 가연물이면 R02(조건부)
- RT 촬영 시간에 관리구역 안 다른 작업이 있으면 R24(금지)
- 조립 인양 경로 아래 인원은 R18(금지), 야드 혼재는 R30

## 작업 금지·출입 제한

- RT 촬영 시간 방사선 관리구역 내 전원 출입 금지(R24)
- 링블록 인양 중 블록 하부·인양 경로 출입 금지(R18)
- 용접 반경 11m 안 도장·세정·유류 취급 작업 금지(R01)
