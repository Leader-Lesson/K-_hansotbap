# SOP-P03 신 철피 링블록·스테이브 지상 선조립과 배관·전기 의장 작업표준 — 합성

- 출처: KOSHA GUIDE·산업안전보건기준에 관한 규칙을 바탕으로 해커톤 시연용으로 합성한 문서. 실제 사업장 표준서가 아니며 협력사명은 가상이다.
- 적용 작업: P03 신 철피 링블록·스테이브 지상 선조립과 배관·전기 의장 (기준 일정 작업 하나에만 적용하는 작업별 표준서)
- 문서번호 SOP-P03 · 개정 1 · 제정(가정) 2026-11-09 · 관리 부서: 원청 안전환경팀(가상) · 적용 현장: 광양 2고로 2차 개수(합성)

## 1. 목적과 적용 범위

- 목적: 노체를 세우기 전에 야드에서 철피 링블록을 용접·조립하고 스테이브·배관·전기까지 미리 붙이는 6개월짜리 작업에서, 용접 불티 화재, 블록 조립 인양 중 낙하, 고소 용접 추락, 비파괴검사(RT) 방사선 피폭을 막는다.
- 적용 범위: 철피 판 절단·용접, 링블록 조립 인양·맞춤, 스테이브 가조립, 배관·전기 의장, 치수 검사·RT 까지. 야드에서 가설(P01)·스크랩 절단(P32)과 같은 시기에 이루어진다.
- 적용 제외: 완성 링블록의 노체 반입·설치는 SOP-P17, 현장 철피 용접·RT는 SOP-P18 를 따른다.

## 2. 작업 개요

- 작업ID: P03
- 협력사(가상): 가상-철구B · 공종: 철구·제관+용접+비파괴검사
- 구역: YARD 조립장·자재 야드
- 기준 일정(가정값): 2026-06-15 ~ 2026-12-17 (D-150~D35)
- 위험 작업 유형: 화기, 고소, 중량물
- 위험 분류 코드(시행령 제53조의2): 1호 화재·폭발, 4호 추락, 5호 낙하·비래, 기타(방사선·고온수증기·고압수)
- 필요 허가: 화기,고소,방사선
- 선행 작업: P01

## 3. 위험 요인과 예상 사고

- 화재·폭발: 용접·절단 불티가 11m 안 도장 작업(용제), 보온재, 유류에 닿는다. 선조립장에서는 도장과 용접이 같은 야드에서 겹치기 쉽다(R01).
- 낙하·비래: 조립 중인 링블록 조각(수십 t)을 크레인으로 세우다 줄걸이가 풀리거나, 가용접만 된 블록이 넘어진다.
- 추락: 블록 높이(수 m)에서 발판 없이 용접하거나 안전대를 걸지 않는다. 블록 안쪽 곡면에서 미끄러진다.
- 방사선: RT 촬영 중 관리구역 안에 다른 업체 작업자가 들어온다. 야간·휴무 시간대로 분리하지 않으면 혼재 야드에서 통제가 어렵다(R24).
- 중독: 도장면·프라이머 위 용접 흄.

## 4. 투입 인원과 역할 (기준 24명, 계획서 인원과 맞춘다)

- 작업책임자 1명: 화기·고소·방사선 허가, 조립 순서·치수 관리
- 화재감시자 2명: 용접 구역마다 상주, 종료 후 30분 감시
- 용접사 10명: 철피 맞대기·필릿 용접(자격 보유)
- 제관공·취부공 5명: 절단·맞춤·가용접, 스테이브 가조립
- 크레인 운전원 1명·신호수 1명·줄걸이 2명: 블록 조립 인양
- 의장공 1명(배관·전기): 배관·케이블 트레이 부착
- 비파괴검사원 1명(RT, 자격 보유): 관리구역 설정·촬영·경보

## 5. 투입 장비·자재·보호구

- 장비: 크롤러 크레인(조립 인양), 용접기(다수), 가스 용기(산소절단기), 그라인더, 고소작업대, 비계·작업발판, 복합 가스측정기(LEL), 풍속계, RT 장비(선원·경보기·선량계 — 3D 모델 없음, 원문 이름 유지), 조명탑
- 자재: 철피 판·링블록 부재, 스테이브, 배관 자재·파이프 랙, 케이블 릴, 와이어로프·샤클, 방화포·불티비산방지포, 소화기, 방사선 관리구역 표지·로프, 조립 지그·가설 지지대
- 보호구: 안전모·안전화·보안경, 용접 보안면·방열 장갑·앞치마, 방진·방독 마스크(도장면 용접), 안전대(2중 걸이), 개인 선량계(RT 검사원)

## 6. 작업 순서 (상세)

1. 화기작업허가서 발급 (용접·절단 구간·시간 기재) — 작업책임자가 날마다 용접·절단할 블록 번호·구간·시간을 적어 화기 허가를 받고 조립장 입구에 게시한다. 같은 야드의 도장·세정 작업 일정을 허가서에 함께 적는다. 확인: 허가서 번호 기록.
2. 작업 전 가스 측정 (LEL 10% 미만, 선조립장 주변 유류·도장 작업 확인) — 용접 위치와 블록 안쪽에서 LEL을 재고, 반경 11m 안에 도장·용제·유류 취급이 있는지 눈으로 확인한다. 있으면 시간을 나누거나 11m 밖으로 옮긴 뒤 시작한다(R01). 확인: 측정값·시각·인접 작업 확인 기록.
3. 가연물 제거·방화포 설치 (반경 11m 내 도장·보온재) — 보온재·목재·방수포·용제통을 11m 밖으로 치우고, 못 치우는 것은 방화포로 덮는다. 확인: 감시자 눈 확인.
4. 화재감시자 배치 (용접 중 상주, 종료 후 30분 감시) — 용접 구역마다 감시자를 두고 소화기 2대를 손 닿는 곳에 둔다. 종료 후 30분 감시 뒤 허가서에 서명한다. 확인: 감시자 서명.
5. 링블록 조립 인양 신호수 지정·줄걸이 점검 — 블록 조각을 세우거나 맞출 때 신호수를 정하고 와이어·샤클·러그 용접부를 점검한다. 중량·무게중심을 도면으로 확인한다. 확인: 점검표·신호수 이름.
6. 인양 경로 하부 출입 통제 — 인양 중 블록 아래와 선회 반경 안에 사람이 없게 안전띠·통제원을 둔다. 가용접 상태 블록은 가설 지지대로 고정하기 전에 줄걸이를 풀지 않는다(R18). 확인: 인양 시간대 기록.
7. 고소 용접 발판·안전대 체결 확인 — 블록 위·안쪽 곡면 용접은 비계·고소작업대 위에서 하고 안전대를 건다. 발판 끝 난간·발끝막이판을 확인한다. 확인: 작업반장 눈 확인 뒤 개시.
8. 비파괴검사(RT) 방사선 관리구역 설정·야간 시간대 분리 — RT는 야간·휴무 시간대로 잡고, 관리구역 [팀 설정값] 경계에 로프·표지·경보기를 두고 전원 퇴출을 확인한 뒤 촬영한다(R24). 확인: 촬영 시간·경계 설정·퇴출 확인 기록.
9. 조립 완료 치수 검사 기록·허가서 반납 — 블록 진원도·치수·용접 검사 결과를 기록하고 반입(P17) 담당에게 넘긴다. 당일 화기 허가서를 반납한다. 확인: 검사 기록·반납 시각.

## 적용하는 공통 표준서

- SOP-01 화기작업
- SOP-03 중량물 인양(크레인)
- 고소 작업은 공통 표준서 없음 — 규칙 제42조~제45조(추락 방지) 적용

## 필수 단계

1. 화기작업허가서 발급 (용접·절단 구간·시간 기재)
2. 작업 전 가스 측정 (LEL 10% 미만, 선조립장 주변 유류·도장 작업 확인)
3. 가연물 제거·방화포 설치 (반경 11m 내 도장·보온재)
4. 화재감시자 배치 (용접 중 상주, 종료 후 30분 감시)
5. 링블록 조립 인양 신호수 지정·줄걸이 점검
6. 인양 경로 하부 출입 통제
7. 고소 용접 발판·안전대 체결 확인
8. 비파괴검사(RT) 방사선 관리구역 설정·야간 시간대 분리
9. 조립 완료 치수 검사 기록·허가서 반납

## 판정에 쓰는 기준

- 계획서 절차에 2·4·8 단계가 없으면 F8 "필수 단계 누락" → F2 결함.
- 핵심 단계를 2·4·8로 고른 이유: 야드 혼재 상황에서 다른 업체가 다치는 세 경로를 막는 단계다. 2(가스 측정·인접 도장 확인)는 용제 증기 폭발을, 4(화재감시자)는 6개월 내내 이어지는 용접의 발화를, 8(RT 관리구역·시간대 분리)은 보이지 않는 방사선 피폭을 막는다. 셋 다 당사자가 아니라 옆 업체가 피해자가 되는 사고라 원청이 계획서에서 반드시 확인한다. 5·6·7은 SOP-03·추락 규칙에서 다시 걸린다.
- 반경 11m 안에 도장·세정(인화성) 작업이 있으면 R01(금지), 가연물이면 R02(조건부)
- RT 촬영 시간에 관리구역 안 다른 작업이 있으면 R24(금지)
- 조립 인양 경로 아래 인원은 R18(금지), 야드 혼재는 R30

## 작업 금지·출입 제한

- RT 촬영 시간 방사선 관리구역 내 전원 출입 금지(R24)
- 링블록 인양 중 블록 하부·인양 경로 출입 금지(R18)
- 용접 반경 11m 안 도장·세정·유류 취급 작업 금지(R01)
- 가설 지지대 고정 전 조립 중 블록 주변 접근 금지(전도)

## 3D 연결 (출입 제한 데이터)

- 구역: YARD(조립장·자재 야드). 3D 구역 모델이 없어 목록 '지상·기타'로 표시한다. 방위는 계획서의 조립 베이·용접 구간 방위(SAME)
- 제한 1: 구역 YARD, 방위 SAME(용접 구간), 종류 WORK_STOP(인화성 물질 사용 작업 중지), 대상 OTHERS(도장·세정·유류), 적용 시점 DURING, 범위 반경 11m(규칙 241조의2), 규칙 R01, 3D 표시 TAPE + SIGN「용접 중 · 인화성 작업 금지」
- 제한 2: 구역 YARD, 방위 SAME(조립 베이), 종류 LIFT_PATH, 대상 OTHERS, 적용 시점 DURING(블록 인양 시간대), 범위 경로 직하 + 선회 반경 [팀 설정값], 규칙 R18, 3D 표시 CONE
- 제한 3: 구역 YARD, 방위 ALL, 종류 ENTRY_BAN, 대상 OTHERS(전원), 적용 시점 BAND:22:00-05:00(RT 촬영 시간대, 계획서 시간대를 따른다), 범위 방사선 관리구역 [팀 설정값], 규칙 R24, 3D 표시 TAPE + SIGN「RT 촬영 중 · 출입 금지」
- 제한 4: 구역 YARD, 방위 ALL, 종류 WORK_STOP(혼재 협의), 대상 P01·P32, 적용 시점 DURING, 범위 구역 전체, 규칙 R30, 3D 표시 BANNER「야드 혼재 3개 업체」

## 비상 조치

- 발화: 감시자 초기 진화, 용접기·가스 밸브 차단, 1분 안 진화 안 되면 대피·원청 소방 연락
- 블록 전도·낙하: 접근 금지 유지, 부상자 발생 시 원청 구급 연락, 재개 전 지지대·줄걸이 재점검
- 추락·매달림: 고소작업대로 접근 구조, 119·원청 구급 연락
- 방사선 사고(선원 미복귀·경계 침입): 검사원이 즉시 촬영 중단·선원 회수, 침입자 선량 기록, 원청 안전환경팀·방사선 안전관리자 보고

## 기록·보관

- 화기 허가서, 가스 측정 기록, 감시자 서명, 인양 점검표, RT 관리구역 설정·촬영 기록, 치수 검사 기록을 원청 안전환경팀이 공사 종료 후 3년 보관(가정)
