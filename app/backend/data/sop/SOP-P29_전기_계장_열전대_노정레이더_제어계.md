# SOP-P29 전기·계장(열전대·노정 레이더·제어계) 작업표준 — 합성

- 출처: KOSHA GUIDE·산업안전보건기준에 관한 규칙을 바탕으로 해커톤 시연용으로 합성한 문서. 실제 사업장 표준서가 아니며 협력사명은 가상이다.
- 적용 작업: P29 전기·계장(열전대·노정 레이더·제어계) (기준 일정 작업 하나에만 적용하는 작업별 표준서)
- 문서번호 SOP-P29 · 개정 1 · 제정(가정) 2026-11-09 · 관리 부서: 원청 안전환경팀(가상) · 적용 현장: 광양 2고로 2차 개수(합성)

## 1. 목적과 적용 범위

- 목적: 노체 열전대, 노정 레벨 레이더(방사선 선원 포함), 제어계 케이블·패널을 설치·교체하는 전기·계장 작업에서, 정전 미확인 감전, 통전 중 동일 회로 작업자 감전, 레이더 선원 탈거 중 방사선 피폭, 고소 케이블 포설 추락, 계장 시운전 중 설비 기동으로 인한 끼임을 막는다.
- 적용 범위: 정전 작업허가·LOTO, 노정 레이더 선원 탈거·재장착, 케이블 포설(노정~제어실), 노 내부 열전대 설치(밀폐공간 허가 상호참조), 제어계 시운전, 통전 복귀까지.
- 적용 제외: 전 구역 에너지 격리 자체(P06, SOP-P06), 장입설비 기계 설치(P23, SOP-P23), 노 내부 축조(P20·P22).

## 2. 작업 개요

- 작업ID: P29
- 협력사(가상): 가상-전기M · 공종: 전기·계장
- 구역: ALL 전 구역 — TOP 노정(레이더), SHELL·STACK(열전대), 제어실·케이블 트레이
- 기준 일정(가정값): 2027-01-11 ~ 2027-03-12 (D60~D120)
- 위험 작업 유형: 고소
- 위험 분류 코드(시행령 제53조의2): 4호 추락, 기타(방사선·고온수증기·고압수)
- 필요 허가: 정전,고소
- 선행 작업: P19 (스테이브·냉각판 설치)

## 3. 위험 요인과 예상 사고

- 감전: 정전·검전 없이 패널을 열거나, 같은 회로에서 다른 사람이 작업 중인데 허가서 반납 전 통전한다(R23).
- 방사선: 노정 레벨 레이더 선원(밀봉 선원)을 떼고 붙이는 동안 관리구역 안 인원이 피폭된다. 노정에는 장입설비 설치(P23) 인원이 상주한다.
- 추락: 노정·철피 외부 케이블 트레이 위 포설, 고소작업대 밖으로 몸을 내밀어 작업.
- 끼임: 계장 시운전 중 장입설비 구동부·컨베이어가 움직이는데 조정 인원이 설비 안에 있다(R22).
- 질식: 노 내부 열전대 설치는 밀폐공간이다. 축조 협력사 허가와 상호참조 없이 들어간다.

## 4. 투입 인원과 역할 (기준 8명, 계획서 인원과 맞춘다)

- 작업책임자(전기안전관리 담당) 1명: 정전 허가, 차단·검전·잠금, 통전 전 허가 반납 확인, 시운전 전 철수 확인
- 방사선 관리 담당 1명: 선원 탈거·재장착, 관리구역 설정·선량 기록(자격 보유)
- 전기공 3명: 패널·케이블 포설, 단자 결선
- 계장공 2명: 열전대·레이더 설치, 루프 점검, 시운전
- 신호·감시 1명: 고소 작업대 하부 통제, 관리구역 출입 통제

## 5. 투입 장비·자재·보호구

- 장비: 고소작업대 1대, 검전기·절연저항계, LOTO 잠금장치·꼬리표, 방사선 측정기(서베이미터), 케이블 릴, 체인블록 1t 1대, 작업등
- 자재: 열전대·보호관, 레벨 레이더 본체·선원 차폐 용기, 케이블·트레이, 패널, 관리구역 표지·로프
- 보호구: 안전모·안전화·보안경, 절연 장갑·절연화, 안전대(고소), 개인 선량계(선원 작업자), 무전기

## 6. 작업 순서 (상세)

1. 정전 작업허가서 발급 (회로·설비 ID 기재) — 작업책임자가 정전·고소 허가를 받고 회로 번호·설비 ID·작업 시간을 적는다. 같은 회로를 쓰는 다른 작업(P23 장입설비, P31 호이스트)의 허가 번호를 함께 적는다(R29). 확인: 허가서 번호·회로 ID 기록.
2. 차단기 개방·검전·잠금 (LOTO 번호) — 차단기를 내리고 검전기로 3상 무전압을 확인한 뒤 잠금장치·꼬리표를 건다. LOTO 번호를 허가서와 P06 격리 목록에 적는다. 확인: 검전 결과·LOTO 번호·사진 1장.
3. 노정 레이더 선원 탈거 시 방사선 관리구역 설정 — 선원 탈거·재장착 전 노정에 관리구역을 로프·표지로 정하고 안 인원을 모두 내보낸다. 작업은 야간·휴무 시간대로 잡아 장입설비 설치(P23) 인원과 겹치지 않게 한다(R24). 서베이미터로 경계 선량을 잰다. 확인: 관리구역 설정·해제 시각, 선량 기록.
4. 고소 케이블 포설 안전대 체결 확인 — 트레이 위·고소작업대 작업자는 안전대를 부착설비에 건다. 고소작업대 난간 밖으로 몸을 내밀지 않는다. 아래 통로는 막는다. 확인: 체결 상태를 작업반장이 눈으로 확인 뒤 개시.
5. 노 내부 열전대 설치 시 밀폐공간 허가 상호 참조 — 노 내부에 들어갈 때는 축조 협력사(가상-축로I)의 밀폐공간 허가 번호를 이 허가서에 적고, 그쪽 감시인 명부에 이름을 올린 뒤 들어간다. 산소 측정값을 함께 확인한다. 확인: 상호참조 번호·명부 기록.
6. 통전 전 동일 회로 작업 허가서 반납 확인 — 통전하기 전 같은 회로·설비 ID로 발급된 모든 허가서가 반납됐는지 원청 안전환경팀에서 확인한다. 하나라도 남아 있으면 통전하지 않는다(R23). 확인: 반납 확인 서명.
7. 계장 시운전 전 설비 주변 인원 철수 확인 — 장입설비·컨베이어 등 움직이는 설비의 시운전 전 설비 안·회전 반경에 사람이 없음을 확인하고 접근 금지 표지를 세운다(R22). 확인: 철수 확인 시각·사람 기록.
8. 작업 종료 기록·허가서 반납 — 루프 점검 결과·시운전 결과를 기록하고 허가서를 반납한다. 선원 재장착 완료·관리구역 해제를 원청 안전환경팀에 알린다.

## 적용하는 공통 표준서

- 고소 작업은 공통 표준서 없음 — 규칙 제42조~제45조(추락 방지) 적용

## 필수 단계

1. 정전 작업허가서 발급 (회로·설비 ID 기재)
2. 차단기 개방·검전·잠금 (LOTO 번호)
3. 노정 레이더 선원 탈거 시 방사선 관리구역 설정
4. 고소 케이블 포설 안전대 체결 확인
5. 노 내부 열전대 설치 시 밀폐공간 허가 상호 참조
6. 통전 전 동일 회로 작업 허가서 반납 확인
7. 계장 시운전 전 설비 주변 인원 철수 확인
8. 작업 종료 기록·허가서 반납

## 판정에 쓰는 기준

- 계획서 절차에 2·3·6 단계가 없으면 F8 "필수 단계 누락" → F2 결함.
- 핵심 단계를 2·3·6으로 고른 이유: 빠지면 바로 사망·중대사고로 이어지는 세 가지다. 2(차단·검전·잠금)는 작업자 본인의 감전, 6(통전 전 허가 반납 확인)은 같은 회로에 남은 다른 사람의 감전, 3(방사선 관리구역)은 노정에 상주하는 타 업체 인원의 피폭을 막는다. 4·5·7은 다른 표준서(규칙 42조, SOP-02, 상대 작업 P23)에서 다시 걸리고, 1·8은 절차 기록이다.
- 허가서 반납 전 통전은 R23(금지, 순서)
- 선원 탈거 시간 관리구역 안 작업은 R24(금지), 시운전 중 접촉은 R22, 허가 상호참조 누락은 R29(결함)

## 작업 금지·출입 제한

- 선원 탈거 시간 방사선 관리구역 내 전원 출입 금지(R24)
- 통전 예정 회로에 걸린 설비 작업 금지(R23)
- 계장 시운전 중 설비 내부·회전 반경 접근 금지(R22)
- 노 내부 열전대 설치는 축조 협력사 밀폐공간 허가와 상호참조 없이는 진입 금지(R29)

## 3D 연결 (출입 제한 데이터)

- 구역: ALL(전 구역) — 선원 작업은 TOP, 열전대는 SHELL·STACK, 케이블은 트레이 경로. 계획서의 구역·방위를 따른다
- 제한 1: 구역 TOP · 방위 ALL · 종류 ENTRY_BAN(방사선 관리구역 출입 금지) · 대상 OTHERS · 시점 STEP:3(선원 탈거·재장착 시간대, 야간·휴무) · 범위 관리구역 반경 [팀 설정값] · 규칙 R24 · 3D 표시 TAPE+SIGN:「방사선 관리구역 · 출입 금지」
- 제한 2: 구역 ALL · 방위 ALL · 종류 WORK_STOP(동일 회로 설비 작업 금지, 통전 전 허가 반납) · 대상 OTHERS(동일 설비 ID) · 시점 STEP:6(통전 시간대) · 범위 — · 규칙 R23 · 3D 표시 BAR_RED(동일 회로 작업 막대 금지색)
- 제한 3: 구역 TOP · 방위 SAME · 종류 ENTRY_BAN(시운전 중 설비 주변 접근 금지) · 대상 OTHERS · 시점 STEP:7 · 범위 회전 반경 [팀 설정값] · 규칙 R22 · 3D 표시 CONE+SIGN:「시운전 중」
- 제한 4: 구역 SHELL · 방위 SAME · 종류 ENTRY_BAN(고소 포설 직하 통로 통제) · 대상 OTHERS · 시점 STEP:4 · 범위 구역 전체 · 규칙 R16 · 3D 표시 CONE

## 비상 조치

- 감전: 전원 차단(차단기·비상정지), 절연물로 분리, 심폐소생술·AED, 119·원청 구급 연락
- 방사선 사고(선원 이탈·차폐 파손): 관리구역 확대·전원 대피, 접근 금지, 방사선 관리 담당이 원청 안전환경팀과 관계 기관에 보고
- 추락자 발생: 작업 중지, 매달린 상태면 즉시 구조, 구조 요청·원청 보고
- 시운전 중 끼임: 비상정지, 전원 차단·LOTO, 구조 뒤 119 연락

## 기록·보관

- 정전 허가서, 검전·LOTO 기록, 방사선 관리구역 설정·선량 기록, 밀폐공간 상호참조 기록, 통전 전 허가 반납 확인 서명, 시운전 철수 확인 기록을 원청 안전환경팀이 공사 종료 후 3년 보관(가정)
