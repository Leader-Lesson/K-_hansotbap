# SOP-P27 열풍 본관·환상관 내화물 작업표준 — 합성

- 출처: KOSHA GUIDE·산업안전보건기준에 관한 규칙을 바탕으로 해커톤 시연용으로 합성한 문서. 실제 사업장 표준서가 아니며 협력사명은 가상이다.
- 적용 작업: P27 열풍 본관·환상관 내화물 (기준 일정 작업 하나에만 적용하는 작업별 표준서)
- 문서번호 SOP-P27 · 개정 1 · 제정(가정) 2026-11-09 · 관리 부서: 원청 안전환경팀(가상) · 적용 현장: 광양 2고로 2차 개수(합성)

## 1. 목적과 적용 범위

- 목적: 열풍 본관과 풍구 레벨 환상관(원형 덕트) 안에서 내화물을 해체·축조하는 밀폐공간·고소 작업에서, 좁은 관 내부 질식·CO 중독, 관 내부 이동 중 추락, 반입 개구부 아래 낙하를 막고, 환상관 내부 작업이 끝나기 전에 송풍·질소 라인이 연결되는 일을 막는다.
- 적용 범위: 환상관·열풍 본관 맨홀 진입, 구 내화물 해체·반출, 신 내화물 축조·캐스터블, 내부 이동 발판 운용, 내화물 반입, 완료·퇴출 확인 서명까지.
- 적용 제외: 열풍로 내부 보수(P26, SOP-P26), 풍구·송풍지관 철거(P11, SOP-P11)와 라인 복구(P34, SOP-P34), 풍구 레벨 내화물·냉각기(P21, SOP-P21).

## 2. 작업 개요

- 작업ID: P27
- 협력사(가상): 가상-축로L · 공종: 축로
- 구역: TUYERE 풍구 레벨(풍구·환상관·송풍지관) — 노체를 두르는 환상관 내부와 열풍로에서 오는 열풍 본관 내부
- 기준 일정(가정값): 2026-12-22 ~ 2027-02-15 (D40~D95)
- 위험 작업 유형: 밀폐공간, 고소
- 위험 분류 코드(시행령 제53조의2): 4호 추락, 5호 낙하·비래
- 필요 허가: 밀폐공간,고소
- 선행 작업: P11 (풍구·냉각기·송풍지관 철거)

## 3. 위험 요인과 예상 사고

- 질식·중독: 환상관은 지름이 사람 키 남짓한 원형 관이라 공기가 잘 안 바뀐다. 내화물 해체 분진, 캐스터블 양생 수증기, 송풍 계통에 남은 질소가 고인다. 송풍·질소 라인이 연결되면 관 안 전원이 쓰러진다(현대제철 2013 공개 사례와 같은 구조).
- 추락: 환상관은 지상에서 높이 있는 관이다. 송풍지관이 빠진 구멍으로 바깥(아래 CASTHOUSE)에 떨어지거나, 관 안 이동 발판 사이로 빠진다.
- 낙하·비래: 반입 개구부로 내화물을 넣을 때 아래 HEARTH·CASTHOUSE 작업자에게 떨어진다. 해체 연와 조각 투하.
- 붕괴: 구 내화물 부분 해체 중 남은 벽체가 무너진다.

## 4. 투입 인원과 역할 (기준 12명, 계획서 인원과 맞춘다)

- 작업책임자 1명: 허가서, 송풍 계통 LOTO 확인, 완료·퇴출 확인 서명(8단계)
- 안전관리자 1명: 산소·CO 측정·연속 측정, 환기팬 점검
- 감시인 2명: 환상관 맨홀 상주(진입 맨홀마다 1명), 출입자 명부, 비상 연락
- 축로공 6명: 구 내화물 해체, 신 내화물 축조·캐스터블
- 신호수·반입 2명: 내화물 반입 개구부 신호, 하부 출입 통제, 체인블록 조작

## 5. 투입 장비·자재·보호구

- 장비: 산소·유해가스 복합측정기 2대(관 내부 연속 1대 고정), 환기팬 2대(송기 덕트를 관 안쪽 끝까지), 체인블록 1t 2대, 이동 발판(비계 발판재), 작업등
- 구조장비: 공기호흡기 2조, 삼각대·구조용 윈치 1조(맨홀 위), 들것
- 자재: 환상관 내화벽돌·캐스터블(내화벽돌 팔레트), 모르타르, 개구부 덮개·난간재, LOTO 꼬리표
- 보호구: 안전모·안전화·보안경, 안전대(관 내부 이동·개구부 주변), 방진마스크, 휴대용 산소·CO 경보기(작업반장)

## 6. 작업 순서 (상세)

1. 밀폐공간 작업허가서 발급 — 작업책임자가 밀폐공간·고소 허가를 받고 진입 맨홀 옆에 게시한다. 허가서에 작업 구간(환상관 방위·본관 구간), 인원, 감시인, 측정 계획을 적는다. 확인: 허가서 번호 기록.
2. 작업 전 산소농도·CO 측정 후 진입 — 진입 전 맨홀 입구, 관 안쪽 끝, 작업 위치 3곳에서 O2 18~23.5%, CO 30ppm 미만, LEL 10% 미만을 확인한다. 관 안쪽 끝이 가장 위험하므로 그 값을 먼저 본다. 확인: 측정값·시각·측정자 기록.
3. 환상관 내부 환기팬 가동·연속 측정 — 송기 덕트를 작업 위치 끝까지 넣고 환기팬을 작업 내내 돌린다. 고정 측정기로 연속 측정하고 1일 2회 이상 기록한다. 경보 시 전원 퇴출. 확인: 가동 시각·측정 기록.
4. 감시인 배치·출입자 명부 기록 — 사용하는 맨홀마다 감시인 1명이 상주하며 명부를 쓴다. 공기호흡기·삼각대를 맨홀 옆에 둔다. 감시인은 다른 일을 겸하지 않는다. 확인: 명부·장비 점검표.
5. 환상관 내부 이동 발판·안전대 체결 확인 — 관 바닥에 발판을 깔고 틈을 막는다. 송풍지관이 빠진 구멍은 덮개로 막고, 덮개를 떼고 작업할 때는 안전대를 건다. 확인: 발판·덮개 점검표.
6. 송풍 계통 LOTO 확인 (송풍지관 P11 철거 완료) — P06 격리 목록과 LOTO 번호를 대조하고, 송풍·질소 상류 밸브가 잠겨 있고 맹판 또는 철거된 송풍지관 자리에 덮개가 있는지 눈으로 확인한다. 라인 복구(P34)는 이 작업 완료 전 시작하지 않는다. 확인: LOTO 번호·점검표.
7. 내화물 반입 개구부 하부 출입 통제 — 내화물을 개구부로 넣을 때 아래(HEARTH·CASTHOUSE)에 사람이 없게 신호수가 막는다. 반입 시간대를 아래층 협력사와 전날 맞춘다. 확인: 반입 시간대를 작업일지에 기록.
8. 작업 종료 퇴출 확인 서명 (송풍 라인 복구 P34 인계) — 마지막 작업자가 나온 뒤 명부를 0명으로 맞추고 관 안 공구·자재를 회수했는지 확인한다. 작업책임자가 "환상관 내부 작업 완료·인원 철수" 서명을 배관 협력사(가상-배관O)와 원청 안전환경팀에 전달한다. 이 서명이 P34 착수 조건의 하나다.

## 적용하는 공통 표준서

- SOP-02 밀폐공간 출입작업
- 고소 작업은 공통 표준서 없음 — 규칙 제42조~제45조(추락 방지) 적용

## 필수 단계

1. 밀폐공간 작업허가서 발급
2. 작업 전 산소농도·CO 측정 후 진입
3. 환상관 내부 환기팬 가동·연속 측정
4. 감시인 배치·출입자 명부 기록
5. 환상관 내부 이동 발판·안전대 체결 확인
6. 송풍 계통 LOTO 확인 (송풍지관 P11 철거 완료)
7. 내화물 반입 개구부 하부 출입 통제
8. 작업 종료 퇴출 확인 서명 (송풍 라인 복구 P34 인계)

## 판정에 쓰는 기준

- 계획서 절차에 2·4·6 단계가 없으면 F8 "필수 단계 누락" → F2 결함.
- 핵심 단계를 2·4·6으로 고른 이유: 좁은 관 안에서 사람이 쓰러지는 사고의 세 고리를 끊는다. 2(산소·CO 측정)는 관 안쪽 끝에 고인 가스를, 4(감시인·명부)는 누가 안에 있는지와 꺼낼 수단을, 6(송풍 계통 LOTO 확인)은 작업 중 송풍·질소가 관 안으로 들어오는 길을 막는다. 1·3·5·7·8은 공통 표준서 SOP-02나 상대 작업(P34 연결) 표준서에서 다시 걸린다.
- 환상관 내부 작업 완료 전 송풍·질소 라인 연결(P34)은 R07·R08(금지)
- 반입 개구부 아래 노저 작업은 R16

## 작업 금지·출입 제한

- 환상관 내부 작업 중 송풍·질소 라인 연결(P34) 금지(R08)
- TUYERE 아래 HEARTH 투하 구간 출입 금지(R16)
- 관 내부 인원이 있는 동안 TUYERE 환상관 주변 타 업체 화기 금지(R05)
- 내화물 반입 시간대 개구부 아래 CASTHOUSE 출입 통제(R18)

## 비상 조치

- 산소·CO 경보: 관 내부 전원 즉시 퇴출(맨홀 쪽으로), 감시인이 명부로 인원 확인, 원청 상황실 보고, 환기 강화·재측정 정상 뒤 재진입
- 인원 쓰러짐(질식 의심): 구조자는 공기호흡기 착용 뒤 진입, 삼각대·윈치로 맨홀 위로 인양, 맨몸 진입 금지, 119·원청 구급 연락
- 추락·발판 이탈: 작업 중지, 구조 요청, 아래 구역 출입 차단
- 내화물 붕괴: 전원 퇴출, 남은 벽체 안정 확인 뒤 재개

## 기록·보관

- 허가서, 산소·CO 측정 기록, 출입자 명부, LOTO 점검표, 발판·덮개 점검표, 반입 시간대 기록, 완료·철수 서명지(8단계)를 원청 안전환경팀이 공사 종료 후 3년 보관(가정)
- 완료·철수 서명지는 P34 착수 조건의 근거 문서로 F5 이력에 남긴다
